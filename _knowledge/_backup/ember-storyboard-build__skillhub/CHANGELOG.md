# Changelog · ember-storyboard-build

本文件记录 ember-storyboard-build 的版本变更。版本号遵循 SemVer。

---

## [1.2.0] — 2026-11-21

**升级原因：融入美学理论，增强审美与创作能力。** 依据《美的历程·美学导论》《美学原理 30 讲》两份资料提炼美学理论，让 skill 生成的分镜方案更丰富、更具审美、更专业。

### 新增知识库（references/）
- `aesthetic-forms.md` — 审美形态与范畴：优美/崇高/悲剧/喜剧/荒诞/意境六大形态的分镜参数映射（运镜/构图/光影/色彩/景别/表演/蒙太奇）、情绪→形态映射表、形态→全片节奏策略。
- `aesthetic-creative.md` — 审美创作方法论：养眼→养心→养神三层递进、意境生成三法（情景交融/虚实相生/境生象外）、艺术三类型、象征隐喻四手段、审美心理设计（格式塔同构/审美距离/移情/内模仿通感）。
- `aesthetic-checklist.md` — 审美质量校验：康德四契机、美感非纯快感、反套路、意境校验、创作深度校验与交付总表。

### 工作流改造（SKILL.md）
- Step 2 增加「审美形态定位」；Step 3 增加「形态→视听同向性」映射原则。
- 新增 Step 5「审美创作深化」——核心创作能力步骤，为分镜脚本注入审美纵深。
- 原「电影感校验」与「evan-design 校验」合并顺延为 Step 6「三重校验」（电影感镜头语言 + 审美哲学质量 + 东方形式气质）。
- 描述、Overview、快速决策表、资源清单同步更新；version → 1.2.0。

### 模板更新
- `output-template.md`、`assets/storyboard-template.md` 增加「审美形态定位」「三层递进骨架」「创作手法」字段与三重校验清单。

### 校验
- 目录与打包 zip 结构校验通过（zip 根目录直接含 SKILL.md）；发布版元数据通过 dry-run 预检。
- 烟测：用示例跑通含审美形态定位与创作深化的完整流程。

## [1.1.0] — 2026-11-21

**升级原因：配色升级。** 扩充配色方案的取色来源与色名规范，提升镜头色彩在东方意境主题下的确定性与跨镜头一致性。

### 变更内容

- `references/shooting-kit.md`：第六节「色彩（含配色）」新增「传统色取色参考」小节，给出两类东方传统色查色入口、适用情绪/场景与取色约束（名实一致、60-30-10、高饱和面积 ≤10%、跨镜头色值连贯）。
- 既有情绪映射、镜头语言与工作流程不变。

### 校验

- 版本号 1.0.0 → 1.1.0；新增内容仅为取色参考入口，不改变任何既有色值。
- 目录与打包 zip 结构校验通过（zip 根目录直接含 SKILL.md）；发布版元数据通过 dry-run 预检。

## [2.0.0] — 2026-11-22

**升级原因：回融 `ember-art-solution` v1.0.0 美学总纲，统一到同一套美学语言，并支持跨场景组合交付。**

### 新增知识库 `references/art-solution/`（15 份）
- 11 份 `core-*.md`：`core-00` 美学分类组织架构总表（三大体系 15 流派、风格 vs 派别、底层逻辑对照）、`core-01` 风格/氛围/感觉路由与定位卡、`core-02` 14 类交付矩阵、`core-03` 三套传统色库、`core-04` 画面六法与留白三法、`core-05` 理论索引、`core-06` 六大审美形态、`core-07` 创作方法论、`core-08` 八意识、`core-09` 情绪全感官、`core-10` 三重质量门禁。
- 3 份 `scene-*.md`：空间 / 声景 / 平面扩展场景。
- 1 份 `bridge.md`：**本领域专属接入桥**，含体系→本领域参数传导表、总纲↔原有 reference 对照索引、冲突裁决口径。

### SKILL.md 改造
- frontmatter：`version` 1.2.0 → **2.0.0**；新增 `artSolution: "ember-art-solution@1.0.0"`、补齐 `slug` / `displayName`；description 增补美学总纲、一句话出方案、组合交付等触发词。
- 新增 **§0 美学总纲（ember-art-solution 统摄）**：明确本 skill 是总控在 视频分镜（D/E） 领域的执行端；新增前置动作「美学体系定位」（S1–S5 产出定位卡摘要，缺信息按五步缺省推断、不追问）；规定参数映射 / 创作深化 / 交付校验三处接入点；给出冲突裁决口径与组合交付路由。
- 新增「版本与归属」段。

### 领域增强
新增「体系 → 视听参数」传导表（东方散点长镜与意象光 / 西方焦点透视与明暗交界 / 伊斯兰循环无限节奏）；E 类 30 秒规格落入总纲：6–10 镜、单镜 2–5 s、意境型 MUST 留 0.5–1.5 s 时间气口、声音不铺满。

### 未改动
原有领域主干、全部工作流步骤、既有 references、模板、色值与数值规范、图标均保持不变；总纲只补「体系归属与立意」层。

### 校验
- 目录与打包 zip 结构校验通过（zip 根目录含同名文件夹，文件夹内直接含 `SKILL.md`）。
- 版本号一致：SKILL.md / `_meta.json` / `_skillhub_meta.json` 均为 2.0.0。
