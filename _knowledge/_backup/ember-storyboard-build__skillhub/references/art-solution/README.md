## 路径约定

- `core-XX` 之间的互引按**本目录内同名文件**解析。
- `domain/*` 的领域库只在总控包 `ember-art-solution` 内完整提供；本 skill 只保留自身领域库（位于上级 `references/`）。
- 本 skill 的原有 references、模板、Token 与数值规范**一律不变**；总纲只补「体系归属与立意」层。
- 冲突裁决以 `bridge.md` 与本 skill `SKILL.md` §0 为准。
