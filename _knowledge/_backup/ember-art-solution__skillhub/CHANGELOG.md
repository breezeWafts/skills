## [1.0.0] — 2026-11-22

**初版。美学主导的全场景内容生成方案总控 skill（`/ember-art-solution`）。**

### 立项目标

用户只需说一句「给我一份【风格 / 氛围 / 感觉】的【产品】方案」，即可交付富含高级审美、且经得起推敲的成品方案；信息不足时自行推断补全，不打断追问。

### 主架构

以工作区《美学分类组织架构总表.xlsx》为最高决策依据，完整转写为 `references/core-00-architecture.md`：
- 第一部分：东方 / 西方 / 阿拉伯-伊斯兰三大体系，二级时代思潮，三级 15 个具体流派；每流派含哲学背景、显著特征、风格与派别区分、构图方式、色调搭配、色表 HEX。
- 第二部分：风格（Style）与派别（Movement / School）辨析。
- 第三部分：三大体系底层逻辑对照（色彩观念 / 光影处理 / 空间构图 / 审美终极目标 / 哲学驱动力）。
