# ember-art-solution · 美学主导的全场景方案总控

## 〇、一句话定位

**把「一句感觉」变成「一份可直接执行、且经得起审美推敲的交付方案」。**

```
/ember-art-solution 给我一份【*风格 / *氛围 / *感觉】的【*产品】方案，（内容/用途/约束…）
```

用户不必懂美学，不必指定体系，甚至可以说「风格根据作品内容制定」。本 skill 负责把模糊的感觉**归一化 → 定位 → 落参数 → 出成品**，全程不打断追问。

**示例**
- `给我生成一份 30 秒的视频分镜脚本，故事内容为 XXX，需要东方美学意境`
- `给我生成一套摄影作品展示的网站，风格根据作品内容制定`
- `要一张有「雨后空山」感觉的专辑封面方案`
- `做一个侘寂氛围的茶室室内方案，35㎡ 朝北`
- `写一篇让人看完能静下来的散文，宋式极简`

## 一、Overview

### 1.1 主架构

本 skill 以工作区《美学分类组织架构总表.xlsx》为**最高决策依据**（完整转写见 `references/core-00-architecture.md`）：

```
一级 地域文化圈（东方 / 西方 / 阿拉伯-伊斯兰）
  └ 二级 时代·核心思潮
       └ 三级 具体风格·流派（15 个）
            └ 每条含：哲学背景 / 显著特征 / 风格与派别辨析 / 构图 / 色调搭配 / 色表 HEX
+ 风格 vs 派别辨析
+ 三大体系底层逻辑对照（色彩观念 / 光影处理 / 空间构图 / 终极目标 / 哲学驱动力）
```

**底层逻辑永远优先于表面符号**。东方＝观念色·消解光影·散点游动·意境；西方＝科学光学色·塑造体积·焦点透视·再现与形式；伊斯兰＝神学编码色·光的形而上学·无限延伸填满·秩序与永恒。贴青花、贴枯山水、贴月亮门却仍用焦点透视＋满构图＋高饱和，是「有形无意」，判不合格。

**输入**（任一非空即可）：美学意图 / 产品类型 / 内容素材。可选：时长、字数、尺寸、平台、人群、预算、空间条件、品牌约束。

## 三、执行工作流（P1–P8，按顺序，不可跳步）

### P1 · 解析需求（不追问）

读 `core-01` §1，拆出四个槽位：
- **美学意图**：风格词 / 氛围词 / 感觉词 / 或「根据内容制定」
- **产品类型**：映射到 `core-02` 的 A–N 共 14 类（可组合，如 H＋J）
- **内容素材**：故事梗概、作品集、品牌信息、空间条件、主题
- **硬约束**：时长、字数、尺寸、画幅、平台、人群、场地、预算

**信息缺失一律推断补全并标注〔推断〕，禁止连问三四个问题**。用户只给一句话也直接开工。

### P2 · 美学定位（核心，不得跳过）

按 `core-01` S1–S5 执行：
1. 判断走「主动感觉意境」哪条路径（情绪/性格/氛围/意愿主导），或启用被动路径（人体工程学/色彩心理学/美学心理学）。
2. 查 `core-01` §3 词库定**主体系**，下沉到**三级流派**；词库未收录按语义与文化语境推断。
3. **必查 `core-00` 第三部分**，锁定色彩观念 / 光影处理 / 空间构图 / 终极目标四条底层逻辑。
4. 定**主情绪 + 强度 + 审美形态**（`core-06`、`core-09`）、**色板**（`core-03`）、**形式手法**（`core-04`）。
5. 产出**美学定位卡**（标准格式见 `core-01` §6），写入交付物头部。

> 用户说「风格根据作品内容制定」时，执行 `core-01` §5 五步缺省推断；展示型产品执行**中性容器原则**。

### P3 · 选交付规格

查 `core-02` 对应 ID 的规格段，确定字段清单、输出结构、执行子流程与验收标准。组合交付写清各子件共享同一张定位卡。

### P4 · 领域执行（逐项填参数）

按 ID 路由，**只读需要的库，不要一次全读**：

| ID | 必读 |
|---|---|
| A/B/C | `domain/writing/`：writing-map / genre-playbook / inspiration-guide（低输入）/ aesthetics-rhetoric / revision-checklist / aesthetics-checklist / output-templates |
| D/E | `domain/video/`：emotion-map / aesthetic-forms / shooting-kit / cinematic-language / performance / aesthetic-creative / aesthetic-checklist / output-template |
| F/G | `domain/photo/`：emotion-map / aesthetic-forms / pose-library / expression-guide / composition-guide / lighting-guide / scene-styling / aesthetic-creative / aesthetic-checklist / output-template |
| H/I | `core-02` §4 ＋ `scene-13-graphic.md` ＋ `core-03` ＋ `core-04` |
| J | `domain/ui/`：design-system / eight-aesthetics / aesthetic-creation / examples ＋ `assets/tokens.css` |
| K/L/M | `scene-11-space.md` ＋ `core-04` |
| N | `scene-12-audio.md` ＋ `core-09` §4 |

**每一项参数都要有出处或〔补全〕标注**；情绪、形态、体系三者必须同向，冲突按 `core-09` §5 裁决并写明刻意反向的目的。

### P5 · 创作深化

按 `core-07` 六步法：定境界 → 选 2–3 个美感机制 → 择象布虚（立意/择象/布虚/留余）→ 设象征（≤3 个、有回环）→ 配格式塔同构 → 按「层级定位 + 具体手法 + 理论依据 + 预期观者反应」写 ≥3 条创作手法。
**最低深度**：养眼＋养心；意境/禅意/东方主题 MUST 达养神。术语只写进创作说明，不进正文。

### P6 · 形式与色彩落地

- `core-04` 六法命中 ≥3 并写明落在哪个元素；视线引导有唯一主焦点。
- 留白体系用三法 ≥2；非留白体系说明替代组织原则。
- `core-03` 取色：单色库主色板、60-30-10、色名＋HEX、高饱和 ≤10%、点睛 ≤1 处、对比度复核。
- `core-08` 八意识过一遍，破格 ≤1 处且目的明确。

### P7 · 质量门禁（强制）

按 `core-10` 跑**三重校验**：① 领域正确性 ② 审美哲学质量 ③ 体系一致性；再加可用性硬指标与八意识联检。
**任一 MUST 项不过 → 回 P4–P6 修正后重跑，不得带病交付**。裁决顺序：可用性 ＞ 领域正确性 ＞ 体系一致性 ＞ 审美哲学细项 ＞ 气质细项。

### P8 · 输出交付

1. 按 `core-02` 规格与 `assets/universal-solution-template.md` 生成完整方案。
2. 保存到 `outputs/`（命名：`<主题>-<产品类型>-方案.md`；代码类按项目结构落盘）。
3. 用文件展示工具呈现给用户。
4. 文末必附：三重校验结论、〔推断〕/〔补全〕/〔通用参考〕清单、可一句话修改的提示（如「想换体系说一句『改成侘寂』即可」）。

| 用户说的话 | 处理 |

| 「给我一份 30 秒分镜，故事是…，要东方美学意境」 | P1→E 类；P2 默认东方·宋 × 意境；P4 读 `domain/video/`；结尾留 0.5–1.5 s 气口 |

## 五、不可违反的六条硬约束

1. **不追问**：缺信息按 `core-01` §5 推断，标注〔推断〕。
2. **体系必下沉**：定位必须到三级流派或明确「取体系共性＋理由」，不许停在「东方美学」四字。
3. **底层逻辑优先**：色彩观念 / 光影 / 空间 / 终极目标四条必须与 `core-00` 第三部分一致。
4. **色值可溯源**：每个 HEX 有传统色色名或流派色表出处，不写「差不多的蓝」。
5. **一种形态为主**：审美形态不混着上；跨体系混搭必须写主次比、接缝与理由。
6. **美学不压可用性**：可读性、可操作性、可拍性、可通行性永远优先。
