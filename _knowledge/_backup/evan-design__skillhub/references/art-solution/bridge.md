# 美学总纲接入桥 · evan-design（视觉与界面规范领域）

> 本文件说明 `ember-art-solution`（美学主导全场景方案总控，v1.0.0）如何注入 `evan-design` v2.0.0。
> **关系**：`ember-art-solution` 是总控，负责统一的体系定位、色板、形式语法与质量门禁；`evan-design` 是它在**互联网产品 UI 领域（交付矩阵 J）**的执行端，且仍是 WorkBuddy 视觉语言的**唯一数值权威**。
> **重要**：本 skill 的三层内核（L1 意境 / L2 比例 / L3 感知）、L0 审美立意层、八意识量化阈值、全部 Token 与对比度实测表**一律不改**。总纲提供的是「体系从哪来、如何与其他 13 类交付对齐」。

## 一、两套「层」的映射（不要混淆）

| `ember-art-solution` 总纲 | `evan-design` 本 skill | 关系 |
|---|---|---|
| `core-00` 三大体系底层逻辑 | L1 东方意境层 | 总纲说明**为什么**东方默认「月白禅」；也给出西方/伊斯兰体系的合法入口 |
| `core-01` 美学定位卡 | L0 审美立意层 | 定位卡是 L0 的**上游输入**：体系/流派/形态/色板先定，再写一句话立意 |
| `core-04` 画面审美六法与留白三法 | L2 西方比例秩序层 / 四、设计决策速查表 | 六法是形式语法层，L2 的数值是它的落地面 |
| `core-03` 三套传统色库 | L3 感知层色板 / `assets/tokens.css` | 总纲提供取色**来源**；色值与对比度仍以本 skill 的 Token 与实测表为准 |
| `core-08` 八意识跨媒介裁决 | `references/eight-aesthetics.md` 量化规范 | 本 skill 的量化版**优先**；总纲版用于非界面交付物 |

## 二、体系 → 界面内核传导表（新增能力）

原规范以东方意境为默认。总纲 `core-00` 允许在合法前提下切换到其他体系，映射如下：

| 主体系 | L0 立意 | L1 气质 | L2 秩序 | L3 色彩 | 适用界面 |
|---|---|---|---|---|---|
| **东方·宋 / 侘寂**（默认） | 意境、物我两忘 | 留白 / 侘寂 / 幽玄 / 阴翳；月白禅 | 斐波那契模数但**弱化可见网格**，分割优先于线条 | 低饱和素色、水墨黑、天青；60-30-10 | 内容型、阅读型、作品展示、文化品牌 |
| **东方·明清** | 雅俗共赏、吉祥圆满 | 饱满、装饰性、世俗化 | 对称均衡、多视角 | 朱砂/明黄/石绿/霁蓝高饱和（**需重算对比度**） | 节庆、电商大促、民俗主题 |
| **西方·古典 / 冷抽象** | 再现与形式、理性秩序 | 负空间服务焦点，不取气韵 | **黄金分割、严格网格、φ 字阶**（本 skill 原生强项） | 三原色＋无彩色 / 光谱色 | 数据仪表盘、工具型产品、SaaS |
| **伊斯兰·阿拔斯 / 摩尔** | 秩序与无限、认主独一外化 | 无限延伸密纹、无中心；格栅切光 | 中心辐射或无限网格 | 绿蓝金白神学编码；琉璃质感 | 纹样系统、装饰层、内向型信息架构 |

**硬约束**：
1. 无论哪个体系，**WCAG 2.1 AA 全部达标**（正文 ≥4.5:1、大字 ≥3:1、UI 图形 ≥3:1）；高饱和传统色作文字通常不达标，改作背景，其上文字另取深色。
2. 切换体系**不修改** `assets/tokens.css` 的既有变量名与结构；新增主题另建变量组。
3. **作品展示站执行中性容器原则**（`core-01` §5）：素底 + 极低饱和 + 大留白 + 单一强调色，UI 退到背景层，禁止强风格抢夺作品注意力。
4. 伊斯兰体系的「填满」不得牺牲可扫读性；无限纹样只用于装饰层与背景，不用于内容区。

## 三、在原有工作流中的三个接入点

| 接入点 | 动作 | 依据 |
|---|---|---|
| **2.1 执行步骤「定立意（L0）」之前** | 增加「**定体系（A0）**」：从用户给的风格/氛围/感觉按 `core-01` S1–S5 产出**美学定位卡摘要**（主体系 / 三级流派 / 底层逻辑四条 / 主形态 / 色板色名＋HEX / 目标观者反应）。用户说「根据作品内容制定」时按 `core-01` §5 五步缺省推断。未指定时默认「东方·宋 取东方共性」，即现有月白禅 | `core-00` `core-01` |
| **「定气质（L1）」与「落感知（L3）」内** | 按 §2 传导表把体系落到八意识选择与主题色；取色时按 `core-03` 从三套传统色库检索色名与 HEX，**复核对比度后**再写入 Token | `core-03` `core-00` |
| **2.3 交付前确认清单之后** | 追加 `core-10` 三重门禁中的「**体系一致性**」10 条，重点排查：东方主题出现强明暗交界/高饱和满构图、伊斯兰主题被套大留白、符号堆砌替代底层逻辑 | `core-10` |

**不改变**：设计哲学内核（第一节）、1.2 冲突裁决口径、1.3 L0 六步创作法、八意识全部量化阈值、主题速览、设计决策速查表、反模式清单、无障碍与不同人群舒适度、条目追加（第七节）。

## 五、冲突裁决口径（延续 v1.1.0 / v1.3.0）

1. **数值与合规永远优先**：具体色值、字号、间距、对比度、焦点环、触摸目标以本 skill 为准。
2. **可用性优先**：《用户体验的要素》五层模型——美学表达不得破坏战略/范围/结构/骨架层。
3. **体系逻辑由总纲裁定**：中西伊的色彩观念 / 光影 / 空间分歧，以 `core-00` 第三部分为准。
4. **L0 是立意表达层**，不改写任何既有数值；A0 定位同理，只提供输入。
5. 本文档与 `SKILL.md` / `design-system.md` 冲突时，以后两者为准。

## 六、一句话调用建议

用户若要「一套网站 + 海报 + 封面 + 品牌文案」或只给「根据作品内容制定风格」，**转由 `ember-art-solution` 总控**做组合交付（J＋H＋I＋A），共享同一张美学定位卡；本 skill 负责其中的界面子件，并继续作为数值与无障碍的唯一权威。
