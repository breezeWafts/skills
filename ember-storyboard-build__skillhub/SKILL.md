### 0.1 新增前置动作 · 美学体系定位（不得跳过）

在原有工作流最前面执行：从用户给的「风格 / 氛围 / 感觉」或内容题材，按 `references/art-solution/core-01-style-router.md` S1–S5 产出**美学定位卡摘要**——主体系（东方 / 西方 / 阿拉伯-伊斯兰）→ 三级流派（`core-00`）→ 底层逻辑四条（色彩观念 / 光影处理 / 空间构图 / 终极目标）→ 主情绪与审美形态（`core-06`）→ 色板（色名＋HEX，`core-03`）→ 目标观者反应。

### 0.2 执行时的三处接入

1. **参数映射阶段**：在既有情绪/形态同向性之外，追加「体系→视听语言 同向性」，逐项核对 `core-00` 第三部分；冲突时以体系逻辑裁决，若刻意反向须写明目的。
2. **创作深化阶段**：调用 `core-07` 三层递进、意境四步、象征回环；`core-04` 六法与留白三法；`core-08` 八意识。
3. **交付校验阶段**：在既有校验清单之外，追加 `core-10` 三重门禁中的「体系一致性」10 条，重点排查：东方主题用西方强明暗、伊斯兰主题加大留白、符号堆砌替代底层逻辑、色值不可溯源。

### 0.3 冲突裁决（重要）

### 0.4 组合交付

若用户同时要多个产品（如「30 秒片子加海报和剧照方案」），或只给「感觉」不给领域参数，**转由 `ember-art-solution` 总控**做组合交付，共享同一张美学定位卡；本 skill 只负责其中的 视频分镜（D/E） 子件。

## Overview

把「一段拍摄内容」转化为「一份可直接执行的专业分镜脚本」。核心逻辑是**情绪 × 审美形态 → 视听语言**：先锁定内容要表达的情绪并定位审美形态，再反推道具、背景、配色、运镜、构图、机位、光影、色彩、景别等全部视听参数，组装成分镜表，**以美学理论深化创作**，最后叠加**电影感镜头语言 + 东方意境美学 + 审美哲学三重校验**。

v1.2.0 起新增审美创作能力：方案不止"技术正确、看起来美"，更要有**审美纵深**——从养眼（形式）到养心（情感）到养神（意境），让每一条片子有理论依据、有情感内核、有余味。知识来源于内置拍摄知识库（源自飞书「摄影摄像」知识库汇总）、evan-design 东方美学，以及《美的历程·美学导论》《美学原理 30 讲》两套美学理论；未覆盖部分按影视专业惯例补全并标注。

**与拍照摄影 skill（ember-photography-posing）的区别**：本 skill 面向**动态影像**——核心是运镜、景别节奏、蒙太奇、时长与声画，输出是分镜脚本；不做摆姿/布光的静态精拍方案（景别/构图等静态要素仍复用）。

**输入**：拍摄内容 / 故事梗概 / 文案 / 一句话创意（可附带时长、平台、风格、规格）。
**输出**：结构化分镜脚本（Markdown 文档），含情绪分析、审美形态定位、视听方案、创作手法、逐镜表、表演指导、三重校验。

## 前置条件

**无外部依赖。** 纯知识型 skill，不调用 MCP、API、网络。所有知识内置于 references/。

## 执行工作流（按顺序，不可跳步）

### Step 1 · 解析需求与规格

从用户输入中提取：
- **内容**：拍摄内容 / 故事 / 文案原文
- **规格**：短视频（15s–5min，竖屏为主）/ 长视频（5–40min，横屏）/ 影视片段（电视剧、电影场景，横屏，按场次组织）。用户未指定时按内容体量判断：单场景+强钩子→短视频；多段落叙事→长视频；有对白/角色冲突/戏剧结构→影视片段，并在交付时注明判断依据。
- **可选约束**：时长、平台（抖音/小红书/B站/影视）、画幅、风格倾向、情绪基调。

若用户只给一句话创意（如"拍一个雨夜失恋的短片"），直接基于创意补全合理情境，不打断询问。

### Step 2 · 情绪分析 + 审美形态定位（核心）

1. **情绪坐标**：
   - **主情绪**（1 个）：如 孤独 / 期待 / 释然 / 压抑 / 炽热 / 怅惘（参考 `references/emotion-map.md` 的情绪词族）。
   - **情绪强度**（弱 / 中 / 强）与**情绪走向**（起-承-转-合 或 单一情绪贯穿）。
   - **情绪关键词 3–5 个**：供后续映射。
2. **审美形态定位**（v1.2.0 新增）：依据主情绪，从 `references/aesthetic-forms.md` 的「情绪→审美形态映射表」定位**主形态**（优美/崇高/悲剧/喜剧/荒诞/意境）与备选形态，并确定风格取向（象征型/古典型/浪漫型，见 `references/aesthetic-creative.md` 第三节）与全片节奏策略（见 aesthetic-forms.md 第五节）。一条片子以一种形态为主，避免调性混乱。

> 触发条件：情绪与形态判断必须有依据——先读 `references/emotion-map.md` 按词族定位情绪，再读 `references/aesthetic-forms.md` 定位审美形态，不得凭空指定。定位结果写入方案头部「审美形态定位」项。

### Step 3 · 情绪 + 形态 → 视听语言映射

依据主情绪与审美形态，从知识库中查表匹配全部视听参数（**每一项都要有出处或补全标注**）：

| 维度 | 来源参考文件 |
|------|-------------|
| 审美形态 / 风格取向 / 节奏策略 | `references/aesthetic-forms.md`、`references/aesthetic-creative.md` |
| 道具 / 背景 / 场景元素 | `references/shooting-kit.md` §道具意象、§场景 |
| 配色 / 色彩基调 | `references/shooting-kit.md` §色彩、`references/aesthetics-evan-design.md` §配色 |
| 运镜 | `references/shooting-kit.md` §运镜、`references/aesthetic-forms.md` §各形态运镜 |
| 构图 / 机位 / 景别 | `references/shooting-kit.md` §构图、§机位、§景别、`references/aesthetics-evan-design.md` §比例 |
| 光影 | `references/shooting-kit.md` §光影 |
| 转场 / 蒙太奇 / 节奏 | `references/cinematic-language.md`、`references/aesthetic-forms.md` §形态→节奏 |
| 角色肢体动作 / 眼神 / 表情 | `references/performance.md` |

映射原则：
- **情绪→视觉的一致性**：每个参数的情绪含义必须与主情绪同向（例：孤独→冷色调、大远景、拉镜头、疏密留白、芦苇/荒原意象）。冲突时以 `references/emotion-map.md` 的映射表为准。
- **形态→视听的同向性**（v1.2.0 新增）：全部参数还须与 Step 2 定位的审美形态同向（例：崇高→低机位仰拍+巨物对比+积累蒙太奇；意境→长镜头+空镜承情+留白+淡出）。冲突时以 `references/aesthetic-forms.md` 的形态参数表为准。
- **补全规则**：知识库无对应条目时，按 `references/performance.md` / `references/cinematic-language.md` 的专业惯例补全，并在脚本该行标注「〔补全〕」。

### Step 4 · 构建分镜脚本

按 Step 1 的规格选择输出结构（模板见 `references/output-template.md` 与 `assets/storyboard-template.md`）：

- **短视频**：钩子开场 → 情绪铺垫 → 高潮 → 收尾/互动。钩子须在前 3 秒。
- **长视频**：分段落，每段有情绪小主题与转场；整体起承转合。
- **影视片段**：按场次（场 1/场 2），每场含场景标题（内/外·日/夜）、对白/动作、镜头组。

每个镜头必须写清：**镜号、景别、机位、运镜、构图、画面内容、光影/色彩、道具、时长、音效/配乐、表演指导（肢体+眼神表情）**。表格字段不够时用镜头详情块补充。

方案头部须含「审美形态定位」项；Step 5 产出的「创作手法」写入方案中，再进入校验。

### Step 5 · 审美创作深化（v1.2.0 新增 · 核心创作能力）

调用 `references/aesthetic-creative.md`，为脚本注入审美纵深，产出方案中的「创作手法」项：

1. **三层递进设计**：明确本片在养眼（形式美）/养心（情感移入）/养神（意境）各层如何着力；短视频至少养眼+养心（钩子在养眼层抓人），意境/禅意主题须达养神；长视频/影视片段可用三层作情绪曲线骨架。
2. **意境生成**（意境类必做）：用情景交融、虚实相生、境生象外三法，把情绪变成可拍的"象与境"，写明情如何注入景、哪些镜头为实哪些为虚（空镜承情）、画外余味是什么。
3. **象征与隐喻**：必要时用浓缩/移置/象征/润饰四法设计道具与意象，标注 `〔象征〕`；用「润饰」思维把散镜组织成起承转合的叙事。
4. **审美心理设计**：让力的结构（运镜方向/线条张力/剪辑节奏）与情绪同构（格式塔）；设计恰当的审美距离（特写/过肩/空镜的亲疏调度）；用移情、内模仿/通感调动观者；追求"瞬间中的永恒"（消逝之光、仪式感日常、恒常意象收尾）。
5. **落笔格式**：每条创作手法写 `层级定位 + 具体手法 + 理论依据 + 预期观者反应`（示例见 aesthetic-creative.md 第七节）。

> 该步骤是"方案更丰富、更具审美、更专业"的关键，不可省略。创作手法写入方案后，才进入校验。

### Step 6 · 三重校验（电影感 + 审美哲学 + 东方气质）

依次对照三份清单，**任一不通过则回 Step 4–5 修正**：

1. **电影感与镜头语言**（`references/cinematic-language.md`）：电影语言四要素（故事、角色、好奇、共鸣）是否齐备；构图 z 轴景深（前中后景）+ xy 轴平衡；对手戏代入感镜头（关系镜头、过肩正反打、视点镜头组、切出镜头）；景别节奏（避免同景别堆砌、避免"拉抽屉"）、动势连贯、蒙太奇与转场动机、视觉焦点顺畅；短/长/影视各自节奏表是否达标。
2. **审美哲学质量**（`references/aesthetic-checklist.md`）：康德四契机（非功利/非概念/无目的合目的/共同感）；美感非纯快感（不止于"好看/炫技"）；反套路（无网红运镜/糖水唯美/炫示性消费）；审美形态定位明确且参数同向；意境三要素齐备；创作深度达标（三层递进、格式塔同构、审美距离、通感）。
3. **东方形式气质**（`references/aesthetics-evan-design.md`，以「全片」为校验单位）：L1 意境（留白/侘寂/物哀/幽玄/禅）；八意识（间/素/秘/并/微/气/假/破，破至多 1 处标注 `ha`）；L2 比例（三分/黄金分割）；L3 配色（60-30-10）。

冲突裁决优先级：间/素/秘（气质）＞并/破（秩序）＞微/气/假（感知）＞审美哲学细项。任一镜头违反「破不滥用」「单镜头焦点≤1」须修正。

### Step 7 · 输出交付

1. 生成完整分镜脚本 Markdown，保存到 `outputs/` 目录（文件名 `<内容主题>-分镜脚本.md`）。
2. 用文件展示工具呈现给用户。
3. 正文末尾附：情绪与审美形态分析摘要、视听方案表、创作手法、〔补全〕项清单、三重校验结论。
