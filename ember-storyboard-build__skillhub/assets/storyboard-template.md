## 五、三重校验结论
电影感镜头语言：
- [ ] 故事/角色/好奇/共鸣具备；前中后景；动势连贯；无同景别堆砌

审美哲学质量（见 aesthetic-checklist.md）：
- [ ] 康德四契机通过；未沦为纯"养眼"；无网红运镜/糖水唯美套路
- [ ] 审美形态定位明确且参数同向；意境类情景交融+虚实相生+境生象外
- [ ] 创作深度：三层递进达标、同构成立、审美距离恰当、有通感

东方气质（见 aesthetics-evan-design.md）：
- [ ] 并：全片色调/运动风格统一
- [ ] 间：主体留白≥40%，禅意镜≥50%
- [ ] 秘：单镜焦点≤1，渐进披露
- [ ] 素：主色饱和≤45%，高饱和≤10%
- [ ] 破：至多1处破格并标注 `ha`，其余守序
- [ ] L2：主体落三分法/黄金分割
- [ ] L3：60-30-10，明度层次清晰
- [ ] 电影感：故事/角色/好奇/共鸣具备；前中后景；动势连贯
