# 电影感与镜头语言

Step 5 校验专用。前半部分源自拍摄知识库（分镜、故事、视觉焦点、设计运动），后半部分为影视专业补全（标注〔补全〕）。

## 一、电影感四要素

**电影语言 = 故事 + 角色 + 好奇 + 共鸣**（源自知识库）。每个镜头组都应至少服务其中一个要素。
- 故事：有没有发生"事"？
- 角色：有没有让人记住的人物状态？
- 好奇：有没有留悬念让观众想看下去？
- 共鸣：有没有可共情的情感/处境？

## 二、构图与空间（电影感基础）

- **构图 = z轴景深（前景/中景/后景）+ xy轴平衡**（源自知识库）。避免纯平面画面。
- 前景（虚化/遮挡）造层次，中景放主体，后景交代环境/情绪。
- xy轴：三分法、黄金分割落主体；注意画面左右视觉重量平衡。

## 三、对手戏代入感镜头组（源自知识库）

- **关系镜头**（中全景）：动作+环境，交代人物关系与相对位置
- **过肩正反打**（OTS）：对话的标准拍法
- **视点镜头组**：看的动作 → 看的内容 → 看的反应（三段缺一不可）
- **切出镜头**：插入细节/环境，制造节奏与呼吸

## 四、蒙太奇与转场（源自知识库）

| 类型 | 用法 |
|------|------|
| 错位蒙太奇 | 不同时空切换制造错觉（恐怖/悬疑） |
| 声音蒙太奇 | 声音提前（下一场声音先入）使衔接丝滑 |
| 对比蒙太奇 | 相似镜头衔接，画面流畅 |
| 相似转场 | 颜色/纹理/形状/音乐相似，连接自然、增强共鸣 |

## 五、故事三层次（源自分镜·故事）

1. 实际发生的（客观事实）
2. 想让观众看到的（反复强调的重点）
3. 观众实际看到的（最终呈现）

**分镜步骤**：台词分格 → 选择画面对应台词 → 检查跳转衔接 → 强调重点（反复强调：反应/景物/切镜头）→ 弱化非重点（删多余画面）。
**目的**：让观众产生情绪、想看。

## 六、动势设计（源自知识库）

- **动势**：元素运动方向。眯眼让元素模糊成色块判断运动方向；分镜切换处动势尽量一致，画面更顺畅。
- 应用：画面切换顺畅；简化创作（按色块设计元素移动）；增加节奏感（正反动势配合产生起伏）。
- 节奏：整体顺畅，热闹/酷炫处几个点跳跃。

## 七、镜头语言自检（源自知识库·拍摄检测）

- [ ] 景别节奏：无同景别连续堆砌、无"拉抽屉"
- [ ] 动势连贯：切换处动势一致
- [ ] 视觉焦点：切换后观众无需跳动焦点（顺畅）
- [ ] 电影感：故事/角色/好奇/共鸣至少满足其一时时
- [ ] 空间：前中后景具备、xy平衡
- [ ] 蒙太奇/转场有动机，非空切

## 八、节奏表（按规格）〔补全〕

| 规格 | 单镜时长 | 镜头密度 | 节奏策略 |
|------|---------|---------|---------|
| 短视频（15s–5min） | 1–3s（钩子镜0.5–1.5s） | 高（15–60镜） | 前3秒强钩子、中段留1–2个记忆点、结尾互动/反转 |
| 长视频（5–40min） | 3–15s | 中 | 段落式，每3–5分钟一个情绪小高潮，张弛交替 |
| 影视片段 | 2–8s（对话镜可更长） | 中低 | 场次结构，重场面调度与表演，留呼吸 |

## 九、叙事结构补全（〔补全〕）

- **起承转合**：短视频="钩子-展开-反转-收"；长视频="建置-发展-高潮-解决"；影视片段="场景目标-阻碍-动作-结果/悬念"。
- **三幕式**：建置（25%）→ 对抗（50%）→ 解决（25%），适配长视频与影视。
- **钩子类型**：疑问、反常、强情绪、悬念画面、金句——短视频前3秒必用其一。
- **情绪曲线**：标注全片情绪强度起伏（弱→中→强→落），避免平铺。

## 十、专业术语速查（〔补全〕）

- **场面调度**：镜头内演员走位与摄影机运动的配合。
- **轴线/180度线**：对话双方保持同一侧机位，避免越轴造成方向混乱。
- **匹配剪辑**：动作/视线/形状的连贯衔接。
- **景深焦点**：浅景深突出主体、深景深交代环境。
- **留白镜头**：空镜承接情绪转场，给观众呼吸（呼应 evan-design「间」）。
