# 影视创作知识库
> 使用说明：本库用于影视短片、长片、纪录片与竖屏短视频的开发、拍摄、后期和交付，不替代具体项目策划。
> 开发时先确定创作意图与人物目标，再依次检查冲突、结构、场景、视听和制作条件，避免从设备或形式倒推内容。
> 各章条目均可转为项目检查项；出现分歧时，以主题表达、人物行动、观众理解和制作安全为优先顺序。
> 所有参数均是起始参考而非固定规则，应通过剧本围读、分镜推演、技术测试和试片按项目修正。
> 引用本库时保留适用条件，不把节奏数值、景别组合或平台规格当成跨项目通用标准。
> 交付前同时核查内容完整、连续统一、声画清楚、版权合规、播放兼容与文件备份，并留存最终确认记录。

## 一、创作总纲：意图、因果与协作

### 1.1 创作意图
- 用一句可验证的话界定作品要讨论的问题、情感方向和审美立场，避免只写抽象口号。
- 区分“故事发生什么”与“作品为何值得表达”，后者决定素材取舍和形式强度。
- 明确目标观众、观看场景、作品时长与传播媒介，将其转化为信息密度和节奏约束。
- 为项目设定三项以内的核心表达目标，后续重大改动逐项检查是否增强这些目标。
- 把创作者个人经验转化为人物可感知的选择、行动和后果，不以说明替代戏剧过程。
- 对复杂主题保持明确价值判断，同时保留人物处境的复杂性，避免人物沦为观点传声筒。
- 在立项页固定记录创作意图、核心受众、类型承诺、形式边界与不可牺牲项。

### 1.2 主题、人物、冲突、结构的因果链
- 从主题提出戏剧问题，再由人物欲望、价值取舍和行动回答，不直接替人物宣布答案。
- 为主人公建立外在目标、内在需求、现实缺口和错误应对方式，使行动具有必然动机。
- 让人物性格决定其应对压力的方式，让行动引发新阻力，再由新阻力迫使人物调整。
- 将对立力量设计为有目标、有方法、有合理性的行动主体，而非单纯制造麻烦的障碍。
- 以“目标—行动—反作用—选择—代价—新局面”检查每场戏是否形成因果推进。
- 确保关键转折由人物选择或可理解的外部压力触发，避免巧合连续解决核心问题。
- 让冲突同时作用于事件、关系和价值三个层面，并优先呈现能产生后果的冲突。
- 逐级提高行动成本、信息风险、关系损失或道德压力，不只提高音量和动作规模。
- 用结构安排人物在何时知道、误解、选择和承担结果，使结构成为主题的压力装置。
- 让结局呈现核心行动累积后的状态变化，并回收最重要的选择及其代价。
- 检查删除任一场景后因果链是否受损；无影响者合并、改写或删除。
- 区分必要伏笔与随意解释，重要能力、关系、物件和信息应在生效前建立。

### 1.3 形式服务内容
- 先判断一场戏需要观众知道什么、感受什么、怀疑什么，再选择景别、机位、运动和剪辑。
- 将视觉风格落实为可重复的构图、光线、色彩、镜头、声音和节奏规则。
- 只有在能改变信息、关系、时空或情绪时采用显著形式，避免把技巧本身当成表达主体。
- 保持形式强度与戏剧强度匹配，低潮段落为高潮段落保留视觉和听觉上升空间。
- 统一创作者各部门对关键场景的理解，防止表演、摄影和音乐分别追逐不同情绪。
- 对每处风格化处理回答“服务何种内容”；无法回答时恢复更清晰的表达方案。
- 形式创新须通过可读性测试，确认目标观众能识别人物、行动、空间和重点。

### 1.4 部门协作与决策
- 由导演维护统一的创作阐释，编剧维护因果与文本，制片维护资源和边界，各部门据此执行。
- 在筹备期完成剧本、分镜、美术、表演、摄影、声音、剪辑和视效的联合拆解。
- 用场次编号和版本号管理跨部门文件，任何改动同步标注受影响的镜头、道具、演员和声音。
- 先解决剧本因果和场面调度，再解决设备配置；先确定叙事需求，再确定技术规格。
- 让摄影与美术共同测试光线、色彩和材质，让录音与摄影共同确认机位及噪声条件。
- 让剪辑尽早参与分镜审查，检查镜头之间是否能形成动作、视线、信息和节奏衔接。
- 让声音设计在剧本阶段介入，提前识别需要现场保留、后期构建或视角转换的声音。
- 对高风险动作、特殊装置和复杂视效执行联合预演，明确安全停止权与替代镜头。
- 每日拍摄后核对素材完整性、连续性、声音质量和后续缺口，不把问题留到杀青后。
- 对创作分歧记录方案、依据、成本和决策人，避免口头变更造成多版本并行。
- 建立最终锁定顺序：内容锁定、画面锁定、声音与调色完成、字幕图形完成、交付校验。

## 二、电影语言：镜头、蒙太奇与时空

### 2.1 场面调度的视听基础
- 把人物位置、朝向、距离、高度、焦点、道具和出入口组织成可读的视觉关系。
- 用画面主次控制观众注意力，保证主体、陪体和环境信息按戏剧需要依次被感知。
- 让前景、中景、背景共同参与叙事，避免只追求层次而加入无关视觉噪声。
- 利用人物入画出画、遮挡、转身、停顿和视线改变调整画面重心与场景节奏。
- 将空间布置与人物目标绑定，使通行、阻隔、占有和撤离都能表达关系变化。
- 保持环境细节符合人物身份与行动逻辑，陈设既服务表演也服务镜头覆盖。
- 在写实与造型之间设定统一尺度，避免某一部门过度风格化破坏整体可信度。

### 2.2 景别与信息控制
- 用远景或全景交代地理、群体关系、行动规模和人物在环境中的处境。
- 用中景组织动作、交流及人物之间的距离，兼顾身体信息与面部信息。
- 用近景突出态度、反应和关系变化，避免在缺乏心理变化时连续停留。
- 用特写呈现决定性细节、瞬间判断或强烈反应，控制使用频率以保留强调作用。
- 景别选择以当前信息任务为准，不以机械轮换制造表面丰富。
- 同一场戏通过景别变化改变叙事距离，使靠近与远离对应认知或情感变化。
- 相邻镜头保持足够的景别、角度或构图差异，避免无动机的相似画面跳接。
- 给人物视线、运动方向和关键动作保留必要空间，同时防止留白削弱主体。
- 拥挤环境优先保证行动和关系可读，不以更宽景别替代有效调度。
- 特写中的表演、焦点和道具连续性应重点复核，细微误差会被显著放大。

### 2.3 视点、角度与镜头参数
- 明确镜头属于客观观察、人物主观、半主观跟随或受限视角，并保持转换有提示。
- 客观视点用于组织信息和观察关系，主观视点用于共享感知，不以主观镜头替代人物塑造。
- 反应镜头既呈现人物心理，也重新分配观众判断，应依据信息价值而非对白轮次选择。
- 俯仰、高低、正侧角度须与权力、距离、陌生感或空间方向相联系，避免固定象征套用。
- 焦距选择同时考虑空间透视、人物变形、机位距离、景深和现场条件。
- 景深控制信息层级；浅景深不能用来掩盖调度不足，深景深必须保证各层内容有秩序。
- 快门、帧率与播放速度共同影响运动质感，特殊处理须测试动作清晰度和情绪效果。
- 分辨率、画幅和锐度服从发行端与观看距离，避免以技术规格取代视觉设计。
- 在同一戏剧单元内控制透视与观看距离的一致，除非变化本身承担叙事功能。

### 2.4 蒙太奇
- 通过镜头并置产生单一镜头无法独立提供的信息、判断、情绪或节奏。
- 叙事蒙太奇按因果、时间或认知顺序组织行动，优先保证人物目标与空间关系可追踪。
- 平行组织须建立可比较的冲突或主题关系，并在交叉时逐步增强互相影响。
- 对比组织须确保差异明确且有表达目的，避免只依赖强烈影像造成空泛意义。
- 隐喻组织须能从人物经验或剧情语境理解，避免脱离叙事另行附加象征。
- 心理组织可重组记忆、想象和感知，但应提供状态入口、内部逻辑与返回现实的依据。
- 以镜头内容的延续或冲突决定切点，不以音乐节拍替代全部剪辑逻辑。
- 每次组接检查新增信息是否大于重复信息，删除只复述上一镜头的画面。
- 节奏加快时仍须保留关键动作、反应和定位镜头，避免信息量超过可识别阈值。
- 蒙太奇段落结束后用明确的新状态承接，确认人物、地点或情绪已经发生变化。

### 2.5 长镜头与景深调度
- 在需要连续时空、完整表演、实时压力或关系渐变时优先考虑长镜头。
- 为长镜头设计起点、发展阶段、转折和终点，不能仅以持续拍摄代替场面组织。
- 让演员、摄影机和焦点的每次移动都有动机，并在移动前后形成不同的信息组合。
- 利用景别和视角的自然变化避免内部单调，但不得破坏行动的连续与空间可读。
- 排练时分别校验表演节奏、移动路线、对焦节点、录音覆盖和安全余量。
- 长镜头中保留可见的反应和停顿，让观众能识别选择发生的过程。
- 若剪辑能更准确地控制信息或表演，则拆分长镜头，不把技术难度当成艺术价值。
- 长镜头与蒙太奇按戏剧任务混合使用，统一于场景节奏而非阵营式偏好。

### 2.6 连续性剪辑与轴线
- 开拍前确立主要行动轴、关系轴和屏幕方向，并在分镜及现场平面图中标注。
- 在轴线一侧组织机位；需要越轴时用人物移动、摄影机运动或中性镜头建立新轴。
- 保持人物出入画方向、行进方向、视线方向和关键道具位置一致。
- 对话场景按既定关系安排视线，重组轴线后先重建空间再继续使用近景。
- 相邻同主体机位尽量形成明显角度或景别变化；常以约三十度作为排查跳切的参考。
- 不以角度数字代替画面检查，背景、透视、主体大小和运动方向也须产生足够差异。
- 动作接点在动作中进行时，确保起势、速度、轨迹、重心和完成阶段能够吻合。
- 通过建立镜头、人物视线和局部细节维持“整体—局部—整体”的空间认知。
- 允许为情绪、断裂感或主观状态有意破坏连续性，但须保持其他定位线索稳定。
- 每场戏至少保留能重建空间和关系的覆盖镜头，防止后期只有碎片无法组接。

### 2.7 时间与空间
- 明确每个段落的时序、时长、地点和时间压力，避免观众因缺少标识而误判。
- 压缩时间时保留行动的关键因与果，重复过程可删，选择过程不可无故省略。
- 延展时间时增加有效感知、反应或决策层次，不重复同一信息拖延时长。
- 闪回、闪前、平行时空和主观时空须由人物动机、信息节点或形式规则触发。
- 时空转换通过动作、声音、构图、光线、字幕或空间标志建立可辨识边界。
- 同一空间的距离和通行时间保持内部一致，特殊压缩应保证不妨碍核心行动理解。
- 新空间先交代关键地理，再进入局部；追逐和动作段落须周期性更新位置关系。
- 通过画外空间、视线、声音和出入画扩展场景，但关键行动不能完全依赖不可见信息。
- 利用重复空间中的陈设、光线或人物位置变化表现时间流逝和关系变化。
- 画幅改变须对应叙事层级或观看规则，避免无动机切换造成空间尺度混乱。

### 2.8 现代画面系统的适用约束
- 虚拟制作先用于空间延展、光线统一和调度整合，须提前验证透视、视差、反射与色彩衔接。
- 实时背景不得替代真实表演支点，演员视线、互动位置和环境光仍需现场统一。
- 数字场景与实拍部分采用一致的空间尺度、镜头逻辑和材质响应，避免只做背景展示。
- 竖屏构图优先设计中近景、纵向层次和中心安全区，同时保留横向关系所需的有效覆盖。
- 为竖屏重新安排人物距离、字幕区域、动作路径和背景重点，不直接裁切横屏母版代替设计。
- 多画幅交付时从筹备期确定共用安全区与独立镜头清单，逐版检查主体和文字完整性。

## 三、剧本开发：结构、场景与对白

### 3.1 前提与故事承诺
- 用“人物在压力下追求目标并付出代价”的方式写出故事前提，检查是否包含行动和结果。
- 明确主人公、核心欲望、主要对立、关键风险与变化方向，再扩展情节。
- 前提应能持续生成冲突，而非只支持单一情境或单次反转。
- 类型承诺决定观众期待，应在开段建立核心体验，并在后段给予有变化的兑现。
- 背景设定只保留会改变人物选择、行动成本或冲突规则的部分。
- 将主题疑问埋入对立双方的有效选择，使每次胜负同时推进故事和价值讨论。
- 用一句话梗概、短梗概和完整大纲逐级扩展，每一级都重新核对因果。

### 3.2 人物构建与人物弧
- 建立人物的生理条件、社会处境、心理需求和价值底线，并让这些因素影响行动。
- 让人物具备优势、缺陷、矛盾和自我解释，避免单一功能化。
- 区分人物想要什么与真正需要什么，两者之间的错位可形成持续内在冲突。
- 给主要人物设置可见目标、隐藏动机和不可轻易跨越的边界。
- 通过选择而非履历说明人物，通过他人受到的影响验证人物行动的分量。
- 人物弧可采用觉醒、堕落、固守或关系重组，但每个阶段都要有压力证据。
- 设计“初始状态—被迫调整—旧方式失效—关键选择—新状态”的变化节点。
- 无显著性格改变的人物也应通过不断升级的选择揭示其本质，并改变周围关系。
- 配角拥有独立目标和行动逻辑，不只承担助攻、阻碍或解释功能。
- 检查每个人物在高潮中的作用，删除无法影响主线、主题或关键关系的冗余人物。

### 3.3 结构工具与升级
- 开段尽快建立常态、人物缺口、核心欲望和扰动事件，使观众理解故事为何此刻开始。
- 第一重大转折让主人公进入无法轻易退回的新处境，并明确后续行动方向。
- 中段通过策略调整、关系变化、信息增加和代价扩大持续推进，避免重复同一阻力。
- 中点可改变目标理解、力量对比或行动规则，使后半段不再只是前半段延长。
- 第二重大转折迫使人物以新的自我认识作出最终选择，而非仅把外部危机放大。
- 高潮集中处理核心目标与核心关系，让最重要的选择产生不可逆后果。
- 收束段落交代必要后果和情绪余波，避免在主要问题解决后重复解释。
- 使用序列或章节管理阶段目标，每个单元都应有自己的压力、转折和状态变化。
- 用场景卡或节拍表排列“行动—反应—新行动”，检查事件间是否存在必然联系。
- 升级可从时间缩短、资源减少、关系破裂、暴露增加和价值冲突加深中选取有效路径。
- 每次升级改变问题性质或应对方式，避免只增加同类障碍数量。
- 保留必要缓冲和反思段落，通过张弛对比提高下一次压力的可感知度。
- 反转须由既有信息支持，在发生时同时带来意外与回顾后的合理。
- 伏笔回收应改变行动或理解，不能只为证明剧本设置了细节。

### 3.4 场景功能与场景卡标准
- 每场戏明确视角人物、当场目标、阻力、策略、转折、出口状态和新增信息。
- 场景必须至少改变事件进展、人物关系、观众认知或情绪方向中的一项，核心场景应形成复合变化。
- 在场景开头确立初始力量和意图方向，在结尾留下与开头不同的局面。
- 尽量从行动已开始或压力已形成处进入，在核心变化完成且新方向出现后退出。
- 将解释性信息转化为争夺、试探、隐瞒、误判或决策过程中的有用途内容。
- 用场景卡记录编号、内外景、地点、时间、出场人物、时长估计和场景目的。
- 补充记录人物目标、冲突双方、关键行动、信息差、转折点和离场状态。
- 标注所需道具、服化状态、特殊效果、声音线索、连续性要点和前后场衔接。
- 对场景卡进行删除测试、换位测试和合并测试，排除重复功能与不合理顺序。
- 检查场景之间的因果接口，确保上一场的结果能成为下一场行动的条件或压力。
- 为场景设计视觉行动，让不可见心理通过姿态、距离、物件使用和选择被观察。
- 将场景长度与信息密度、表演需要和全片节奏共同评估，不平均分配篇幅。

### 3.5 对白与潜文本
- 让每句对白服务行动目的、关系变化、信息控制或人物刻画，删除无功能寒暄。
- 区分人物的教育、职业、地域、节奏、措辞和防御方式，保持声音可辨识。
- 人物在冲突中通常有所保留，通过回避、转移、试探和言外之意形成潜文本。
- 避免让双方直接说明彼此已知的信息，背景内容应附着于当前利益争夺。
- 对白长度服从呼吸、情绪和交锋节奏，长段陈述须包含态度变化或行动层次。
- 让听者的反应参与意义生成，重要对白后保留必要的停顿、动作或镜头空间。
- 减少重复画面已经明确表达的内容，优先补充画面无法提供的新关系和新意图。
- 专业用语只在人物会使用且观众能从语境理解时保留，不用术语制造虚假深度。
- 通过朗读检查口语性、气口、重音和角色区分，删除书面化总结。
- 沉默也是行动，须明确沉默者拒绝、等待、掩饰或判断的具体目的。

### 3.6 剧本呈现与长短片差异
- 场景标题准确标明内外景、地点和时间，动作段落使用可见、可听、可拍的表述。
- 动作描述按当前发生的顺序书写，突出关键动作和状态，不代替导演规定全部机位。
- 人物首次出场提供与行动相关的必要识别信息，避免无关外貌清单。
- 对白、人物提示和必要的画外或场外标识保持格式统一，减少现场误读。
- 剧本页数、预计时长和拍摄量只作联动估算，最终以围读、分镜和制片拆解校准。
- 长片允许多线关系、渐进伏笔和多次策略变化，但各线须汇入核心冲突并控制认知负担。
- 短片优先集中人物、时空、目标和主要转折，以少量高浓度场景完成完整变化。
- 短片不依靠压缩长片大纲制造密度，应缩小问题规模并保留选择与后果的完整过程。
- 超短视频先建立可识别情境与观看承诺，再快速制造变化，结尾须兑现而非突然中断。
- 无论篇幅长短，都不以省略必要动机换取速度，以合并次要过程提高效率。
- 完稿后分别进行因果审读、人物审读、对白朗读、视觉化审读和可拍性审读。

## 四、分镜、摄影机与动作拍摄

### 4.1 分镜字段与使用流程
- 每格分镜标注项目、场次、镜号、版本、画幅和预计时长，保证可检索。
- 画面内清楚呈现景别、机位、主体位置、运动方向、视线和前后关系。
- 文字栏记录镜头内容、人物动作、摄影机运动、起止构图和关键表演节点。
- 补充对白或声音提示、转场方式、特效需求、拍摄方法及与前后镜头的连接。
- 对复杂镜头绘制起幅、过程关键帧和落幅，避免单张图无法表达运动结果。
- 用平面图同步标注场景轴线、机位、灯光、演员路线和设备移动范围。
- 先按叙事必要性设计镜头，再按场地和制作条件合并优化，保留必要的空间覆盖。
- 用动态分镜或预演验证时长、动作、视线、节奏和声音入口，提前发现不可剪辑段落。
- 分镜作为沟通基准而非机械限制，现场调整须记录并检查对后续镜头的影响。
- 每日按镜号核对已拍、漏拍、备选和补拍状态，保证素材与工程命名一致。

### 4.2 摄影机运动及禁忌
- 运动必须有叙事动机：跟随行动、改变视点、揭示信息、重建关系或强化心理状态。
- 每次运动预先确定起幅、触发点、路径、速度和落幅，起落画面均应具备独立构图价值。
- 推近用于缩小注意范围或增强压力，拉远用于释放语境、孤立人物或改变关系理解。
- 摇摄用于连接空间、跟随方向或控制揭示，起止须有明确目标，避免无目的扫视。
- 移摄与跟摄用于保持行动关系或改变空间层次，速度须匹配人物运动和情绪。
- 升降用于改变高度、规模与空间关系，避免只展示设备行程。
- 环绕用于重组人物与环境关系，须检查轴线变化、背景连贯和运动安全。
- 手持用于贴近身体感、即时性和不稳定状态，应控制晃动频率以保留表演信息。
- 变焦与机位移动产生不同透视效果，选择时以空间感受为准，不相互随意替代。
- 禁止无动机运动、运动中失去主体、落幅无重点、速度无变化和连续多镜同向重复。
- 禁止为掩盖调度不足而频繁晃动，也不以稳定器滑行替代人物行动设计。
- 快速运动须核查滚动快门、焦点、曝光、运动模糊和安全边界。
- 需要静态观察时果断固定机位，让画内运动承担节奏，避免所有镜头都处于移动状态。

### 4.3 支撑与移动设备选择
- 三脚架适用于固定构图、精确重复、长焦和稳定观察，提前校验水平、阻尼与承重。
- 独脚架适用于需要快速转移的有限稳定支撑，不能替代完全固定机位。
- 肩扛适用于跟随表演并保留身体反馈，须规划体力、对焦和录音位置。
- 手持适用于受限空间和主观贴近，采用安全握持与身体支撑降低无意义震动。
- 稳定器适用于平滑穿行和连续跟拍，须测试重心、步伐、转弯、上下坡及风阻。
- 滑轨适用于短距离、可重复的精确位移，运动长度须服务信息揭示而非炫技。
- 轨道车适用于较长或复杂运动，提前检查地面、轨道平整、速度一致和制动安全。
- 摇臂适用于高度与纵深变化，设置物理限位、警戒区和配重检查。
- 航拍只在大范围地理、规模或路径确有必要时使用，遵守空域、人员和天气限制。
- 车载及特殊挂载须由合格人员实施，独立评估固定、减震、通信和应急停止。
- 设备组合以满足镜头任务的最简方案优先，同时准备低复杂度替代机位。
- 任何支撑设备都须核对载荷、锁紧、供电、线缆、防坠和人员动线。

### 4.4 动作场景覆盖
- 动作首先表达人物目标、能力、性格和关系，再考虑视觉冲击与规模。
- 开段建立地理、参与方、出入口、危险源和相对位置，随后周期性更新。
- 将动作拆成意图、准备、发起、接触、结果和反应，确定哪些阶段必须完整呈现。
- 为关键行动保留主镜头，用近景和细节补充力量、判断与后果，不用碎片替代全部过程。
- 景别变化须匹配动作幅度，较大动作保留身体和方向，较小动作突出手感与表情。
- 冲击镜头之后安排受伤、失误、调整或关系变化的反应，使动作产生戏剧后果。
- 使用不同角度时保持运动轴、速度、重心和动作阶段连续，避免重复接触造成跳变。
- 镜头长度依据观众识别时间确定，复杂地理和关键技巧适当延长，重复过程缩短。
- 快速剪辑与连续长镜头按场景阶段交替，形成建立、升级、失衡、重组和收束的节奏。
- 速度与节奏由动作设计、表演速度、镜头运动、景别、剪辑和声音共同决定。
- 快慢速处理须对应主观感知、力量强调或时间变形，避免在一场戏内无规则混用。
- 现场按预演划分安全区、运动区和拍摄区，任何镜头不得以未受控风险换取效果。
- 收集动作全景、关键局部、反应、环境和必要空镜，为后期重建节奏保留余地。
- 声音设计区分准备、发力、接触、环境和后果层级，避免所有冲击使用同等强度。

### 4.5 速度、节奏与现场技术核验
- 以戏剧事件密度定义节奏，不把镜头平均长度当成唯一指标。
- 同一段落通过镜头时长、内部动作和声音密度形成递增、停顿、突变或回落。
- 每场拍摄前测试分辨率、帧率、快门、编码、色彩、存储和供电，并统一项目设置。
- 特殊帧率与快放慢放须考虑最终播放帧率、声音处理和曝光余量。
- 焦点计划跟随戏剧重点而非单纯跟随最近人物，转移速度和时机应可重复。
- 曝光与色温变化若跨镜头连续，记录数据并拍摄必要参照，减少后期不匹配。
- 高速运动、低照度和复杂光源环境下进行实际监看测试，不只依赖设备参数。
- 现场回放同时检查内容、连续、焦点、曝光、声音和安全性，确认后再撤景或转场。

## 五、演员调度、视线与群体场面

### 5.1 表演与行动
- 将每场表演拆解为目标、障碍、策略、关键发现和行动调整，避免只规定情绪结果。
- 让演员明确上一场的残留状态和本场的即时需要，保证行动来源连续。
- 用可执行的动词沟通表演任务，不使用抽象形容替代行为方向。
- 情绪由行动受阻和关系变化生成，不要求演员持续维持单一强度。
- 为倾听、判断和反应保留时间，反应不是对白之间的空白，而是场景的重要组成部分。
- 通过围读统一人物关系、事实信息和潜文本，通过走调度解决身体与空间问题。
- 排练先保证行动逻辑，再固定位置与节奏，为现场发现和镜头需要保留调整空间。
- 对高强度段落建立进入、维持和退出机制，控制重复拍摄对演员状态的影响。

### 5.2 演员调度与心理空间
- 用人物间距离、朝向、高度、遮挡和移动表达亲疏、控制、回避与依赖。
- 每次重要位移由新信息、策略变化、情绪压力或实际任务触发，避免为构图随意走动。
- 让人物占有或让出空间体现力量变化，避免始终通过对白说明关系。
- 入场须带来新压力或信息，出场须留下状态变化，并兼顾下一场衔接。
- 道具使用应与目标和性格相关，既提供行动支点，也形成可连续的视觉节拍。
- 停顿用于判断、抵抗、期待或关系重组，长度由内部行动而非外部计时决定。
- 静态人物也可通过视线、重心、呼吸和微动作保持场景张力。
- 摄影机位置与演员调度共同设计，避免先摆机位再迫使人物做不自然移动。
- 在焦点、画框和光线限制内为演员保留行动自由，并用技术排练确认关键节点。

### 5.3 视线与空间统一
- 明确每个视线镜头的观看者、目标和方向，拍前核对画内外位置关系。
- 视线匹配同时检查水平方向、俯仰角度、距离感和目标运动，不只检查左右。
- 主观镜头前后的观看与反应须形成清楚的因果顺序，避免观众误认视点归属。
- 跨镜头保持人物身体朝向、坐姿、手势、道具和情绪强度的连续。
- 多人对话重新分组时重新确认关系轴和视线网络，防止局部正确而整体空间冲突。
- 画外声音与视线共同提示空间时，方向、距离和移动速度应相互支持。
- 现场用平面图记录最终调度和机位，补拍时据此恢复空间关系。

### 5.4 群体与群像场面
- 先确定群体场面的主要行动和当前视觉中心，再将人物分成具有不同任务的小组。
- 通过前后景、高低、疏密、动静和方向差异建立层级，避免所有人平均面向镜头。
- 小组行动围绕主要事件形成支持、干扰、观察或反向压力，不制造无意义背景活动。
- 主要人物转移时同步安排焦点、声音和其他小组反应，使注意力转换可被观众跟随。
- 群体反应设置先后与强弱差异，保留个体态度，避免整齐划一削弱真实感。
- 用前景遮挡、人物穿行和声音连接不同小组，扩展空间而不破坏主轴。
- 群像叙事为主要人物分配清晰目标和关键场次，以共同事件或主题连接不同人物弧。
- 复杂群戏先排练无摄影机的完整行动，再确定主镜头、补充镜头和反应覆盖。
- 连续拍摄时记录人群位置、动作阶段、道具消耗和服装状态，保证跨镜头可衔接。

## 六、剪辑、声音与基本混合

### 6.1 剪辑判断与剪辑点
- 先按场景目标和人物变化组织镜头，再检查动作连续、空间清晰和节奏准确。
- 粗剪优先验证因果与信息顺序，不因技术瑕疵过早放弃内容上必要的镜头。
- 剪辑点可落在动作、视线、判断、情绪变化、语言重音或声音变化上，须选择最有意义的一项。
- 动作剪辑保持轨迹和速度一致，利用动作中的切点减少接缝，但不机械追求无缝。
- 情绪剪辑在人物内部状态改变时切换，避免仅按对白句尾机械剪切。
- 信息剪辑控制观众与人物的知识差，决定先见结果、先见原因或同步发现。
- 反应镜头应提供新态度或改变权力关系，避免反复切回没有变化的倾听者。
- 每次剪切检查是否删除必要呼吸、动作准备或后果，是否保留多余重复。
- 用无声观看检查视觉叙事，用闭眼聆听检查语言与声音叙事，再合并评估。
- 对节奏问题先调整镜头内容、顺序和场景结构，再使用变速或短切修饰。
- 画面锁定前完成主要视效、字幕和重新构图需求评估，避免后期反复改动。

### 6.2 转场与段落组织
- 直接切作为默认连接方式，依靠内容、动作、视线和声音形成清晰组接。
- 叠化用于较明显的时间、记忆或状态流动，长度与情绪变化匹配，避免替代普通剪切。
- 淡入淡出用于较大的段落边界和观看状态转换，使用频率服从整体结构。
- 匹配转场须同时具有形状、运动、声音或意义关联，不能只有表面图形相似。
- 声音提前或延后进入可连接时空、引导期待或保留余韵，须保持叙事归属清楚。
- 遮挡、出画入画和运动方向可形成自然转场，前后镜头的速度与方向应衔接。
- 时空跳跃较大时提供必要时间、地点或状态标识，标识应与既有形式规则一致。
- 避免连续堆叠多种转场效果，显著转场只用于真正需要划分的结构节点。
- 每场戏出口保留下一场所需的问题、情绪或行动动量，使段落连接有推动力。

### 6.3 声画关系与声音叙事
- 建立环境、动作、对白、音乐和特殊效果的声音层次，并明确各场戏的主要听觉视角。
- 同步声增强动作触感与空间真实，非同步声可延展画外空间、时间或心理。
- 声画对位须产生新的判断或情绪，不为反差而反差，并保证观众能理解关系。
- 主观音效应有明确人物感知依据，进入和退出与视点变化一致。
- 环境声记录空间大小、材质、气候、距离和背景活动，保持同场景连续。
- 现场优先获得清晰对白和必要动作声，同时采集环境底声与关键独立效果。
- 画外音承担画面不能提供的叙述、主观或时间功能，不重复朗读可见内容。
- 静默用于改变注意力和制造听觉空间，须保留合理的环境或身体细节以维持真实。

### 6.4 音乐、效果与节奏
- 音乐服务人物、结构、节奏和情绪方向，不用持续铺满来替代表演或剪辑。
- 确定音乐进入与退出的戏剧节点，避免仅因段落需要“热闹”而添加。
- 音乐情绪可支持、克制或反向作用于画面，但须与整体价值判断一致。
- 重要对白和关键效果出现时给音乐让出频段与动态空间，避免多元素争夺注意。
- 动作效果区分材质、重量、距离和力量层次，避免同一强响度反复刺激。
- 喜剧和悬念的效果使用服从信息与时机，不提前泄露反应或反转。
- 环境变化、转场和时间流逝可用连续声音线索统一，减少不必要的解释性画面。
- 所有音乐、录音和效果确认授权范围、期限、地域、媒介及署名要求。

### 6.5 基本混合与母版检查
- 按对白清晰、叙事重点、空间真实和动态舒适确定混合优先级。
- 先完成剪辑、降噪、修复和素材同步，再进行电平、均衡、动态、空间与自动化处理。
- 对白在句间、镜头间和场景间保持可理解度与音色一致，降噪不得产生明显伪影。
- 环境和效果建立连续声床，剪接处的底噪、混响与空间方向须平滑或有动机变化。
- 控制峰值、瞬态和低频堆积，给高冲击段落保留与平静段落的动态差。
- 在目标播放设备与小音量条件下复核清晰度，同时检查耳机和立体声兼容。
- 响度、峰值、声道、采样和封装规格按发行平台当期要求设定，不套用单一数值。
- 输出前检查全片开头、结尾、转场、字幕、音乐授权和声画同步，保留无音乐等必要分轨版本。
- 最终母版进行完整实时观看，不用抽看替代整片技术验收。

## 七、类型与媒介创作要点

### 7.1 动作
- 优先保证人物目标、空间地理、动作因果和伤害后果清晰。
- 每段动作改变力量对比或人物关系，避免可互换的连续招式堆积。
- 用准备与反应建立期待，用节奏变化和有限信息制造紧张。
- 动作风格统一于人物能力、身体条件和世界规则，特技不替代戏剧选择。
- 安全预演、受控替身、装置检查和应急预案优先于镜头完成度。

### 7.2 悬疑
- 先确定观众相对人物知道更多、同步或更少，并稳定管理信息差。
- 悬念来自可理解的危险、时间压力和未完成行动，不只来自隐瞒事实。
- 线索须可观察、可回溯并按重要性分配强调，误导不得篡改已经明确呈现的事实。
- 每次揭示改变人物行动或观众对既有信息的理解，避免重复确认同一疑点。
- 控制解释段落长度，让答案同时兑现情感、人物和因果，而非只说明谜题。
- 声音与剪辑可延缓或提前信息，但不得无意泄露关键身份和结果。

### 7.3 喜剧
- 从人物欲望、性格偏差、关系权力和处境不匹配产生喜剧，不依赖无功能笑料堆砌。
- 建立清晰的行为规则与预期，再通过升级、错位、延迟或反转打破预期。
- 笑点前的信息必须充分，笑点后的反应必须准确，避免镜头或对白提前泄底。
- 通过对白节奏、停顿、视线、景别和剪辑共同控制时机，不只用表演放大。
- 连续笑点改变角度或提高代价，避免同一机制无变化重复。
- 保持人物对处境的认真程度，让人物行动可信而非主动讨好观众。
- 审视笑点代价与对象，避免无必要伤害削弱作品立场和人物认同。

### 7.4 爱情与关系
- 为双方建立独立欲望、生活逻辑和情感防御，使关系变化来自具体互动。
- 通过吸引、试探、靠近、误判、选择和承诺形成阶段推进。
- 关系阻力同时作用于现实条件和人物内部，不依靠可轻易澄清的误会长期拖延。
- 关键时刻用行为证明态度变化，对白只承担必要的表达与保留。
- 利用距离、触碰、视线、共享空间和声音呈现亲密程度，避免形式化甜腻。
- 冲突后必须留下新的认知、边界或代价，不能无变化复位。
- 结局依据人物此前选择决定亲密、分离或开放状态，保持情感因果完整。

### 7.5 纪录片
- 在拍摄前明确主题问题、人物进入权限、伦理边界和不可预知的开放方向。
- 以持续观察和真实行动构建叙事，不为预设结论诱导事实或制造冲突。
- 对关键事实进行多源核验，区分亲历陈述、材料证据、创作者观察和推测。
- 采访围绕经验、行动、记忆和矛盾展开，保留语境并记录时间地点与授权范围。
- 现场采集完整行动、环境、关系和空镜，避免只积累访谈而缺少可视化证据。
- 剪辑允许重组素材结构，但不得改变事件原意、因果归属和人物立场。
- 对隐私、未成年人、创伤、风险和弱势处境执行知情同意与必要保护。
- 使用重演、动画或资料素材时清楚区分其性质，避免被误认为同期事实。
- 保留原始素材、采访记录、授权、事实核查和版本修改的可追溯档案。

### 7.6 竖屏与短视频
- 首屏迅速建立人物、情境、异常或观看收益，避免无信息片头和冗长标识。
- 在前段兑现清晰的内容承诺，再以新信息、关系变化或结果期待维持观看。
- 单条内容集中一个主要目标或认知变化，多余支线转入系列结构。
- 采用短场景、明确节拍和较早转折，但仍保留关键行动的原因与结果。
- 竖屏优先中近景、纵向运动和少量清晰主体，复杂关系通过调度而非密集字幕说明。
- 字幕服务信息定位和无声观看，控制行长、停留、字号和安全区，避免遮挡面部及动作。
- 强节拍不等于持续快切，应让镜头长度与理解难度相匹配并保留关键反应。
- 系列化保持人物、问题或形式承诺稳定，各集独立成立并留下合理的后续动量。
- 依据平台数据复盘前段流失、完播、复看和互动，但不用单一指标替代内容判断。
- 发布前按平台核对时长、画幅、码率、响度、字幕、封面、版权和社区规范。

## 八、短片与短视频全流程检查表

### 8.1 立项与创意筛选
- [ ] 用一页内写明创作意图、目标观众、类型、时长、媒介和核心表达目标。
- [ ] 一句话梗概包含主人公、目标、阻力、行动与变化方向。
- [ ] 核心冲突能持续生成行动，不依赖单次巧合或结尾解释成立。
- [ ] 主要人物具有明确需求、可执行目标和必须付出的代价。
- [ ] 题材、场景、演员、动作、视效和周期在现有资源内可实现。
- [ ] 涉及真实人物、敏感事件、隐私和未成年人的内容已评估伦理与法律边界。
- [ ] 已形成三项以内的创作优先级，并确定时间、成本与质量冲突时的取舍原则。
- [ ] 立项结论明确为推进、修改后复核或停止，不以模糊状态进入筹备。

### 8.2 剧本开发与锁定
- [ ] 完成人物小传、关系图、故事梗概、分场大纲和场景卡。
- [ ] 每场戏均有目标、阻力、转折、出口状态及不可替代的功能。
- [ ] 主要转折由人物行动或已建立的外部压力造成。
- [ ] 冲突逐级升级，关键选择成本增加，高潮处理核心问题。
- [ ] 对白经过朗读，人物声音可区分，潜文本与气口明确。
- [ ] 开头建立观看承诺，结尾兑现类型与情感承诺。
- [ ] 已删除重复信息、无功能场景、不可拍描述和依赖画面重复的解释。
- [ ] 完成围读并记录时长、表演、逻辑、场景合并和制作困难。
- [ ] 完成制片拆解，标明演员、场景、道具、服化、声音、视效、动作与特殊风险。
- [ ] 锁定剧本编号与版本，后续变更通过统一记录同步所有部门。

### 8.3 视听方案与分镜
- [ ] 已形成摄影、美术、表演、剪辑和声音的统一创作阐述。
- [ ] 已确定画幅、景别体系、视点规则、镜头运动边界和色彩光线方向。
- [ ] 分镜字段完整，包含镜号、画面、动作、运镜、声音、时长与衔接。
- [ ] 对话、动作和复杂空间具有建立镜头、必要反应及补拍覆盖。
- [ ] 轴线、屏幕方向、视线、出入画和动作接点已经预审。
- [ ] 长镜头具有内部转折和完整起落幅，蒙太奇段落具有明确组接逻辑。
- [ ] 动态分镜已验证片长、节奏、理解难度和镜头可拍性。
- [ ] 竖屏或多画幅项目已检查安全区、字幕、主体与独立镜头需求。
- [ ] 虚拟制作或视效镜头已完成技术测试，并明确实拍与后期责任边界。
- [ ] 设备方案由镜头任务推导，且每个复杂方案都有可执行替代方案。

### 8.4 制片筹备与安全
- [ ] 通告计划按演员、场景、日夜、天气、转场和技术难度合理排序。
- [ ] 场地已勘景并确认尺寸、光线、电源、噪声、出入、许可和备用条件。
- [ ] 演员合同、肖像授权、场地授权、音乐与素材授权路径明确。
- [ ] 服化道清单与场景连续性状态一致，关键消耗品有备份。
- [ ] 摄影、录音、灯光、存储和供电配置经过联合测试。
- [ ] 动作、特技、车辆、火水、高处、航拍和人群场面已制定专项安全方案。
- [ ] 现场明确安全负责人、通信方式、停止条件、急救和应急撤离流程。
- [ ] 每日数据备份、运输、保管、素材命名和访问权限责任到人。
- [ ] 预算包含后期、授权、补拍、存储、字幕、交付和不可预见费用。
- [ ] 已确定天气、场地失效、演员变动和设备故障时的缩减优先级。

### 8.5 排练与技术测试
- [ ] 演员理解人物目标、行动线、关系变化和关键潜文本。
- [ ] 复杂场面已完成无镜头走调度，再进行摄影机与演员联合排练。
- [ ] 群戏的视线、分组、焦点转移、出入画和群体反应已确认。
- [ ] 运镜路线、对焦节点、起止构图、灯光变化和录音位置已实测。
- [ ] 关键服装、化妆、道具、材质和色彩在实际光线下通过镜头测试。
- [ ] 特殊帧率、快门、稳定器、车载、航拍和虚拟制作均有测试结果。
- [ ] 对白、环境、动作声和无线备份方案已验证，现场噪声有控制措施。
- [ ] 高风险动作按实际速度分级预演，未受控风险未进入正式拍摄。
- [ ] 测试素材已进入后期流程，确认编码、同步、色彩、声音和存储可用。

### 8.6 拍摄现场
- [ ] 开拍前确认剧本版本、场次目标、调度、机位、轴线和连续状态。
- [ ] 每条拍摄后检查表演、构图、焦点、曝光、运动、录音和安全。
- [ ] 关键动作保留完整主镜头及必要局部，空间变化后补建立关系。
- [ ] 记录最佳条、备选条、问题条和导演意图，场记与素材编号一致。
- [ ] 拍摄对白时覆盖必要反应、停顿和画外空间，不只覆盖说话者。
- [ ] 现场采集环境底声、独立效果和特殊动作声，并标注对应场次。
- [ ] 改变分镜时检查前后镜头、演员连续、声音和后期视效的影响。
- [ ] 每日收工前核对镜头清单、漏拍项、补拍项和次日衔接状态。
- [ ] 素材至少形成相互独立的备份并抽样验证，校验通过后才清理介质。
- [ ] 未经授权不对外发布剧照、片段、个人信息和现场敏感资料。

### 8.7 素材管理与粗剪
- [ ] 素材按项目、日期、场次、镜号和机位归档，场记、录音与视频可对应。
- [ ] 工程采用统一帧率、分辨率、色彩、音频采样和时间码设置。
- [ ] 完成同步、代理、命名、校验和备份，原始文件保持只读留存。
- [ ] 粗剪先验证场景顺序、人物行动和因果，再处理精细节奏与效果。
- [ ] 每场戏有明确进入点、转折和退出点，重复信息已删除。
- [ ] 对话空间、动作地理、视线和状态连续可被首次观看者理解。
- [ ] 已标出缺失镜头、临时素材、视效、字幕、音乐和声音需求。
- [ ] 试映记录按理解、情感、节奏和类型承诺分类，不直接照单全收意见。
- [ ] 修改优先解决结构原因，再处理镜头长度和局部修饰。
- [ ] 每次审片输出带版本、时间码和修改清单，确保反馈指向同一版本。

### 8.8 精剪、声音、调色与视效
- [ ] 精剪已控制剪辑点、反应、停顿、信息差、场景动量和整体时长。
- [ ] 转场由内容和结构驱动，未使用无动机效果遮盖衔接问题。
- [ ] 对白完成剪辑、修复和电平统一，环境与效果建立连续空间。
- [ ] 音乐进入退出有戏剧依据，未掩盖对白和关键动作信息。
- [ ] 混音保留动态层次，并针对发行端核验响度、峰值和声道。
- [ ] 调色先统一曝光、白平衡和镜头匹配，再完成风格与局部强调。
- [ ] 肤感、材质、夜景细节和高光在实际输出条件下检查，不只依赖高亮监看。
- [ ] 视效与实拍在透视、运动、景深、颗粒、色彩和光线上统一。
- [ ] 字幕、图形、片尾和署名经过文字校对，位置符合各画幅安全区。
- [ ] 所有第三方素材、字体、音乐、效果和肖像授权已归档。
- [ ] 画面锁定后的任何改动均同步检查声音、字幕、视效和交付文件。

### 8.9 试片与质量验收
- [ ] 使用目标观众进行无讲解试片，检验人物、目标、空间和转折是否清楚。
- [ ] 记录首次困惑、情绪偏离、节奏疲劳和信息遗漏出现的准确时间码。
- [ ] 区分个体偏好与普遍理解问题，修改后针对原问题复测。
- [ ] 完整检查黑场、静帧、闪烁、坏点、跳音、爆音、口型、字幕和片尾。
- [ ] 检查画面安全区、文字可读、色彩一致、声画同步和播放兼容。
- [ ] 在电脑、移动端、耳机和常见外放条件下抽查关键段落并完整母版验收。
- [ ] 类型承诺、人物弧、核心冲突和创作意图均已在成片中兑现。
- [ ] 所有审查意见已闭环，最终版本由规定责任人确认。

### 8.10 输出、发布与归档
- [ ] 按平台分别确认封装、编码、分辨率、帧率、码率、色彩、响度和文件大小。
- [ ] 横竖屏、多语言、无字幕、无障碍和分轨版本按实际发行需求输出。
- [ ] 文件名包含项目、版本、画幅、语言、日期或状态，避免使用含糊的最终版命名。
- [ ] 输出文件重新完整播放并校验时长、大小、校验值和声画同步。
- [ ] 封面、标题、简介、标签和发布文案准确反映内容，不作无法兑现的承诺。
- [ ] 发布节奏、评论回应、数据观察和下架机制有明确负责人。
- [ ] 复盘区分内容、结构、画面、声音、包装、发布时间和受众匹配因素。
- [ ] 数据结论用于提出下一轮假设，不将相关性直接当成创作因果。
- [ ] 归档剧本、分镜、合同授权、工程、原始素材、母版、分轨、字幕和修改记录。
- [ ] 至少保留主归档与独立备份，定期抽检可恢复性并控制敏感资料访问权限。
