## 二、通用执行主流程（所有产品共用）

```
P1 解析需求      → core-01 §1 槽位表；确定产品 ID 与硬约束
P2 美学定位      → core-01 S1–S5，产出「美学定位卡」
P3 交付规格选择  → 本文件对应 ID 的规格段，确定字段与输出结构
P4 领域执行      → 调用 domain/ 或 scene-* 的子流程，逐项填参数
P5 创作深化      → core-07：三层递进 / 意境四步 / 象征隐喻 / 审美心理
P6 形式与色彩落地 → core-04 画面形式六法 + core-03 取色 + core-08 八意识
P7 质量门禁      → core-10：三重校验（领域正确性 / 审美哲学 / 体系一致性），不过则回 P4–P6
P8 交付          → 按模板输出，附定位卡、〔推断〕/〔补全〕清单、校验结论
```

**不得跳步**。尤其 P2 与 P7：没有定位卡的方案不产出，没过门禁的不交付。

## 三、各产品交付规格与子流程

### A · 文章 / 散文 / 随笔

- **规格**：标题（含备选 2）／正文／小节节奏／创作说明（灵魂点、动机、审美定调）／审美校验记录。
- **子流程**：`domain/writing/writing-map.md` 定位动机与灵魂 → inspiration-guide.md（低输入时）→ genre-playbook.md 选体裁结构 → aesthetics-rhetoric.md 配修辞与审美距离 → 生成正文 → revision-checklist.md + aesthetics-checklist.md 双清单修改。
- **美学注入点**：意境四层（情景交融/虚实相生/境生象外/得意忘言）；留白=不把话说尽；感官词汇通道与体系一致（东方重味觉/触觉/气，西方重视觉/比例）。
- **验收**：读完后有「余味」而非只有信息；无术语堆砌；体系对应的句式节奏成立（东方短句多停顿，西方长句多逻辑连接）。

### B · 小说 / 故事

- **规格**：人物关系／三幕或起承转合骨架／完整文本（或首章＋后续大纲）／意象系统表／审美定调。
- **子流程**：`domain/writing/writing-map.md`（故事思维、灵魂、视角）→ genre-playbook.md → `domain/video/剧本.md` 类结构可参考「目标-阻碍-努力-结果-意外-转机-结局」→ 意象系统按 `core-07` 象征四法布置 → 交付前双清单。
- **美学注入点**：核心意象贯穿（境生象外）；空缺与省略承担节奏；物哀/无常用细节而非抒情直说。
- **验收**：意象有回环；情绪曲线与体系节奏一致；不以形容词密度冒充文采。

### C · 广告文案 / 品牌叙事 / 演讲稿 / 论文

- **规格**：核心主张／主文案（含多版本）／延展文案／调性说明／审美与合规校验。
- **子流程**：同 A，另加「期望结果」约束（《其他参考.md》：缓解焦虑、引发共鸣、带点正能量、幽默后反省、哭完振作、看完思考）。
- **美学注入点**：品牌气质映射到体系色板与字体气质；文案留白给读者补足。
- **验收**：主张可复述；调性与定位卡一致；无浮夸炫示性表达。

### D · 长视频分镜脚本（>3 min / 影视片段）

- **规格**：导演阐述／场景表／逐镜分镜表（镜号/时长/景别/机位/运镜/构图/光影/色彩/道具/表演/声音/转场）／情绪曲线／审美形态与三层递进骨架／拍摄清单。
- **子流程**：`domain/video/` 全流程——emotion-map.md 定情绪 → aesthetic-forms.md 定形态与全片节奏 → shooting-kit.md 查道具/场景/色彩/运镜/构图/光影 → cinematic-language.md 做蒙太奇与转场 → performance.md 给表演指导 → aesthetic-creative.md 深化 → aesthetic-checklist.md 校验。
- **美学注入点**：按 `core-00` 第三部分定全片空间逻辑（东方散点游观＝长镜头卷轴感；西方焦点＝明确轴线与 30° 法则；伊斯兰无限＝循环往复的纹样式节奏）。
- **验收**：镜头语言四要素齐备（故事/角色/好奇/共鸣）；无同景别堆砌；色彩跨镜头连贯；光影逻辑与体系一致。

### E · 短视频分镜脚本（≤3 min，含 30 秒示例）

- **规格**：钩子（0–3 s）／逐秒或逐镜表／卡点节奏／声音轨（环境音/BGM/效果音/台词）／字幕与版式／结尾余韵／发布平台适配。
- **子流程**：同 D，节奏改用 `domain/video/爆款内容特点.txt` 提炼的「失衡→蓄力→爆发→命中→余震→控制」爽点公式与主情绪映射；30 秒建议 6–10 镜，单镜 2–5 s，避免 >12 镜。
- **美学注入点**：**留白在时间里**——给 1 个空镜或静默拍（0.5–1.5 s）作「气口」；东方意境类结尾用淡出/空镜承情而非硬切；声音留白与画面留白同步。
- **验收**：前 3 秒有明确钩子；有时间气口；声音不是全程铺满；符合平台画幅（9:16 为主）。

### F · 单张照片拍摄方案

- **规格**：情绪与形态定位／视觉方案表／创作手法／摆姿详述／表情眼神／布光方案／构图设计／拍摄参数／引导话术／校验结论。
- **子流程**：`domain/photo/` 全流程——emotion-map.md → aesthetic-forms.md → pose-library.md + expression-guide.md + composition-guide.md + lighting-guide.md + scene-styling.md → aesthetic-creative.md → 双重校验。
- **美学注入点**：`core-04` 画面审美六法全量适用；体系决定光影（东方意象光 / 西方塑造体积 / 伊斯兰切割光）。
- **验收**：参数与情绪同向；环境可行性优先；有引导话术；不落糖水片/网红脸套路。

### G · 一组照片 / 系列写真

- **规格**：整体主题／情绪曲线／视觉统一约定／逐张清单（编号/主题/景别/摆姿/表情/构图/布光/道具/情绪作用/审美层级）／变化维度／过渡说明。
- **子流程**：同 F，另用 `core-07` 三层递进作曲线骨架（养眼开场 → 养心铺陈 → 养神收尾）。
- **美学注入点**：景别递进（远→全→中→近→特）对应「游观」；整套一次「破」（八意识之破，≤1 处）。
- **验收**：无同景别同姿态堆砌；色值跨张连贯；有起承转合。

### H · 海报方案

- **规格**：版式栅格与视觉动线／信息层级（主标题/副标/正文/落款）／字体方案（族数 ≤2、字阶）／色板（60-30-10，含色名 HEX）／主视觉描述／留白比例／尺寸与出血／材质工艺建议／系列延展规则。
- **子流程**：见本文件 §4「平面通用子流程」。
- **验收**：3 米外可读主信息、30 cm 内有细节；破格 ≤1 处；对比度达标。

### I · 封面 / 装帧

- **规格**：封面／书脊／封底／勒口／开本与版心／纸张与工艺（烫印、压凹、专色、裸脊）／系列延展（同套书识别系统）／书名字阶与留白。
- **子流程**：§4 ＋ scene-13-graphic.md；触觉层按 `scene-11` 材质原则。
- **美学注入点**：东方体系「素底＋单点」、明清/波斯「满地纹＋边框叙事」、西方「网格＋强对比」三者不可混用；书脊在书架上的连续纹样是系列感关键。
- **验收**：缩略图（电商 200px）仍可识别；材质与体系气质一致；无信息过载。

### J · 互联网产品 UI / 网站 / 落地页 / 仪表盘

- **规格**：信息架构／页面结构／设计 Token（色/字/间距/圆角/动效）／关键组件／响应式与无障碍／可运行代码或高保真描述／设计说明。
- **子流程**：`domain/ui/` 全流程——design-system.md（三层内核：L1 意境 / L2 比例 / L3 感知）→ eight-aesthetics.md（八意识量化）→ aesthetic-creation.md（L0 立意）→ examples.md → `assets/tokens.css`。
- **美学注入点**：**先把 `core-00` 的体系逻辑映射到三层内核**——东方→L1 强（留白/阴翳/季节感）；西方→L2 强（黄金分割/网格/模数）；伊斯兰→纹样层与「无限延伸」的信息组织，但**仍须满足可读性与 WCAG**。
- **验收**：正文对比度 ≥4.5:1、大字 ≥3:1、UI 图形 ≥3:1；同屏字体 ≤2 族；焦点环可见；状态不只靠颜色；作品展示站执行 `core-01` §5 中性容器原则。

### K · 室内设计 / 空间方案

- **规格**：空间叙事（一句话立意）／平面动线与停留节奏／分区／材质表（温润粗朴/冷硬精工按体系）／光方案（自然光时变＋人工光层次）／声景与气味／陈设清单／四时变化／落地约束。
- **子流程**：scene-11-space.md。
- **验收**：动线有收放（抑→扬）；实体退让给「空」；光不均匀、以暗托明；声景为寂静划轮廓而非填满。

### L · 园林 / 庭院设计

- **规格**：立意与游观动线／造景手法表（借/框/漏/夹/对/障/添/藏）／叠山理水／植物与四时／铺装与纹样／视线经营图／亭榭点位／夜景光。
- **子流程**：scene-11-space.md §园林专章；明清美学的「移步换景」与侘寂的「枯山水」按 `core-00` 分派。
- **验收**：不一览无余；有「小中见大」；借景有明确对象；四时皆有可看之处。

### M · 造景 / 陈设 / 展陈 / 装置

- **规格**：主题与叙事线／视线经营（主视点/次视点/拍点位）／前中后景层次／材料与质感／光影与时间／可拍性（出片位）／安全与动线。
- **子流程**：scene-11-space.md §造景专章 ＋ `core-04` 画面审美六法（把三维场景当一幅可进入的画）。
- **验收**：至少一处框景/借景；有单焦点；留白处可容纳人；不堆砌符号。

### N · 声景 / 听觉 / 配乐 / 多媒体

- **规格**：声音立意／声源清单（环境音/效果音/音乐/人声/静默）／层次与响度／频谱与音色／时间节奏与留白／通感映射表（听觉↔视觉/触觉/嗅觉）／与画面的对位关系。
- **子流程**：scene-12-audio.md。
- **美学注入点**：**声音留白是高级感的核心**——以稀声反衬寂静（「蝉噪林逾静」）；东方用泛音、余韵、非均等节拍；西方用主题动机与和声推进；伊斯兰用循环与无限节奏。
- **验收**：不是全程铺满 BGM；至少有 1 处刻意静默；声源有远近层次；与体系的空间逻辑同向。

## 四、平面通用子流程（H / I 共用，也可供 J 首屏参考）

```
1 定信息层级：主信息唯一，其余按 1 : 0.618 : 0.382 递减，禁止多个同级主角
2 定栅格与版心：西方体系用黄金分割/网格；东方用偏置与气口；伊斯兰用中心辐射/无限网格
3 定留白：色彩留白（减色相、降饱和、素色托主体）／构图留白（减形、偏置、省略环境）
         ／光影留白（减信息、光不平均、以暗托明、以雾遮形）——core-04 §2
4 定视觉动线：主体确定 → 具象引导（路、河、枝）／抽象引导（色块、光影、透视、手势眼神）
             → 串联次要重点（core-04 §6）
5 定色：core-03 取色，60-30-10，高饱和面积 ≤10%，点睛色 ≤1 处
6 定字：族 ≤2，字阶按体系节奏（东方疏朗/西方紧凑），行距不小于字高 1.5 倍（东方宜更大）
7 定质感：纸纹/绢纹/粗陶/金属/玻璃/琉璃按体系材质观选一，不混搭超过 2 类
8 校验：3 米可读性、缩略图识别度、对比度、破格数量、core-10 全部条目
```

## 六、组合交付（常见）

| 用户要的 | 组合 | 统一方式 |
|---|---|---|

| 一支片子从脚本到宣发 | D/E + H + F | 分镜定主视觉帧，海报取该帧构图，剧照按 F 规格补拍 |
