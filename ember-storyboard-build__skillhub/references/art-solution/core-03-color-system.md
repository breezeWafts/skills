# 三大传统色体系与取色规范

> 色彩是「体系落地」最快也最容易出错的一环。本文件把工作区 `素材/` 目录三套真实色表转成可执行的取色规范。
> **铁律**：所有色值必须能溯源到「色库色名 + HEX」或 `core-00` 流派色表；禁止凭感觉写「差不多是这个蓝」。

| **日式传统色** | 250 色 | NIPPON COLORS（nipponcolors.com） | `日式传统色.csv` / `.json` / `.md` | `色卡/NNN_ROMANJI.svg`（250 张） | `日式传统色-色板.svg` / `-色板预览.png` |

### 字段口径（务必先看，三套不同）

- **中国传统色**：`色名 / 拼音 / HEX / RGB / CMYK`。HEX 为**权威值**（屏幕取色、设计使用一律以 HEX 为准）；8 条颜色 HEX 与原站 RGB 不一致，表中已保留原值并标注，**不得自行换算修正**。CMYK 是印刷参考配方，与 RGB 非标准色域换算关系（平均通道偏差约 21/255），**禁止用 CMYK 反推屏幕色**。
- **日式传统色**：`色名 / 读音 / HEX / RGB / CMYK`，HEX 为站点 `rgb` 字段原值；CMYK 同为印刷配方参考（平均偏差约 18.7/255），口径同上。
- **伊斯兰色**：**不是逐色命名传统色表**，而是 6 组预设配色方案（清真寺 / 书法 / 沙特国旗 / 斋月 / 蔓藤纹 / 沙漠）。`名称 = 方案译名 · 色序`；HEX 是唯一由站点直接提供的值，RGB 与 CMYK 均为派生值。其 CMYK 为无 ICC 的标准换算，**口径与前两套不同，不可混用**。

> 印刷交付：一律以实物打样与印厂 ICC 为准；screen 设计只报 HEX。

## 四、取色五步法

```
1 定色彩观念：先查 core-00 第三部分——
   东方=观念色（服务伦理/心境）／伊斯兰=神学编码色／西方=科学光学色
2 选色库：按 §2 映射，一套方案只进一个主色库
3 定结构：60-30-10（主 60% / 辅 30% / 点睛 10%）
   · 高饱和面积 ≤10%（含点睛色）
   · 点睛色在单幅/单屏中 ≤1 处（八意识之「破」）
4 定明度优先：先确定明度层级与对比关系，再调色相；
   东方体系明度差宜小（柔和），西方宜大（体积），伊斯兰靠反光与琉璃提亮
5 复核：可读性对比度、跨帧/跨页色值连贯、名实一致（色名与用途气质相符）
```

**名实一致**：不要把「月白」用作热烈主色，也不要用「赭石」表达清冷；传统色名自带文化语义，误用比乱取色更伤高级感。

**对比度硬指标（UI / 图文 / 海报文字）**：正文 ≥ 4.5:1，大字 ≥ 3:1，UI 图形 ≥ 3:1（WCAG 2.1 AA）。传统色多为低饱和浅色，**作文字时通常不达标**，应改作背景，其上文字另取深色（如 `#5E7075`、`#1C1C1C`）。状态不得只靠颜色区分。

## 五、色彩心理速查（跨体系通用底层）

来源：工作区《应用-电影视频/情绪/03色彩.txt》与《表达.txt》，用于「被动感受意境」路径。

| 维度 | 取值 → 心理效应 |
|---|---|
| 色相 | 红＝心跳加快、癫狂／欲望／危险；蓝＝理智、忧郁、成长；金黄＝热烈情感；绿＝诗意自然、纯真、希望；紫＝神秘梦幻、诱惑；橙＝温暖、苍凉；黑白＝深沉、反思、怀旧、艺术象征 |
| 色温 | 冷色＝寒冷与漫长、疏离、贫穷；暖色＝温暖和谐、富足 |
| 饱和度 | 轻快色调＝心情愉悦；高饱和高对比＝情感热烈；**低饱和莫兰迪＝高级与宁静** |
| 明度比例 | 高调＝轻、空、明亮；低调＝重、实、幽玄；黑白位置决定视觉重量 |

**体系化修正**：西方按上表直接用（科学色/视觉心理）；东方须先过「观念色」过滤（宋尚青、水墨为上、五色令人目盲），伊斯兰须先过「神学编码」过滤（绿/蓝/金/白各有固定象征，不得按情绪随意改）。

## 六、反模式

1. **为「高级感」一律降饱和**——明清、波斯、构成主义恰恰需要高饱和与强对比；降错体系等于抹掉流派。
2. **传统色名当装饰词**——写「天青」却给 `#4A90D9`，名实不符。
3. **多套色库混取主色**——中式色名 + 日式色名 + 伊斯兰方案各取一色拼成主色板，文化语境断裂。
4. **点睛色泛滥**——朱砂、金、高饱和到处点，破坏「破至多 1 处」的秩序。
5. **忽略印刷口径**——把站点 CMYK 当屏幕换算或反之，导致打样偏色。
