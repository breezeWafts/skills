# 六大审美形态 · 跨媒介统摄表

> 来源：`domain/photo/aesthetic-forms.md`、`domain/video/aesthetic-forms.md`、`domain/ui/aesthetic-creation.md` 的合并统一版，并把参数从「摄影/分镜」扩展到**全部 14 类交付物**。
> **地位**：`core-01` S4 定位「主形态」时以本表为准；一个方案以一种形态为主，避免调性混乱。

## 一、形态全景

| 阵营 | 形态 | 核心心理 |
|---|---|---|
| **正价值**（主体 ≥ 客体） | 优美、悲剧、崇高 | 主体得以确证、提升 |
| **负价值**（主体 < 客体） | 丑、喜剧、荒诞 | 主体否定对象、获得释放 |
| **中国独尊** | 意境 | 情景交融、境生象外 |

**选用流程**：主情绪 → 形态（§3）→ 风格取向（象征型 / 古典型 / 浪漫型，见 `core-07`）→ 全案节奏（§4）→ 参数同向性校验。

## 二、六形态速查（内核 → 跨媒介参数）

### 2.1 优美 Grace / Beauty

- **内核**：和谐平静、形式完美，主客和谐统一，对人的本质的**直接肯定**。静态和谐美。
- **心理**：平静、愉悦、宁静；与爱、同情相连。
- **通用参数**：对称 / 三分 / 均衡结构；柔和漫射光、低光比；相似色或单色、低饱和、明快清透；舒展的钝角线条；中近景、主体完整；节奏均匀舒缓；声音以中频、圆润、无突兀峰值为宜；文字句式匀停。
- **适配情绪**：温暖、治愈、松弛、幸福、日常之美。
- **避坑**：流于「糖水片 / 甜腻文案」——只有形式讨好而无情感内核。必须补一层「养心」（见 `core-07` 三层递进）。

### 2.2 崇高 Sublime

- **内核**：主体与客体对立冲突后趋于统一，是**间接的愉快**（由痛而快）；人的本质力量经对象震撼压抑后显现。动态冲突美。
- **两类**：数量的崇高（体积巨大：大海、星空、崇山、无垠荒原）；力量的崇高（威力巨大且人无法抵抗）。
- **通用参数**：低机位仰拍 / 巨物尺度对比 / 强明暗交界 / 高反差 / 断裂与对角线动势；色彩可高对比或极简到近乎单色；节奏为「积累 → 压迫 → 释放」；声音用低频、大动态范围、留一段压迫性静默再进入；文字用「先阻后扬」的长句推进。
- **适配情绪**：敬畏、震撼、辽阔、史诗、庄严、孤绝的抗争。
- **避坑**：只有大场面没有「由痛而快」的过程。MUST 写出主体被压抑后再被提升的转折。

### 2.3 悲剧 Tragic

- **内核**：有价值的东西被毁灭，主体在痛感中获得尊严与确证。
- **通用参数**：低明度、冷调或褪色；构图偏压抑（框架、遮挡、下沉重心）；节奏缓慢而不可逆；光影以暗托明；文字克制、不煽情，用细节承载痛感；声音稀疏、多留白。
- **适配情绪**：伤逝、遗憾、无常、怀旧、怅惘。
- **避坑**：以眼泪和形容词堆情绪。**悲剧的尊严来自克制**。

### 2.4 喜剧 / 幽默 Comic

- **内核**：主体以透明错位否定对象，获得轻松的释放。
- **通用参数**：错位、反差、重复与打破；明快中高饱和；节奏快、有明确的「 setup → punch 」；构图可倾斜、可打破均衡；文字用反转、方言梗、身份不匹配；声音用突停与意外音效。
- **适配情绪**：轻快、荒诞感、笑完后反省。
- **避坑**：只为笑而笑。按《其他参考.md》的期望结果，最好留一点「笑完之后反省」。

### 2.5 丑 / 荒诞 Ugly / Absurd

- **内核**：主体被客体压倒，形式失序、意义断裂，获得否定性的释放。
- **通用参数**：非对称、断裂、畸变、失衡构图；不和谐色并置；非线性、重复而无进展的节奏；文字用间离、不可靠叙事；声音用不协和与错位。
- **适配情绪**：不安、迷惘、荒诞、黑色幽默。
- **避坑**：把「丑」当「随便做」。荒诞需要严格的内部结构，否则只是乱。

### 2.6 意境 Yijing（中国独尊）

- **内核**：情景交融、虚实相生、境生象外、得意忘言；意义在空处发生。
- **通用参数**：**留白三法至少两法**（色彩/构图/光影留白）；意象光、散点游观、非对称偏置；低饱和素色；单焦点；慢节奏，结尾留余韵；声音以稀声反衬寂静；文字用具体物象代替抒情，不写尽。
- **适配情绪**：平静、禅意、空灵、怅然、物哀、幽玄。
- **避坑**：符号堆砌（月亮门＋竹子＋青瓷＋书法却无气口）；把「空」当「少」。意境 MUST 有「观者以想象补足」的位置。
- **生成四步**：立意 → 择象 → 布虚 → 留余（见 `core-07` §4）。

## 四、形态 → 全案节奏策略

| 形态 | 起 | 承 | 转 | 合 | 结尾处理 |
|---|---|---|---|---|---|
| 优美 | 平稳进入 | 均匀铺陈 | 轻微起伏 | 回归和谐 | 收拢、温暖落点 |
| 崇高 | 压迫/渺小 | 持续积累 | 爆发/释放 | 主体被提升 | 有重量的收束，忌轻飘 |
| 悲剧 | 埋下珍贵 | 缓步失去 | 不可逆的毁损 | 尊严的余烬 | 留白，不解释 |
| 喜剧 | 建立常规 | 重复强化 | 一次错位 | 释放 | 可留一句余味 |
| 荒诞 | 失衡 | 无进展循环 | 意义断裂 | 不解决 | 开放式，忌强行圆回 |
| 意境 | 择象、远观 | 情景渐融 | 布虚、留气口 | 境生象外 | 淡出/空镜/静默/不写尽 |

> 短视频（E 类）把上述四段压缩为 0–3 s / 3–15 s / 15–25 s / 25–30 s；**意境型必须留 0.5–1.5 s 空镜或静默作「气口」**。

## 五、形态参数的「同向性」校验（P7 必过）

对交付物中每一项参数问一句：「它的情绪含义与主形态同向吗？」

| 主形态 | 同向示例 | 冲突示例（须修正） |
|---|---|---|
| 意境 | 冷调、大留白、长镜头、空镜承情、淡出 | 快切卡点、满构图、高饱和撞色、硬切收尾 |
| 崇高 | 低机位仰拍、巨物对比、积累蒙太奇 | 平视中景、均匀柔光、轻快 BGM |
| 优美 | 对称、柔和漫射光、相似色、钝角线条 | 断裂构图、锐角、阴阳脸、强撞色 |
| 悲剧 | 低明度、慢节奏、克制文字 | 密集笑点、明快高饱和 |
| 喜剧 | 错位、快节奏、反差 | 长镜头凝视、压抑低频 |
| 荒诞 | 断裂、非线性、不协和 | 严整对称与闭合叙事 |

冲突时以本表和 `core-00` 的体系逻辑裁决；若确需反差制造张力，**必须在方案中写明「此处刻意反向，目的为……」**。

## 六、与体系的关系（不要混淆）

- **体系**（`core-00`）回答「用哪套文化逻辑看世界」；**形态**（本文件）回答「让观者产生哪一类审美经验」。二者正交，可自由组合。
- 常见组合：东方·宋 × 意境（默认）／东方·明清 × 优美／西方·哥特 × 崇高／西方·印象派 × 优美／西方·构成主义 × 崇高或荒诞／伊斯兰·阿拔斯 × 崇高（秩序与无限）。
- **不建议**：伊斯兰体系 × 荒诞（与「完美秩序、拒绝残缺」的终极目标冲突）；东方·宋 × 喜剧中的强闹感（可轻幽默，不宜失序）。
