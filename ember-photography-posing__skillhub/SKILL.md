## 〇、美学总纲（ember-art-solution 统摄 · v2.2.0）

### 0.1 新增前置动作 · 美学体系定位（不得跳过）

在原有工作流最前面执行：从用户给的「风格 / 氛围 / 感觉」或内容题材，按 `references/art-solution/core-01-style-router.md` S1–S5 产出**美学定位卡摘要**——主体系（东方 / 西方 / 阿拉伯-伊斯兰）→ 三级流派（`core-00`）→ 底层逻辑四条（色彩观念 / 光影处理 / 空间构图 / 终极目标）→ 主情绪与审美形态（`core-06`）→ 色板（色名＋HEX，`core-03`）→ 目标观者反应。

1. **参数映射阶段**：在既有情绪/形态同向性之外，追加「体系→布光/构图/色彩 同向性」，逐项核对 `core-00` 第三部分；冲突时以体系逻辑裁决，若刻意反向须写明目的。

## Overview

把「环境 + 情绪 + 拍摄对象」转化为「一份可直接执行的专业拍照方案」。核心逻辑是**情绪 × 环境 × 审美形态 → 静态视觉语言**：先锁定情绪、环境，并**定位审美形态**（优美/崇高/悲剧/喜剧/荒诞/意境），再反推摆姿、表情眼神、构图景别、机位画幅、布光光质、色彩道具、场景搭配，**以美学理论深化创作**（三层递进、意境生成、象征隐喻），最后组装成**单张精拍方案**或**套图系列方案**，并叠加**东方意境美学 + 审美哲学双重校验**。

v1.2.0 起新增审美创作能力：方案不止"技术正确、看起来美"，更要有**审美纵深**——从养眼（形式）到养心（情感）到养神（意境），让每一张照片有理论依据、有情感内核、有余味。知识来源于内置摄影知识库（源自飞书「摄影摄像」知识库汇总）、evan-design 东方美学，以及《美的历程·美学导论》《美学原理 30 讲》两套美学理论；未覆盖部分按人像摄影专业惯例补全并标注。

**与视频分镜 skill（ember-storyboard-build）的区别**：本 skill 面向**静态瞬间**——核心是摆姿、表情、构图与布光，输出是单张或套图方案，不产出运镜/时长/蒙太奇等动态分镜要素（景别/机位等静态要素仍复用）。

**输入**：环境或场景 + 情绪或主题 + 拍摄对象（可选：单张/套图、人数、性别、用途/平台、画幅、服装、拍摄时间）。
**输出**：结构化拍照方案（Markdown 文档），含情绪分析、审美形态定位、视觉方案表、创作手法、摆姿详述、布光方案、构图设计、拍摄参数、引导话术、双重审美校验。

## 前置条件

**无外部依赖。** 纯知识型 skill，不调用 MCP、API、网络。所有知识内置于 references/。

## 执行工作流（按顺序，不可跳步）

### Step 1 · 解析需求与类型

从用户输入中提取：
- **环境/场景**：如「旧街道」「咖啡馆落地窗」「海边日落」「室内白墙」「废墟」「雨中」。用户未给出时，按情绪推荐 1–2 个适配场景并说明依据，不打断询问。
- **情绪/主题**：要表达的核心感觉（如 孤独、松弛、炽热、期待、禅意）。
- **拍摄对象**：单人 / 情侣 / 闺蜜 / 家庭 / 婚纱 / 儿童；性别与气质倾向。
- **类型**：**单张**（一张精拍，深挖细节）/ **套图**（4–12 张系列，有主题、情绪曲线与景别节奏）。用户未指定时按内容判断：单一情绪 + 单一场景 → 单张；有故事线 / 多情绪 / 多场景 / 明确写真需求 → 套图，并在交付时注明判断依据。
- **可选约束**：画幅（3:4 / 4:5 / 9:16 / 1:1 / 16:9）、用途平台（小红书 / 朋友圈 / 写真 / 商业）、服装风格、拍摄时段（黄金时刻 / 正午 / 蓝调 / 夜景）。

若用户只给一句话（如「在旧书店拍一个孤独的女孩」），直接补全合理情境，不打断询问。

### Step 2 · 情绪分析 + 审美形态定位（核心）

1. **情绪坐标**：
   - **主情绪**（1 个）：参考 `references/emotion-map.md` 的 8 大情绪词族定位。
   - **情绪强度**（弱 / 中 / 强）与**情绪关键词 3–5 个**。
   - **环境—情绪关系**：判断环境本身传递的情绪，是需要**顺应强化**（暖光小馆→温馨）还是**反差制造张力**（喧闹街头→孤独）。反差方案须在方案中说明。
2. **审美形态定位**（v1.2.0 新增）：依据主情绪，从 `references/aesthetic-forms.md` 的「情绪→审美形态映射表」定位**主形态**（优美/崇高/悲剧/喜剧/荒诞/意境）与备选形态，并确定风格取向（象征型/古典型/浪漫型，见 `references/aesthetic-creative.md` 第三节）。一个方案以一种形态为主，避免调性混乱。

> 触发条件：情绪与形态判断必须有依据——先读 `references/emotion-map.md` 按词族定位情绪，再读 `references/aesthetic-forms.md` 定位审美形态，不得凭空指定。

### Step 3 · 情绪 + 环境 → 视觉方案映射

依据主情绪、环境与审美形态，从知识库查表匹配全部视觉参数（**每一项都要有出处或补全标注**）：

| 维度 | 来源参考文件 |
|------|-------------|
| 审美形态 / 风格取向 | `references/aesthetic-forms.md`、`references/aesthetic-creative.md` |
| 摆姿（体态/四肢/站坐蹲躺/互动姿势） | `references/pose-library.md` |
| 表情 / 眼神 | `references/expression-guide.md` |
| 构图 / 景别 / 机位 / 画幅 | `references/composition-guide.md` |
| 布光（自然光/人造光/光质/光位/光比/辅具） | `references/lighting-guide.md` |
| 场景 / 背景 / 道具 / 配色 | `references/scene-styling.md`、`references/aesthetics-evan-design.md` |

映射原则：
- **情绪→视觉的一致性**：每个参数的情绪含义必须与主情绪同向（例：孤独→冷调、大远景、疏密留白、背面机位、低调硬光、芦苇/荒原意象）。冲突时以 `references/emotion-map.md` 的映射表为准。
- **形态→视觉的同向性**：全部参数还须与 Step 2 定位的审美形态同向（例：崇高→巨物对比、低机位仰拍、强明暗；意境→虚实相生、留白、单焦点）。
- **环境优先约束**：布光与构图必须适配给定环境（室内窗边不套用正午顶光方案，夜景不套用黄金时刻方案）；当理想参数与真实环境冲突时，以环境可行性优先，并给出替代方案。
- **自然光优先**：优先评估可用自然光；自然光不足或需强化情绪时才引入补光/人造光，并明确标注补光方式。
- **补全规则**：知识库无对应条目时，按相关专业惯例补全，并在方案该行标注「〔补全〕」。

### Step 4 · 构建拍照方案

按 Step 1 的类型选择输出结构（模板见 `references/output-template.md` 与 `assets/photo-plan-template.md`）：

**单张精拍方案**：
- 视觉方案表（**审美形态定位** + 摆姿/表情/构图/机位/景别/画幅/布光/色彩/道具/场景）
- **创作手法**（Step 5 产出，见下）
- **摆姿详述**：按头—手—身—腿分部位描述，应用「三面法则」（破面/破线），给出最终定格姿态
- **表情眼神**：具体表情 + 眼神方向 + 情绪依据
- **布光方案**：光型光位 + 光质光比 + 辅具 + 文字光位示意；室内/室外分别说明
- **构图设计**：画幅、景别、机位高度、构图法、留白比例、视觉焦点、前中后景
- **拍摄参数建议**：焦段 / 光圈 / 快门 / ISO / 白平衡参考值（标注〔通用参考〕，强调按现场测光调整）
- **引导话术**：3–5 句可直接对拍摄对象说的引导语

**套图系列方案**：
- 整体主题、情绪曲线（弱→中→强→落）、视觉统一约定（同一色调 / 服装 / 光向 / 场景）、**审美形态与三层递进骨架**（可用"养眼开场→养心铺陈→养神收尾"作情绪曲线骨架）
- **系列清单**：逐张给出 编号 / 主题 / 景别 / 摆姿 / 表情 / 构图 / 布光 / 道具 / 情绪作用 / 审美层级
- **变化维度**：景别递进（远→全→中→近→特）、姿态变化（站→坐→倚→卧）、情绪递进、光线时段或光位变化，避免同景别同姿态堆砌
- 每张拍摄要点与承上启下的过渡

### Step 5 · 审美创作深化（v1.2.0 新增 · 核心创作能力）

调用 `references/aesthetic-creative.md`，为方案注入审美纵深，产出方案中的「创作手法」项：

1. **三层递进设计**：明确本方案在养眼（形式美）/养心（情感移入）/养神（意境）各层如何着力；单张至少养眼+养心，意境/禅意主题须达养神；套图可用三层作情绪曲线骨架。
2. **意境生成**（意境类必做）：用情景交融、虚实相生、境生象外三法，把情绪变成可拍的"象与境"，写明情如何注入景、虚实在哪里、画外余味是什么。
3. **象征与隐喻**：必要时用浓缩/移置/象征/润饰四法设计道具与意象，标注 `〔象征〕`。
4. **审美心理设计**：让力的结构（线条/方向/张力）与情绪同构（格式塔）；设置恰当审美距离；用移情、内模仿/通感调动观者；追求"瞬间中的永恒"。
5. **落笔格式**：每条创作手法写 `层级定位 + 具体手法 + 理论依据 + 预期观者反应`（示例见 aesthetic-creative.md 第七节）。

> 该步骤是"方案更丰富、更具审美、更专业"的关键，不可省略。创作手法写入方案后，才进入校验。

### Step 6 · 双重审美校验

依次对照两份清单，**任一不通过则回 Step 4–5 修正**：

1. **审美哲学质量**（`references/aesthetic-checklist.md`）：康德四契机（非功利/非概念/无目的合目的/共同感）；美感非纯快感（不止于"养眼/糖水片"）；反套路（无网红脸/炫示性消费/审美疲劳）；审美形态定位明确且参数同向；意境三要素齐备；创作深度达标（三层递进、格式塔同构、审美距离、通感）。
2. **东方形式气质**（`references/aesthetics-evan-design.md`，把「全片」理解为「整组照片」）：L1 意境（留白/侘寂/物哀/幽玄/禅）；八意识（间/素/秘/并/微/气/假/破，破至多 1 处标注 `ha`）；L2 比例（三分/黄金分割）；L3 配色（60-30-10）。

冲突裁决优先级：间/素/秘（气质）＞并/破（秩序）＞微/气/假（感知）＞审美哲学细项。任一照片违反「破不滥用」「单镜焦点≤1」须修正。

### Step 7 · 输出交付

1. 生成完整拍照方案 Markdown，保存到 `outputs/` 目录（单张：`<主题>-拍照方案.md`；套图：`<主题>-套图方案.md`）。
2. 用文件展示工具呈现给用户。
3. 正文末尾附：情绪与审美形态分析摘要、视觉方案表、创作手法、〔补全〕项清单、双重审美校验结论。
