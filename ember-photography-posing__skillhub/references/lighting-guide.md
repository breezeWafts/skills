# 布光方案知识库（自然光 / 人造光）

拍照方案的布光核心库。第一部分源自飞书摄影知识库·光影（情绪含义表），人造光光型、光质光位光比、辅具按人像摄影专业惯例补全（标注〔补全〕）。Step 3 按情绪查用，Step 4 落地布光方案。**原则：自然光优先，人造光服务于情绪；一切布光选择都要能说清情绪依据。**

## 一、光的三要素（〔补全〕）

| 要素 | 说明 | 情绪影响 |
|------|------|---------|
| **光质** | 硬光（方向性强、边缘锐、阴影硬）/ 柔光（漫射、过渡柔、阴影柔） | 硬光→冲突、力量、戏剧、质感；柔光→温柔、私密、治愈 |
| **光位** | 光相对主体的方向：顺/侧/侧逆/逆/顶/底光 | 决定面部结构与明暗分布 |
| **光比** | 亮部与暗部亮度比（1:1 柔 → 1:8+ 戏剧） | 低光比→平和温柔；高光比→强烈对立、神秘 |

## 二、自然光方案（优先）

| 自然光 | 特点 | 适配情绪 / 用法 |
|--------|------|----------------|
| 黄金时刻（日出日落） | 暖金、低角度、长影、柔和 | 温暖、浪漫、憧憬、崇高；逆光拍金边发丝光 |
| 蓝调时刻（日落后） | 冷蓝、天空与灯光平衡 | 孤独、静谧、都市情绪；配合环境灯光 |
| 阴天散射光 | 天然柔光箱、无硬影、均匀 | 温柔、平静、治愈、极简；适合特写 |
| 柔和窗边光 | 私密、过渡柔、方向感 | 温柔、脆弱与坚韧并存、居家疗愈；经典人像 |
| 逆光 / 边缘光 | 金边轮廓、眼神光、光晕 | 希望、神圣、憧憬、生命力；需反光板/补光打亮面部 |
| 树影 / 斑驳光 | 光影斑驳、自然纹理 | 侘寂、自然、故事感；脸上有斑驳光影 |
| 丁达尔光 / 光束 | 穿透尘埃/雾的可见光路 | 希望、神圣、幽玄、禅意 |
| 正午顶光 | 硬、眼窝鼻下阴影重 | 一般需规避；刻意用可造强烈对比/硬朗风格 |
| 雾气 / 光晕（气） | 空气感、朦胧 | 空气感、场域、幽玄 |

**自然光使用要点**：找阴影（避免正午直射）、找反射面（白墙/地面补光）、善用反光板（见第六节）、逆光必补面部。

## 三、人造光光型（〔补全〕）

| 光型 | 打法 | 效果 / 情绪 |
|------|------|------------|
| 伦勃朗光 | 主光 45° 高位，脸颊形成三角形亮区 | 戏剧、立体、经典男性肖像、神秘深沉 |
| 蝴蝶光（帕帕拉奇） | 正面上方 45° 打下，鼻下蝴蝶形阴影 | 优雅、时尚、复古女性肖像、颧骨立体 |
| 环形光 | 主光偏正前 45° 略高，颧骨下环形阴影 | 柔美时尚、眼神光环形（美妆/时尚） |
| 分割光 | 主光 90° 侧打，脸分明暗两半 | 硬朗、神秘、表里不一、对峙 |
| 侧光 / 分手光 | 侧面低角度打亮轮廓 | 质感立体、个性、阳刚 |
| 逆光轮廓光 | 主体后方打光，勾勒边缘 | 金边、神圣、希望、剪影 |
| 底光 | 下方往上打 | 恐怖、诡异（谨慎使用，特殊情绪） |
| 顺光（平光） | 相机方向正面打 | 无阴影、平淡讨喜、证件照/清新 |

## 四、三点布光法（〔补全〕）

经典人像布光框架，可按情绪简化为单灯/双灯：
1. **主光（Key）**：塑造主体形态与明暗结构，决定光型，是最强光源。
2. **辅光（Fill）**：填充阴影、控制光比；比主光弱（常用反光板代替）。光比越小越柔和。
3. **轮廓光（Rim）**：主体后方勾边，分离主体与背景，增加立体与神圣感。
4. **背景光**（可选）：打亮背景、制造光斑或渐变，营造空间与氛围。

**简化策略**：外景自然光作主光 + 反光板作辅光；室内单灯 + 窗光；追求戏剧仅用主光 + 轮廓光（高光比）。

## 五、光比与情绪（〔补全〕）

| 光比 | 效果 | 适配情绪 |
|------|------|---------|
| 1:1 – 1:2 | 过渡柔和、明亮均匀 | 温暖、治愈、清新、美大人像 |
| 1:3 – 1:4 | 有立体感但不夸张 | 通用人像、自然、纪实 |
| 1:6 – 1:8 | 明暗强烈、戏剧化 | 压抑、神秘、孤独、力量 |
| 1:8+ | 大面积暗、局部亮 | 悬疑、孤独、低调、庄重 |

## 六、常用辅具（〔补全〕）

| 辅具 | 作用 |
|------|------|
| 反光板（银/金/白/黑/柔） | 银=强补冷光；金=暖补；白=柔和自然；黑=加深阴影塑形；柔=透光柔化 |
| 柔光箱 / 柔光伞 | 把硬光变柔光，柔和均匀、显肤质好 |
| 雷达罩 / 聚光筒 | 聚拢光线、局部打亮、戏剧感 |
| 旗板 / 遮光板 | 挡光、制造阴影、控制光比 |
| 黑旗 | 吸光压暗、加深立体 |
| 色片 | 改变光色，制造情绪（红/蓝/暖） |

## 七、情绪 → 布光速查表（核心）

| 情绪 | 光质 | 光位 / 光型 | 光比 | 色温 |
|------|------|------------|------|------|
| 孤独/怅惘 | 硬光/柔光皆有 | 只留轮廓光、阴阳脸、单侧光、大面积暗 | 高（1:6+） | 冷 |
| 温暖/治愈 | 柔光 | 窗光、暖光、逆光+反光板补光 | 低（1:1–1:2） | 暖 |
| 炽热/生命力 | 硬光 | 强对比、侧逆光、轮廓光、高光溢出、色片 | 高 | 暖/混合 |
| 期待/憧憬 | 柔中带硬 | 逆光、边缘光、晨光、光斑、丁达尔 | 中 | 明亮暖 |
| 平静/禅意 | 柔光/漫射 | 柔和自然光、低对比、雾气、窗光柔射 | 低 | 中性偏冷 |
| 压抑/恐惧 | 硬光 | 阴阳脸、只留轮廓光、分割光、明暗同框 | 高 | 冷暗 |
| 壮丽/崇高 | 硬光/逆光 | 逆光剪影、金色时刻、强明暗 | 高 | 暖金 |

## 八、布光方案写法（落入拍照方案）

每项写清：**光源类型（自然/人造）+ 光位 + 光质 + 光比 + 辅具 + 情绪依据**，并给出文字光位示意。

示例（孤独·窗边）：
```
主光：左侧窗柔光（45°侧光）→ 半张脸明半张脸暗（阴阳脸·表里不一）
辅光：无 / 黑色反光板吸光 → 暗部保留氛围（光比 1:6 高·孤独压抑）
轮廓：窗逆光勾右侧发丝金边 → 希望与孤独并置
色温：偏冷 5000K+ → 清冷疏离
示意：  [窗光]→ 🧍‍♀️    ▓暗部（无补光）
```

## 九、常见避坑

- 逆光不补面部（脸黑成剪影，除非刻意剪影情绪）。
- 顶光直射导致眼窝/鼻下重影。
- 光比与情绪矛盾（治愈场景用高反差硬光）。
- 光向与整组不统一（套图光向漂移，违反「并」）。
- 色温混乱（暖光冷光随意混用，无情绪依据）。
