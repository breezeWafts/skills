# 摆姿库（Pose Library）

拍照方案的核心知识库。前半部分源自飞书「摄影摄像」知识库·约拍·摆姿引导，后半部分按人像摄影专业惯例补全（标注〔补全〕）。Step 3 按情绪查用，Step 4 组装具体姿态。所有姿态需服务于「三面法则」与情绪表达，避免为摆而摆。

## 一、体态基础（源自约拍·摆姿）

### 1.1 脊柱与三椎
- **头顶上提、后颈拉伸**，双肩降低后靠，深吸收腹。
- **颈椎拉伸**：头部挺直，避免探头/缩脖。
- **胸椎伸展**：自信有力，打开胸腔。
- **腰椎弧度**：性感迷人，腰线立起（避免过度塌腰）。

### 1.2 重心
- 双脚尖**不能平行**（平行=呆板立正）。
- 双脚交叉时**重心放后脚**，前脚轻点。
- 稍息踩台阶：大腿与地面夹角 >45°（避免死板直角）。
- 重心永远"一条腿承重的动态平衡"，忌双腿平均受力。

### 1.3 关节与线条
- 手臂**避免僵直**，用关键线条引导视线到突出部位。
- **直角**→干练有力；**锐角**→抢眼冲击（时尚动感）；**钝角**→平静浪漫。
- 手腕保持自然弧度；手臂摆成**菱形**避免横平分割画面。
- 关节处（肘、腕、膝）避免正对镜头形成"切断感"。

### 1.4 手臂摆放四法
1. **依靠搭放**：倚墙、栏杆、椅背、膝盖，身体自然放松。
2. **双手组成画框**：双手在脸侧/腰间围合，聚焦面部。
3. **拿握提**：持道具（花、杯、书、帽、伞），分散紧张感。
4. **群拍触碰连接**：搂抱、搭肩、牵手，建立人物关系。

### 1.5 三面法则（破面 / 破线）—— 立体与错落的关键
- **破面**：y 轴固定，x/z 轴动（如头正身侧）→ 产生立体感。
- **破线**：y 轴变化，画面无长直线/平行线（偏头、摆胯、弯手）→ 产生错落。
- 细分六破：
  - **破脸面**：转脸 / 道具遮脸 / 光影雕刻脸
  - **破胸面**：扭胯、高低肩
  - **破腿面**：踮脚、交叉、前后踢
  - **破头线**：倒头、歪头
  - **破胸线**：转身叉腰
  - **破腿线**：踮脚交叉

### 1.6 支点
有支撑点身体自然放松——自身支点（稍息、单腿承重）或环境支点（墙、树、栏杆、椅、地面）。无支点时主动制造（手插袋、手扶物、倚靠）。

### 1.7 道具互动
有互动可分散注意力、缓解紧张，让表情更自然。凡拍人像，优先给手一个"任务"。

## 二、单人姿态

### 2.1 站姿
| 姿态 | 要点 | 适配情绪 |
|------|------|---------|
| 经典 S 形 | 重心后脚、胯侧顶、肩反向、破面破线 | 柔美、自信、曲线（女性 classic） |
| 稍息式 | 一腿承重一腿轻点、踩台阶夹角>45° | 松弛、日常、自然 |
| 交叉腿 | 前后交叉、重心后脚、踮脚尖 | 俏皮、随性、腿长 |
| 倚靠式 | 倚墙/树/栏杆、肩或臀为支点 | 慵懒、放松、故事感 |
| 挺拔式 | 双脚分开与肩同宽、脊柱立直、直角线条 | 干练、力量、正式（男性 classic） |
| 行走抓拍 | 迈步中自然摆臂、身体微前倾 | 自由、动态、纪实 |

### 2.2 坐姿
- **台阶坐**：居高临下或仰拍，双腿一屈一伸，手撑身后制造斜线。
- **椅子坐**：坐 1/3，身体前倾或侧坐，避免整个人陷进去。
- **地面坐**：盘腿/侧坐/一腿屈起抱膝，手撑地制造支点。
- 通用：坐姿注意**腰背立直**（避免驼背塌腰），腿部避免正对镜头缩短比例。

### 2.3 蹲姿 / 跪姿〔补全〕
- **蹲姿**：一腿全蹲一腿半跪，重心前倾，手肘搭膝；低位机位仰拍显高大或平拍显亲和。
- **跪姿**：跪坐、单膝跪，臀部坐脚跟，腰背挺直；适合草地、沙滩。
- 适配：童趣、亲近自然、亲和、野性生命力。

### 2.4 躺姿 / 卧姿〔补全〕
- 侧躺（手托头、身体呈 S 曲线）、平躺（仰拍天空、四肢自然舒展）、俯卧（手撑下巴）。
- 适配：慵懒、私密、松弛、梦幻；草地/床/沙滩/窗边。

## 三、手臂与手部特写

- **手部任务**：撩头发、扶眼镜、整理衣领、托腮、摸耳垂、持道具、触碰面部。
- **避免**：手臂紧贴身体压扁轮廓、手正对镜头张开、手部僵直无 gesture。
- **手部特写**〔补全〕：手抚花瓣、握咖啡杯、托腮、指尖触窗——承载"微"细节情绪。

## 四、按情绪选姿态（速查）

| 情绪 | 姿态关键词 |
|------|-----------|
| 孤独/寂寥 | 背影、抱臂、缩肩、独坐、低头、动作缓慢、面部回避镜头 |
| 温暖/治愈 | 依靠、轻触、身体前倾、放松、双手连接、浅笑前倾 |
| 炽热/生命力 | 大动作、跳跃、握拳、发丝飞扬、衣摆动势、锐角线条 |
| 期待/憧憬 | 向上伸展、望远方、迈步、迎风、张臂、仰头 |
| 平静/禅意 | 静止端坐、闭目、极简动作、一侧凝神、中正松弛 |
| 压抑/恐惧 | 僵硬、后缩、护身、紧抓、蜷缩、背对镜头 |
| 壮丽/崇高 | 屹立、张臂、背影远望、渺小人影置身壮阔 |

## 五、互动姿势（多人）

### 5.1 情侣 / 婚纱
- 依偎（头靠肩）、牵手同行、深情对视、背后拥抱、额头相抵、背影牵手远去。
- 婚纱专项〔补全〕：新郎新娘错位站（男后女前半步）、牵手回眸、拖裙摆造型、头纱互动、轻吻额头、_hand-in-hand_ 走向光。
- 站姿避免两人完全正面并排（呆板），用前后错位与身体微倾制造层次。

### 5.2 闺蜜 / 朋友
- 搭肩、背靠背、头靠头、相视大笑、并肩行走、互相整理头发。

### 5.3 家庭 / 亲子
- 抱起、牵手、围坐、视线汇聚于孩子、长辈与晚辈的身体倾斜呼应。

### 5.4 多人构图原则〔补全〕
- 有主次（视觉焦点 1 个），避免人人看镜头排排站。
- 用身体朝向与视线建立关系线；前后错落制造纵深。

## 六、摆姿引导技巧（摄影师怎么让对象摆好）

源自约拍·酝酿 + 补全：
1. **酝酿三步**：①感受场景第一印象 → ②确定适合的故事和情绪 → ③让对象配合做表情动作。
2. **先固定仪态，再抓拍表情**：先摆好身体姿态与机位，倒数"3-2-1 看镜头"再抓表情。
3. **假想场景法**：给对象构造情境（"想象你刚收到一封期待已久的信"），再抓自然反应。
4. **暗示场景法**：暗示对象所处场景后再抓拍，比直接命令更自然。
5. **引导情绪法**：先开玩笑放松，或让其听/闻/看真实刺激后再抓。
6. **给手任务法**：让手拿着道具或做具体动作，缓解"手不知道往哪放"。
7. **连续抓拍**：摆好大姿态后连拍，从微变化中选最佳瞬间。

## 七、常见避坑

- 四肢正对镜头被"切断"（关节处尤其忌讳）。
- 手臂贴身压扁身体轮廓。
- 全身正对镜头立正（呆板）——始终破面破线。
- 重心双腿平均分配（僵硬）——一腿承重。
- 驼背塌腰、探头缩脖。
- 眼神空洞无情绪指向。
- 下巴过度前伸（显双下巴）或过度低头。
