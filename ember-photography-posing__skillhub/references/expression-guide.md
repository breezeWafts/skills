# 表情与眼神指导

用于拍照方案「表情眼神」项。源自飞书摄影知识库·约拍·酝酿 + 影视表演专业补全（标注〔补全〕）。人像摄影中，表情眼神是情绪的最终落点，必须与主情绪同向。

## 一、酝酿法（源自约拍·酝酿）

**酝酿三步**：①场景第一感觉 → ②适合的故事和情绪 → ③人物配合的表情动作。

**核心技巧**：
- **先固定仪态，抓拍表情**：先摆好身体、定好机位，倒数 321 或直接假想场景后再抓。
- **抓拍法**：暗示对象所处场景再抓拍；引导情绪（玩笑）后再抓；直接感受（听、闻、看）后抓。
- **情绪词库（19 个）**：专注、向往、迷茫、憧憬、孤独、忧郁、伤感、怅惘、期待、悸动、寂寥、眷恋、释然、怅然、恍惚、温柔、松弛、炽热、平静。

## 二、表情库（按强度分级）

| 强度 | 微笑系 | 沉静系 | 浓烈系 |
|------|--------|--------|--------|
| 弱 | 微抿嘴、淡淡浅笑、嘴角轻扬 | 面无表情、松弛中性、目光平和 | —— |
| 中 | 露齿微笑、闭眼笑、抿唇笑 | 若有所思、垂眼、微张唇 | 扬眉、挑眉、微张口 |
| 强 | 开怀大笑、仰头笑 | 紧锁眉、咬唇、抿紧 | 睁眼张口、强烈情绪、怒目 |

## 三、眼神方向（情绪含义）

| 眼神 | 含义 / 适配 |
|------|------------|
| 直视镜头 | 打破第四堵墙、强烈代入、真诚或挑衅 |
| 看向画外引导线 | 引导观众视线、悬念、故事感 |
| 垂眼 / 失焦 | 内心戏、孤独、伤感、禅意 |
| 远眺 / 仰望 | 憧憬、希望、向往、思念 |
| 闭眼 | 沉浸、禅意、感受（光/风）、释放 |
| 侧目回眸 | 眷恋、故事感、抓拍灵动 |
| 眼神光 | 逆光/窗光点亮瞳孔，增强生命力（补光时重点保留） |

**视线—留白配合**〔补全〕：人物看向的方向要留出更多画面空间（视线留白），忌眼神顶到画面边缘。

## 四、情绪 → 表情 / 眼神 / 肢体映射

| 情绪 | 表情 | 眼神 | 肢体/动作 |
|------|------|------|----------|
| 孤独/寂寥 | 目光放空、微垂眼、淡漠 | 失焦、望画外远处 | 背影、抱臂、缩肩、独坐、动作缓慢 |
| 期待/憧憬 | 眼神发亮、微扬唇、抬头 | 远眺、仰望光束 | 身体前倾、向上伸展、迈步 |
| 伤感/怅惘 | 垂眼、抿唇、眼神失焦 | 低垂、空洞 | 低头、手抚物、缓慢转身、停顿 |
| 释然 | 深呼吸、微笑、闭眼 | 平和、微闭 | 舒展、张臂、放下动作 |
| 炽热/激情 | 睁眼、张口、强烈表情 | 凌厉、直视 | 快速大动作、握拳、前冲 |
| 压抑/恐惧 | 紧锁眉、咬唇、瞳孔收缩 | 惊惶或空洞 | 僵硬、后缩、护身、手部紧抓 |
| 温柔/眷恋 | 柔和眼神、浅笑 | 深情对视、轻垂 | 轻触、依靠、缓慢靠近 |
| 专注/禅意 | 面部松弛、无张力 | 凝视一点或闭目 | 身体中正、动作极简、手稳定持物 |

## 五、眼神与面部坐标（源自知识库·眼神指导）

- **坐标组合**（面向镜头强、远离镜头弱）：眼睛与下巴偏面向，锁骨偏远离，头部正/斜配合。
- 破脸面：转脸 / 道具遮脸 / 光影雕刻脸，避免面部完全平正呆板。

## 六、表演补全（〔补全〕）

- **微表情**：嘴角肌肉细微抽动、眼神短暂游移、呼吸节奏变化——特写中传达压抑情绪的关键。
- **动作节奏**：情绪激动时动作快而碎，平静时动作慢而连续；动作中的"停顿"本身是情绪。
- **手的语言**：紧握（紧张）、摊开（坦诚）、抚摸（眷恋）、遮挡（羞怯/隐藏）。
- **呼气瞬间**：在呼气末端按快门，面部最放松自然（人像抓拍实用技巧）。

## 七、表情引导写法（落入拍照方案）

每项含人物照片，表情眼神写 2–4 项，格式：
`表情 + 眼神方向 + 情绪依据`
示例：`目光放空微垂眼→望向窗外远处（孤独·怅惘）；呼气瞬间抓拍，避免僵笑`

## 八、常见避坑

- 假笑（眼睛不笑）——引导真实情绪而非命令"笑一个"。
- 瞪眼、眼神空洞无指向。
- 憋气导致的面部紧绷——按快门前提示呼气。
- 下巴过度前伸或过度低头。
