# 情绪 → 静态摄影视觉语言映射表

本文件是「情绪驱动拍照方案」的核心查表。Step 2 用它定位主情绪，Step 3 用它把情绪映射到摆姿、表情、构图、布光、色彩等全部静态摄影参数。冲突时以本表为准。参数具体内涵见对应知识库（pose-library / lighting-guide 等）。

## 一、情绪词族与主情绪词典

把要表达的情绪关键词归入以下 8 大词族（括号内为近义/细分情绪）：

| 词族 | 主情绪 | 细分情绪词 |
|------|--------|-----------|
| **孤寂族** | 孤独 | 孤独、寂寥、失落、空虚、疏离、迷茫、怅惘、伤感、忧郁、落寞、清冷 |
| **温情族** | 温暖 | 温馨、幸福、眷恋、治愈、柔软、亲密、感恩、安心、怀旧、松弛 |
| **炽烈族** | 炽热 | 炽热、激情、狂喜、兴奋、愤怒、冲击力、生命力、躁动、野性 |
| **憧憬族** | 期待 | 期待、向往、憧憬、希望、悸动、好奇、昂扬、追光、自由 |
| **静谧族** | 平静 | 平静、释然、专注、禅意、安宁、空灵、恬淡、超脱、极简 |
| **压抑族** | 压抑 | 压抑、恐惧、紧张、不安、绝望、危机、神秘、悬疑、束缚、疏离 |
| **怅惘族** | 怅然 | 怅然、恍惚、伤逝、物哀、无常、遗憾、惋惜、释怀前的痛 |
| **壮丽族** | 崇高 | 崇高、震撼、辽阔、敬畏、史诗、庄严、孤绝的抗争 |

**强度判定**：弱（克制、日常）/ 中（明显但不外放）/ 强（戏剧化、极致）。强度决定姿态幅度、色彩浓度、光比与表情张力。

## 二、情绪 → 静态摄影参数映射表（核心）

### 2.1 孤独 / 怅惘 / 压抑（冷色·疏离组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 大远景、远景为主（人物渺小、被困环境）；少量局部特写 |
| 机位 | 背面机位、高机位俯拍；低机位仰拍表现压迫 |
| 构图 | 疏密留白、框架构图（困境束缚）、人物占画面比重小、前后遮挡、单焦点 |
| 画幅 | 横幅 16:9 或 3:2 突出环境空旷；人物压至画面一侧 |
| 摆姿 | 背影、抱臂、缩肩、独坐、低头、动作缓慢收敛；面部或眼神回避镜头 |
| 表情眼神 | 目光放空、微垂眼、淡漠；垂眼失焦、望向画外远处 |
| 布光 | 低调硬光、单侧光、只留轮廓光面部暗（隐藏内心）、阴阳脸、大面积暗部；冷色温 |
| 色彩 | 冷色调、低饱和、冷蓝/青灰；点缀极少暖色 |
| 道具/场景 | 芦苇（隔离脆弱）、残阳、荒原、大海、雨、铁栏杆/百叶窗/门缝（隔阂束缚）、残垣断壁、空旷街道 |
| 参数氛围 | 大光圈虚化环境氛围 / 或小光圈冷清全景，按主体取舍 |

### 2.2 温暖 / 温情 / 治愈（暖色·亲近组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 中景、近景为主（互动与表情），特写（细节情感） |
| 机位 | 平视（人文纪实）、略低机位（亲切） |
| 构图 | 居中/对称（和谐稳定）、前景虚化（层次）、暖色光斑、眼神接触 |
| 画幅 | 竖幅 4:5 / 3:4 适合人像特写与半身 |
| 摆姿 | 依靠、轻触、双手连接（搂抱搭肩）、身体微前倾、放松自然 |
| 表情眼神 | 柔和眼神、浅笑、真诚直视镜头或深情对视 |
| 布光 | 柔和窗边光、暖光、明暗过渡柔和、逆光+反光板补光、低光比；暖色温 |
| 色彩 | 暖色调、低饱和暖色、暖橙/米黄点缀 |
| 道具/场景 | 烟火气、咖啡/书、花、毛毯、室内窗边、家庭场景、暖光小馆 |
| 参数氛围 | 大光圈柔焦背景、暖调白平衡、柔光 |

### 2.3 炽烈 / 激情 / 生命力（高饱和·动感组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 近景、特写为主，强化身体线条与局部张力 |
| 机位 | 低机位仰拍（高大强势）、动势倾斜机位 |
| 构图 | 强化动态（倾斜、断裂）、锐角线条、高饱和色块、破面破线（立体错落） |
| 画幅 | 竖幅 9:16 冲击力强 / 方图 1:1 聚焦 |
| 摆姿 | 快速大动作、握拳、前冲、大幅度肢体、跳跃、发丝飞扬、衣摆动势 |
| 表情眼神 | 睁眼、张口、强烈表情、直视或凌厉眼神 |
| 布光 | 强对比硬光、侧逆光、轮廓光、高光溢出、红色/彩色色片；高光比 |
| 色彩 | 红色（热望）、高饱和、高对比；「破」只留 1 处点睛 |
| 道具/场景 | 烟火、运动场景、色彩浓烈背景、动态元素 |
| 参数氛围 | 高速快门凝固动势 / 慢门拉丝；高对比 |
| 参数氛围 | 高饱和、强对比、硬光 |

### 2.4 期待 / 憧憬 / 希望（向光·上升组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 远景→中景→近景（从环境到主体到表情），套图中递进使用 |
| 机位 | 仰拍（向往）、平视 |
| 构图 | 引导线（道路/河流引向远方）、黄金分割主体、前方留白（未来感）、天空留白 |
| 画幅 | 横幅 16:9 / 3:2 展示天空与远方 |
| 摆姿 | 向上伸展、身体前倾、望向远方、迈步、迎风、张开手臂 |
| 表情眼神 | 眼神发亮、微扬唇、抬头远眺、看向光束 |
| 布光 | 逆光、边缘光、晨光、光斑、丁达尔光、镜头眩光；明亮 |
| 色彩 | 明亮暖色 + 天空蓝、清透、中高饱和 |
| 道具/场景 | 天空、道路、窗、光束、地平线、气球、飞鸟 |
| 参数氛围 | 逆光点测人脸+补光、大光圈光斑、清新通透 |

### 2.5 平静 / 禅意 / 释然（留白·极简组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 大远景、空镜、固定景别；人物占比小 |
| 机位 | 平视、对称、固定机位 |
| 构图 | 大面积留白（≥50%）、三分法、极简几何、单焦点、枯山水式排布 |
| 画幅 | 横幅或方图，突出留白与呼吸感 |
| 摆姿 | 静止、端坐、闭目、动作极简、一侧凝神、松弛中正 |
| 表情眼神 | 闭眼或垂眼、面部松弛无张力、禅定感 |
| 布光 | 柔和自然光、漫射、低对比、雾气、窗光柔射 |
| 色彩 | 低饱和（≤45%）、月白/宣纸白/靛青、近乎单色 |
| 道具/场景 | 天空、水面、远山、空房间、留白墙面、枯枝、茶 |
| 参数氛围 | 小光圈保持清晰层次 / 柔焦漫射，低对比低饱和 |

### 2.6 压抑 / 恐惧 / 悬疑（冷暗·束缚组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 近景、特写、变形特写；大远景压迫 |
| 机位 | 低机位仰拍（压迫）、背面机位（未知）、倾斜机位 |
| 构图 | 框架构图（束缚）、画框嵌套、遮挡、面部阴影、不完整构图 |
| 画幅 | 竖幅压迫 / 方图紧闭 |
| 摆姿 | 僵硬、后缩、护身、手部紧抓、蜷缩、背对镜头 |
| 表情眼神 | 紧锁眉、咬唇、瞳孔收缩、眼神惊惶或空洞 |
| 布光 | 阴阳脸、只留轮廓光、硬光阴影、明暗同框、分割光；冷暗 |
| 色彩 | 冷色低饱和、青灰/墨绿、红色点缀（血腥惊悚） |
| 道具/场景 | 铁栏杆/百叶窗/门缝（隔阂）、雨、雷电、密植荒地、残垣断壁、窄廊 |
| 参数氛围 | 高对比、暗部保留细节、冷调白平衡 |

### 2.7 壮丽 / 崇高 / 史诗（辽阔·震撼组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 大远景、全景为主（人与巨物/自然对比） |
| 机位 | 低机位仰拍（崇高）、高机位/航拍 |
| 构图 | 辽阔留白、地平线、巨物与人对比、对称庄严 |
| 画幅 | 横幅 16:9 / 宽幅全景 |
| 摆姿 | 屹立、张开双臂、背影远望、渺小人影置身壮阔环境 |
| 表情眼神 | 坚毅、仰望、凝视远方 |
| 布光 | 逆光、剪影、金色时刻、强明暗、丁达尔光 |
| 色彩 | 高对比、石青/赭石/金色、开阔色域 |
| 道具/场景 | 大海、荒原、天空、山川、残阳、巨物 |
| 参数氛围 | 小光圈全景清晰、渐变灰平衡天空与地面、逆光剪影 |

## 三、情绪 → 色彩基调速查

| 情绪 | 主色 | 辅色 | 点缀（≤10%） |
|------|------|------|-------------|
| 孤独/怅惘 | 冷蓝/青灰 | 月白 | 极暖一点 |
| 温暖/治愈 | 暖米黄 | 暖橙 | 苔绿 |
| 炽热/激情 | 深红 | 橙 | 朱砂（唯一破格） |
| 期待/憧憬 | 天光蓝 | 暖白 | 藤黄 |
| 平静/禅意 | 宣纸白/月白 | 靛青 | 无或极淡 |
| 压抑/悬疑 | 墨绿/青灰 | 冷灰 | 暗红 |
| 壮丽/史诗 | 石青 | 赭石 | 金 |

> 配色统一遵守 60-30-10（主:辅:强调），高饱和面积 ≤10%，情绪再强烈也只留 1 处「破」。
