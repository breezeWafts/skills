# Changelog

## 1.4.0 · 2026-11-23

知识库融合完成后，补齐平台上传用的 PNG 位图图标资产；功能逻辑不变。

- 新增 `assets/png/`：主图标 16 / 32 / 48 / 64 / 128 / 180 / 192 / 256 / 512 px 共 9 档，深色 / 单色 / 卡片三变体 512 px，不透明暖白底 512 px，六枚配套图标各 64 / 256 px，`favicon.ico`（16/32/48）与无文字 `preview.png` 总览，共 27 个文件。
- 全部 PNG 带真实 RGBA alpha 通道，四角透明；每个尺寸由矢量在目标像素原生栅格化，不做放大缩图。不透明版供不接受透明通道的平台使用；180 / 192 / 512 覆盖 Apple touch icon 与 PWA 常见规格。
- 新增 `scripts/build_icons_png.py`：无头浏览器渲染 + Pillow 切片，可复现地生成全套 PNG。逐张自检尺寸、alpha 边界（防静默裁切）、不透明占比与关键配色。
- 实测修正三处栅格化陷阱：① `cairosvg` 缺 libcairo DLL 且不解析 CSS `var()`，改用 Chromium 原生解析；② 无头浏览器可视高度比 `--window-size` 少约 70px，需给窗口高度加余量并分页渲染，否则底部被裁；③ 重复启动浏览器须使用独立 `--user-data-dir`，否则窗口尺寸参数被旧进程吞掉。
- `references/icon-system.md` 追加 PNG 资产清单与尺寸用途表；SKILL.md 参考文件表同步。另出独立压缩包 `dist/ember-reader-icons-png-v1.4.0.zip`，便于直接上传平台。
