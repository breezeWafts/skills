# 内容获取路径与合规检查

Step 2 必读。目标：在不违反版权与访问限制的前提下，尽可能完整地取得书籍内容，并如实声明覆盖度。

## 一、按输入类型分流

### 1.1 本地书籍文件

优先路径（用户已合法持有文件，覆盖度最高）：

| 类型 | 处理方式 |
|---|---|
| PDF | 调用本地 PDF 读取能力，提取全文文本、目录、页码；扫描件需先做文字识别，识别失败则如实声明 |
| DOCX / WPS | 调用本地 Office 读取能力，保留标题层级作为文法层骨架 |
| EPUB | 解包取 OPF 目录与 XHTML 正文，按 spine 顺序拼接 |
| TXT / MD | 直接读取，按标题或空行切章 |
| 图片版书籍 / 截图 | 逐页识别文字，标注识别置信度低的段落 |

读取后立刻记录：总章数、总页数、成功提取的章节列表、失败章节列表。

### 1.2 书籍链接

1. 取用户给定页面的公开正文（在线阅读页、作者公开稿、出版社试读页、公开课讲义、百科条目）。
2. 页面需要登录、付费或含反爬限制时，停止在该页面，不尝试绕过。
3. 从页面提取目录、章节标题与可见正文，作为骨架与主干部素材。
4. 记录 URL、抓取日期、页面可见范围。

### 1.3 仅给书名（联网检索）

构造多轮检索，逐轮补充材料，不追求一次性拿到全文：

1. `书名 + 作者 + 目录` —— 重建文法层骨架
2. `书名 + 内容简介 / 序言 / 后记` —— 定位作者意图
3. `书名 + 核心观点 / 书评 / 读书笔记` —— 交叉验证主干命题
4. `书名 + 作者访谈 / 公开课 / 演讲` —— 补作者自述，标注为二手以外的作者一手表述
5. `书名 + PDF / 全文 / 开源 / 公有领域` —— 仅在确认合法开放时取用；命中盗版站点一律跳过
6. 公有领域作品（作者逝世超过保护期、古籍、开放许可出版物）可取全文，并注明版本来源

检索结果须记录来源链接与日期，供 L4 引用。

## 二、多本书的处理

1. 逐本独立执行 Step 2–4，各自产出材料清单、覆盖度声明与内容池。
2. 识别共同主题（书名、目录、作者意图三者中至少两项重合才判为共同主题）。
3. 有共同主题：合并 L1 中语义等价的主干，分歧项直接送入 L4 四栏中的「分歧」；Step 5 的 L4 先做书与书互证，再补外部同类资料。
4. 无共同主题：按书分别走四级交互，或询问用户是否要以某一本为主线。

## 三、覆盖度声明模板（首次输出前必须给出）

```
【材料清单】
- 来源 1：类型 / 名称 / 链接或路径 / 取得日期
- 来源 2：…
【覆盖度】
- 全文是否取得：是 / 否
- 已覆盖章节：…（约 X%）
- 未覆盖章节：…
- 说明：未获取全文，以下提炼仅基于上述材料；缺口处标注〔未覆盖〕，不以常识补齐。
```

覆盖度声明必须随 L1 首次输出一并展示，其后每级可简写为「覆盖度同上」。

## 四、合规检查清单（Step 2 结束前逐项确认）

- [ ] 未绕过任何付费墙、登录限制或 DRM？
- [ ] 未从盗版站点抓取正文？
- [ ] 未整章复制受版权保护内容，仅用概括转述与短引？
- [ ] 短引均标注出处（章/节/页码或 URL）？
- [ ] 二手资料（书评、笔记）已与原文区分标注？
- [ ] 未取得全文时已明确声明，且未假装通读全书？
- [ ] 覆盖度百分比为如实估算，未夸大？
- [ ] 资料冲突时并列呈现，未擅自裁决？

## 五、失败降级策略

| 情形 | 降级动作 |
|---|---|
| 文件损坏 / 无法解析 | 说明原因，改用书名联网检索公开资料 |
| 仅能取得目录与简介 | 只做 L1 骨架与作者意图，明确标注 L2/L3 暂不可用，并询问用户能否补充文件 |
| 检索结果互相矛盾 | 并列列出各来源说法，标为 L4「分歧」，不替用户选边 |
| 完全无法取得任何材料 | 停止流程，告知无法合法获取，请用户提供文件或合法链接，不编造内容 |
