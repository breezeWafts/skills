本文件是「超级读者」的方法论骨架，完整还原工作区八张思维导图截图的节点与层级，并说明每条如何编排进四级渐进流程。执行技能时按需查阅对应小节，不必全文背诵。

## 一、思考能力（两张图）

### 1.1 思考能力1 · 四大支柱

中心主题「思考能力」，四条主干：

| 主干 | 子节点 |
|---|---|
| 批判思维 | 谨慎判断是非 / 大胆假设 / 小心求证 / 切记盲从 |
| 提问 | （单一节点，强调主动发问本身即思考） |
| 了解问题 | 探究决策背后的原因 / 多角度看问题 / 提前预测可能的结果 |
| 独立思考 | （展开见 1.2） |

### 1.2 思考能力2 · 独立思考的展开

主干「独立思考」下分四支：

- **过程**
  - 现象，结果，解决方案
  - 思考的三个环节：哪些是已知的 / 掌握了什么事实 / 得到什么未知的东西 / 观察到什么现象
  - 思维的过程：通过什么资料 / 得出什么结论
- **方法**：读懂内容 / 局部正确但推理错误 / 事实正确但价值观错误 / 是否有更好的想法
- **练习流程**
  - 写评论：换位思考，自己在病人的角度怎么想怎么做；评价（态度），而不是感想（个人化的喜好）
  - 思维工具：比喻法（抽象比喻成具体）/ 对立面思考 / 贴标签（第一印象、最具特点的表面印象）/ 画图形辅助思考
  - 行动习惯 → 应变能力：概念为「紧张压力下迅速反应的能力」；5 秒发表见解；训练含 cold call、即兴发言两分钟准备
  - 深化想法 → 深度阅读：信息二八取舍
  - 加速决断：接到任务自己做决策，想好应对策略再请示老板
- **认知提升（黑匣子思维）**：尝试 → 失败 → 改进 → 再失败 → 总结教训 → 正确认知

### 1.3 在技能中的落点

| 方法论条目 | 落点 |
|---|---|
| 批判思维四律、了解问题三问 | **L4 同类对照**：对每个分歧做假设／求证／多角度／结果预测 |
| 思考的三个环节、思维的过程 | **Step 4 语义层扫描**：区分已知事实、未知结论、支撑资料 |
| 局部正确但推理错误 / 事实正确但价值观错误 | **L2 修饰层**的「慢想」标注：定位读者卡住的推理断点 |
| 比喻法 / 对立面思考 / 贴标签 / 画图形 | **L3 例证层**可选思维工具 |
| 评价（态度）而非感想（个人喜好） | **L1 作者意图**的表述规范：写主张，不写读后感 |
| 信息二八取舍 | **Step 4 分层切分**：主干只保留约两成高价值命题 |
| 黑匣子思维六步、5 秒发表见解 | **Step 6 复习方案**：费曼自检与快速复述训练 |

## 二、阅读（三张图）

### 2.1 阅读1 · 流程与四层阅读

中心「阅读」三阶段：准备 → 开始 → 结尾。

「准备」主干对应四层阅读，是本技能四级渐进交互的直接理论来源：

| 阅读层次 | 目标 | 对应级别 |
|---|---|---|
| 基础阅读 | 了解意思 | **L1 主干** |
| 解释阅读 | 抓重点 | **L2 修饰·知识点** |
| 分析阅读 | 理解消化主题 | **L3 例证·故事·类比** |
| 主题阅读 | 深入领域 | **L4 同类对照** |

> 这条映射是整套技能的设计轴心：四级渐进不是随意分层，而是让用户在「看懂就停」的机制下，自然地从基础阅读走到主题阅读。

### 2.2 阅读2 · 「开始」阶段：方法与应用

- **方法**
  - 四官发力：抬眼看＝视野宽度 / 指重点＝引导阅读 / 快进读＝朗读机器 / 思重点＝高效秘密
  - 疑难杂症：易快难慢（思考）/ 无声胜有声 / 背经典磨细节
- **应用 · 核梳读书法**
  - 简单概括：提出问题 / 问题的分析结果 / 解决办法
  - 快读：理顺＝碎片化信息拼凑完整；关注大框架＝忽略细枝末节
  - 慢想：思考中的放在特定难点 → 第一遍没有读懂的逻辑 / 没有理解的多义词
  - 检验是否读懂：一两句话概括内容 / 作者的意图 / 文字背后隐含的意义 / 读后收获

### 2.3 阅读3 · 「结尾」阶段：读书笔记与读后感

- **读书笔记 · 三种记法**：摘录式＝摘抄金句 / 注释式＝借助工具书 / 批注式＝批注思考质疑点
- **三栏式（核心产出结构）**
  - 方法 · 分模块：分解＝提出问题 / 解决问题 / 应用解决问题的方法 / 注意事项
  - 每模块分三栏：**内容＝原文主干 / 感悟＝自己的理解 / 行动＝做点什么**
  - 应用（按书类调整三栏的对应关系）：
    - 干货书：概括内容 / 知识点感悟 / 尝试书中方法
    - 小说：尊重一记 / 内容对应情节 / 感情对应小说背后的意义 / 行动结合自身的体会
    - 教材：内容对应知识讲解 / 感悟对应知识的理解 / 行动对应举例
    - 科普：内容对应概念、推理 / 感情的意义对知识的理解 / 行动对应用知识解释身边现象
  - 一页纸：**16 关键词 vs 10 金句**
- **读后感**
  - 吃书：快读 / 目录查阅 / 简单概括
  - 找口：提问题 / 讲故事 / 分析热点新闻
  - 复盘：结合自己的情况回顾作者的理念

### 2.4 在技能中的落点

| 方法论条目 | 落点 |
|---|---|
| 四层阅读 | **四级渐进交互的整体骨架**（见 2.1 映射表） |
| 快读·关注大框架 / 忽略细枝末节、易快难慢 | **L1 主干**的切分原则与「只给骨架」的输出纪律 |
| 慢想·第一遍没读懂的逻辑与多义词 | **L2** 的难点标注，也是用户「看不懂」时优先补的位置 |
| 检验是否读懂四问 | **L1 输出前自检**与 **Step 6 检验清单**，两处复用 |
| 简单概括三步（提出问题／分析结果／解决办法） | **L1 全书骨架**的组织模板 |
| 三栏式 + 分模块五段 | **L2 分知识点展示**的固定表格结构 |
| 一页纸 16 关键词 vs 10 金句 | **Step 7 精简知识库**的核心产物 |
| 吃书 / 找口 / 复盘 | **Step 2 材料处理**、**L3 找讲述切口**、**Step 6 一页纸复盘** |
| 批注思考质疑点 | **L4 分歧与反例**栏目的素材 |

## 三、学习 · 整体性学习

中心「整体性学习」，两条主干：

- **方法**
  - 快速阅读：笔记辅助思考 / 图像辅助记忆
  - 知识串联：熟悉理论建模 / 模型分析新知
  - 学以致用：费曼技巧
  - 提高效率 → 持续：作息 / 专注 / 每日阅读 / 简化环境
- **思维**：图钉学习法 / 知识结构网

**落点**：整体构成 Step 6 学习路径四段；「图钉学习法」用于给每个主干命题指定一个记忆锚点；「知识结构网」用于说明新知挂接在读者既有知识的位置；费曼技巧转为自检题；持续四要素转为复习节奏的约束条件。

## 四、效率 · 时间分配与精力管理

中心「效率」，三条主干：

- **方法**（单一节点）
- **时间分配**：早上精力最充沛
- **精力管理**
  - 被动安排：不经大脑思考，想到就做
  - 主动安排：经过计划 - 重要程度象限
  - 精力消耗（理解 - 判断 - 抉择）：任务切换 / 陌生人通电话 / 考试做题 / 判断并修改错误

**落点**：Step 6 时间排程把「理解-判断-抉择」类高耗任务（读主干、做对照、写费曼答案）放在早上精力充沛时段；用重要程度象限做主动安排而非被动想到就做；明确减少任务切换，避免把高耗任务碎片化。

## 五、拆书 · 步骤与分类型应用

### 5.1 步骤（三步）

1. **知道核心话题**：书名 / 豆瓣（查元数据与口碑定位）
2. **找出要点**：用原文内容解释要点
3. **拔高**：现实事件（旁观者变成参与者）

### 5.2 应用（按书籍类型）

| 类型 | 拆解要点 |
|---|---|
| 干货类 | 这是什么意思 / 它有什么用 / 它有什么表现形式 / 具体怎么做 / 有哪些应用领域 |
| 文学类 | 情节 / 作者观点 / 作者想法 / 作者态度 |
| 传记类 | 故事概括＝知道故事 / 用自己的话说＝从故事了解角色 / 加入自己的感悟＝从故事悟出道理；要点：通过故事总结道理、结合自己体会道理、活学活用 |
| 科普类 | 抓大放小＝抓住核心推理理论、忽略跟主题过程不相关的复杂细节；专业不语 / 基础知识 / 逐层理解 / 逻辑推理 |
| 散文类 | 没有中心＝围绕一个主题 / 通过散乱的文字，抓住散文的神 |

### 5.3 在技能中的落点

「知道核心话题 → 找出要点 → 拔高」正好对应 **L1（核心话题与主干）→ L2（用原文修饰解释要点）→ L3 结尾（拔高到现实事件）**；5.2 的分类型问法详见 `references/book-types.md`，是 Step 3 判定类型后 L1/L2 提问模板的来源。
