# 学习复习方案模板与导出数据契约

Step 6、Step 7 必读。方案依据「整体性学习」与「效率」两张思维导图；导出依据「阅读3」的三栏式与一页纸方法。

## 一、学习与复习方案模板

### 1.1 学习路径（整体性学习四段）

| 段 | 动作 | 具体产出 | 挂接位置 |
|---|---|---|---|
| 快速阅读 | 笔记辅助思考、图像辅助记忆 | 一页纸骨架、L1 主干卡 | — |
| 知识串联 | 熟悉理论建模、模型分析新知 | 每个主干命题写明「它挂在我已有知识 X 上」 | 知识结构网 |
| 学以致用 | 费曼技巧 | 用自己的话讲清每条主干的 60 秒答案 | 图钉学习法锚点 |
| 提高效率 · 持续 | 作息 / 专注 / 每日阅读 / 简化环境 | 固定的每日阅读时段与环境约束 | — |

对每个 L1 主干指定一个**图钉**（一个具体、可回忆的意象或亲身经历），并写明它在知识结构网中的挂接位置。

### 1.2 时间排程（效率 · 早上精力最充沛）

| 时段 | 任务类型 | 安排依据 |
|---|---|---|
| 早上（精力充沛） | 理解 - 判断 - 抉择类高耗任务：读主干、做 L4 对照、写费曼答案 | 精力最充沛时段给高耗任务 |
| 午后 | 整理类：三栏式笔记、关键词卡、脑图绘制 | 低耗、可中断 |
| 碎片时间 | 复述、回忆、翻卡 | 不与高耗任务混排 |

**硬约束**：用重要程度象限做主动安排，避免「不经大脑思考，想到就做」的被动安排；减少任务切换，不把高耗任务拆碎；把「判断并修改错误」类任务集中处理。

### 1.3 复习节奏（间隔 + 最小动作）

| 轮次 | 时间点 | 最小动作 | 检验 |
|---|---|---|---|
| 第 1 轮 | 当晚 | 不看材料复述一句话主旨与 3–7 条主干 | 一两句话能否概括内容 |
| 第 2 轮 | 次日 | 对每个主干补出被省略的限定条件 | 能否说出作者意图 |
| 第 3 轮 | 第 3 天 | 各举一个自己的例子替换书中例证 | 能否指出文字背后隐含的意义 |
| 第 4 轮 | 第 7 天 | 60 秒费曼讲解 + 找一处反例 | 能否列出读后收获 |
| 第 5 轮 | 第 15 / 30 天 | 一页纸复盘：结合自己的情况回顾作者的理念 | 能否把知识用于解释身边现象 |

复述失败时按「黑匣子思维」六步走：尝试 → 失败 → 改进 → 再失败 → 总结教训 → 正确认知；并做 5 秒发表见解的应变练习。

### 1.4 检验清单（交付前逐项）

- [ ] 一两句话概括内容
- [ ] 说出作者意图
- [ ] 指出文字背后隐含的意义
- [ ] 列出读后收获

## 二、授权导出协议

### 2.1 授权话术（逐项请求，不得默认全选）

```
本次阅读已完成。是否需要我把结果落盘？请逐项确认：
① 导出思维导图（L1 主干 → L2 知识点 → L3 例证 → L4 对照）
② 导出精简知识库（一页纸 16 关键词 vs 10 金句 + 三栏式笔记）
③ 导出分层内容池 JSON（便于后续复用）
可只选其中一项；未确认的项目不生成任何文件。
```

用户确认后再询问输出目录（默认当前工作区）。遇同名文件先询问，不静默覆盖。

### 2.2 产物清单

| 产物 | 格式 | 生成方式 |
|---|---|---|
| 脑图（优先） | `.xmind` | 调用本地脑图能力创建，层级按 书名 → L1 → L2 → L3 → L4 |
| 脑图（通用） | `.mmd`（Mermaid）/ `.opml` / `.md` | 由 `scripts/export_knowledge.py` 生成 |
| 精简知识库 | `.md` | 由脚本生成：一页纸 + 三栏式 + 分模块 |
| 分层内容池 | `.json` | 由脚本规范化后另存 |

## 三、分层内容池 JSON 数据契约

模板见 `assets/layers-template.json`。字段约定（脚本按此读取，缺省字段自动跳过）：

```jsonc
{
  "book": {
    "title": "书名", "author": "作者", "type": "干货类|教材类|科普类|文学类|传记类|散文类",
    "sources": ["来源链接或路径"], "coverage": "覆盖度声明", "generated_at": "YYYY-MM-DD"
  },
  "l1": [
    { "id": "L1-1", "text": "主干命题（≤30字）", "source": "章/节/页码", "certainty": "原文|推断" }
  ],
  "l2": [
    { "id": "L2-1", "parent": "L1-1", "knowledge_point": "知识点名",
      "content": "原文主干 + 修饰", "insight": "这层限定改变了什么理解",
      "action": "做点什么", "source": "", "certainty": "原文|推断" }
  ],
  "l3": [
    { "id": "L3-1", "parent": "L1-1", "kind": "示例|故事|类比|数据",
      "content": "例证内容", "supports": "把什么讲具体了", "source": "" }
  ],
  "l4": {
    "consensus": [{ "text": "", "source": "" }],
    "divergence": [{ "text": "", "source": "" }],
    "supplement": [{ "text": "", "source": "" }],
    "counterexample": [{ "text": "", "source": "" }]
  },
  "keywords": ["16 个关键词"],
  "quotes": ["10 条金句"],
  "study_plan": { "path": "", "schedule": "", "review": "", "checks": [] }
}
```

**规则**：`l2`/`l3` 的 `parent` 必须指向存在的 `l1.id`；推断类内容不得进入 `l1`；`l4` 每条须带 `source`。

## 四、脚本用法

```bash
python scripts/export_knowledge.py --input <分层内容池.json> --outdir <输出目录> [--prefix <文件名前缀>]
```

- 仅使用 Python 标准库，无第三方依赖，无网络请求。
- 产出 `<前缀>-knowledge-base.md`、`<前缀>-mindmap.mmd`、`<前缀>-mindmap.opml`、`<前缀>-layers.json`。
- 默认不覆盖：同名文件已存在时脚本报错退出并返回非 0，由调用方询问用户后决定是否加 `--force`。
- 脚本只做确定性格式转换，不改写内容、不补全缺失信息、不生成书籍观点。

## 五、导出自检

- [ ] 用户已对每一项产物明确授权？
- [ ] 脑图层级严格为 书名 → L1 → L2 → L3 → L4，未颠倒？
- [ ] 知识库含一页纸（16 关键词 vs 10 金句）与三栏式笔记？
- [ ] 每条内容保留原文定位与〔推断〕标记？
- [ ] 覆盖度声明随知识库一并保留，未被导出过程抹去？
- [ ] 未静默覆盖任何既有文件？
