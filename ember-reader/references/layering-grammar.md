# 语法 · 文法 · 语义三层提炼规则

本文件定义如何把一本书切分成四级内容池（L1 主干 / L2 修饰·知识点 / L3 例证·故事·类比 / L4 同类对照）。Step 4 必读。

## 一、三轮扫描

### 1.1 语法层（句子级）

对每个承载主张的句子做成分分析，判定它属于哪一层：

| 成分 | 识别标志 | 归入 |
|---|---|---|
| 主语 + 谓语 + 宾语（核心命题） | 删去其余成分后句子仍成立、命题不变 | **L1** |
| 定语 | 「…的」、属性、范围、归属、数量、限定 | **L2** |
| 状语 | 时间、条件、程度、方式、否定、频率、假设、对象 | **L2** |
| 补语 | 结果、趋向、程度、可能、状态补充 | **L2** |
| 关联词 | 因为/所以、虽然/但是、只有/才、除非、否则、一旦 | **L2**（逻辑限定） |
| 插入语、注释、括号补充 | 即、也就是说、换言之、附注 | **L2** 或 **L3**（视是否含例） |
| 举例、故事、类比 | 例如、比如、譬如、有个…、就像、好比、案例、实验、数据 | **L3** |

**主干判定三问**：① 删掉这段，作者的核心主张是否改变？② 它是否可被一个不带形容词的判断句复述？③ 它是否依赖某个具体人物/场景/数字才成立？前两问为「否/是」且第三问为「否」→ L1；第三问为「是」→ L3；其余 → L2。

### 1.2 文法层（篇章级）

扫描目录、章节标题、段落首尾句、转折与总结句，重建全书骨架：

1. **提出问题**（作者要解决什么）
2. **分析结果**（问题为何存在）
3. **解决办法**（核心主张）
4. **应用方法**（怎么用）
5. **注意事项**（边界、例外、误区）

骨架对应 L1 的「3–6 段式结构」；五个环节同时是 L2 每个知识点分块内部的固定组织顺序。论证链中的每一环记录其支撑的 L1 编号，形成可追溯的挂载关系。

### 1.3 语义层（意图级）

在不虚构的前提下判定：

- **作者意图**：作者想改变读者的哪一个认知（写主张，不写读后感；参考思考能力图「评价（态度），而不是感想（个人化的喜好）」）
- **隐含意义**：文字背后未明说但由论证链必然推出的前提；无法确证时标注〔推断〕
- **概念定义**：术语首次出现处的定义，归入 L2
- **价值立场**：作者赞成/反对什么，归入 L1 意图或 L4 分歧素材
- **资料与结论的对应**：区分「哪些是已知的 / 掌握了什么事实 / 得到什么未知的东西 / 观察到什么现象」「通过什么资料 / 得出什么结论」

## 二、四级内容池结构

每条记录固定字段：

```
编号 | 层级 | 挂载的 L1 编号 | 内容（概括转述或短引） | 原文定位（章/节/页码） | 确定性（原文 / 〔推断〕）
```

- **L1 主干**：3–7 条，每条一句判断句，≤30 字，禁止形容词、例子、故事、比喻。
- **L2 修饰·知识点**：按 L1 编号分组，每组 2–5 块；每块含限定成分 + 三栏式笔记。限定成分须写明它**改变了主干的什么**（缩小范围 / 增加条件 / 给出例外 / 反转否定 / 明确程度）。
- **L3 例证·故事·类比**：每条标明支撑的 L1 编号与「它把什么讲具体了」；故事性内容保留必要的人物与转折，但不复制整段原文。
- **L4 同类对照**：共识 / 分歧 / 补充 / 反例四栏，每条附来源链接与检索日期；此层在 Step 5 的 L4 才联网填充，Step 4 只预留结构。

## 三、切分示例（抽象演示）

原句：「在信息过载的环境里，只要读者先抓住作者的核心主张，就能像在陌生城市先找到主干道一样，快速判断一本书是否值得细读。」

- **L1**：先抓核心主张，可快速判断书是否值得细读。
- **L2**：
  - 条件限定：在信息过载的环境里（限定了适用场景）
  - 条件连词：只要…就…（把结论变成充分条件，须提示并非唯一路径）
  - 程度限定：快速（限定效率，不承诺必然正确）
- **L3**：类比「像在陌生城市先找到主干道一样」（把抽象的判断过程具象化，支撑 L1）。
- **L4**：待联网检索同类阅读方法书籍做对照。

## 四、挂载与追溯规则

1. L2、L3 每条必须挂到至少一个 L1 编号；挂不上说明该内容对主干无贡献，降级为「背景材料」不入池。
2. 一条内容同时支撑多条主干时分别标注，不复制多份。
3. 无法定位原文位置的，写「定位缺失」并标注〔推断〕；推断内容不得进入 L1。
4. 覆盖度不足时，未覆盖章节对应的主干命题留空并注明，禁止用常识补齐冒充书中内容。
5. 多本书各自建池；共同主题下的相同主干做合并，分歧项直接送入 L4。

## 五、切分自检清单

- [ ] L1 每条 ≤30 字、无形容词、无例子、无比喻？
- [ ] L1 命中「核梳读书法」检验四问（能否一句话概括、作者意图、隐含意义、读后收获）？
- [ ] L2 每条写明了「这层限定改变了主干的什么」？
- [ ] L3 每条标明了支撑的 L1 编号？
- [ ] 全池每条都有原文定位或〔推断〕标记？
- [ ] 是否遵守信息二八取舍，主干只保留高价值命题？
- [ ] 分层是否纯净（L1 无修饰、L2 无故事、L3 不堆结论）？
