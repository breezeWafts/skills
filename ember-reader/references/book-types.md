# 分类型拆书策略

Step 3 必读。类型判定后，L1 主干形态、L2 修饰重点、L3 例证选取与 Step 6 方案侧重均按本表调整。问法主要来自「拆书」思维导图的应用分支，三栏式对应关系来自「阅读3」思维导图。

## 一、类型判定规则

按优先级判定：① 目录结构 → ② 序言/引言中的写作目的 → ③ 正文主要表达方式。跨类时取主类并注明次类，禁止用同一套问法套所有书。

| 类型 | 判定特征 |
|---|---|
| 干货类 | 目录为方法/原则/步骤清单，承诺解决具体问题 |
| 教材类 | 有知识体系、定义、习题、循序渐进的章节依赖 |
| 科普类 | 以解释机制与推理链为主，含概念、实验、证据 |
| 文学类 | 以情节、人物、叙事为主，观点隐含在叙事中 |
| 传记类 | 以时间线/人物经历为主，道理从故事中得出 |
| 散文类 | 形散，无明确中心论证，靠主题与气韵贯穿 |

## 二、六类拆解对照表

### 2.1 干货类

- **L1 主干形态**：可执行的判断句或祈使句（「做 X 能达到 Y」）
- **L1 五问**（拆书原表）：这是什么意思 / 它有什么用 / 它有什么表现形式 / 具体怎么做 / 有哪些应用领域
- **L2 修饰重点**：适用条件、前提、例外、程度、失效边界；三栏式对应「概括内容 / 知识点感悟 / 尝试书中方法」
- **L3 例证特点**：操作步骤演示、正反案例、失败教训
- **L4 对照维度**：同类方法书在「适用条件」与「失败边界」上的分歧
- **方案侧重**：学以致用，每知识点配一个可执行动作

### 2.2 教材类

- **L1 主干形态**：定义、定理、原理（「X 是 Y」「若 A 则 B」）
- **L1 问法**：本章要定义什么 / 它与上一章的依赖是什么 / 学完应会做什么
- **L2 修饰重点**：定义域、约束条件、符号约定、易混概念辨析；三栏式对应「内容对应知识讲解 / 感悟对应知识的理解 / 行动对应举例」
- **L3 例证特点**：例题、推导过程、反例
- **L4 对照维度**：不同教材对同一概念的定义差异与记号差异
- **方案侧重**：知识串联、逐层理解、习题检验

### 2.3 科普类

- **L1 主干形态**：机制性解释（「A 通过 B 导致 C」）
- **L1 问法**：抓大放小——抓住核心推理理论，忽略跟主题过程不相关的复杂细节
- **L2 修饰重点**：专业不语（术语白话化）/ 基础知识 / 逐层理解 / 逻辑推理链的每一环；三栏式对应「内容对应概念、推理 / 感悟对应对知识的理解 / 行动对应应用知识解释身边现象」
- **L3 例证特点**：实验、数据、类比、思想实验
- **L4 对照维度**：同类科普对同一机制的解释差异、新证据对旧结论的修正
- **方案侧重**：模型分析新知、用知识解释身边现象

### 2.4 文学类

- **L1 主干形态**：作者态度与命题（「作者借 X 表达对 Y 的看法」）
- **L1 四问**（拆书原表）：情节 / 作者观点 / 作者想法 / 作者态度
- **L2 修饰重点**：叙事视角、时间线、人物关系限定、意象反复出现的位置；三栏式对应「内容对应情节 / 感情对应小说背后的意义 / 行动结合自身的体会」（并保留「尊重一记」）
- **L3 例证特点**：关键情节、转折、场景细节；用「找口」方式切入（提问题 / 讲故事 / 分析热点新闻）
- **L4 对照维度**：评论界的不同解读、同作者或同流派作品互证
- **方案侧重**：写评论——换位思考、评价（态度）而非感想（个人喜好）

### 2.5 传记类

- **L1 主干形态**：从经历中提炼的道理（「X 阶段的抉择导致 Y，说明 Z」）
- **L1 问法**：故事概括＝知道故事 / 用自己的话说＝从故事了解角色 / 加入自己的感悟＝从故事悟出道理
- **L2 修饰重点**：时代背景、抉择约束、动机与结果的差异；要点为「通过故事总结道理 / 结合自己体会道理 / 活学活用」
- **L3 例证特点**：关键场景、对话、抉择时刻
- **L4 对照维度**：不同传记对同一事件的叙述差异、其他当事人视角
- **方案侧重**：复盘，结合自己的情况回顾作者的理念

### 2.6 散文类

- **L1 主干形态**：主题与气质，而非论证结论（「围绕 X 主题，抓住散文的神」）
- **L1 问法**：没有中心＝围绕一个主题 / 通过散乱的文字，抓住散文的神
- **L2 修饰重点**：意象、语气、节奏、情感转折；允许主干命题以「氛围命题」形式存在，但须标注其非论证性
- **L3 例证特点**：具体物象、细节描写
- **L4 对照维度**：同主题散文的气质差异、作者其他篇目
- **方案侧重**：摘录式笔记（摘抄金句）、一页纸 10 金句

## 三、类型与四级渐进的弹性

- 文学/传记/散文类的 L1 允许出现「作者态度」而非纯主谓宾判断，但仍禁止铺陈情节与例子。
- 教材/科普类 L2 的知识点分块可多于 5 块，但每块仍须遵守「提出问题 → 分析结果 → 解决办法 → 应用方法 → 注意事项」。
- 干货类 L3 的「拔高」优先接现实事件（旁观者变成参与者），其余类型可接写作或讨论任务。
- 所有类型的 L4 四栏（共识/分歧/补充/反例）与来源标注要求一致，不因类型减免。
