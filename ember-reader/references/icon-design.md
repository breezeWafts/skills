# 图标设计说明 · 超级读者「剥枝见干」· v1.2.0

依据 `/evan-design` L0 立意 → L1 八意识 → L2 秩序 → L3 感知 → 逐条校验执行。**v1.2.0 按用户提供的技能列表截图重做视觉语言**：立意与四级语义不变，形式由「宣纸白线稿」改为「白瓷片 app-icon」，并且**画面内 0 个文本节点**（仅保留不可见的 `<title>` / `<desc>` 无障碍名称）。产出 `icon.svg` / `icon-dark.svg` / `icon-mono.svg` / `icon-card.svg` 四件主资产。

## 一、美学立意（L0）

**一句话境界：剥枝见干。** 让一枚 34px 的小图形传达「从满页文字里，一层层剥出那句作者真正想说的话」——观者感到的是从看不懂到忽然懂了的那口松气，而不是「这是个阅读软件」。

- **主范畴：优美。** 阅读、教育、需要安全感的场景默认映射「优美」；形式取小、和谐、柔顺、无冲突。
- **次范畴：意境。** 技能处理书与理解，属文化主题；用虚实相生与留余，而非贴水墨符号。
- **未采纳**：崇高（尺度压迫）、喜剧/荒诞（范畴错配）、纯装饰性「中国风」（符号挪用）。
- **价值观校验**：阅读 = 安静、可反复、不催促；不制造焦虑、不暗示速成，与技能「看懂就停、不替用户判断」的交互伦理一致。

## 二、美感机制（已转译为形式）

| 机制 | 图形转译 |
|---|---|
| 格式塔同构 | 深蓝灰实心书封里，用底色「挖」出一根垂直主干与三对自下而上收短的分叉；力的方向由外向内收束、自下而上生长，与「由繁入简、层层剥离」的理解过程同构。分叉长度对应 L4 对照 → L3 例证 → L2 修饰，主干本身即 L1。 |
| 升华与暗示（秘） | 不画文字、不画眼睛灯泡等直白符号；知识树是**负形**而非描画出来的，观者自行补全「从书里长出来」的一层。 |
| 心理距离（相框） | 白色 squircle 把主视觉从深色界面中框出；图形只占容器约一半，四周大留白，形成观照空间。 |

**意境四步**：立意「剥枝见干」→ 择象「一册合起的书 + 一根主干」（仅此一象）→ 布虚「单一色块 + 大留白」→ 留余「主干顶端以一枚小圆点收笔，不封口」。

## 三、v1.2.0 风格修订（用户参考图优先）

参考截图量测结果，作为本次形式的硬依据：

| 项目 | 参考图实测 | 本版落地 |
|---|---|---|
| 卡片 | `#242424`，圆角 ≈18px（高约 100px） | `icon-card.svg`：`#1C1C1C`，`rx=28`（176 画布） |
| 图标容器 | 44×46px，暖白 `#F9F7F2`，圆角约 32% | 64 画布 `rx=20`（31%），`#FAF8F3` |
| 图形 | 深蓝灰 `#526883` 为主的极简几何 / 细线 | 实心书封 `#526883` + 底色负形线稿，线宽 1.5 |
| 占比 | 图形约占容器线性尺寸 50% | 书封 30/62 ≈ 48% |
| 文字 | 图标内无文字；标题描述在卡片右侧 | **整套 0 个 `<text>` 节点**；不做任何字标、数字、字母 |

**本次替换**
- 删除 `assets/brand-lockup.svg`（含「超级读者 / EMBER READER」两行字标）——用户明确要求不要文字。
- 新增 `assets/icon-card.svg`：深色圆角卡片 + 居中一枚白色 squircle 图标，无任何文字，直接复现参考图的视觉节奏。
- 三版主图标**路径完全一致**，仅根部 Token 换色：浅色（暖白 / 靛蓝灰 / 朱砂）、暗色（墨底 / 明度补偿 `#708CB1` / `#E0705F`）、单色（暖白 / 纯墨 / 0 破格）。
- 配套六枚与 sprite 同步换用同一容器、同一书脊基线、同一线宽；语义仍只由形态承担。

**技术例外（实测）**：`rx` 是 SVG 1.1 几何属性，Chromium 在 presentation attribute 中不解析 `var()`（无头浏览器截图验证：`rx="var(--icon-radius)"` 会退化为直角）。故容器圆角写字面值 `20`，颜色、描边、卡片底色仍全部由根部 Token 驱动，宿主可覆盖。根部保留 `--icon-radius` 作为该数值的文档化记录。

## 四、形式落地（L1 → L3）

| 层 | 决策 | Token / 数值 |
|---|---|---|
| L1 · 微 | 全部线稿 1.5px、圆端点；尺寸档 34 / 21 / 16px | `--icon-stroke:1.5` |
| L1 · 间 | 图形集中 30×30 单位，周边留白 >40%；分隔靠留白 | 容器仅一层 `rgba(28,28,28,0.06)` 1px 边界 |

| L1 · 破 | **主图标 1 处受控破格**：右上角朱砂实心点，显式 `--accent-ha`；其余元素 100% 合规 | `#B5483A`（浅）／`#E0705F`（暗）／单色版同墨色 |

| 无障碍 | 靛蓝灰/暖白 ≈5.2:1、暗色 ≈4.4:1，均 ≥3:1；朱砂点同时是「唯一实心圆点」的形状编码，单色版改为墨点，不依赖颜色；`<title>`/`<desc>` 提供可读名称 | WCAG 2.1 AA |

## 五、审美自检

**四契机**：质（去掉用途，收束的枝与一点朱砂仍是自足小景）／量（无需解释「四级渐进」，直觉读出「很多东西收成一根」）／关系（负形挖空本为留余，恰好对应「从书里剥出主干」）／情状（换成书+灯泡/眼睛/大脑就不像本技能）。

**进阶层级**：养眼（低饱和、秩序清晰）→ 养心（收束的力结构带来「忽然懂了」的松弛）→ 养神（顶端留余、境生象外）。文化主题目标第三层，由「虚」的结构与单一物象达成。

**三赛道**：功能（三档尺寸、三版覆盖浅/暗/单色、sprite 可内联）／审美（范畴一致、焦点 ≤1、破格 ≤1、通过「度」检查）／价值（不制造速成焦虑、不挪用文化符号、不靠颜色单独编码）。

**速查表核对**：留白 ≥40% ✅｜斐波那契间距 ✅｜无字号（纯图形）✅｜图形对比 ≥3:1 ✅｜不单靠颜色 ✅｜饱和度 ≤45% ✅｜焦点 ≤1 ✅｜无纯白纯黑 ✅｜渐变 0 ✅｜Token 驱动（rx 例外已记录）✅｜破格 1 处且已标注 ✅｜无自动动效 ✅｜**画面内文字 0** ✅。

## 六、复用约定

- 需要「参考图那种观感」时直接用 `assets/icon-card.svg`；需要单枚图标时用 `assets/icon.svg` 放进任何深色圆角容器。
- 前端内嵌保留根部 Token；宿主已引入全局 Token 时可覆盖同名变量。暗色适配覆盖 `--icon-bg` / `--icon-ink` / `--icon-cut` / `--icon-edge`，**不要**简单反色。
- **禁止在图标内添加任何文字、字标、数字或字母**；层级语义一律由分叉形态承担。
- 破格点色值不得改为其他高饱和色；移除破格改为 0 处同样合规。
- 重新生成整套资产：`python scripts/build_icons.py`（脚本会自检 XML 与「无 `<text>` 节点」）。
