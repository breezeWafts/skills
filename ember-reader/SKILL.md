# 超级读者 · Ember Reader

## Overview

把「一本书或多本书」转化为「按理解深度逐级展开的知识结构」。核心逻辑是**句子成分即理解层级**：先抽出主谓宾级主干命题（作者到底想说什么），再挂回定状补级修饰限定（把主干拆成知识点），再补上例证、故事与类比（把抽象讲具体），最后引入同类书籍做主题阅读对照。每一级都由用户自己判断「看懂没有」，看不懂才展开下一级，绝不一次性倾倒全部内容。

方法论骨架来自内置的五套思维导图（思考能力、阅读、整体性学习、效率、拆书），完整提炼与映射见 `references/methodology.md`。

**内置知识库**：`knowledge/` 下五领域规则库（IT／数据分析／美学艺术／摄影／影视，约 4741 行、506 个章节）。命中领域时，用库中的定义、规则、检查清单与反模式作为**概念锚点**，帮助把书里的主张、限定与例证拆得更清楚；它只是参照系，不是书的内容。判定、取用与标注规则见 `references/knowledge-bridge.md`。

**输入**：书名 / 书籍链接 / 本地书籍文件，一本或多本，可混合给出。
**输出**：对话内逐级展开的分层讲解 → 学习与复习方案 → 经授权后落盘的思维导图与精简知识库。

## 触发门禁（先于一切规则执行）

- 触发方式固定为 `/ember-reader` 或「超级读者」；用户直接给出书名、书籍链接、书籍文件并表达读/拆/提炼意图时同样触发。
- 触发词出现后，剥离触发词再执行后续流程。
- 单纯的书名闲聊、购买建议、普通知识问答不触发本技能的拆分流程，按常规对话处理。

## 前置条件与合规边界（硬约束，违反即停止）

1. **合法来源优先**：内容获取严格按「用户提供的本地文件 ＞ 用户提供的公开链接 ＞ 联网可合法获取的公开资料（目录、序言、试读、摘要、书评、作者访谈、公开课讲义、公有领域全文、图书馆开放元数据）」顺序进行。
2. **禁止绕过**：不得绕过付费墙、登录限制或 DRM，不得从盗版站点抓取全文，不得整章复制受版权保护的正文。
3. **覆盖度如实标注**：无法合法取得全文时，禁止假装已读全书。必须声明「未获取全文」，列出已获取材料清单与覆盖章节比例，并只基于已获取部分做结构性提炼；推断所得一律标注〔推断〕。
4. **引用克制**：以概括、转述为主；确需引用时使用短句并标注出处（章/节/页码）。
5. **不虚构**：不得编造书中不存在的观点、案例、数据或章节。资料冲突时并列呈现并标注来源，不擅自裁决。

## 执行工作流（按顺序，不可跳步）

### Step 1 · 解析输入

提取书目清单（一本或多本）及每本的输入类型：书名、链接、本地文件。确认用户是否已给出阅读目标（考试、写作、实践、通识了解）；未给出时按「通识理解」继续，不打断询问。多本书时记录它们之间是否存在共同主题，供 L4 主题阅读使用。

### Step 2 · 获取内容

读 `references/acquisition.md` 后执行：本地文件按类型调用对应的读取能力（PDF / Word / EPUB / 纯文本 / Markdown）；链接取公开页面正文；书名联网检索合法公开资料并尽力取得目录与结构化内容。逐本产出「材料清单 + 覆盖度声明」。对每本书明确写出：已覆盖章节、未覆盖章节、全文是否取得。

### Step 3 · 判定书籍类型

读 `references/book-types.md`，把每本书归入干货类 / 教材类 / 科普类 / 文学类 / 传记类 / 散文类之一（跨类时取主类并注明次类）。类型决定后续主干命题的形态与拆书问法，不得用同一套问法套所有书。

### Step 3.5 · 知识库锚定（命中领域才执行）

读 `references/knowledge-bridge.md`，用书名、目录与已获取摘要判定本书是否落在内置五领域（IT／数据分析／美学艺术／摄影／影视）：

1. 运行 `python scripts/knowledge.py domains` 查看领域与路由关键词；跨领域取主库，次库只补概念定义。
2. 用 `python scripts/knowledge.py query "<3–6 个核心概念词>" --domain <id> --top 5 --max-chars 6000` 取回带「文件 · 章节 · 行号」的片段；无命中时先用 `sections --domain <id>` 浏览章节树再换词。
3. 把片段整理为 **K 参照卡片**（定义锚点／规则校准／检查清单／反模式／流程框架），挂到对应 L1 主干编号，存入内容池旁路；每本默认 3–8 张，单次载入不超过 6000 字符。
4. **未命中则明确记录「知识库未命中」**，后续四级不得引入知识库内容，禁止硬套规则。命中结论与理由写入材料清单，随首次输出一并声明。

硬约束：知识库是参照，不是书的内容。任何 K 条目输出时必须带 `〔知识库·文件｜章节｜行号〕`，与书中原意分栏或分条呈现，冲突并列不裁决；**L1 只用 K 卡片做内部自检，不得输出**。知识库命中不改变覆盖度声明，也不替代 L4 的联网检索。

### Step 4 · 三层提炼，建立分层内容池

读 `references/layering-grammar.md`，对全书做三轮扫描并在内部建立分层内容池（此阶段**不向用户输出**）：

| 层 | 扫描对象 | 归入 |
|---|---|---|
| 语法层 | 句子成分：主谓宾 / 定状补 / 关联词 / 限定与例外 | L1 主干命题、L2 修饰限定 |
| 文法层 | 篇章结构：章节层级、论证链、提出问题→解决问题→方法→注意事项 | 全书骨架、知识点分块 |
| 语义层 | 作者意图、隐含意义、概念定义、例证与类比、价值立场 | 作者意图、L3 例证、〔推断〕标注 |

内容池固定为四级展示内容：**L1 主干 / L2 修饰·知识点 / L3 例证·故事·类比 / L4 同类对照**；另设**旁路 K 参照条目**（Step 3.5），K 不占展示层级、不单独成级。每一条内容必须携带原文定位（章/节/页码或〔推断〕标记）与其所挂载的 L1 主干编号；K 条目则携带 `〔知识库·文件｜章节｜行号〕`。多本书时各自建池，再按共同主题合并 L4。

### Step 5 · 四级渐进交互（核心，逐层询问）

严格遵守「一次只给一层、由用户决定深入」的协议。每级展示完必须停下并给出三选一：**① 已看懂，到此为止　② 没看懂，展开下一层　③ 针对第 N 条再讲**。禁止替用户判断理解程度，禁止提前透露下一级内容。用户可跳级、回退或指定某条主干命题深入。

#### L1 · 主干干货（默认首屏，必给）

只输出去掉全部修饰与例证后的**骨架**，回答「这本书想把什么告诉读者、作者想传达什么」：

- 一句话主旨（不超过 30 字）
- 3–7 条主干命题（每条一个主谓宾级判断句，不带形容词、不带例子）
- 作者意图（作者写这本书要改变读者的什么认知）
- 全书骨架（3–6 段式结构，对应基础阅读：了解意思）

按「核梳读书法」的四问自检后再输出：一两句话能否概括内容、作者意图是否明确、文字背后隐含的意义、读后收获。此层出现任何举例、故事、比喻、修饰语即为不合格，须回炉重切。

#### L2 · 修饰层 · 分知识点（用户表示不懂才展开）

把定语、状语、补语、程度、范围、条件、例外、因果、否定等限定成分挂回各自的主干命题，按知识点分块展示。每块采用三栏式笔记：

| 内容（原文主干 + 修饰） | 感悟（这层限定改变了什么理解） | 行动（据此做点什么） |
|---|---|---|

每块内部按「提出问题 → 分析结果 → 解决办法 → 应用方法 → 注意事项」组织；对第一遍没读懂的逻辑与多义词做「慢想」标注。对应解释阅读：抓重点。

命中知识库时，在知识点块的三栏之后**另附**「〔知识库参照〕」条目：给出该概念在库中的定义、适用条件、边界或检查项，标注 `〔知识库·文件｜章节｜行号〕`。禁止把知识库规则写进「内容」栏冒充原文，也禁止用它替换书中的限定成分。

#### L3 · 例证层 · 故事与类比（仍不懂才展开）

展示书中为讲清主干而使用的示例、实验、数据、故事性叙述、类比与比喻，逐条标明它支撑哪一条 L1 主干。可调用思维工具：抽象比喻成具体、对立面思考、贴标签（第一印象／最具特点的表面印象）、画图形辅助思考。结尾做「拔高」：把要点接回现实事件，让旁观者变成参与者。对应分析阅读：理解消化主题。

命中知识库时，可把每条例证映射到 K 卡片的对应规则或「失败信号」，形成「例证 ↔ 规则」对照，说明这个例子究竟在证明什么。例证本身仍只取书中内容，映射是参照，不得新增书中没有的故事。

#### L4 · 同类对照（最后一层，需联网）

联网检索同类别书籍或同类别核心内容，做主题阅读式多维对照，输出四栏：**共识 / 分歧 / 补充 / 反例**，并注明来源链接。调用批判思维四律：大胆假设、小心求证、谨慎判断是非、切记盲从；对每个分歧追问「探究决策背后的原因」「多角度看问题」「提前预测可能的结果」。多本书输入时先做书与书之间的互证，再补外部同类资料。对应主题阅读：深入领域。

命中知识库时，在四栏之后增加「**知识库校准**」小节：指出哪些共识／分歧／反例在本地库中有对应规则、检查项或反模式，逐条标注 `〔知识库·…〕`。联网资料与知识库并列为两类来源；二者冲突时并列呈现、不擅自裁决，也不得以知识库替代联网检索。

> 每一级结束时复述当前层级编号与已展开范围，方便用户随时回退。L4 完成后不再主动展开新内容，直接进入 Step 6。

### Step 6 · 学习与复习方案

读 `references/outputs.md` 与 `references/methodology.md`，按书籍类型、用户阅读目标、当前已展开到的层级，生成个性化方案，必须包含：

- **学习路径**：整体性学习的四段（快速阅读 → 知识串联 → 学以致用／费曼技巧 → 持续专注），并给出「图钉学习法」的锚点与「知识结构网」的挂接位置。
- **时间排程**：早上精力最充沛的时段安排理解-判断-抉择类高耗任务；按重要程度象限做主动安排；明确减少任务切换，避免把高耗任务拆碎。
- **复习节奏**：间隔复习时间表（含每次复习只做的最小动作）、费曼自检题、一页纸复盘（结合自己的情况回顾作者的理念）。
- **检验清单**：读后能否一两句话概括、能否说出作者意图、能否指出隐含意义、能否列出读后收获。
- **知识库验收项**（仅命中时）：复用库中流程清单／检查清单作为补充验收项并标注来源，不替代上述读后四问，不把行业规范写成用户必做动作。

### Step 7 · 授权后导出（未获授权不得写任何文件）

逐项向用户请求明确授权，用户确认哪些才做哪些，不得默认全选：

1. **思维导图**：结构化脑图文件（优先 `.xmind`，调用本地脑图能力；或输出 Mermaid / OPML / Markdown 层级），层级固定为 书名 → L1 主干 → L2 知识点 → L3 例证 → L4 对照。
2. **精简知识库**：一页纸（16 关键词 vs 10 金句）、三栏式笔记合集、按模块拆分的知识条目，Markdown 输出；命中领域且用户授权时可附「知识库参照索引」（文件 · 章节 · 行号），单独成节、不与书籍条目混排。
3. **可选**：分层内容池 JSON（供后续复用）。

使用 `scripts/export_knowledge.py` 做确定性转换：先把分层内容池整理为 `assets/layers-template.json` 的结构，再运行脚本产出 Markdown 知识库、Mermaid 脑图与 OPML。默认输出到当前工作区，遇同名文件先询问，不静默覆盖。

## 交付铁律（不满足任一条，不得交付）

1. **分层纯净**：L1 不含修饰与例证；L2 不含故事；L3 不重复 L1 结论式堆砌；L4 有可核查来源。
2. **交互不可跳过**：未经用户表态不得自行展开下一级；每级末尾三选一齐全。
3. **可追溯**：每条内容有原文定位或〔推断〕标记，覆盖度声明随首次输出一并给出。
4. **合规**：无付费墙绕过、无盗版全文、无整章复制、无虚构内容。
5. **方案落地**：学习复习方案含具体时段、具体动作、具体检验项，不写空泛建议。
6. **授权前置**：任何落盘文件都发生在用户明确授权之后。
