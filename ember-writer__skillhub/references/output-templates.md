# 输出模板

按 `SKILL.md` Step 0 判定的模式取用。模板中的方括号为占位，生成时替换为实际内容；不需要的字段整块删除，不保留空壳。

---

## A. 完整生成（direct）

```
# [标题]

[正文：起 → 承 → 转 → 合，用段落自然承载，不强制四个小标题]

---

## 创作说明

- **体裁**：[体裁] ｜ 判定依据：[依据]
- **动机**：为什么写——[回答]；解决什么问题——[回答]
- **灵魂点**：[卖点 / 爆点 / 动情点] — [具体是什么]
- **审美定调**：目标层级 [养眼 / 养心 / 养神]；主审美形态 [优美 / 悲剧 / 崇高 / 丑 / 喜 / 荒诞]；核心意象 [≤1 个]
- **视角与手法**：[自我观察 / 上帝视角]；[选用的手法与技巧]；[选用的审美修辞]
- **修改记录**：[逐条列出实际修改项；无修改写「全部检查项通过」]
- **审美校验**：通过项与未达标项（按 `aesthetics-checklist.md` 格式）
- **待人工复核**：[无法静态确认的项，如事实、数据、引文来源、读者实际感受]
```

## B. 交互生成（interactive）

每一轮只推进一个阶段，末尾附 2–4 个下一步选项。

### 轮次模板

```
## 第 [n] 轮 · [阶段名：灵魂与动机 / 构思骨架 / 正文初稿 / 修改方案]

[本阶段产出]

### 下一步，选一个：
1. [选项一：具体动作]
2. [选项二：具体动作]
3. [选项三：具体动作]
（或直接用一句话告诉我你的想法）
```

### 阶段顺序

1. 第 1 轮：灵魂与动机（含受众反应目标）
2. 第 2 轮：起承转合骨架（长篇含人物表与分章）
3. 第 3 轮：正文初稿
4. 第 4 轮：修改方案与终稿

用户说「你定 / 按你的来 / 直接写完」时，立即切回 direct，一次交付终稿。

## D. 低输入引导（coach）首轮

```
我先给你 3 个可写的方向（基于你提到的「[用户原话关键词]」）：

方向 A｜[灵魂点类型]：[具体的点]
- 一句话梗概：[谁 / 什么处境 / 反常的事 / 结果]
- 标题：[可用标题]
- 推荐体裁：[体裁]
- 情绪落点：[读完想让人产生什么感受]

方向 B｜……

方向 C｜……

选一个（A/B/C），或说「你定」由我选最贴合的一个直接写。
```

---

## 交付规则

1. 文件写入 `outputs/`，命名 `<主题>-<体裁>.md`；同名文件存在时追加序号。
2. 用文件展示工具呈现给用户；正文回复只给摘要与关键结论，不重复整篇全文。
3. 待人工复核项必须显式列出；不得用「已确认」掩盖未验证内容。
4. 用户素材中的真实经历、数据、姓名不得擅自改写或补全；缺处标「待补」。
