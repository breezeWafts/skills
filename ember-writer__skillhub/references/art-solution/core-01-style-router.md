# 风格 / 氛围 / 感觉 → 美学定位路由引擎

> 本文件是 `ember-art-solution` 的**核心引擎**：把用户一句自然语言（「给我一份 XX 风格 / XX 氛围 / XX 感觉的 XX 产品方案」）解析成一张可执行的**美学定位卡（Aesthetic Brief）**，后续所有交付物都从这张卡展开。
> **设计目标**：用户只说一句话就能出完整方案，不追问、不打断；缺失信息一律按本文件的推断规则补全并在交付物里标注「〔推断〕」。

---

## 一、输入语法（用户只需说到这个程度）

```
/ember-art-solution 给我一份【风格/氛围/感觉】的【产品】方案，内容是【素材/主题/用途】
```

三个槽位，**任意一个非空即可启动**：

| 槽位 | 典型说法 | 缺失时怎么办 |
|---|---|---|
| **美学意图** | 「东方美学意境」「侘寂感」「清冷高级感」「宋式极简」「赛博但要有留白」「温暖治愈」「根据作品内容制定」 | 见 §5 缺省推断：从内容主题、受众、用途反推 |
| **产品类型** | 30 秒分镜脚本 / 一组照片 / 海报 / 网站 / 小说 / 室内 / 庭院 | 从「内容是…」判断；实在无法判断时默认给「方案 + 视觉基调」 |
| **内容素材** | 故事梗概、作品集、品牌信息、空间条件、字数时长、平台 | 按专业惯例补全，标注「〔推断〕」 |

**示例（真实调用）**
- `给我生成一份 30 秒的视频分镜脚本，故事内容为 XXX，需要东方美学意境`
- `给我生成一套摄影作品展示的网站，风格根据作品内容制定`
- `要一张有「雨后空山」感觉的专辑封面方案`
- `做一个侘寂氛围的茶室室内方案，35㎡，朝北`

## 二、四条「主动感觉意境」路径 + 三条「被动感受意境」路径

来源：工作区《其他参考.md》。**先判断用户走哪条路，再决定推断依据**，避免把「氛围」误当「情绪」处理。

### 2.1 主动感觉意境（用户明确给了主观指向）

| 路径 | 识别信号 | 推断依据 | 落卡字段 |
|---|---|---|---|
| **情绪主导** | 「孤独」「治愈」「怅惘」「燃」「压抑」 | 按情绪词族定位主情绪 → 审美形态 → 全感官参数（`core-09`） | 主情绪 / 强度 / 审美形态 |
| **性格主导** | 「内敛」「克制的」「少年气」「清冷疏离」「温润」 | 把性格转译成形式气质：内敛→低饱和+减形+慢节奏；外放→高饱和+动势+快节奏 | 气质形容词 / 节奏 |
| **氛围主导** | 「雨夜」「空山」「旧书店」「清晨薄雾」「市井烟火」 | 氛围=场景＋气象＋光＋声的复合体，先拆成「时间/天气/光/声/材质」五要素再定体系 | 场景五要素 / 体系 |
| **意愿主导** | 「想让人慢下来」「想表达放下」「希望看完有力量」 | 从愿景/潜意识反推：目标观者反应 → 需要的美感机制（移情、心理距离、升华） | 目标反应 / 美感机制 |

### 2.2 被动感受意境（用户没给感觉，靠科学底座托底）

| 路径 | 何时启用 | 硬约束 |
|---|---|---|
| **人体工程学（舒适）** | UI / 空间 / 长图文 / 任何有操作或动线的产品 | 界面布局操作顺畅、可扫读、动线不折返；空间尺度与停留节奏合理。此项**优先于纯 aesthetic 表达** |
| **色彩心理学** | 未指定风格但要「高级 / 舒服 / 专业」 | 按 `core-03` 与 `core-09` 的色彩情绪映射取色；低饱和莫兰迪=高级与宁静，高饱和高对比=情感热烈 |
| **美学心理学** | 需要「讲得出道理」时 | 调用 `core-07` 的格式塔同构、审美距离、移情、内模仿/通感，为参数找心理依据 |

> **裁决顺序**：用户明确意图 ＞ 被动人体工程学硬约束 ＞ 色彩心理学 ＞ 美学心理学。任何美学表达不得违反可用性与可读性。

## 四、五步定位法（S1–S5，不可跳步）

| 步 | 动作 | 依据 | 产出 |
|---|---|---|---|
| **S1 解析** | 拆出美学意图 / 产品类型 / 内容素材 / 硬约束（尺寸、时长、平台、字数、预算、人群） | §1 | 需求槽位表 |
| **S2 定体系** | 按 §3.1 词库定位一级体系；词库未收录时按语义最近项 + 内容文化语境推断，标注〔推断〕 | `core-00` 第一部分 | 主体系（+ 可选次体系与主次比） |
| **S3 定流派与逻辑** | 下沉到三级流派；**必查 `core-00` 第三部分**锁定色彩观念 / 光影 / 空间 / 终极目标 | `core-00` 第一、三部分 | 流派名 + 四条底层逻辑 |
| **S4 定形态、情绪与色** | 按 §3.2 定主情绪与审美形态；按 `core-03` 取色板（主色/辅色/点睛色 + 色名 + HEX）；按 `core-04` 定形式手法 | `core-03/04/06/09` | 形态 + 情绪强度 + 色板 + 形式手法 |
| **S5 出定位卡** | 汇总成「美学定位卡」写进交付物头部，并声明期望的观者反应 | `core-07` | Aesthetic Brief |

### 跨体系混搭规则（仅在用户明确要求或内容强需要时启用）

1. 指定**主次比**（默认 7:3），主体系决定空间逻辑与光影，次体系只贡献色彩或纹饰层。
2. 明确**接缝**：写清哪些元素属于主体系、哪些属于次体系、二者在什么位置过渡。
3. **禁止**：东方的「留白」与伊斯兰的「填满」同时作为全局构图原则；西方的「焦点透视」与东方的「散点游观」在同一画面无过渡并存。
4. 混搭方案必须在定位卡里写「混搭理由」，否则退回单体系。

## 五、缺省推断规则（用户说「风格根据作品内容制定」时）

当美学意图缺失或用户主动授权由内容决定时，按以下顺序推断，**每一步都要在交付物里给出一句依据**：

1. **看题材的文化语境**：涉及山水、茶、书、禅、器物、四时 → 东方（宋/侘寂）；涉及几何、机械、都市、数据、科技 → 西方（冷抽象/构成主义）；涉及纹样、穹顶、沙漠、星月 → 伊斯兰。
2. **看作品本身的色彩与明度**：低饱和、灰调、留白多的作品 → 宋代/侘寂；高饱和强对比 → 明清/印象派/波斯；单色或黑白 → 宋代水墨 / 冷抽象。
3. **看用途与受众**：作品展示站 → 让位给作品，用「中性容器」策略（宣纸白/墨黑底 + 极低饱和 + 大留白 + 单一强调色），体系取宋代极简；商业促销 → 明清或波斯的饱满高饱和；专业工具 → 冷抽象的网格秩序。
4. **看情绪基调**：内容偏静 → 意境；偏冲突 → 崇高/悲剧；偏轻快 → 优美/喜剧。
5. 仍有歧义时，**默认「东方·宋代美学（取东方共性）+ 意境形态 + 中性容器」**，并明确标注这是默认取值、可一句话改。

> **中性容器原则**（展示型产品专用）：当交付物是为了呈现别人的作品（摄影作品站、画册、作品集、展览页），美学表达必须**退到背景层**——大面积素底、极窄色域、克制的字阶、充足留白、动效仅用于引导视线，禁止用强风格抢夺作品注意力。

## 六、美学定位卡（Aesthetic Brief）· 标准格式

每张交付物头部 MUST 含此卡（可压缩为表格，但字段齐全）：

```markdown
## 美学定位卡
- 需求原话：……
- 主体系 / 流派：东方美学 · 中式 · 宋代美学（或「取东方共性」＋理由）
- 底层逻辑：观念色 / 消解光影·意象光 / 散点游动·留白气口 / 终极目标=意境
- 主情绪 / 强度 / 审美形态：平静 · 中 · 意境
- 风格 or 派别：风格调用（说明是否跨时空）  ※ 见 core-00 第二部分
- 色板：主 天青 #8CB8C9（60%）／辅 宣纸白 #FAF8F3（30%）／点睛 朱砂 #B03A2E（10%，≤1 处）
- 形式手法：色彩留白 + 构图留白 + 光影留白（三法见 core-04）
- 感官基调：视觉…／听觉…／材质…／节奏…
- 目标观者反应：先松一口气，继而静下来，最后有一点余味
- 混搭（如有）：主 7 : 次 3，接缝在……
- 〔推断〕项：场景时段、受众、平台……
```

## 七、反模式

1. **只给形容词不给参数**：「高级、有质感、有氛围」而不落到体系/色值/构图/光影 → 不合格。
2. **风格词当滤镜**：把「侘寂」理解成「加个滤镜 + 摆个粗陶」，却仍用对称满构图与高饱和 → 违反底层逻辑。
3. **追问成灾**：用户已给出足够信息还连问三四个问题 → 违反「一句话出方案」目标，按 §5 推断。
4. **跨体系无主次**：同时出现月亮门、彩窗、蒙德里安网格且无接缝说明。
5. **忽略硬约束**：为了留白把正文对比度压到不可读，或为了动势让 30 秒脚本塞 40 个镜头。

> 定位完成 → 去 `core-02-delivery-matrix.md` 选交付规格与执行子流程。
