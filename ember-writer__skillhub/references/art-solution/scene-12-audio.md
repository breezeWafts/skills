# 听觉美学 · 声景 / 配乐 / 通感（N）

> 服务 `core-02` 的 N 类交付，并为 D/E（分镜）、K/L/M（空间）、J（交互反馈音）提供听觉规范。
> **总纲**（《其他参考.md》）：「美学直观的表达就是画面和声音」。声音与画面同为**直接的审美载体**，不是画面的附属装饰。
> 知识来源：`应用-电影视频/表达.txt`「声音」条、`剪辑.txt`「声音转场」、`情绪 01–09`、`转场切换.txt`、`core-09` §4，以及联网补全的中式五感营造与声景资料。

## 一、声景五层结构

| 层 | 内容 | 美学职能 | 约束 |
|---|---|---|---|
| **环境音** | 风、雨、虫、市井、空间底噪、房间 tone | 定义场域的远近、大小、材质与季节（对应八意识之「气」） | 优先真实收录；须有远近层次，不能是一层平铺的底噪 |
| **效果音** | 器皿、脚步、门、衣袂、炭火、檐滴 | 承担「微」与「内模仿」，以极轻的声响调动身体记忆 | 音量宜低，靠质感而非响度取胜 |
| **音乐** | 主题动机 / 泛音 / 循环 / 和声推进 | 承载情绪曲线与形态节奏 | **不铺满**；必须有明确进入点与退出点 |
| **人声** | 台词、旁白、呼吸、停顿 | 承载叙事与「间」 | 呼吸与停顿是内容，不是待剪掉的空白 |
| **静默** | 刻意无声段 | **以稀声反衬寂静**，为寂静划出轮廓与深度 | **每案至少 1 处**；静默前后须有声源作对照 |

> 「蝉噪林逾静，鸟鸣山更幽」——**寂静是被声音量出来的**。真正的静谧不是死寂，而是足以容纳所有细微声响的广阔背景。

## 二、声音留白（听觉版的留白三法）

对应 `core-04` §2，把视觉留白三法转成听觉：

| 视觉法 | 听觉转译 |
|---|---|
| **色彩留白**（减色相、降饱和） | **减声源与减频段**：只留 1–2 个声源，收窄频谱，避免全频段铺满 |
| **构图留白**（减形、偏置、省略环境） | **减信息密度**：省略说明性音效，把主声源偏置到声场一侧，留出声像空域 |
| **光影留白**（减信息、光不平均、以暗托明） | **响度不平均**：以低响度托出一次清越的高响度细节，以静默托出一声 |

三条至少用两条。**「此处不放 BGM」是一个明确的设计决策，必须写进方案**，不能是遗漏。

## 三、体系化声音（按 `core-00` 第三部分推导）

| 体系 | 空间逻辑 | 声音组织 | 典型音色 | 禁忌 |
|---|---|---|---|---|
| **东方**（宋 / 侘寂） | 散点游动、留白气口、时间延展 | **非均等节拍、泛音与余韵、稀疏事件、长静默**；声音随四时与偶然发生，不按小节推进 | 古琴泛音、钟、檐滴、竹帘、炭火、雨、虫、尺八气声 | 满铺的强节奏 BGM、四四拍循环、密集音效 |
| **西方**（古典 / 近代） | 焦点、比例、递进与再现 | **主题动机—发展—再现**，和声推进与动态积累；有明确高潮点与终止式 | 弦乐、钢琴、管风琴、按形态选配器 | 无结构的环境噪声堆砌 |
| **伊斯兰** | 无限延伸、无中心、循环几何 | **循环与无限节奏**，均匀、无始无终，纹样式重复而非主题发展 | 打击乐循环、吟诵、细密装饰音型 | 强烈的起止对比、戏剧性终止 |

> 与形态的配合：崇高＝低频 + 大动态 + 压迫性静默后释放；悲剧＝稀疏渐弱 + 余韵；喜剧＝突停与意外音效；荒诞＝不协和与错位；意境＝稀声 + 静默 + 泛音。详见 `core-06` §2、`core-09` §2。

## 四、通感映射表（跨感官方案与文字描写用）

| 听觉属性 | 稳定联觉 | 可对应的视觉 / 触觉 / 空间 |
|---|---|---|
| 低频、浑厚 | 重、暗、大、近身 | 深色、粗粝材质、低明度、大体量 |
| 高频、清透 | 轻、亮、远、锐 | 浅色、玻璃/瓷、高明度、细小体量 |
| 长混响 / 泛音余韵 | 空、远、有余味 | 大留白、雾、空镜、虚处 |
| 短促干声 | 实、近、确定 | 硬边、实焦、明确轮廓 |
| 声像偏置 | 空间不平衡、有方向与期待 | 偏心构图、引导线 |
| 渐强 / 音高上行 | 上升、希望、展开 | 上摇、向光、开口 |
| 渐弱 / 静默 | 收束、余韵、留白 | 淡出、空镜、不写尽 |
| 粗糙噪声质感 | 涩、旧、岁月 | 未打磨石、夯土、包浆 |
| 圆润中频 | 温、润、可亲 | 原木、棉麻、暖光 |

**用法**：写作（A/B/C）里用通感把「气氛」变成可感的身体经验；空间（K/L/M）里用声源定义人在空间中的距离感；分镜（D/E）里用声音与画面的通感一致性做「同向性」校验。

## 五、声画关系四种

| 关系 | 说明 | 适用 |
|---|---|---|
| **同步** | 声源与画面同源同时，强化真实感 | 纪实、生活细节、效果音 |
| **对位（平行）** | 声音与画面情绪同向但不同源，互相加持 | 意境、温情、崇高 |
| **反差（对立）** | 声画情绪相反，制造张力或反讽 | 悲剧、荒诞、批判性内容；**须写明目的** |
| **窜前 / 延后** | 声音先于画面出现，或画面切走后声音延续 | 转场、悬念、余韵（八意识之「秘」） |

**转场声音四法**（`应用-电影视频/剪辑.txt`、`转场切换.txt`）：
1. **声音窜前**：先有钢琴声，再切到有钢琴的画面。
2. **相同声音转场**：打电话、同一段环境音跨场景延续。
3. **语言转场**：用台词引导观众，让场景转换符合逻辑。
4. **反差声音转场**：用声音的骤变制造时空跳跃。

无技巧转场同样适用于听觉：相似音色、相似节奏、遮挡式静默、定格后的一声。

## 六、时间节奏与气口

| 交付物 | 节奏要求 |
|---|---|
| 短视频（E） | 卡点可密，但 MUST 留 0.5–1.5 s 空镜或静默作「气口」；结尾意境型用淡出/余韵，不用硬切 |
| 长视频（D） | 声音有起承转合，与 `core-06` §4 形态节奏同步；全片至少 2 处静默段 |
| 空间（K/L/M） | 声景随动线分段；每个停留点有专属声源；至少 1 处「只闻自然声」的区域 |
| UI（J） | 反馈音极短、极轻、可关闭；不得有自动播放的循环音 |
| 纯声景（N） | 有明确的进入—铺陈—稀声—静默—余韵结构 |

## 七、N 类交付规格

```markdown
## 声音立意（一句话境界目标）
## 体系与形态定位（引用美学定位卡）
## 声源清单：环境音 / 效果音 / 音乐 / 人声 / 静默（逐项列内容与来源）
## 层次与响度：近—中—远三层，各层响度关系与峰谷位置
## 频谱与音色：频段分配、音色选择、体系依据
## 时间结构：时间轴分段（含至少 1 处静默与 1 处余韵）
## 通感映射表：听觉属性 ↔ 视觉/触觉/空间
## 与画面的对位关系：同步 / 对位 / 反差 / 窜前，逐段标注
## 转场与衔接：声音转场四法的选用位置
## 落地约束：采样来源、设备、混音、播放环境、响度标准
## 校验结论
```

**验收硬指标**
1. 不是全程铺满；至少 1 处刻意静默。
2. 声源有近中远三层，非单层平铺。
3. 声音组织方式与体系的空间逻辑同向（东方非均等／西方动机发展／伊斯兰循环）。
4. 通感映射与视觉方案不打架。
5. 所有反差/窜前处理写明目的。
6. 符合 `core-10` 第一重 N 类必过项与八意识「间 / 气 / 微 / 秘」。

## 八、反模式

1. **BGM 全程铺满**：把「有配乐」等同于「有声音设计」，消灭寂静。
2. **静默是遗漏**：方案里没写，实际是懒得做——必须作为决策写明。
3. **音效百科**：每个动作都配一个提示音，剥夺「微」与内模仿。
4. **体系错配**：侘寂空间放强烈的四四拍循环，或哥特崇高主题用轻快电子音且无说明。
5. **声画两张皮**：画面大留白、声音却密集；或画面慢、声音快切。
6. **忽略播放环境**：为手机外放设计的低频在手机上完全听不见，落地即失效。
