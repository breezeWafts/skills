## 一、八大情绪词族

| 词族 | 主情绪 | 细分情绪词 |
|---|---|---|
| 孤寂族 | 孤独 | 孤独、寂寥、失落、空虚、疏离、迷茫、怅惘、伤感、忧郁、落寞 |
| 温情族 | 温暖 | 温馨、幸福、眷恋、治愈、柔软、亲密、感恩、安心、怀旧 |
| 炽烈族 | 炽热 | 炽热、激情、狂喜、兴奋、愤怒、冲击力、生命力、躁动 |
| 憧憬族 | 期待 | 期待、向往、憧憬、希望、悸动、好奇、昂扬、追光 |
| 静谧族 | 平静 | 平静、释然、专注、禅意、安宁、空灵、恬淡、超脱 |
| 压抑族 | 压抑 | 压抑、恐惧、紧张、不安、绝望、危机、神秘、悬疑、束缚 |
| 怅惘族 | 怅然 | 怅然、恍惚、伤逝、物哀、无常、遗憾、惋惜、释怀前的痛 |
| 壮丽族 | 崇高 | 崇高、震撼、辽阔、敬畏、史诗、庄严、孤绝的抗争 |

**强度**：弱（克制、日常）／中（明显但不外放）／强（戏剧化、极致）。强度决定运镜幅度、色彩浓度、节奏密度、响度动态范围。

**环境—情绪关系**：先判断环境本身传递的情绪，选择**顺应强化**（暖光小馆→温馨）或**反差制造张力**（喧闹街头→孤独）。反差方案 MUST 在交付物中写明目的。

## 二、情绪 → 全感官参数总表

### 2.1 孤独 / 怅惘 / 压抑（冷色 · 疏离组）

| 维度 | 参数 |
|---|---|
| 景别 | 大远景、远景为主（人物渺小、被困环境）；少量局部特写；**避免中近景连缀** |
| 机位 / 视角 | 背面机位、高机位俯拍；低机位仰拍表现压迫；广角人像拉开人际距离 |
| 运镜 | 拉镜头（孤独、留白、阻碍）、缓慢跟随（心理压力）、固定长镜；旋转表迷茫 |
| 构图 | 疏密留白、框架构图（困境束缚）、人物占比小、前后遮挡、倾斜（情绪失衡） |
| 光影 | 只有轮廓光而面部暗（隐藏内心）、阴阳脸（表里不一）、冷光／底光（不安）；以暗托明 |
| 色彩 | 冷色温、低饱和莫兰迪、蓝灰；色相数 ≤3；大面积素底 |
| 焦距 / 画幅 | 长焦压缩（人与环境分离）或广角（人与环境相融但疏远）；3:2 可表执念与困住 |
| 听觉 | 低频环境声、远处单声源、长混响、**大段静默**；忌铺满 BGM |
| 材质 / 触觉 | 冷、涩、粗粝；玻璃、素混凝土、未打磨石 |
| 空间 | 大空域、单人动线、出口不明确；园林用夹景收束视线制造孤绝 |
| 时间节奏 | 慢、长、少切；留 1 处时间气口 |
| 文字 | 短句、多停顿、少形容词；用具体物象代替「他很孤独」 |

### 2.2 温暖 / 温情 / 治愈（暖色 · 亲近组）

| 维度 | 参数 |
|---|---|
| 景别 | 中景、中近景为主；近景特写抓手部与眼神 |
| 机位 | 平视（朋友关系）、略高 15°（柔和）；过肩正反打建立关系 |
| 运镜 | 缓慢推（走进人物）、轻跟随、平摇带出关系 |
| 构图 | 对称或三分、均衡稳定、圆形/曲线、双人同框 |
| 光影 | 柔和漫射光、窗光、黄金时刻、暖光、低光比；明暗过渡柔 |
| 色彩 | 暖色温、低饱和相似色、米白木色；可一点橙／黄点睛 |
| 听觉 | 中频圆润、生活声（水沸、器皿、人声）、温和 BGM 不抢戏 |
| 材质 | 温润：原木、棉麻、手工纸、陶 |
| 空间 | 围合而可亲、停留点明确、可触距离 |
| 时间节奏 | 均匀舒缓，起承转合温和 |
| 文字 | 匀停句式、具体生活细节、留一点幽默或自省（避免纯甜） |

### 2.3 炽烈 / 激情 / 生命力（高饱和 · 动感组）

| 维度 | 参数 |
|---|---|
| 景别 | 远近快速交替、大量特写抓决定性瞬间 |
| 机位 | 低机位仰拍、正面略侧、追随 |
| 运镜 | 快推、甩镜、手持微晃、环绕、卡点混剪 |
| 构图 | 对角线、断裂、倾斜、非对称；强化动态（脊线弯曲/倾斜/断裂） |
| 光影 | 强明暗、硬光、逆光轮廓、高对比 |
| 色彩 | 高饱和高对比、补色并置（先立疏密/明度骨架再上高饱和） |
| 焦距 | 长焦「点杀」抓瞬间；慢门追随留拖影 |
| 听觉 | 大动态范围、强节奏、卡点、峰值明确 |
| 材质 | 金属、漆、玻璃反光 |
| 空间 | 开放、可奔跑、动势不折返 |
| 时间节奏 | 快切、密度高、"失衡→蓄力→爆发→命中→余震→控制" |
| 文字 | 短促、动词密集、句长骤变 |

### 2.4 期待 / 憧憬 / 希望（向光 · 上升组）

| 维度 | 参数 |
|---|---|
| 景别 | 全景起手 → 中近景收束；留出向上/向远的空间 |
| 机位 | 低角度、上摇、升降镜头 |
| 运镜 | 推（走进）、上摇（逐步展示）、缓慢升降、由暗向明的移动 |
| 构图 | 引导线指向光源、天光占比大、上留白 |
| 光影 | 逆光、晨光、丁达尔、由暗转明 |
| 色彩 | 明快清透、高明度、暖金／淡青；低对比 |
| 听觉 | 渐强、音高上行、留一个明亮泛音 |
| 空间 | 开口、通透、视线可及远处 |
| 文字 | 句式由短渐长、语势上扬、结尾不封死 |

### 2.5 平静 / 禅意 / 释然（留白 · 极简组）

| 维度 | 参数 |
|---|---|
| 景别 | 远景与空镜为主，单焦点，极少特写 |
| 机位 | 平视、固定机位、长镜头 |
| 运镜 | 几乎不动；移镜头如卷轴般徐徐展开 |
| 构图 | 大留白、偏置、非对称、计白当黑；减形、省略环境 |
| 光影 | 意象光（均匀、无明暗交界线）、以雾遮形、白墙竹影、逆光剪影 |
| 色彩 | 减色相、降饱和、素色/无彩色托主体；色相数 ≤2 |
| 听觉 | **以稀声反衬寂静**：檐滴、风过竹帘、炭火轻响；至少 1 处刻意静默 |
| 材质 | 素、粗朴、本色：原木、宣纸、粗陶、夯土、苔 |
| 空间 | 素壁、空院、让渡与呼吸；借景把外部引入 |
| 时间节奏 | 极慢、少切、结尾淡出／空镜／不写尽 |
| 文字 | 极简、具体物象、不解释、不抒情直说 |

### 2.6 压抑 / 恐惧 / 悬疑（冷暗 · 束缚组）

| 维度 | 参数 |
|---|---|
| 景别 | 大特写与远景极端交替；局部特写造神秘感 |
| 机位 | 高角度俯拍（渺小化）、倾斜角（失衡）、POV |
| 运镜 | 缓慢推近、旋转（暗流涌动）、手持微晃（受创主观） |
| 构图 | 框架（禁锢）、遮挡、窄画幅、水平挤压；镜与窗作符号 |
| 光影 | 底光（恐怖）、冷光（阴暗）、顶光、面部阴影；明暗差大 |
| 色彩 | 深蓝黑、低明度冷调；一处红作危险信号 |
| 听觉 | 环境音、呼吸、钟表（时间限制）、突然静音；对话突然停顿 |
| 空间 | 狭窄、出口隐藏、动线折返 |
| 时间节奏 | 延迟揭示、卖关子、强调时间 |
| 文字 | 信息 withholding、细节延迟满足、不可靠叙述 |

### 2.7 壮丽 / 崇高 / 史诗（辽阔 · 震撼组）

| 维度 | 参数 |
|---|---|
| 景别 | 大远景、大全景；人物与巨物同框 |
| 机位 | 低机位仰拍、航拍 |
| 运镜 | 拉（对比与强调）、升降、积累蒙太奇 |
| 构图 | 垂直轴、中心对称、巨物尺度对比 |
| 光影 | 强明暗、逆光剪影、体积光 |
| 色彩 | 高对比或极简近单色；金／深红／宝石蓝按体系取 |
| 听觉 | 低频、大动态、压迫性静默后释放 |
| 空间 | 高耸、开阔、不可动摇的秩序 |
| 文字 | 「先阻后扬」长句推进，写出由痛而快的过程 |

### 2.8 怅然 / 物哀 / 无常（余韵组）

| 维度 | 参数 |
|---|---|
| 景别 | 中远景与凋零物象的特写交替 |
| 机位 | 平视、略远、不介入 |
| 运镜 | 慢、拉、叠化转场（时间流逝） |
| 构图 | 偏心、残缺、大量留白、聚焦微观纹理 |
| 光影 | 阴翳层次、斜侧光、低明度暖灰、慢门拖影 |
| 色彩 | 大地灰调、褪色感、低明度；日式利休茶／灰桜系 |
| 听觉 | 余韵长的泛音（钟、琴）、渐弱、一声之后留静默 |
| 材质 | 带时间痕迹：包浆、金缮、枯木、旧纸 |
| 空间 | 痕迹可辨、四时流转可见 |
| 文字 | 克制、细节承载、不解释、留余味 |

## 三、情绪 → 色彩基调速查

| 情绪组 | 色温 | 饱和度 | 明度 | 主色倾向 | 高饱和面积 |
|---|---|---|---|---|---|
| 孤独 / 压抑 | 冷 | 低（莫兰迪） | 中低 | 蓝灰、墨、月白 | ≤5% |
| 温暖 / 治愈 | 暖 | 中低 | 中高 | 米白、木、淡橙 | ≤8% |
| 炽热 | 暖或强对比 | 高 | 高 | 红、金黄、补色并置 | ≤10% |
| 期待 | 偏暖 | 低中 | 高 | 淡青、暖金、天光白 | ≤8% |
| 平静 / 禅意 | 中性偏冷 | 极低 | 中高 | 素白、青灰、水墨 | ≤3% |
| 怅然 / 物哀 | 中性偏暖 | 低 | 中低 | 灰樱、利休茶、苔 | ≤5% |
| 壮丽 / 崇高 | 按体系 | 中高或极简 | 对比大 | 金、深红、宝石蓝 | ≤10% |

> 与 `core-03` §5 色彩心理一致；东方体系须再过「观念色」过滤，伊斯兰须过「神学编码」过滤。

## 四、声音维度细则（N 类与所有含听感的交付物）

| 层 | 内容 | 美学约束 |
|---|---|---|
| 环境音 | 风、雨、虫、市井、空间底噪 | 定义场域远近与大小；优先真实收录 |
| 效果音 | 器皿、脚步、门、衣袂 | 承担「微」与「内模仿」，极轻即可 |
| 音乐 | 主题动机 / 泛音 / 循环 | 不铺满；须有进入点与退出点 |
| 人声 | 台词、旁白、呼吸 | 呼吸与停顿是「间」 |
| **静默** | 刻意无声段 | **每案至少 1 处**；以稀声反衬寂静，蝉噪林逾静 |

**转场声音**：声音窜前（先闻其声）、相同声音转场（打电话/钢琴）、语言转场、反差声音转场。见 `domain/video/cinematic-language.md`。

**通感映射**（写作与跨感官方案用）：低频↔厚重/暗色；高频↔清透/浅色；泛音↔余韵/留白；混响↔空间尺度；粗糙质感↔低频噪声；温润材质↔中频圆润。
