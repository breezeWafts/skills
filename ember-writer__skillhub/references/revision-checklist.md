# 修改清单（交付前强制关卡）

源自思维导图「步骤 → 修改」分支。按顺序逐项过关；任何一项不通过就回到正文修正。无法静态确认的项标为「待人工复核」，不得默认通过。

---

## 1. 字词句语法

### 1.1 标点

- 对照《标点符号用法》规范检查逗号、句号、问号、引号、破折号、省略号。
- 常见错误：一逗到底；引号内外位置错；并列短语之间误用逗号；句末多余标点。
- 交付要求：全文标点统一，无半角全角混用（引用原文除外）。

### 1.2 字：错字、别字

- 高频别字逐字核对；拿不准的字查证后再用。
- 方法（思维导图原文）：多读书；整理「100 个常见错别字」清单逐一排查。
- 注意：同音字误用（「再/在」「的/得/地」「做/作」）单独清查。

### 1.3 的 / 得 / 地

| 结构 | 思维导图口径 | 示例 |
|------|-------------|------|
| 名词 + 的 + 名词 | 后面修饰前面 | 我的祖国 |
| 并列关系 | 并列成分之间用「的」 | 我和他的书 |
| 动词 + 得 + 补语 | 后面修饰前面 | 走得快 |
| 形容词/副词 + 地 + 动词 | 前面修饰后面 | 慢慢地说 |

### 1.4 词

- **词性**：确认词性使用正确，贬义词不用于褒扬语境，褒义词不用于贬损语境。
- **词语搭配**：缩短句子，留下核心做搭配检测（思维导图原文）。
- **词的丰富性**：相近词中选最佳，避免一段内重复同一词；不为了丰富而堆砌同义词。

### 1.5 句

| 病句类型 | 思维导图示例 | 修正要点 |
|---------|-------------|---------|
| 语序不当 | 修饰语位置错置导致语义拧巴 | 调整定语/状语顺序，让修饰关系清楚 |
| 搭配不当 | 「展开活动，纪念五四青年节的到来」 | 「纪念」不与「到来」搭配 → 改为「纪念五四青年节」或「迎接五四青年节的到来」 |
| 成分残缺 | 「由于他拾金不昧，得到老师和同学的夸奖」 | 「由于」掩埋主语 → 删「由于」或补出主语 |
| 结构混乱 | 「你好好学习，怎么可能好成绩是可想而知的」 | 两个句式杂糅 → 拆成两句：「你好好学习，取得好成绩是可想而知的」 |
| 含混不清 | 「小王看见老李同他的战友聊天」 | 「他的战友」指代不明 → 写明是谁的战友 |
| 逻辑错误 | 「能否解决交通拥堵问题，是当务之急」 | 两面词与一面判断不匹配 → 「解决交通拥堵问题，才是当务之急」 |

## 2. 框架：均衡

- 起承转合四段是否比例失衡？「承」过长而「合」过短需压缩或补写。
- 各章节/段落是否头重脚轻？按内容重要性重排篇幅。
- 删去与动机无关的段落，即使写得再好（内容为结局服务）。

---

## 3. 除「我」

- 删去不必要的「我觉得」「我认为」「在我看来」等主观介入标记。
- 事实直接用事实陈述；观点用论据支撑，不用第一人称背书。
- 例外：第一人称叙事、演讲稿、个人随笔保留「我」，但仍需检查是否重复冗余。

---

## 4. 态度客观中立

- 论文/议论文/说明性内容尤其严格：不用情绪化副词、不标签化人物、不以偏概全。
- 对立观点先准确复述再回应，不歪曲后反驳（稻草人）。
- 数据与引文有来源；无来源处标「待补来源」，不编造。

---

## 5. 语言温度：大道理说具体

- 把抽象道理换成可感知的场景、动作、物件或数字。
- 检查句式：「要努力」→「每天把最难的那件事先做掉」。
- 温度检查：读起来是否有人的体温，而不是模板腔。

---

## 6. 文字感染力：由浅入深

- 思维导图原文：先写表面映像，再逐步补充。
- 顺序：具体可见的表层 → 背后的原因/关系 → 情感或意义 → 留白收束。
- 禁止一上来就上价值；禁止结尾空喊口号。

---

- [ ] 六类病句已查（语序、搭配、残缺、结构混乱、含混、逻辑）

- [ ] 已除不必要的「我」
- [ ] 态度客观中立（适用时）
- [ ] 大道理已换成具体说法
