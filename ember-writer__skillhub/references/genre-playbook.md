# 体裁写作手册

按 `SKILL.md` Step 1 判定的体裁取用本章。所有体裁共用起承转合骨架，差异在「承」与「转」的展开方式、以及交付前必过关卡。

---

## 1. 小说（短篇 / 微小说 / 长篇大纲）

**骨架落法**
- 起：开场即给出人物 + 处境 + 异常信号（钩子）；可用倒叙先放结果。
- 承：铺陈人物关系与目标，逐步加压；用具体场景和形象衬托人物，不用抽象形容词贴标签（技巧·间接描述）。
- 转：冲突爆发或反转，揭开了「不一样的点」；用短句加快节奏，前后对比制造冲突（手法·叙述）。
- 合：交代结局，回扣开头的异常信号；留白给读者思考空间。

**必过关卡**
- 灵魂点：这篇靠卖点 / 爆点 / 动情点中的哪一个被记住？
- 视角：自我观察还是上帝视角？全文是否一致？
- 素材筛选：用新不用旧、用近不用远、用大不用小。
- 叙事方法：顺叙、倒叙、插叙选定一种为主。

**开篇可选**：悬念式（提出问题）、反常式（耸人听闻/反常规）、细节式（一个具体动作或物件）。
**收尾可选**：回扣式、留白式、反转式、升华式。

**长篇大纲额外要求**：给出人物表、分卷/分章起承转合、每章灵魂点。

## 2. 广告文案

**骨架落法**
- 起：标题（按七种公式选，见下）+ 第一句直击效益。
- 承：把参数换成体感（读者听得懂：具体尺寸≈手掌大小；电量≈待机 × 天），说明读者看到效益。
- 转：卖点具体化 + 与竞品/旧方式的对比；对目标群体换说法。
- 合：一句话行动指向（促进销售/达到沟通效果）。

**标题七式**（源自思维导图）
1. 直接诉求：「清仓大减价」
2. 隐含表达：「租车行业第二名」「让别人涨知识」
3. 「如何」开头：「如何写一手好字」
4. 提问：「你有多久没读完一本书了」
5. 祈使句：「试试这种新手机」
6. 任务式：「一生必看的十部电影」
7. 见证式：「某冠军告诉你技巧」

**必过关卡**
- 用调：走进人心 / 促进销售 / 吸引注意力 / 达到沟通效果 / 说服消费者，锁定一个主目标。
- 读者第一位：每个专业参数都换成读者可感知的说法。
- 内容逻辑清晰：卖点具体、简称拉近距离、目标群体明确、结构简约。
- 做好市场研究：竞品与受众信息不足时，先写「待补市场事实」占位，不编造数据。

## 3. 拆书稿

**骨架落法**
- 起：引入话题——讲故事 / 提问题 / 分析痛点，三选一。
- 承：呈现书中三个观点——合并观点 / 优选观点 / 理顺逻辑，三观点之间要有递进。
- 转：把书中观点与读者现实处境对接（代入法）。
- 合：拔高立意——代入法 / 问答法 / 呼应法。

**必过关卡**
- 三个观点必须来自原书，不得杜撰；原书信息不足时标注待补。
- 每个观点配一个可验证的例子或行动建议。
- 结尾必须回答「读者读完能改变什么」。

---

## 4. 论文 / 议论文

**骨架落法**
- 起：提出论点，回答「为什么写、解决什么问题」。
- 承：分论点 + 论据 + 论证；重要的话放开头；将松散素材连贯、孤立内容变成整体。
- 转：引入反方观点或边界条件，再回应——体现「不一样的点」。
- 合：总结论证，回扣论点，给出结论或研究指向。

**必过关卡**
- 论点单一明确；论据与论点同向。
- 态度客观中立（思维导图修改分支）：避免情绪化措辞与人身指向。
- 逻辑错误零容忍：见 `revision-checklist.md` §句子层。
- 数据、引文、文献若无来源，标注「待补来源」，不得编造。
- 语言准确、自然；术语首次出现给定义。

---

## 5. 演讲稿 / 个人叙事（故事思维型）

**骨架落法**
- 起：让对方听懂 + 置身其中——用一个具体场景开场。
- 承：叙述铺垫第一层，给出「我/他经历同样的事」。
- 转：展示逻辑——让别人相信「经历同样的事也会有类似结果」；加入新视角。
- 合：总结强化或拔高，给出可带走的行动或信念；呼应开头场景。

**必过关卡**
- 富有感触、展示逻辑、认知相符三项逐条自检。
- 抒情压在事实之后（手法·抒情：情绪写在文字里，不做空洞喊话）。
- 结合读者实际情况做引导，避免「你应该」式说教；大道理说具体。

---

## 6. 新媒体文章 / 散文

**骨架落法**
- 起：标题 + 前三句给出钩子或立场；迎合读者（读者立场优先）。
- 承：场景、细节、例子推进；节奏靠意思转换换行；短句与长句交替。
- 转：提出新东西或新视角对待（议论手法第三步）。
- 合：由浅入深，先写表面映像再逐步补充；留白收尾。

**必过关卡**
- 文字感染力：由浅入深，表面映像 → 逐步补充。
- 语言丰富、准确、自然；不堆砌形容词。
- 段落均衡，不头重脚轻。
- 除「我」：删去不必要的主观介入（第一人称叙事除外）。

## 体裁判定速查

| 素材里有什么 | 默认体裁 |
|-------------|---------|
| 人物、情节、冲突、场景 | 小说 |
| 产品、卖点、受众、转化目标 | 广告文案 |
| 书名、章节、核心观点 | 拆书稿 |
| 论点、论据、研究问题 | 论文/议论文 |
| 主张、听众、号召 | 演讲稿 |
| 生活片段、感悟、观点杂感 | 新媒体文章/散文 |

判定后必须在交付时说明依据，用户可纠正。
