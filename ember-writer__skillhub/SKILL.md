# ember-writer · 内容创作生成器

## 〇、美学总纲（ember-art-solution 统摄 · v2.1.0）

**本 skill 是 `ember-art-solution`（美学主导全场景方案总控，v1.1.0）在 文字内容（A/B/C） 领域的执行端。** 总控负责统一的体系定位、色板、形式语法与质量门禁；本 skill 保留全部原有领域主干与数值规范。完整接入说明见 `references/art-solution/bridge.md`。

### 0.1 新增前置动作 · 美学体系定位（不得跳过）

在原有工作流最前面执行：从用户给的「风格 / 氛围 / 感觉」或内容题材，按 `references/art-solution/core-01-style-router.md` S1–S5 产出**美学定位卡摘要**——主体系（东方 / 西方 / 阿拉伯-伊斯兰）→ 三级流派（`core-00`）→ 底层逻辑四条（色彩观念 / 光影处理 / 空间构图 / 终极目标）→ 主情绪与审美形态（`core-06`）→ 色板（色名＋HEX，`core-03`）→ 目标观者反应。
用户未给风格或说「根据内容制定」时，按 `core-01` §5 五步缺省推断并标注〔推断〕，**不打断追问**。

### 0.2 执行时的三处接入

1. **参数映射阶段**：在既有情绪/形态同向性之外，追加「体系→语言节奏与意象 同向性」，逐项核对 `core-00` 第三部分；冲突时以体系逻辑裁决，若刻意反向须写明目的。
2. **创作深化阶段**：调用 `core-07` 三层递进、意境四步、象征回环；`core-04` 六法与留白三法；`core-08` 八意识。
3. **交付校验阶段**：在既有校验清单之外，追加 `core-10` 三重门禁中的「体系一致性」10 条，重点排查：东方主题用西方强明暗、伊斯兰主题加大留白、符号堆砌替代底层逻辑、色值不可溯源。

### 0.3 冲突裁决（重要）

写作主干（灵魂/动机/起承转合/体裁/修改清单）优先 ＞ 既有 12 项审美清单 ＞ 体系逻辑 ＞ 审美哲学细项；术语只写进创作说明，不进正文。

### 0.4 组合交付

若用户同时要多个产品（如「写一篇品牌故事并做配套海报」），或只给「感觉」不给领域参数，**转由 `ember-art-solution` 总控**做组合交付，共享同一张美学定位卡；本 skill 只负责其中的 文字内容（A/B/C） 子件。

## Overview

把「一个体裁 + 一份素材/一个想法/一种情绪」转化为「一份可交付的完整内容作品」。核心逻辑是**先立灵魂与动机，再定审美调性，搭起承转合，最后用双重清单（语法 + 审美）逐项过关**：不是拿到提示就开写，而是先确认「为什么写、解决什么问题、靠什么点打动人」，再按体裁结构落笔，交付前强制执行修改与审美校验。

知识全部内置于 `references/`：写作主干来自一张写作方法论思维导图的完整拆解（v1.0.0）；v1.1.0 增补美学理论工具箱——把《美的历程·美学导论》与《美学原理 30 讲》的审美形态、审美心理、意境与艺术哲学转译为可执行的写作决策，让作品不止「通顺」，更具备艺术性与审美深度。无需外部 API、MCP 或网络。

**输入**：体裁类型 + 故事/内容素材、一个想法、一段情绪描述，或仅几句话。
**输出**：完整内容作品（Markdown），可附创作思路摘要、修改说明、交互选项。

## 前置条件

无外部依赖。纯知识型 skill；所有方法、模板、清单均在 `references/` 与 `assets/`。

## 执行工作流（按顺序，不可跳步）

### Step 0 · 判定生成模式

根据用户指令选择模式，未明确时默认 **direct**：

| 模式 | 触发信号 | 行为 |
|------|---------|------|
| `direct` 完整生成 | "直接写""生成完整""帮我写一篇" | 一次性走完 Step 1–8，交付全文 |
| `interactive` 交互生成 | "一步步来""交互""先给大纲""每轮确认" | 在 Step 2、Step 4、Step 6 后暂停，每轮给出「当前产出 + 2–4 个下一步选项」等待选择 |
| `coach` 引导生成 | 素材稀薄、只有情绪词或"不知道写什么" | 走 Step 3 的低输入引导，先给 3 个方向建议再写 |

交互模式下每轮只推进一个阶段，禁止一次性倒出全文；用户说"你定/按你的来"时立即切回 `direct`。

### Step 1 · 解析需求与体裁

从用户输入中提取：

- **体裁**：小说（短篇/微小说/长篇大纲）、广告文案、拆书稿、论文/议论文、演讲稿/个人叙事、新媒体文章/散文。未指定时按素材特征判断并在交付时说明依据：有情节与人物→小说；有产品与卖点→广告文案；有书籍与观点→拆书稿；有论点与论据→论文/议论文；有主张与听众→演讲稿；其他→新媒体文章。
- **素材**：故事梗概、原始文字、产品信息、观点、数据、片段。
- **约束**：字数、平台、受众、风格、人称、必须包含或回避的内容。
- **审美诉求**：用户是否要求文采、艺术性、意境、高级感、美感；是否明确要求朴素平实（后者按 `aesthetics-checklist.md` 裁决口径放宽审美 MUST）。
- **完整度信号**：素材是否足够支撑写作，决定 Step 3 是否介入。

### Step 2 · 定位灵魂与动机（核心，不得跳过）

动笔前先定三件事，全部写入创作说明（交互模式在此暂停确认）：

1. **动机**：为什么写？解决什么问题？（对应 `references/writing-map.md` §动机）
2. **灵魂**：卖点 / 爆点（耸人听闻、反常规）/ 动情点（感动人的），至少锁定一个"点"（§灵魂）。
3. **受众反应**：读完要让人获得什么——走进人心、促进销售、吸引注意力、达到沟通效果、说服消费者，或"对方能听懂、让对方置身其中、听完有反思和改变"（§故事思维）。
4. **审美定调**（v1.1.0 新增，不得跳过）：依据 `references/aesthetics-creative.md` 锁定三项——
   - **目标层级**：养眼 / 养心 / 养神（广告至少养心；小说、散文、演讲稿追求养神；论文以养心 + 清晰为要）。
   - **主审美形态**：优美 / 悲剧 / 崇高 / 丑 / 喜 / 荒诞，选一个主形态，与灵魂点同向（动情点→优美或悲剧；爆点→崇高、喜剧或荒诞；卖点→优美或崇高）。
   - **核心意象**：至多 1 个；若走潜意识路线，按 `aesthetics-creative.md` §5 的浓缩/移置/象征/润饰四法处理用户素材。
   三项写入创作说明；交互模式在此与灵魂、动机一起暂停确认。

灵魂、动机与审美调性不清时，禁止直接进入 Step 4；按 Step 3 补全。

### Step 3 · 灵感补全（低输入 / 情绪 / 潜意识）

输入稀薄时不要空泛追问"你想写什么"，按 `references/inspiration-guide.md` 执行：

1. **信息完整度分级**：充足（体裁+素材+意图齐全）→ 直接进 Step 4；中等（缺 1–2 项）→ 只补缺项；稀薄（仅情绪词/一句话/想法碎片）→ 启动补全。
2. **情绪坐标**：识别主情绪、强度、走向，把情绪映射为意象、节奏、句式、视角与结尾方式。
3. **潜意识线索**：从用户措辞里提取重复词、比喻、未展开的枝节、矛盾点，作为创作燃料；用引导问题挖掘后凝练成 3 个方向。
4. **给建议而非空问**：输出 3 个具体可用的方向（每个含灵魂点 + 一句话梗概 + 标题），让用户选；用户说"你定"时选最贴合情绪的一个并说明依据。

### Step 4 · 构思：起承转合

按 `references/writing-map.md` §构思 搭建骨架：

- **起**：开头，为什么写——第一句就要给出钩子或立场。
- **承**：承接，写的是什么——展开背景、人物、论点或场景。
- **转**：转折，不一样的点——冲突、反常、新视角或意外发现。
- **合**：总结——回扣动机，给出交代、升华或行动指向。

按 Step 1 判定的体裁，套用 `references/genre-playbook.md` 的专用结构；叙事类依据 §步骤 选顺叙、倒叙或插叙。交互模式在此暂停，先交付骨架。

### Step 5 · 配置手法、技巧与视角

从方法论中选用并落到具体段落，不堆砌：

- **手法**（§手法）：叙述（提出问题制造悬念、短句加快节奏、前后对比制造冲突、举例、并列结构带入故事）；议论（叙述铺垫→总结强化或拔高→提出新东西）；抒情（藏在文字里的情绪、结合读者实际引导、举例）。
- **技巧**（§技巧）：留白（给读者思考空间）；间接描述（用行为或具体场景衬托人物）；欲扬先抑（先贬再夸）。
- **故事思维**（§体裁）：富有感触、展示逻辑（让别人相信"经历同样的事也会有类似结果"）、认知相符（愿意听、听完有反思和改变）。
- **视角**（§视角）：自我观察或上帝视角，全文保持一致；切换须有明确标记。
- **素材运用**（§素材）：词语准确/有力/走心/贴切、节奏靠意思转换换行；念头用"用新不用旧、用近不用远、用大不用小"筛选，靠"甩出去、拉回来"过渡。
- **审美修辞**（v1.1.0 新增）：按 `references/aesthetics-rhetoric.md` 把 Step 2 的审美调性落到字句——选优美的匀停或崇高的先阻后扬；定悲剧的尊严写法或喜剧的透明错位；调用与体裁相配的感官词汇通道（华夏味觉/欧洲视觉/印度肉身）；用审美距离开关决定拉近或推远；按意境四层自检决定留白。美学工具只作后台依据，术语不得写进正文。

### Step 6 · 生成正文

按 `references/output-templates.md` 与 `assets/writer-template.md` 输出完整初稿：

- 标题与起承转合齐全；段落节奏有长短变化，重要的话放开头。
- 广告文案须过"读者第一位、内容逻辑清晰、标题公式、市场研究"四关（§体裁）。
- 论文/议论文须论点明确、论据支撑、逻辑连贯、态度客观中立。
- 全文写完再进入修改，禁止边写边改导致中断。交互模式在此暂停，交付初稿供修改方向选择。

### Step 7 · 执行修改清单（交付前强制）

逐项对照 `references/revision-checklist.md` 过关，不得跳过：

1. **字词句语法**：标点规范；错别字与"的/得/地"；词性、词语搭配、词的丰富性；句子的语序、搭配、成分残缺、结构混乱、含混不清、逻辑错误。
2. **框架**：均衡，不头重脚轻。
3. **除"我"**：删去不必要的主观介入。
4. **态度客观中立**：议论文与说明性内容尤其严格。
5. **语言温度**：大道理说具体。
6. **文字感染力**：由浅入深，先写表面映像再逐步补充。

语法清单通过后，继续执行 **审美校验**（v1.1.0 新增）：逐项对照 `references/aesthetics-checklist.md` 的 12 项检查——MUST 项必须全过（审美目标层级明确、形态一致、有意味的形式、留白有效、审美距离恰当、意象节制、价值观底线；选用崇高时须写出由痛而快的过程），SHOULD 项未达标可在说明中披露后交付。未过项回到对应步骤修正后再交付。

输出末尾附「修改记录」与「审美校验」两段，列出实际修改项与审美通过/未达项；静态无法判断的项（尤其是读者是否被打动）标为待人工复核，不得自称达成。

### Step 8 · 交付

1. 完整内容保存到 `outputs/`（文件名 `<主题>-<体裁>.md`），用文件展示工具呈现。
2. 正文末尾附：体裁判断依据、灵魂与动机摘要、审美定调（目标层级/主形态/核心意象）、修改记录、审美校验记录。
3. 交互模式在每轮末尾给 2–4 个下一步选项；用户确认后再推进。
