# 通用交付方案骨架 · Universal Solution Template

> 适用于 `ember-art-solution` 全部 14 类交付（A–N）。按 `core-02` 对应 ID 增删字段；**定位卡与校验结论不可删**。
> 使用方式：复制本骨架 → 逐项填充 → 删除未用字段与提示文字 → 保存为 `outputs/<主题>-<产品>-方案.md`。
