# 美学分类组织架构总表 · 本 skill 的最高决策依据

> **来源**：工作区《美学分类组织架构总表.xlsx》（第一部分：流派分类组织架构；第二部分：风格与派别辨析；第三部分：三大体系底层逻辑对照）。本文件是该表的完整知识化转写，是 `ember-art-solution` 全部美学定位的**第一依据**。
> **地位**：任何交付物在「定风格」环节都必须回到本表取体系、取流派、取色表；不得凭印象拼贴传统元素。与领域知识库冲突时，以本表的体系归属与底层逻辑为准。

---

## 零、使用规则（MUST）

1. **先定体系，再定流派，再定形态与色**。用户说「东方美学意境」时，必须在东方体系内继续下沉到宋代 / 明清 / 侘寂之一，或明确说明「取东方共性、不落具体朝代」并给出理由。
2. **一种交付物以一个体系为主**。跨体系混搭须指定主次（如 7:3），并说明混搭的接缝在哪里；禁止无主次的符号拼盘。
3. **风格 ≠ 派别**（见第二部分）。用户要「风格」时给形式语言，要「派别」时才引入历史语境与成员谱系。
4. **色值必须取自本表色表或 `core-03-color-system.md` 的三套传统色库**，标注色名与 HEX；禁止随手取「看起来像」的近似色。
5. **底层逻辑优先于表面符号**。决定「留白 / 填满 / 焦点透视 / 消解光影」时，查第三部分，不靠元素罗列。

## 一、美学流派分类组织架构（一级 → 二级 → 三级）

### 顶层气质速览

| 一级（地域文化圈） | 一句话内核 | 审美终极目标 |
|---|---|---|
| **东方美学** | 重意、重悟、天人合一 | 意境：物我两忘、写意；接受残缺与短暂 |
| **西方美学** | 重逻辑、科学、再现与形式 | 再现与形式：从神的秩序到人的理性与主观情感 |
| **阿拉伯-伊斯兰美学** | 认主独一、非具象、无限性 | 以抽象符号指向不可见的无限，追求秩序与永恒 |

### 1 · 东方美学（重意、悟、天人合一）

#### 1.1 中式美学（儒释道融合、文以载道）

**① 宋代美学（极简 / 理学巅峰）**

| 维度 | 内容 |
|---|---|
| 哲学/历史背景 | 程朱理学「格物致知」，士大夫阶层主导，追求「静观内省」与「大道至简」 |
| 显著特征与表现 | 内敛、淡雅素净、平淡天真；拒绝外在炫技，追求事物本质（理）与自然本真。宋瓷单色釉（材质美）、院体花鸟（观物精微）、水墨山水 |
| 风格与派别区分 | 风格：极简主义、文人画风格。派别：北宋「大山堂堂」全景山水派；南宋「马一角、夏半边」边角山水派 |
| 构图方式 | 留白与散点透视：计白当黑、空灵虚无；北宋多「高远/深远」纪念碑式，南宋多偏心、截断式留白 |
| 色调与搭配 | 低饱和、冷调、水墨为上；摒弃唐代浓艳，推崇天然矿物/植物色与单色釉 |
| 色表（HEX） | 天青 `#8CB8C9`、粉青、梅子青、水墨黑 `#212121`、藤黄 `#E8B849` |

**② 明清美学（世俗化 / 繁复工艺）**

| 维度 | 内容 |
|---|---|
| 哲学/历史背景 | 阳明心学强调本心，商品经济繁荣、市民阶层崛起、资本主义萌芽 |
| 显著特征与表现 | 雅俗共赏、装饰性极强、奇巧繁复、世俗化。景泰蓝、粉彩/珐琅彩、明清小说版画、繁复木雕与江南园林 |
| 风格与派别区分 | 风格：装饰主义、世俗写实。派别：吴门画派（文人世俗化）、扬州八怪（个性化写意） |
| 构图方式 | 饱满与移步换景：画面填满、对称均衡；园林讲究「移步换景」与多视角叙事；「图必有意，意必吉祥」 |
| 色调与搭配 | 高饱和、强对比、富丽堂皇；大红大绿、金银勾勒、青花与釉里红极致发展 |
| 色表（HEX） | 朱砂红 `#C03312`、明黄 `#F2C111`、石绿 `#16A951`、霁蓝 `#17308F` |

#### 1.2 日式美学（禅宗、神道教、无常观）

**③ 侘寂 Wabi-Sabi（含物哀、幽玄）**

| 维度 | 内容 |
|---|---|
| 哲学/历史背景 | 佛教「无常」思想，神道教对自然的敬畏；接受短暂、残缺与不完美 |
| 显著特征与表现 | 质朴、不对称、枯槁、欣赏岁月痕迹；「物哀」为对转瞬即逝的共情，「幽玄」为深邃暗影的余情。粗陶茶具、枯山水、未打磨木材、金缮工艺 |
| 风格与派别区分 | 风格：残缺美、自然主义、阴翳美学。区别于中式的「圆满」与西方的「几何完美」 |
| 构图方式 | 非对称与微观聚焦：偏心构图、大量留白、打破均衡、聚焦局部微观纹理 |
| 色调与搭配 | 大地色系、灰调、自然原色、低明度与阴影层次；拒绝人工高饱和，用枯木、苔藓、泥土色 |
| 色表（HEX） | 枯木灰 `#8B7D6B`、苔藓绿、泥土褐、宣纸白 |

> 与八大审美意识（微/并/气/间/秘/素/假/破）的接口见 `core-08-eight-aesthetics.md`。

### 2 · 西方美学（重逻辑、科学、再现与形式）

#### 2.1 古典与中世纪（神学、理念论、模仿论）

**④ 哥特式 Gothic（12–16 世纪）**

| 维度 | 内容 |
|---|---|
| 哲学/历史背景 | 中世纪经院哲学，渴望摆脱尘世沉重、向天国升华；教会观念与城市发展结合。古希腊另以「美是数的和谐」与黄金分割为基 |
| 显著特征与表现 | 高耸、轻盈、尖锐、神秘、繁复装饰。尖肋拱顶、飞扶壁、束柱、彩色玻璃花窗、修长形体雕塑 |
| 风格与派别区分 | 风格：垂直动势、神秘主义、崇高感。派别：早期法国哥特、英国垂直式、晚期火焰式 |
| 构图方式 | 垂直轴与层级叙事：强烈垂直线引导视线向上；建筑分格立面，绘画/手抄本用层级叙事与装饰边框 |
| 色调与搭配 | 暗调空间与高饱和透光色对比；彩窗以红、蓝为主（蓝=天国，红=基督鲜血），辅以金与石灰灰 |
| 色表（HEX） | 宝石蓝 `#173E67`、深红 `#8D2734`、金箔 `#D4AF37`、羊皮纸白 |

#### 2.2 近代思潮（光学、实证主义、人本）

**⑤ 印象派（19 世纪中后期，含巴洛克/洛可可对照）**

| 维度 | 内容 |
|---|---|
| 哲学/历史背景 | 光谱理论与摄影术：色彩是光的反射，摄影术迫使绘画放弃绝对写实转向瞬间感官。巴洛克源于君主专制与反宗教改革，洛可可源于 18 世纪法国贵族享乐主义 |
| 显著特征与表现 | 捕捉瞬间光影、户外写生、忽略轮廓线、笔触松散；原色并列、补色对比，把闪烁阳光与微妙阴影引入画面 |
| 风格与派别区分 | 派别：印象派（莫奈/雷诺阿，重光色）、新印象派（修拉，点彩）、后印象派（塞尚/梵高，重主观情感与结构）。对照：巴洛克=动态戏剧性；洛可可=精致柔美甜腻 |
| 构图方式 | 截断式与不对称：受浮世绘影响，打破中心构图，俯视、截断式边缘构图；巴洛克用对角线/螺旋动势 |
| 色调与搭配 | 高明度、光谱色、条件色；拒绝纯黑与暗土色，阴影用环境色互补色（阳光黄↔阴影紫、橙↔蓝），浅色打底；洛可可用粉彩色系 |
| 色表（HEX） | 钴蓝 `#0047AB`、镉黄 `#FFF600`、紫罗兰 `#8A2BE2`、环境灰 `#B0C4DE`、玫瑰粉 `#F7CAC9` |

#### 2.3 现代与当代（工业、集体主义、反叛）

**⑥ 苏联构成主义（1910s–1920s）**

| 维度 | 内容 |
|---|---|
| 背景 | 十月革命与工业化，艺术服务于无产阶级政治，赞美工业文明与机械结构 |
| 特征与表现 | 几何结构、工业材料、刚烈感、实用主义导向。钢铁螺旋建筑、照相蒙太奇海报、无衬线字体 |
| 风格与派别区分 | 派别：至上主义（马列维奇，纯粹几何）、构成主义（塔特林，重实用与结构） |
| 构图方式 | 动态对角线与几何化：多重透视、对角线动势、直线与基本几何体分割画面 |
| 色调与搭配 | 强对比、工业感；黑、白、灰、红、蓝、黄等基础色，大面积红黑对比 |
| 色表（HEX） | 苏维埃红 `#CC0000`、海报黑 `#111111`、工业灰 `#708090`、纯白 |

**⑦ 苏联社会主义现实主义（1930s–1980s）**

| 维度 | 内容 |
|---|---|
| 背景 | 斯大林时期与国家工程，先锋实验被禁，国家需要人人能理解的视觉语言 |
| 特征与表现 | 宏大叙事、健康强壮人物、明亮理想化场景、视觉预言。斯大林式帝国风建筑（高耸对称）、歌颂领袖与丰收的宣传画/电影 |
| 风格与派别区分 | 风格：理想化写实、崇高美学。区别于西方批判现实主义，强调「典型环境中的典型人物」与阶级立场 |
| 构图方式 | 仰视与中心对称：领袖高于人群，仰拍强调崇高；建筑强调巨大、对称、不可动摇的秩序感 |
| 色调与搭配 | 明亮、温暖、煽动性；大面积红（革命/鲜血/热情，制造被包围的错觉），辅以金色与明亮环境光 |
| 色表（HEX） | 旗帜红 `#CC0000`、金黄 `#D4AF37`、天空蓝、麦浪黄 `#F4C430` |

**⑧ 抽象主义（20 世纪初）**

| 维度 | 内容 |
|---|---|
| 背景 | 反物质主义与精神探索：格式塔心理学、柏格森生命哲学，彻底抛弃具象客观世界 |
| 特征与表现 | 通过点线面与色彩表达纯粹内在情感或宇宙秩序；无具象物体，纯粹形式意味 |
| 风格与派别区分 | 派别：热抽象（康定斯基，直觉/音乐性/情感喷发）、冷抽象（蒙德里安，理性/秩序/数学逻辑） |
| 构图方式 | 无中心或绝对网格：热抽象自由发散动势；冷抽象严格水平/垂直网格分割 |
| 色调与搭配 | 冷抽象严格限制三原色与无彩色；热抽象色彩奔放 |
| 色表（HEX） | 原红 `#E32636`、原黄 `#F4D03F`、原蓝 `#003893`、纯黑、纯白 |

### 3 · 阿拉伯-伊斯兰美学（认主独一、非具象、无限性）

#### 3.1 古典伊斯兰时期（7–13 世纪，神学与数学融合）

**⑨ 早期伊斯兰与倭马亚风格（融合期）**

| 维度 | 内容 |
|---|---|
| 背景 | 继承闪族文明，吸收古罗马、拜占庭、波斯萨珊元素；《古兰经》确立「真主至美」但禁止偶像崇拜 |
| 特征与表现 | 从具象向抽象过渡，保留部分自然主义装饰但开始程式化。圆顶清真寺、沙漠宫殿壁画、库法体书法萌芽 |
| 风格与派别区分 | 过渡性混合风格；区别于后期纯抽象，此阶段仍有拜占庭马赛克与波斯灰泥痕迹 |
| 构图方式 | 集中式平面与拱券：沿用罗马/拜占庭穹顶与拱门，强调内部空间统一性与朝向（米哈拉布） |
| 色调与搭配 | 金色、深蓝、大地色；延续拜占庭金底马赛克，辅以沙漠土黄与石灰白 |
| 色表（HEX） | 金箔 `#D4AF37`、拜占庭蓝 `#1F3A93`、砂岩黄 `#C2B280` |

**⑩ 阿拔斯黄金时代美学（几何与理性的巅峰）**

| 维度 | 内容 |
|---|---|
| 背景 | 翻译运动与智慧宫，新柏拉图主义「神美论」确立；花拉子米等把几何学应用于艺术 |
| 特征与表现 | 高度数学化的抽象，几何纹样成为宇宙秩序象征；书法获神圣地位。星形多边形几何纹、蔓藤花纹（Arabesque）、誊抄体/三一体书法 |
| 风格与派别区分 | 派别：巴格达学派（重理性几何）、安达卢西亚-玛格雷布风格（重繁密植物纹与马蹄拱） |
| 构图方式 | 无限延伸与无中心：图案无起点终点，象征真主无限；圆规/直尺精密网格构造；视线持续游走而非聚焦一点 |
| 色调与搭配 | 绿、蓝、金、白四色核心：绿=天堂/神圣，蓝=苍穹/精神，金=完美/永恒，白=纯洁 |
| 色表（HEX） | 翡翠绿 `#009B77`、松石蓝 `#40E0D0`、古金 `#CFB53B`、釉白 `#F5F5F5` |

#### 3.2 中世纪晚期至近代（地域分化与世俗化）

**⑪ 波斯-中亚伊斯兰风格（萨法维 / 帖木儿）**

| 维度 | 内容 |
|---|---|
| 背景 | 苏菲神秘主义：物质世界是面纱，艺术旨在揭开面纱感知真主；什叶派文化影响加深 |
| 特征与表现 | 色彩极度绚丽，植物纹样柔美流畅，细密画发展出非写实空间。伊斯法罕皇家清真寺蓝砖、波斯地毯、书籍装帧 |
| 风格与派别区分 | 装饰主义极致、诗意化；比阿拉伯本土更柔和、色彩更丰富，细密画允许有限度人物描绘（非崇拜用途） |
| 构图方式 | 分层透视与边框叙事：细密画垂直叠加而非焦点透视；建筑立面布满彩釉瓷砖拼花，形成「光之织物」 |
| 色调与搭配 | 高饱和宝石色；深蓝与松石绿渐变，辅以珊瑚红、藏红花黄，大量琉璃砖反光 |
| 色表（HEX） | 伊斯法罕蓝 `#173E67`、松石绿 `#00CED1`、藏红花 `#F4C430` |

**⑫ 奥斯曼-土耳其风格（帝国宏大叙事）**

| 维度 | 内容 |
|---|---|
| 背景 | 帝国集权与正统逊尼派，国家工程主导，强调秩序、宏伟与宗教正统；建筑师锡南确立经典形制 |
| 特征与表现 | 巨大中央穹顶、铅笔状宣礼塔、伊兹尼克瓷砖花卉纹样。蓝色清真寺、苏莱曼尼耶清真寺 |
| 风格与派别区分 | 纪念碑式崇高、标准化装饰；比波斯更庄重肃穆，几何更严谨，花卉纹样高度程式化（康乃馨、郁金香） |
| 构图方式 | 垂直轴与穹顶统摄：强烈垂直升腾感（尖塔+穹顶）；室内以中央穹顶为绝对核心，对称布局 |
| 色调与搭配 | 蓝白为主调，点缀红绿；伊兹尼克瓷砖钴蓝、番茄红、翠绿、白底，金色用于书法与穹顶装饰 |
| 色表（HEX） | 伊兹尼克蓝 `#003153`、番茄红 `#FF6347`、瓷白 `#FFFFFF` |

**⑬ 摩尔式 / 安达卢西亚风格（西班牙-北非）**

| 维度 | 内容 |
|---|---|
| 背景 | 伊斯兰与基督教文化交汇，科尔多瓦/格拉纳达王朝，后与天主教共存形成穆德哈尔风格 |
| 特征与表现 | 马蹄拱、钟乳石状穆喀纳斯穹顶、极繁密石膏雕花与 Zellige 马赛克。阿尔罕布拉宫、科尔多瓦大清真寺 |
| 风格与派别区分 | 精致、内向、光影游戏；比中东更注重室内庭院与水景，装饰密度极高，几乎不留空白 |
| 构图方式 | 内向型庭院与光影分割：封闭外墙、内向庭院（Riad）；用格栅（Mashrabiya）切割光线，创造幽玄氛围 |
| 色调与搭配 | 艳丽对比与土色基底：亮蓝、紫、红、绿高饱和用于马赛克瓷砖；墙面用赭石、土黄营造柔和环境 |
| 色表（HEX） | 摩尔蓝 `#2E5090`、赭石 `#CC7722`、祖母绿 `#50C878` |

## 二、风格（Style）与派别（Movement / School）辨析

| 辨析维度 | 风格 Style | 派别 Movement / School |
|---|---|---|
| 定义本质 | 基于视觉特征、形式语言与表现手法的归纳分类 | 基于共同宣言、组织、特定时代与地域的艺术家群体 |
| 时空跨度 | 可跨越时空。「哥特式」12 世纪诞生，19 世纪有哥特复兴；「极简风格」可涵盖宋代美学与现代包豪斯 | 严格时空局限。「印象派」特指 19 世纪末法国巴黎特定画家群体；「苏联构成主义」特指 1920 年代苏联先锋组织 |
| 形成机制 | 后世艺术史家、批评家据视觉共性总结提炼的标签 | 艺术家主动结社、发表宣言（如《现实主义宣言》），有明确理论纲领与代表人物 |
| 判断依据 | 构图、光影、色彩搭配、笔触、材质（垂直线条＋红蓝彩窗 = 哥特风格） | 历史文献、展览记录、成员名单、理论著作（参加 1874 年无名艺术家展览 = 印象派成员） |

**对生成的约束**：用户说「宋代风格」是合法的跨时空风格调用；说「印象派」时必须带上 19 世纪末光学/外光的语境约束，不可把它当纯配色滤镜。二者混用时要明确「取风格的形式语言，不claim派别的身份」。

## 三、东方 / 阿拉伯-伊斯兰 / 西方 · 美学底层逻辑区分

| 分析维度 | 东方美学（中/日为代表） | 阿拉伯-伊斯兰美学 | 西方美学（古典/近代为代表） |
|---|---|---|---|
| **色彩观念** | **观念色 / 哲学色**：色彩服务于伦理、五行或心境。宋代尚青（阴柔含蓄）、水墨为上（道家「五色令人目盲」）；日本侘寂排斥人工色 | **神学编码色**：色彩不服务光学或纯情感，有严格宗教象征——绿=天堂与神圣，蓝=苍穹与精神，金=永恒之光，白=纯洁 | **科学色 / 光学色**：色彩服务物理真实或视觉心理。印象派基于光谱分析与互补色理论；苏联基于色彩心理学（红色的煽动性） |
| **光影处理** | **消解光影**：忽略固定光源与明暗交界线，追求「固有色」与「气韵」，多为均匀「意象光」；日本另欣赏阴翳中的层次 | **光的形而上学**：以彩色玻璃、琉璃砖、格栅切割光线，制造「神圣之光」与幽玄氛围，光本身即装饰对象与宗教体验媒介 | **塑造体积**：强调光源色、环境色、明暗交界线。从巴洛克明暗法到印象派环境互补色阴影，光影是塑造空间的核心手段 |
| **空间构图** | **游动透视（散点）**：视点移动（长卷、园林移步换景），讲究留白与「气口」，画面是时间的延展 | **无限延伸与填满（Horror Vacui）**：图案无起点终点、无中心，以无限重复的精确几何象征真主的无限与完美，排斥偶然性与残缺感 | **焦点透视 / 几何分割**：视点固定（文艺复兴透视法），或基于数学比例（黄金分割、蒙德里安网格），画面是空间的截取 |
| **审美终极目标** | **意境**：天人合一、物我两忘、写意；接受自然的残缺与短暂（侘寂） | **认主独一的外化**：以反模仿、反偶像的抽象符号指向不可见的无限，追求秩序与永恒，拒绝残缺 | **再现与形式**：模仿自然、理念显现、形式意味；从神的秩序走向人的理性与主观情感 |
| **哲学驱动力** | 儒（伦理秩序）、道（自然无为）、释（空灵顿悟） | 伊斯兰神学（认主独一）、新柏拉图主义神美论、苏菲神秘主义；兼收希腊数学理性 | 古希腊理性、基督教神学、启蒙理性、现代人本与科学主义 |

### 三条最容易犯的错（反模式）

1. **东方主题用西方光影**：给宋式意境打强明暗交界线与硬轮廓光 → 气韵尽失。应改为均匀意象光、以暗托明、以雾遮形。
2. **伊斯兰主题加留白**：把「空灵留白」当作通用高级感 → 与 Horror Vacui 直接冲突。伊斯兰体系应做无限延伸的密纹，留白只出现在结构呼吸处。
3. **符号堆砌替代底层逻辑**：贴青花、贴枯山水、贴月亮门却仍用焦点透视 + 高饱和 + 满构图 → 有形无意。先用第三部分定逻辑，再选元素。
