# 日本八大审美意识 · 跨媒介裁决表

> 思想基底：对自然的敬畏 ＋ 对秩序的迷恋。原生语境见《日本的八个审美意识》黑川雅之（`core-05`）。
> 本文件把原为界面量化设计的八意识（`domain/ui/eight-aesthetics.md`）扩展到**全部 14 类交付物**，作为气质层的统一审视角度与分歧裁决依据。
> **UI 的具体数值阈值仍以 `domain/ui/eight-aesthetics.md` 与 `assets/tokens.css` 为准**，本文件只给跨媒介口径。

---

## 一、八意识总表

| 意识 | 读音 | 一句话内核 | 归属层 | 跨媒介一句话 |
|---|---|---|---|---|
| **微** | Bi | 细节中蕴含整体 | L1→L3 | 一个细节要能让人推知整体，细节不是装饰 |
| **并** | Hei | 独立而统一 | L1→L2 | 各单元保持个性，但由同一套秩序收拢 |
| **气** | Ki | 无形的场域 | L1→L3 | 让看不见的氛围（光晕、混响、纸纹、气息）成立 |
| **间** | Ma | 即若即离的流动空间 | L1→L2 | 留白即呼吸；间距承担节奏而非空隙 |
| **秘** | Hi | 秘而不宣的想象力 | L1 | 渐进披露，不一次给全，靠暗示调动想象 |
| **素** | So | 返璞归真的本色 | L1→L3 | 保留材料本色，低饱和、不高人工修饰 |
| **假** | Ke | 对大自然的绝对信赖 | L1 | 交还给时间与自然：季节、痕迹、无常、不完美 |
| **破** | Ha | 秩序中的偶然性 | L1→L2 | 全案至多一处破格，作为点睛 |

**使用原则**：八意识不是八套样式，而是对**同一套方案**的八种审视角度。当某意识与具体数值冲突时，按「**间 / 素 / 秘（气质）＞ 并 / 破（秩序）＞ 微 / 气 / 假（感知）**」优先级裁决。

## 二、逐意识跨媒介转译

### 1 · 微 Bi — 细节中蕴含整体

「细微之处有神灵」，一瞬含过去与未来、一叶知整体。

| 介质 | 转译 |
|---|---|
| 文字 | 一个精准的物象细节代替大段描写；用词自洽于全篇语域 |
| 影像/摄影 | 袖口、水汽、指尖等微细节承载情绪；景深与焦点服务这一细节 |
| 平面/封面 | 描边、字距、圆角、压凹等微规格全案一致 |
| UI | 图标描边宽度恒定、微交互反馈自洽（数值见 `domain/ui/`） |
| 空间/园林 | 一片瓦当、一处收口、一块石头的纹理与整体材质同源 |
| 声景 | 极轻的环境细节（衣袂、器皿轻响）反而定义整个场域 |

**反例**：细节各自精彩却与整体无关；为「精致」堆满细节。

### 2 · 并 Hei — 独立而统一

| 介质 | 转译 |
|---|---|
| 文字 | 章节/段落各有语气，但同一叙述契约 |
| 影像 | 每个镜头独立成立，又由统一的色调、光向、轴线收拢 |
| 套图 | 逐张景别姿态不同，但服装/色板/光向一致 |
| 平面系列 | 系列海报各有主视觉，共享栅格与字阶 |
| UI | 组件独立可复用，统一 Token 与栅格 |
| 空间 | 各分区功能独立，由同一材料语言与动线串联 |

**反例**：为统一而抹平所有变化（变成重复），或为变化而各说各话。

### 3 · 气 Ki — 无形的场域

| 介质 | 转译 |
|---|---|
| 文字 | 语感、气息、句间空白形成的「场」 |
| 影像 | 雾、光晕、空气透视、 dust in the air |
| 摄影 | 逆光雾气、柔焦、暗角形成的包裹感 |
| 平面/UI | 极淡纸纹/噪点、柔和阴影、模糊景深层 |
| 空间 | 穿堂风、香氛、温湿度、光的弥散 |
| 声景 | 混响与空间残响定义「房间有多大」 |

**反例**：把「气」做成一层滤镜特效；全场均匀无轻重。

### 4 · 间 Ma — 即若即离的流动空间

**最核心的意识**，与 `core-04` §2 留白三法直接对接。

| 介质 | 转译 |
|---|---|
| 文字 | 段落与句间停顿、省略、不写尽 |
| 影像 | 空镜、静默拍、镜头之间的呼吸、淡出 |
| 摄影 | 构图留白、主体偏置、素色托主体 |
| 平面/UI | 间距模数、「分割优先于线条」、内容密度与空白交替 |
| 空间/园林 | 素壁、空院、廊的转折、抑→扬的收放 |
| 声景 | 以稀声反衬寂静，静默是内容的组成部分 |

**反例**：把「间」理解为「空着没东西」；或用线条/色块把每个空处都填满。

### 5 · 秘 Hi — 秘而不宣的想象力

| 介质 | 转译 |
|---|---|
| 文字 | 暗示、伏笔、延迟揭示、不可靠叙事 |
| 影像 | 局部先于全貌、遮挡转场、视线留悬念 |
| 摄影 | 背面机位、半遮、只给细节不给全脸 |
| 平面 | 主信息给足，次信息渐进披露；留一处「不解释」 |
| UI | 渐进披露、单焦点、折叠层级 |
| 空间 | 漏景、障景、「先挡后放」、园中园 |
| 声景 | 声音先于画面出现（声音窜前）、只闻其声不见其源 |

**反例**：一次摊开全部信息；或把「秘」做成故弄玄虚。

### 6 · 素 So — 返璞归真的本色

| 介质 | 转译 |
|---|---|
| 文字 | 少修饰、具体名词与动词、去除形容词堆叠 |
| 影像/摄影 | 低饱和、自然光优先、少后期 |
| 平面/UI | 素底、有限色域、无渐变堆叠 |
| 空间 | 原木不覆厚漆、夯土留颗粒、手工纸透纤维 |
| 声景 | 原生环境声优先于合成音色 |

**反例**：把「素」做成寡淡无色；或口称素、实则全套精修。

### 7 · 假 Ke — 对大自然的绝对信赖

「假」是「借」，把主导权交还给自然与时间。

| 介质 | 转译 |
|---|---|
| 文字 | 四时、天气、物候推动情绪，而非作者硬拧 |
| 影像/摄影 | 用真实时段光（黄金时刻、蓝调、阴雨）、允许偶然入画 |
| 平面 | 季节色、纸材自然变化 |
| 空间/园林 | 借景（远山、邻木、天光）、允许青苔与包浆、留时间痕迹 |
| 声景 | 收录真实雨声、风声、虫鸣，随环境起伏 |

**反例**：全人工布光却称「自然」；抹掉一切使用痕迹与老化。

### 8 · 破 Ha — 秩序中的偶然性

| 介质 | 转译 |
|---|---|
| 文字 | 全篇一处句式突变或一句破格的话 |
| 影像 | 全片一处甩镜/快推/断裂节奏 |
| 套图 | 整套一张打破统一约定（如唯一一张直视镜头） |
| 平面/UI | 一处朱砂单点、一处破格卡片 |
| 空间 | 一块形如远山的枯木、一处不合规的置石 |
| 声景 | 一次意外声响打破循环 |

**硬约束**：**每幅 / 每屏 / 每套 / 每片至多 1 处**，且除破格外**其余元素 100% 合规**。破格必须可说出目的；「恰好 1 处」的旧口径作废，允许 0 处。
**反例**：处处破格＝没有秩序；破格处同时违反可读性与无障碍。

## 三、体系适配

| 体系 | 八意识适用度 |
|---|---|
| 东方·日式（侘寂） | **全量适用**，是原生语境 |
| 东方·中式（宋） | 间/素/秘/微/气 高度适用；并/破 按中式「气韵」调整；假 对应四时与借景 |
| 东方·中式（明清） | 微/并/气/假 适用；间（留白）需收缩，因画面偏饱满 |
| 西方 | 只借用「并」（统一性）、「微」（细节自洽）、「破」（焦点强调）作为普适形式原则；不套用「秘/假/素」的文化含义 |
| 伊斯兰 | 「并」（几何统一）与「破」（慎用）可借用；「间」（留白）**不适用**，与 Horror Vacui 冲突 |

## 四、八意识联检清单（P7 气质层逐项确认）

1. **微**：每个细节能否推知整体规范？
2. **并**：各单元既独立又被同一秩序收拢？
3. **气**：有没有「看不见但能感到」的场？
4. **间**：留白是否承担节奏与呼吸，而非只是空？
5. **秘**：是否留了不一次给全的位置？
6. **素**：材料/色彩是否保住本色，未被过度修饰？
7. **假**：有没有把一部分主导权交给自然与时间（四时、痕迹、偶然）？
8. **破**：破格是否 ≤1 处、目的明确、其余 100% 合规？

> 冲突时回到 §1 优先级；**可用性与可读性永远优先于任何一条气质意识**。
