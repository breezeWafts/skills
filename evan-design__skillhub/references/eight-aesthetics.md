# 日本八大审美意识 · WorkBuddy 量化落地规范

本文件把「微、并、气、间、秘、素、假、破」八个审美意识转译为可测量、可校验、可写入 CSS Token 的设计规则。思想基底：对自然的敬畏 + 对秩序的迷恋。

**与三层哲学的映射：**

| 意识 | 读音 | 一句话内核 | 归属层 | 主要承接的既有规范 |
|------|------|-----------|--------|-------------------|
| 微 | Bi | 细节中蕴含整体 | L1 → L3 | 描边/图标/圆角/微交互 |
| 并 | Hei | 独立而统一 | L1 → L2 | 统一性原则、栅格、版心比例 |
| 气 | Ki | 无形的场域 | L1 → L3 | 阴影、噪点材质、模糊景深 |
| 间 | Ma | 即若即离的流动空间 | L1 → L2 | 中式留白、间距模数、分割优先间距 |
| 秘 | Hi | 秘而不宣的想象力 | L1 | 幽玄、渐进披露、单焦点 |
| 素 | So | 返璞归真的本色 | L1 → L3 | 侘寂、低饱和、自然素材 |
| 假 | Ke | 对大自然的绝对信赖 | L1 | 物哀、季节感、保留痕迹 |
| 破 | Ha | 秩序中的偶然性 | L1 → L2 | 枯山水布局、圆角自然差异 |

**使用原则：** 八意识是 L1 意境层的展开，用于解释「为什么这样设计」，也是设计分歧时的裁决依据。它们不是八套独立样式，而是对同一套 Token 的八种审视角度。当某个意识与具体数值冲突时，按「间/素/秘（气质）＞并/破（秩序）＞微/气/假（感知）」优先级裁决。

---

## 1 · 微（Bi）— 细节中蕴含整体

**内核**：细微之处有神灵。细节不是渺小，而是「一瞬含过去与未来」「一叶知整体」。落到界面：每个可交互细节都必须自洽地反映整体规范。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 图标描边宽度 | 恒定 1.5px，端点 `round` | 代码审查：全局无第二种描边宽度 |
| 图标尺寸档位 | 仅 16 / 21 / 34px 三档 | 禁止出现中间值 |
| 描边透明度 | `rgba(28,28,28,0.08)` | Token `--color-border-subtle` |
| 字号精度 | 精确使用 68/42/26/20/16/13 | 禁止取整改写（如 42→40） |
| 圆角自然差异 | 基准 ±2px 内 | 主容器12/卡片10/输入框8 |
| 可交互元素反馈态 | hover/press 覆盖 100% | 逐个元素检查是否有 micro 动效 |
| 微交互时长 | 150ms ease-out | Token `--duration-micro` |

### CSS 实现

```css
.icon {
  stroke-width: 1.5;
  stroke-linecap: round;
  stroke-linejoin: round;
  width: 21px; height: 21px;   /* 仅 16/21/34 三档 */
}
.interactive { transition: opacity var(--duration-micro) ease-out; }
.interactive:active { opacity: 0.72; }
```

**反例**：图标 1px/1.5px/2px 混用；字号被四舍五入成整数；按钮无 hover 态。

## 2 · 并（Hei）— 独立而统一

**内核**：每个独立个体从一开始就顾及整体。个体保持独立，又与整体及社会和谐关联——映射到界面即「组件自治 + 系统统一」，也对应日本語「 Democracy 」式的相互体谅：组件互不侵犯，为相邻元素留出空间。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 色板/间距/字体阶梯套数 | 各仅 1 套 | 跨页面风格漂移视为缺陷 |
| 栅格栏数 / 间距 | 12 栏 / gap 21px | 布局验证 |
| 版心比例 | 主内容:侧栏 = 61.8:38.2 | 布局验证 |
| 点击热区间距 | ≥ 8px | 移动端实测 |
| 色彩配比 | 主 60% / 辅 30% / 强调 10% | 面积估算 |
| 硬编码颜色/间距 | 0 处 | 代码审查：全部引用 Token |

### CSS 实现

```css
.layout {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: var(--grid-gap);            /* 21px */
  max-width: var(--container-max); /* 1280px */
}
.content { grid-column: span 8; }   /* 8/12 ≈ 61.8% */
.sidebar { grid-column: span 4; }   /* 4/12 ≈ 38.2% */
```

**反例**：两套主色板并存；组件擅自改间距；相邻可点元素贴在一起无热区。

## 3 · 气（Ki）— 无形的场域

**内核**：人或物不是孤立存在，而是「包含周围空气的人或物」。木柱散发自然之气，石头冰冷——材质自带场域。落到界面：阴影、噪点、模糊共同构成元素的「气场」，让物体与背景之间有空气感。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 浮层阴影层数 | ≥ 3 层柔和阴影 | 禁止单层硬投影 |
| 阴影模糊半径 | 2 / 12 / 40px 递进 | Token `--shadow-soft` |
| 模态景深 | `blur(12px) saturate(0.9)` | 模态背景实测 |
| 纸张噪点透明度 | 2–4% | Token `--noise-opacity: 0.03` |
| 材质温度一致性 | 同屏暖/冷材质基调统一 | 木/纸偏暖、石/金属偏冷，不混用 |
| 暗色场域 | 边缘微光 `inset 0 0 0 1px rgba(255,255,255,0.06)` | 替代硬阴影 |

### CSS 实现

```css
.card {
  box-shadow:
    0 1px 2px rgba(28,28,28,0.04),
    0 4px 12px rgba(28,28,28,0.06),
    0 16px 40px rgba(28,28,28,0.04);
}
.paper::after {
  content:""; position:absolute; inset:0; pointer-events:none;
  background-image: url(noise.png); opacity: var(--noise-opacity);
}
.modal-backdrop {
  backdrop-filter: blur(12px) saturate(0.9);
}
```

**反例**：`box-shadow: 0 2px 4px #000` 硬投影；纯白平面无空气感；模态背景全透明无景深。

## 4 · 间（Ma）— 即若即离的流动空间

**内核**：由「气」形成的流动空间，是日本审美最特别的元素。建筑用柱子而非实墙区隔，空间得以从室内流向自然、从一室流向另一处。落到界面：用留白与间距分隔，而非边框；空间是流动的、可呼吸的。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 内容区留白占比 | ≥ 40%；首屏 ≥ 50% | 视觉或工具测量 |
| 主视觉周围留白 | ≥ 相邻区块间距 × 1.618 | 间距比测量 |
| 区块四周呼吸边距 | ≥ 21px（`--space-4`） | 布局检查 |
| 分隔手段 | 间距优先；边框仅 `rgba 0.08` 1px | 能不用线则不用 |
| 长页停顿点 | 每 618px 一个留白停顿 | 卷轴式长页 |
| 留白 vs 边框分隔比 | 留白分隔 ≥ 80% | 走查统计 |

### CSS 实现

```css
.section { padding-block: var(--space-6); }         /* 55px 呼吸 */
.hero { padding-inline: var(--space-7); }           /* 89px */
.hero__visual { margin: calc(var(--space-4) * 1.618); }
/* 长页停顿 */
.scroll-stop { margin-block: 618px 0; }
```

**反例**：填满式布局；用 1px 实线把每个模块框起来；区块贴边无呼吸区。

## 5 · 秘（Hi）— 秘而不宣的想象力

**内核**：不表现全部，通过部分隐藏驱动对方想象，迫使观者主动参与。「不懂」本身成为参与的动机。落到界面：信息渐进披露，首屏只露一线，其余藏在 hover / 更多 / 转场之后。绘画中虚化无边界的边缘最富想象——对应界面的柔边与遮罩。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 首屏主 CTA 数量 | 恰好 1 个 | 视觉评审 |
| 单屏主要任务数 | ≤ 3 | 任务盘点 |
| 视觉焦点数 | ≤ 1 | 大小/色彩/位置三重对比 |
| 信息暴露层级 | 首屏 ≤ 2 层，其余渐进 | 逐级点开验证 |
| 次级操作收纳 | 收进「更多」或 hover 态 | 走查 |
| 虚化边缘宽度 | 8–21px（mask 渐隐） | 图片/插画柔边 |
| 揭示转场时长 | 300ms `--duration-expand` | 代码审查 |

### CSS 实现

```css
.reveal-edge {
  -webkit-mask-image: linear-gradient(to bottom, #000 60%, transparent 100%);
  mask-image: linear-gradient(to bottom, #000 60%, transparent 100%);
}
.progressive { max-height: 0; overflow: hidden;
  transition: max-height var(--duration-expand) var(--ease-zen); }
.progressive.is-open { max-height: 500px; }
```

**反例**：首屏堆多个同等权重按钮；把所有信息一次性摊开；硬切边图片。

## 6 · 素（So）— 返璞归真的本色

**内核**：保持最朴实的本色之美，不添加杂念的纯真。信赖自然、顺势而为。木材风化显木纹、青竹变金褐、泥土斑驳——推崇自然素材，背后是面对自然的谦卑。落到界面：低饱和、无多余装饰、材质本色。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 主色饱和度 HSL S | ≤ 45% | HSL 校验 |
| 高饱和色面积 | ≤ 10% | 面积估算 |
| 渐变/高光/塑料质感 | 0 处 | 代码审查 |
| 纯白背景 / 纯黑文字 | 禁用，用 #FAF8F3 / #1C1C1C | Token 校验 |
| 同屏字体族 | ≤ 2（字体库 5 族为候选，同屏仅用 ≤2） | 字体审查 |
| 自然素材色 | 褪色靛蓝/氧化铜绿等「旧感」色 | 色板核对 |
| 噪点材质 | 2–4% 纸张颗粒 | `--noise-opacity` |

### CSS 实现

```css
:root {
  --color-accent: #2E4A6B;   /* HSL S≈40%，旧感靛蓝 */
}
/* 禁止：linear-gradient 高光、box-shadow 塑料反光 */
```

**反例**：`linear-gradient(135deg,#f00,#00f)` 撞色高光；纯 #FFF 背景；一屏三种字体。

## 7 · 假（Ke）— 对大自然的绝对信赖

**内核**：「假」有借之意——不抗拒、顺势而为。自然有最完美的秩序，人应顺应融入。庭园保留落叶、茶室土墙斑驳不修葺一新、保留修复痕迹——把腐朽过程也视为美。落到界面：季节性、痕迹感、状态消逝可被温柔感知（物哀）。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 季节主题色 | 4 套可切换：春·天水碧 #4F7877 / 夏·石青 #2E5A88 / 秋·赭石 #A0522D / 冬·月白（仅背景） | 主题切换验证 |
| 浅季节色用字 | 月白 #C9D2D3 对宣纸白仅 1.45:1，禁作文字；其上文字用 #5E7075（4.88:1） | 对比度实测 |
| 状态过渡时长 | 400–600ms `cubic-bezier(0.22,1,0.36,1)` | 代码审查 |
| 删除/归档撤销窗口 | 5 秒 | 交互计时 |
| 空状态文案 | 「此处尚无痕迹」+ 极简植物线稿 | 文案走查 |
| 痕迹保留 | 破损/修复痕迹不被完全抹平（圆角 ±2px、斑驳纹理） | 视觉评审 |
| 消逝动效 | 淡出 + 下沉 8px | 动效审查 |

### CSS 实现

```css
[data-season="spring"] { --color-accent: #4F7877; } /* 天水碧（深，4.62:1）*/
[data-season="summer"] { --color-accent: #2E5A88; } /* 石青 */
[data-season="autumn"] { --color-accent: #A0522D; } /* 赭石 */
[data-season="winter"] { --color-accent: #5E7075; } /* 冬季深青灰文字（4.88:1）；月白 #C9D2D3 仅作背景 */
.state-fade { transition: opacity 600ms var(--ease-zen),
                        transform 600ms var(--ease-zen); }
.state-fade.is-leaving { opacity:0; transform: translateY(8px); }
```

**反例**：状态瞬间消失无过渡；空态写「暂无数据」；删除不可撤销；季节色全年不变。

## 8 · 破（Ha）— 秩序中的偶然性

**内核**：遵守既定秩序与技术之后，寻找偶然性的力量。雕刻大师近乎完成时闭眼抡下一锤——那一锤的「偶然」即是破。前期遵循自然与秩序，最终一破打破常规，赋予作品超越技术的生命力。落到界面：在严格遵守规范的基础上，允许一处刻意的、受控的「破格」成为点睛 focal point。

### 量化指标

| 指标 | 阈值 | 校验方法 |
|------|------|---------|
| 破格元素数量 | 每屏 **0 或 1 处**（至多 1 处，可选） | 视觉评审：多则泛滥；零破格亦合规。v1.1.0 统一口径，原"恰好 1 处"作废 |
| 破的前提 | 除破格外其余元素 **100%** 完全合规 | 先校验再评估破；破格元素本身不计入合规分母。原"99%"作废 |
| 破的类型 | 错位/超规尺寸/单处高饱和点缀 三选一 | 不得同时叠加 |
| 枯山水布局 | 成组但不均分，组间留白 `--space-6/7` | 仪表盘走查 |
| 圆角自然差异 | ±2px 内视为「假性破」，不计入破格 | 侘寂容差 |
| 破格标注 | 用 `--accent-ha` Token 显式声明 | 代码审查：避免误判为 bug |
| 破格朱砂对比度 | #B03A2E / 宣纸白 = 5.67:1 | 满足正文 AA；暗底改 #E0705F |

### CSS 实现

```css
:root { --accent-ha: #B03A2E; }   /* 朱砂：唯一的破格强调色 */
.zen-dashboard { display:flex; gap: var(--space-6); } /* 成组不均分 */
.ha-accent {                       /* 全屏唯一一处破格 */
  /* 例：单处超规字号或朱砂点缀，其余元素严格守规 */
  color: var(--accent-ha);
}
```

**反例**：满屏多处「随机」错位（那是混乱不是破）；未守秩序就乱加装饰；破格元素超过 1 处。

**关键**：破是「先守后破、破而不滥」。它必须在除破格外其余元素 **100%** 完全合规的前提下才成立——没有秩序的破只是噪音。破是**可选**点睛（0 或 1 处），不是强制项；全屏守规、零破格同样是合规交付。

## 八意识联检清单（界面定稿前）

- [ ] 微：图标描边 1.5px 三档尺寸，交互元素 100% 有 150ms 反馈
- [ ] 并：单套 Token、12 栏栅格、61.8:38.2 版心、0 硬编码
- [ ] 气：≥3 层柔和阴影、模态 blur(12px)、噪点 2–4%
- [ ] 间：留白≥40%（首屏≥50%）、留白分隔≥80%、间距比 1.618
- [ ] 秘：首屏 1 个 CTA、焦点≤1、信息渐进、边缘虚化
- [ ] 素：饱和度≤45%、渐变 0、无纯白纯黑、字体≤2
- [ ] 假：季节主题、400–600ms 消逝、5 秒撤销、「此处尚无痕迹」
- [ ] 破：其余元素 100% 合规前提下，至多 1 处（0 或 1）受控破格并标注 `--accent-ha`
- [ ] 无障碍：状态色另配图标/文字；浅季节色未承载正文；正文对比度 ≥ 4.5:1
