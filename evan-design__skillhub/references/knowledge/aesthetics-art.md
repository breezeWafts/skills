# 美学艺术类知识库
> 定位：把哲学、美学、艺术史与设计方法转成可执行的创作规则，不提供作品故事、轶事或软件操作教程。
> 适用：平面、绘画、建筑与空间、产品、数字界面、信息可视化，以及跨媒介创作的立意、制作和评审。
> 读法：先用第一篇确定价值与感知依据，再用第二篇选择形式方法，最后用第三篇组织流程、验收与复盘。
> 使用：每条规则都应落到尺寸、比例、层级、路径、样本、测试或记录；“高级、和谐、有意境”不得单独作为验收依据。
> 原则：历史命题与现代转译分开表述；相似范畴只作对照，不把某一文明的规则冒充普遍定律。
> 边界：剔除铅字工艺和过时软件步骤，保留比例、构成、阅读、材料、观看等长期有效的原理。
> 维护：涉及无障碍、生成式人工智能、版权、环保和平台规范时，以项目所在地的现行法规与合同为准。

## 第一篇　美学底层逻辑

### 第一章　美的定义不是单选题
#### 1. 理念路径：美是可感形式对意义的显现
- 核心判断：作品是否让抽象内容获得不可替代的感性存在，而不是给既定口号加装饰。
- 操作定义：先写出一句内容命题，再逐项说明色彩、形体、材质、声音或空间为何非此不可。
- 适用任务：纪念性空间、品牌核心价值、主题展陈、观念艺术。
- 验证方法：遮去说明文字后，目标受众仍能感知主要态度；恢复文字后，形式与解释不互相矛盾。
- 失败信号：任何风格都能替换而不影响内容，或只有长篇阐释才能证明作品成立。
#### 2. 形式路径：美是要素关系的秩序与张力的统一
- 核心判断：点、线、面、体、色、光、材质之间是否形成可辨的主次、比例、节奏和整体性。
- 操作定义：把“好看”拆成可测关系，包括对齐、间距、面积、方向、明度、密度、尺度和重复变量。
- 适用任务：抽象绘画、版式、立面、标志、产品轮廓、动态图形。
- 验证方法：删除或移动一个要素，记录整体是否失去平衡、方向或重点；无影响者多半应删。
- 失败信号：局部均精细而整体无主从，或把对称、黄金比例等单一公式当作结论。
#### 3. 情感路径：美是可被传达和共同经验的感受
- 核心判断：形式是否把私人情绪转化为他人可进入的情调，而非只记录创作者当时的激动。
- 操作定义：指定一个主导情绪和不超过两个辅助情绪，并给每种情绪配置形色、节奏和空间线索。
- 适用任务：叙事图像、表演、服装、商业传播、疗愈空间。
- 验证方法：测试受众先说出的感受词与强度，再追问由哪些形式线索引起。
- 失败信号：受众只报告刺激、困惑或生理不适，创作者却用“见仁见智”拒绝校准。
#### 4. 生活路径：美在实践、使用和日常关系中被生成
- 核心判断：作品是否改善行动、身体感受、时间利用和人与环境的相处方式。
- 操作定义：把功能完成度、学习成本、维护负担、触感和长期使用后的变化纳入审美评价。
- 适用任务：产品、住宅、公共环境、服装、服务触点。
- 验证方法：用真实尺寸、真实任务和真实光照测试，记录行为而不只审静态效果图。
- 失败信号：首次观看醒目，持续使用却增加清理、误操作、疲劳或资源浪费。
#### 5. 制度路径：美也生产身份、等级、规范与共同价值
- 核心判断：形式在允许谁进入、突出谁、遮蔽谁、鼓励何种行为，必须与感官评价同时追问。
- 操作定义：列出赞助者、制定者、使用者、维护者、被代表者和被排除者，检查各自的可见度与收益。
- 适用任务：公共文化、城市空间、品牌系统、数据叙事、跨文明设计。
- 验证方法：审查礼仪、消费、劳动和传播条件，识别“普遍品味”背后的历史制度。
- 失败信号：把权力偏好的宏大、昂贵、统一或纯洁，直接等同于所有人的美。
#### 6. 五条路径的联合使用
- 立意阶段先选主路径，避免同时用五套标准互相抵销。
- 形式草图阶段至少通过“形式＋情感”检查，防止概念正确但感知空洞。
- 产品与环境方案必须通过“生活＋制度”检查，防止只优化照片和传播。
- 评审时分别记录“我喜欢什么”“它如何实现”“它影响谁”，不把个人趣味冒充专业结论。
- 最终判断允许冲突，但必须公开取舍：为何牺牲局部装饰、效率、熟悉度或一致性。

### 第二章　审美心理机制：从感知到再创造
#### 1. 感知：先组织，后辨认
- 视觉系统优先捕捉轮廓、对比、方向、群组和运动，细小语义通常随后进入注意。
- 接近的元素易被归为一组；分组首先靠间距，不宜先依赖边框和分割线。
- 相似的颜色、字形、形状或材质会被理解为同类；同类组件必须保持关键特征一致。
- 连续线和对齐边会引导视线；断线、错位和破格只应在需要改变路径时使用。
- 闭合倾向会补足不完整轮廓；省略部分形体时必须保留足够的闭合线索。
- 图底关系决定何者成为主体；缩小、变灰和模糊都可改变图底，而非只有放大主体。
- 感知具有情境性，颜色、大小和重量感会受邻域影响，单件打样不能代替整体测试。
#### 2. 情感：评价常与身体唤醒同时发生
- 高对比、突发运动、尖锐方向和强饱和可提高唤醒，但不等于提高价值或好感。
- 熟悉度降低识别成本，陌生度提供探索回报；创新方案应保留一项稳定的认知锚点。
- 情绪会影响注意宽度，过度焦虑或兴奋可能缩小信息搜索范围。
- 身体尺度、温度、触感、回声和移动阻力都参与情绪，不得只用屏幕色稿推断空间体验。
- 美感可以包含悲伤、敬畏、紧张与矛盾，目标不是一律制造愉悦，而是形成合宜的情感距离。
- 情感测试须记录强度、持续时间和行为后果，不只收集“喜欢／不喜欢”。
#### 3. 理解：知识与文化为感知定向
- 符号意义依赖共同体、历史与使用语境，同一颜色、姿势或图形不具跨文化固定含义。
- 观看者会以既有类型预测对象；违背类型前应确认偏离能被注意且可学习。
- 标题、图注和空间位置会改变图像解释，文字不是中性附件。
- 专业知识能提升细节辨别，也可能造成专家盲区；新手与熟手应分别测试。
- 多义性必须受作品线索约束；彼此矛盾且无法定位的解释是歧义，不是开放。
- 评审意见须区分事实观察、意义推断和价值判断，禁止把推断写成画面事实。
#### 4. 想象：在空白与关系中补足未尽之意
- 想象不是任意添加，而是依据已有形式、记忆与情感生成可能的整体。
- 留白、遮挡、剪影、局部和间接叙事可减少明说，但必须留下方向明确的补足线索。
- 再造性想象用于根据描述还原对象，创造性想象用于重组经验形成新关系。
- 想象力需要素材库存；持续观察、分类、记录和回看比等待偶然灵感更可靠。
- 测试“能否补出预期意义”时，不先展示标准答案，以免解释文字替作品完成任务。
#### 5. 四机制的循环与校准
- 创作顺序可采用“感知草图→情感目标→语义校验→想象留口”，再返回感知层调整。
- 评审顺序先看五秒内的注意路径，再看一分钟内的理解，最后看延时记忆与再访意愿。
- 对高刺激方案增加减弱测试：逐项降低饱和、速度或反差，找出仍成立的最低强度。
- 对高留白方案增加补足测试：确认空白改善了分组、停顿或意义，而非掩盖内容不足。
- 对多义方案设置意义边界：列出可接受解释与不可接受误读，逐项用形式线索排除。

### 第三章　美与真、善、用、权力的关系
#### 1. 美与真
- 艺术之真不等于摄影式相似，可表现为结构可信、情感诚实、材料真实或经验可感。
- 再现必然包含选择，取景、视点、比例和省略都在构造真实，不得声称图像天然客观。
- 数据之美不得掩盖来源、单位、缺失和不确定性；形式清晰不能替错误数据背书。
- 历史材料的残损、风化、锈蚀与修补应分别记录，不以现代修复制造“完整原作”的假象。
- 合成图像须统一光源、透视、比例、边缘和颗粒，同时明确其为合成而非现场证据。
#### 2. 美与善
- 审美完善不能抵销欺骗、歧视、伤害或资源剥夺，伦理验收应独立设置否决项。
- 教化有效并不等于内容正确；越具感染力的形式，越要审查其引导方向。
- 尊重观看者的自主判断，不用羞辱、恐惧或虚假稀缺操纵选择。
- 对弱势群体的呈现应避免猎奇、刻板和替他人发言，涉及真实人物时确认授权与解释权。
- 善不是额外装饰主题，而应进入可及性、劳动条件、材料来源和后续维护。
#### 3. 美与用
- 功能不是形式的敌人；用途、限制与反馈本身可以生成清晰形态。
- 装饰在帮助识别、分区、保护、触知、记忆或意义表达时具有功能，不应一概删除。
- 功能效率也不能独占审美判断，仪式感、游戏、沉思和象征可有非工具性价值。
- 预示用途的形状须与实际操作一致，不能为视觉语义制造错误动作暗示。
- 操作状态、限制条件和结果反馈须可见或可感，避免用户依赖额外猜测。
- 验收同时测“会不会用”“愿不愿用”“用久后是否仍合适”。
#### 4. 美与权力
- 尺度、轴线、门槛、视线与中心位置会组织等级，设计前应说明等级是否必要。
- 统一视觉系统可降低协作成本，也可能压平地方差异；保留合法变体和退出机制。
- 纪念性不应只靠巨大和昂贵，可用光影、行进、材料与共同参与建立庄严经验。
- 平台模板和算法偏好会塑造流行风格，须记录主动选择，避免把推荐结果当成审美规律。
- 经典标准来自历史筛选而非天然永恒，引用时同时记录其适用语境与排除过的声音。

### 第四章　思想如何转化为审美与设计规则
#### 1. 使用对照表的三条纪律
- “思想源头”用于理解价值方向，“审美原则”用于组织经验，“当代规则”是可检验转译，三者不可互相冒充。
- 不把哲学名词直接变成视觉标签；每次转译必须写出中间机制和测试方法。
- 同一项目不宜调用过多思想源头，优先解决真实矛盾，避免符号拼贴。
#### 2. 中国思想：关系、生命、规范与效用
| 思想源头 | 审美原则 | 可执行设计规则 |
|---|---|---|
| 儒家礼乐 | 形式组织行为，节奏协调共同经验 | 先画行为与情绪流程，再定空间、动效或展陈节奏；每项形式须对应引导、反馈或连接。 |
| 乐合同、礼别异 | 和谐保留差异，协同不等于同一 | 同类组件统一关键规则，同时保留角色差异；检查差异是否仍可辨、是否破坏共同秩序。 |
| 文质彬彬 | 内容与修辞互相成全 | 分别进行去装饰与恢复装饰两轮评审；内容不成立或装饰不增理解均返工。 |
| 绘事后素 | 先立底色与本体，再施表层增饰 | 先锁定内容结构、网格与材料基底，再添加纹理、特效和风格化元素。 |
| 中和 | 差异要素合节而成和 | 每个视域最多保留两条主导对比轴，其余变量降级，避免所有要素同时争夺注意。 |
| 尽善尽美 | 形式价值不替代伦理价值 | 形式、可用、诚实、可及分别评分；任何伦理否决项不得由视觉高分抵销。 |
| 道法自然 | 顺应物性和条件，减少强制雕琢 | 先测试材料、平台与身体行为倾向，再定形态；不把“自然”缩减为木纹和绿色。 |
| 天人合一 | 人、物、时节与环境构成关系整体 | 把光线、季节、维护、周边使用纳入方案，按时间切片测试而非只验收集成瞬间。 |
| 有无相生 | 实体与空缺共同产生功能 | 将空白、间隔和空腔列入尺寸系统；删除要素后必须确认分组、路径或使用得到改善。 |
| 大音希声、大象无形 | 强烈经验可由低显度形式承载 | 限制高饱和、强阴影和大幅运动，只留一个主信号，其余以微细变化支持。 |
| 大巧若拙 | 技术不炫示，精确藏于自然感 | 隐藏不影响理解的加工痕迹，但不得牺牲结构安全、可维修性和真实材料感。 |
| 禅之空 | 对象依缘显现，不执固定形相 | 对核心组件提供情境变体，检查不同尺寸与内容下是否仍保持关系而非死守外观。 |
| 禅之当下直观 | 经验直接发生，不让概念替代感知 | 每个关键场景设一个当下主任务；先测实际注意与身体反应，再补概念说明。 |
| 寂与清明 | 止息扰动而保留微细变化 | 降低无关对比，同时保留必要反馈、材质或时间变化，避免静到无法定位。 |
| 墨家尚用 | 公共效用与成本约束审美 | 在方案前列出制作、维护、能耗和可及性成本；装饰无体验收益且显著增负时删除。 |
| 名家辨名实 | 类别与指称依赖所立标准 | 为图标、组件和符号建立命名规则与边界样本，测试“像何物、属何类”是否一致。 |
| 阴阳关联 | 差异在动态消长中平衡 | 用成对变量调整明暗、虚实、开合，不采用固定二元色表；测试整体变化过程。 |
| 法家规范 | 标准明确且执行一致 | 建立可复用尺寸、命名和验收规则；同时设例外审批，防止一致性压制合理差异。 |
| 师造化 | 外部观察经主体转化 | 至少完成一次真实样本观察，提炼结构、运动或生长规则，而非复制表面纹理。 |
| 气韵生动 | 整体活性优先于局部堆砌 | 用统一方向、速度或笔势贯穿全局，删除打断整体动势的孤立炫技。 |
| 意境 | 情景交融并生象外余意 | 指定主情绪与环境线索，保留一处有依据的暗示，测试余意是否由形式触发。 |
| 风骨 | 内在支撑与感发力量统一 | 先定信息骨架、结构承重与视觉重音，再加风格；抽走风格层后核心仍须成立。 |
| 传神 | 关键特征胜过平均精细 | 选择一至两个不可替代的识别特征优先刻画，其余细节降低精度。 |
| 写意 | 有依据地概括并显现判断 | 建立“保留、强化、省略”清单，每次省略都说明为何不损害对象之意。 |
| 藏露 | 显隐安排发现过程 | 首层只给决策必需信息，次级内容渐进展开；被藏内容须有明确可寻线索。 |
| 留白 | 空处参与构图与意义生成 | 用周围边界、方向和密度定义空白；无结构作用的空白须重新分配，而非盲目扩大。 |
#### 3. 西方及其他文明：形式、显现、接受与情调
| 思想源头 | 审美原则 | 可执行设计规则 |
|---|---|---|
| 数与比例 | 可测关系建立秩序 | 以一个基础模数生成间距、字号或构件，再按视距与材料作光学修正，不机械套黄金比例。 |
| 柏拉图理念 | 个别显现指向可理解类型 | 明确组件核心不变量与可变项；变体不得破坏核心类型识别。 |
| 亚里士多德整一 | 部分按必要性组成整体 | 逐元素追问删除后整体是否受损；无明确回答者删除或合并。 |
| 模仿与认识 | 再现可揭示行动结构而非复制外表 | 选择与主题有因果关系的特征，检查变形是否仍保持结构与行动可信。 |
| 中世纪神显 | 光使不可见秩序获得感性显现 | 用亮度层级编码真实信息层级，不随机加辉光；象征须依赖可学习语境。 |
| 哥特垂直性 | 结构与行进共同组织超越经验 | 用连续竖向构件和上行路径引导视线，同时设置人体尺度和休息节点。 |
| 文艺复兴人文尺度 | 身体、比例与空间相互参照 | 关键尺度须用真实人体与活动范围校核，不以孤立效果图判断纪念性。 |
| 线性透视 | 统一视点构造连贯空间 | 同场景统一相机、地平线与消失点；另做移动视角测试，承认其观看制度边界。 |
| 古典和谐 | 部分合宜、整体克制、形式得体 | 根据题材和使用场景确定装饰密度，避免把复古元素当作和谐本身。 |
| 康德无功利 | 审美经验不被占有与功用完全吸收 | 增加一次不依赖促销与品牌收益的形式评审，但不得取消功能验收。 |
| 康德崇高 | 失度感与主体能力形成张力 | 大尺度场景提供定位、退出与安全参照，以敬畏而非迷失为目标。 |
| 优美 | 连续、柔和与合宜降低感知阻力 | 控制曲率、过渡与明暗变化，同时保留识别对比，避免柔弱等同于低对比。 |
| 黑格尔理念显现 | 内容取得与其相称的感性形式 | 先写内容命题，再证明材质、色彩与节奏的必要性，拒绝无内容依据的风格复古。 |
| 艺术的历史性 | 形式须放回精神内容与时代条件 | 评审历史风格时同步记录技术、制度和受众，不将时代特征剪成自由素材。 |
| 尼采日神／酒神 | 清晰形象与生命冲动相互牵动 | 先建立稳定网格，再在战略位置破格；检查破格是否增能而非造成操作混乱。 |
| 现象学 | 作品在具体、具身经验中显现 | 用真实尺寸、距离、光线和持握方式测试，记录身体移动与感知变化。 |
| 形式自律 | 点线面色可不依附再现而产生意义 | 先建立纯形式变量表，再检验主次、节奏与张力；不得用题材解释掩盖构成薄弱。 |
| 现代性 | 新材料、技术与生活改变形式语言 | 每次采用传统样式前检查当代使用条件，优先让现实约束生成新形式。 |
| 接受美学 | 意义在接受者期待视域中生成 | 分别测试新手与熟手预期，保留文本约束下的多种解释，排除失控歧义。 |
| 空白与具体化 | 作品以空缺召唤受约束的参与 | 只省略可由上下文补足的信息，并记录受众实际补足路径。 |
| 物哀 | 短暂与变易使情感获得深度 | 用时间、状态或季节变化承载主情绪，避免固定悲伤滤镜。 |
| 幽玄 | 部分遮蔽与暗示扩大未尽之意 | 选择遮挡层级和揭示顺序，保留可追踪线索，测试深远而非含混。 |
| 侘寂 | 简素、不足与真实时间痕迹 | 区分主动节制与材料老化，只采用一种主路径，不用统一做旧滤镜。 |
| 间 | 间隔与停顿使前后要素发生关系 | 用时间或空间间隔界定节奏，检查删除间隔后关系是否明显受损。 |
| 伊斯兰几何 | 简单单元经规则生成无限秩序 | 先设计可无缝扩展的母单元与变换规则，再检查边界、层级和缩放。 |
| 书法性秩序 | 语义、线条、比例和布局共同成美 | 同时验收文字可读性与笔势节奏，不让造型破坏必要语义。 |
| 印度味论 | 主导情调由情境与表现关系生成 | 指定一个主味，分别配置情境因、动作反馈和辅助情绪，测试辅助元素是否冲淡主味。 |
| 原生艺术的直接性 | 非学院规则也可形成强烈个人秩序 | 分析轮廓、重复、密度与私人符号的内部一致性，不以“未经训练”替代质量判断。 |

### 第五章　中国美学范畴的可操作定义
#### 1. 气韵
- 定义：形象、笔墨、色彩、空间与整体运动共同形成的生命活性。
- 操作：先确定贯通全局的主方向或呼吸节奏，再组织局部变化。
- 验收：缩小观看仍见整体之“势”，放大观看可见局部对势的回应。
- 反例边界：柔光、烟雾、飞白和古风滤镜本身不产生气韵。
#### 2. 意境
- 定义：可感情景、主体情意与象外余意的统一。
- 操作：分别列出实景支点、情绪方向和留白暗示，三者不得互相替代。
- 验收：受众能从具体线索出发形成超出字面但不相冲突的理解。
- 反例边界：空泛氛围、朦胧滤镜和无信息场景不等于意境。
#### 3. 风骨
- 定义：内在结构支撑与贯穿整体的感发力量。
- 操作：先做骨架图和重音图，确认视觉或物理承重，再处理表面风格。
- 验收：删去装饰后仍有清楚结构和方向，题材柔弱也不失支撑。
- 反例边界：粗黑、巨大、刚直和宏大不自动等于有骨。
#### 4. 传神
- 定义：通过关键形神特征传达对象的神情、性格和生命状态。
- 操作：找出最具区分度的姿态、比例、眼神、重心或行为线索并优先刻画。
- 验收：减少次要细节后识别与性格反而更清楚。
- 反例边界：平均加细、照片级复制和局部肖似不保证传神。
#### 5. 写意
- 定义：依据观察与理解，以有选择的概括摄取对象之意，并显现主体笔势。
- 操作：为每一处保留、强化、变形和省略写出依据。
- 验收：概括后的结构仍可辨，笔触或形式选择具有一致判断。
- 反例边界：草率、缺少训练和任意变形不是自由写意。
#### 6. 留白
- 定义：未绘、未说、未占用之处作为构图、节奏和意义的主动部分。
- 操作：把空白纳入网格、时间和动线尺寸，明确其分组、停顿或余韵任务。
- 验收：填入内容后整体反而更差，说明空白确有必要。
- 反例边界：内容不足、对齐失败和空洞等待不能借留白免责。
#### 7. 藏露
- 定义：通过遮挡、远近、侧写与渐进披露控制发现过程。
- 操作：画出每层信息的首次可见条件、揭示线索和完成路径。
- 验收：首层重点明确，深层内容可找到，揭示顺序产生预期认知变化。
- 反例边界：无提示的隐藏是可用性缺失，一览无余也未必充分。
#### 8. 师造化
- 定义：以自然和真实经验为依据，经观察、选择与心源转化生成形式。
- 操作：记录结构、受力、生长、运动、时节或行为规律，再转成形式规则。
- 验收：新方案保留对象的机制而非仅表面相似。
- 反例边界：自然纹理、仿生轮廓和绿色配色不自动构成师造化。
#### 9. 虚实、开合与动静
- 虚实：用清晰度、密度、遮挡和色层分配确定信息主次，虚处仍须支撑整体。
- 开合：先设聚合与释放的节点，使观看有收束也有展开，避免全程同一密度。
- 动静：以稳定网格承托局部方向变化，动态越强，静态参照越要明确。
- 联合验收：用连续观看或实际行进记录节奏，不能只检查单张静帧。

### 第六章　西方美学范畴的可操作定义
#### 1. 比例与尺度
- 比例是部分与部分、部分与整体的数值或视觉关系；尺度是对象同身体、环境和用途的关系。
- 先选一个基础模数控制重复，再针对视距、透视、材料和视觉错觉修正。
- 大尺度必须配置人体、家具、栏杆、文字或邻近构件作为参照。
- 固定比例只是候选起点，最终以识别、舒适、结构与整体感知验收。
#### 2. 和谐
- 和谐是有差异要素在共同秩序中的协调，不是同色、同形或低对比。
- 先确定统一变量，再确定少量变化变量；每项变化应服务层级、节奏或重点。
- 检查冲突是否有意图和承托，无功能与语义收益的冲突应降低。
- 和谐可包含张力，评审需记录张力是否被整体结构吸收。
#### 3. 优美
- 优美通常依赖连续轮廓、适度尺度、流畅过渡和较低感知阻力。
- 用曲率、线宽、色彩过渡和节奏连续性实现，不以柔弱、甜美或装饰繁密替代。
- 保持必要的文字对比和操作反馈，避免为了柔和牺牲可及性。
- 优美适用于低威胁、亲近和流畅经验，不必强加于所有题材。
#### 4. 崇高
- 崇高涉及尺度或力量超出日常把握时，主体感知与精神能力形成的张力。
- 通过连续尺度参照、路径递进、光影和结构方向形成，而非单纯放大。
- 同时提供安全、定位、退出和理解支点，避免把恐惧与迷失当作崇高。
- 验收记录敬畏、压迫、迷失三者的比例与成因。
#### 5. 现代性
- 现代性关注技术、生产、城市生活和主体经验变化所要求的新形式。
- 评估材料与媒介是否回应当代条件，而非把某种历史现代风格永久化。
- 允许标准化、模块化和机械生产显现其逻辑，同时审查标准化对人的排斥。
- 任何“新”都须说明解决了什么现实问题，不能只用反传统证明价值。
#### 6. 形式自律
- 形式自律指点、线、面、色、体及其关系可独立成为审美对象。
- 先抽离题材，检查灰阶、方向、面积、密度和节奏是否仍能成立。
- 再以题材检验形式是否误导读义，自律不等于与社会意义彻底隔绝。
- 失败时优先调整关系变量，不急于添加叙事、符号或说明文字。

## 第二篇　美学表现方法的底层逻辑

### 第七章　设计：功能—形式—语义—体验
#### 1. 功能层：明确对象如何工作
- 用“谁在何种情境完成什么任务”定义功能，不以抽象人群替代具体使用条件。
- 列出核心任务、辅助任务、异常状态和不可接受后果，按优先级分配资源。
- 把物理限制、认知限制、时间限制和维护限制写入任务书。
- 预示用途的形态与真实动作一致；可见操作、可感限制和结果反馈形成闭环。
- 每个核心功能至少有一个可观察的完成指标，不能用满意度单独替代。
#### 2. 形式层：把功能组织为可感结构
- 以点定焦点、以线定方向、以面定区域、以体定空间、以材质定触感和时间性。
- 统一先于变化：先确定网格、模数、基调和主方向，再引入少量破格。
- 对比负责区分，重复负责关联，渐变负责过渡，特异负责重音。
- 均衡不等于镜像对称，可用面积、明度、位置和方向形成不对称平衡。
- 每个局部至少承担结构、识别、导向、情感或使用中的一项任务。
#### 3. 语义层：控制对象被如何理解
- 区分指示、相似和约定三类意义线索，分别测试是否指向正确、形似恰当、约定可学习。
- 符号须在目标尺寸、观看距离和实际背景下测试，不以放大稿判断识别。
- 一个视域集中一个主语义，辅助符号不得引入相互竞争的解释。
- 修辞变形须保持核心指称，超现实合成须统一光源、透视、材质和边缘。
- 历史符号必须连同原有语境研究，不将宗教、礼仪和族群标记当作无主装饰。
#### 4. 体验层：把使用过程当作时间性作品
- 画出进入、探索、行动、反馈、退出和再次返回的完整路径。
- 在每个节点记录注意目标、身体动作、认知负荷、情绪变化和恢复方式。
- 初次体验强调可理解，熟练体验强调效率，长期体验强调可维护与不厌烦。
- 动效只在解释状态、空间关系、因果或节奏时使用，并提供减弱运动的方案。
- 故障、等待、空状态和离开也属于体验，不得只设计理想路径。
#### 5. 四层联动的验收
- 去掉形式风格后，核心任务是否仍能完成。
- 去掉说明文字后，主要用途与层级是否仍可理解。
- 恢复形式与语义后，体验是否更清楚而非仅更刺激。
- 真实使用后，形式是否保持，语义是否漂移，维护是否改变原初价值。
- 四层冲突时，先守安全与诚实，再守核心任务，最后调整风格偏好。

### 第八章　创意生成：从问题结构到形式发明
#### 1. 创意生成的基本流程
- 界定题目：分别写下对象、目标、受众、场景、限制和禁止项。
- 建立库存：收集事实、感官样本、使用问题、形式规则与反证，不先收集最终风格。
- 发散：在限定时间内追求数量与差异，暂缓评价，避免第一轮就回到熟悉答案。
- 聚类：按机制而非表面题材归组，找出重复假设与空缺方向。
- 收敛：用目标符合度、差异性、可实施性和伦理风险筛选少数候选。
- 原型：把候选变成低成本可测试形式，记录失败原因，再进入下一轮。
- 沉淀：保存被淘汰方向及淘汰理由，防止团队周期性重复同一误区。
#### 2. 发散法
- 把问题拆成对象、属性、动作、场景、受众、材料和时间七个维度，逐维列变量。
- 每轮只改变一个维度，确保新方案差异能被定位。
- 强制完成“常规、反向、极端、删除、替换、跨尺度”六类方向后再评估。
- 头脑发散阶段不辩论可行性，但须遵守真实、尊重和安全底线。
- 数量目标完成后增加“第二轮陌生化”，禁止直接沿用首轮最显眼方案。
#### 3. 联想法
- 相似联想提取形状、颜色、声音或运动共性，防止只联想到同题材图片。
- 接近联想提取时间、空间和使用场景的邻接关系，适合构建流程与环境。
- 对比联想从相反属性寻找结构，如轻重、开合、显隐，但不得停留于简单反转。
- 因果联想追问“何物导致何种变化”，适合把产品利益转成视觉动作。
- 自由联想之后必须回连题目，写出联想链，删掉无法回到核心问题的末端。
#### 4. 逆向法
- 反转目标：暂时研究如何让任务更困难，再定位真正需要消除的阻力。
- 反转角色：从维护者、旁观者、新手或被影响者重写问题。
- 反转顺序：先设计结果、退出或回收，再反推进入和制作过程。
- 反转假设：把“必须可见、必须连续、必须昂贵”等默认条件逐条取消验证。
- 逆向只用于发现盲点，最终方案仍需正面满足安全、理解与伦理要求。
#### 5. 限制法
- 把颜色、材料、时间、尺寸、字数或操作步骤中的一项设为硬限制。
- 限制应来自真实问题或研究假设，不为制造难度而随意设障。
- 在限制内先穷尽结构变化，再申请增加资源，防止靠加特效解决构成问题。
- 对照“有限制／无限制”原型，判断限制是否提高识别、统一或创新。
- 最终删除限制时，只恢复经测试证明有收益的自由度。
#### 6. 移植法
- 从其他媒介或领域提取机制，而非复制轮廓和风格。
- 用“原问题—原机制—原约束—新题目—新约束”五栏记录迁移。
- 先检验机制在新材料与尺度下是否成立，再决定外观。
- 跨文明移植额外记录礼仪、身份、权力和禁用语境。
- 移植失败时回到机制层，不用表面装饰掩盖不适配。
#### 7. 组合法
- 属性列举：列出各部件的属性，再替换一个属性并观察整体关系。
- 形态分析：以关键维度建立矩阵，系统组合而非随机拼接。
- 功能组合：两个功能共享同一结构时，验证是否相互促进而非互相妨碍。
- 语义组合：两个意象必须在同一视觉动作中相遇，避免两张图简单并排。
- 系列组合：固定色底、尺度、网格或视角，仅改变核心变量，形成统一而有差异的系统。
#### 8. 类比、缺点列举与矛盾解决
- 类比先找关系结构，再找外观对应；关系无法对应时立即放弃类比。
- 缺点列举须来自观察、测试或维护记录，不用主观喜好冒充问题。
- 把核心矛盾写成“需要甲以获得乙，又需要非甲以避免丙”，再寻找分离、合并或条件化方案。
- 对相互冲突的要求按时间、空间、对象或层级分离，避免折中成双方都受损。
- 每次创意收敛至少保留一个保守方案和一个结构创新方案作对照。

### 第九章　建筑与空间：空间、比例、光影、材料、场地
#### 1. 空间：先组织行为与感知，再塑造轮廓
- 以进入、停留、穿行、交汇、独处和退出定义空间类型。
- 用围合、开口、高差、顶面和家具划分区域，避免只依赖平面色块。
- 主轴负责方向，节点负责停顿，边界负责过渡，三者不得互相代替。
- 狭长空间可通过垂直堆叠、错位开口与核心服务带释放使用面积。
- 暗空间须保留少量高亮参照，指示出口、踏步、尺度和主要方向。
- 连续重复可制造纵深与格律，重复单元内应保留有控制的变量。
#### 2. 比例：从几何生成到光学修正
- 先画平面、立面、剖面共享的轴线与模数，确保形态逻辑可跨图追踪。
- 集中式空间用同一中心组织平面、鼓座、顶盖与采光，避免向心秩序被局部开口破坏。
- 大型立面用水平分带、重复开洞和收分把体量拆成可读层级。
- 退台、分段与收尖可调整顶部体量感，但须同时核对结构与使用面积。
- 几何母题可贯通平面与立面，禁止只在表皮复制无结构关系的符号。
- 最终用真实视距与斜视校核，计算比例不等于视觉比例。
#### 3. 光影：把光当作时间与方向的构造
- 先分析日照方向、时段、天气和人工照明，再决定开口与表面。
- 顶光强调高耸和中心，侧光强调起伏与材质，逆光强调剪影，低平光会削弱立体信息。
- 采光网格的重复阴影可形成第二套图案，须避免与主要导向冲突。
- 暗环境中用发光门洞、踏步或工作面建立方向，不做无信息辉光。
- 夜景照明呼应竖向结构、横向连接或入口层级，避免均匀泛亮抹平空间。
- 光色与材料色联合打样，不能以白模或屏幕亮度替代现场光测试。
#### 4. 材料：让构造、触感与老化共同说话
- 材料选择同时考虑结构性能、触感、声学、反光、维护、来源与可修复性。
- 拼接分缝应与受力、模数、门窗和主要方向呼应，避免随机贴面。
- 冷暖、粗细、软硬对比用于明确空间角色，不以材料数量制造丰富。
- 木材、织物与暖光可软化工业结构，但须满足防火、耐磨和维护条件。
- 保留真实老化与修补逻辑，不用统一做旧掩盖材料品质或施工误差。
- 结构本身可成为主景；外露时必须让连接、方向和尺度可读。
#### 5. 场地：建筑是关系网络而非孤立物体
- 记录地形、水体、植被、气候、周边尺度、既有路径和视线，不以空地假设开始。
- 低伏体量、覆土和连续地景用于控制天际线，同时核对排水、采光与可达性。
- 高标志物与低功能体可分工，减少整体体量过高并提高远景定位。
- 新旧建筑之间设置清楚的尺度过渡层，避免巨大体量直接压迫历史界面。
- 城市摄影与评估保留道路、电线、旧楼、行人和维护设施，以真实干扰检验设计。
- 遗址与石窟类空间把岩体、栈道、洞窟、造像和观看路径作为整体，不只截取室内图像。
#### 6. 空间方案的证据链
- 总平面说明场地、道路、开放空间和建筑群关系。
- 平面说明功能与流线，立面说明比例与分带，剖面说明高度、结构与光。
- 轴测或分解图说明体块叠加，模型说明整体关系，实景说明材质、光线和使用状态。
- 全貌、组合、局部构成观看顺序：先环境，再单元，最后节点与表面。
- 多方案比较固定视角、背景、比例和光照，避免用渲染差异掩盖方案差异。
- 每张分析图只回答一个问题，图例、颜色和线型保持跨页一致。

### 第十章　绘画与视觉艺术：构图、形色、笔触、观看方式
#### 1. 构图：建立观看路径
- 先确定主体、次主体和视觉终点，再布置具象或抽象引导线。
- 道路、建筑边、手势、眼神可具象引导，色块、光影、透视和方向可抽象引导。
- 中轴和对称适合稳定秩序，局部扭转、偏移和错落用于避免僵硬。
- 三角组合可形成稳定主从，螺旋与斜向动势适合多角度或连续观看。
- 对峙构图让视线汇聚到相遇点，队列构图依靠重复与色彩分段形成节奏。
- 强动势画面须用稳定色块、边界或品牌区收束，避免能量无出口。
#### 2. 空间与层次
- 前后遮挡、近大远小、前实后虚可建立基本纵深。
- 前粗后细的线条、前暖后冷的色层和前清晰后朦胧的边缘可强化距离。
- 近景暖而清晰、远景冷而浅淡可形成空气透视，但不得机械套用于所有光照。
- 平面空间可用分带、叠合、剪影和概念位置组织，不必服从单点透视。
- 统一视点场景须共享地平线、消失点和光源；移动观看另做一致性测试。
- 残片、遗址与历史图像必须保留真实边缘和层积，不臆测补全缺失信息。
#### 3. 形与色：从再现到自律
- 具象绘画先抓轮廓、重心、结构与识别特征，再处理表面细节。
- 抽象绘画先建立点、线、面、体和笔触的元素语汇，再组织其关系。
- 灰阶可替代色彩组织主次，先用少量深块与大量浅块确定视觉锚点。
- 重复必须保留变量，大小、明度、方向或间距的变化比机械复制更有节奏。
- 斜线产生方向与速度，粗细差可形成前后关系，无需额外写实阴影。
- 非写实色彩须服从情调与构成，不以自然固有色限制表现，也不任意堆色。
#### 4. 正负形、疏密与动静
- 负形是主动构图部分，检查空白轮廓是否与实体同样清楚。
- 透雕、镂空和线群的力量来自实体与空隙互换，不能只描述实体轮廓。
- 疏密负责呼吸与注意力分配，密处需有共同方向或层级，疏处需有边界支撑。
- 静态均衡可由少数重块平衡多数轻块，不必依赖镜像。
- 动态来自脊线弯曲、轴线偏移、倾斜、断裂和方向连续的笔触。
- 高速与高密不得同时覆盖全画面，应保留定位与休息区域。
#### 5. 笔触、材料与直接性
- 笔触记录速度、压力、方向和工具，强化动态时先统一其运动逻辑。
- 粗轮廓可统一高饱和色块，细密线条需白底、深底或留白托衬。
- 正面构图、简化比例和手写文字可增强直接性，但须以内部一致性而非“天真”评价。
- 私人符号、日期、队列和同心环可形成个人秩序，同时提供可重复识别的结构。
- 非学院形式不应被浪漫化；仍须检查密度、轮廓、节奏与观看持续性。
- 材料差异通过同规格并置更易比较，档案展示保持中性底、统一图注和真实比例。
#### 6. 观看方式与展示
- 全貌负责构图，局部放大负责笔触、雕饰、工艺和材料，两者必须配对。
- 器物图像同时交代俯视与侧视，立体实物与平面印痕在相关时配对。
- 白底适合读深色轮廓与铸造细节，黑底适合衬托金属、镂空和高光，按材质选择。
- 小件放大后必须给出尺度，避免细节清晰而实际大小被误判。
- 图版之间设置无图或低密页面作为停顿，避免强图彼此抵销。
- 图注沿外缘组织，不压住主体；可见事实与身份判断分开书写。

### 第十一章　配色：属性、关系、语义与媒介
#### 1. 三属性：把颜色变成可调整变量
- 色相决定颜色在色序中的类别，用于区分、关联和建立冷暖方向。
- 明度决定明暗层级，是远观识别、文字可读和形体重量的优先变量。
- 纯度决定鲜艳程度，用于控制刺激、焦点和面积耐受度。
- 调色时每次只改一个属性，记录对层级、情绪和材质的独立影响。
- 先用灰阶验证主次，再添加色相与纯度，避免色彩掩盖明度结构问题。
- 同一色名在不同明度、纯度、面积和邻域中效果不同，禁止脱离组合评价单色。
#### 2. 对比：建立识别与重点
- 色相对比负责类别区分，明度对比负责可读与空间，纯度对比负责焦点与退让。
- 冷暖对比可组织前后和情绪，但冷暖会随邻色变化，须在实际组合中判断。
- 面积对比决定色彩权重，小面积高纯色可平衡大面积低纯色。
- 补色与强饱和对比适合短时焦点，不宜无差别铺满长时阅读区域。
- 强纹理已提供高密信息时，色库应收敛，避免色彩继续增加噪声。
- 暗色画面用少量高明度焦点建立入口，并保留足够中间调维持形体。
#### 3. 调和：建立共同秩序
- 近似色相可形成连续调性，但仍须以明度差区分层级。
- 同明度或同纯度可统一多色相，同时检查关键元素是否失去识别。
- 重复某一主色、间色或中性色，可在不同区域建立关联。
- 用黑、白、灰和低饱和色缓冲高饱和组合，缓冲色也须参与明度结构。
- 调和不是取消对比；至少保留一个明确主对比轴和一个次对比轴。
- 修改前后对照须固定素材、布局和光照，才能判断配色调整的真实作用。
#### 4. 60—30—10面积法则
- 将约六成面积设为主色，约三成为辅助色，约一成为强调色，作为初始比例而非普遍定律。
- 主色负责环境与基调，辅助色负责分区与承托，强调色负责行动或视觉焦点。
- 比例按视觉面积与出现频率共同估算，不能只数色板数量。
- 高纯度、强纹理和高对比色具有更大感知权重，实际面积可低于名义比例。
- 多场景系统允许比例随任务变化，但强调色的语义必须稳定。
- 若比例导致焦点不明，先调整面积与明度，再增加新颜色。
#### 5. 色彩心理与文化语义
- 暖色常提高亲近与激活感，冷色常降低视觉逼近感，但强度受明度、纯度和材质影响。
- 红、蓝、绿等色的社会含义依赖历史、宗教、行业与地区，不使用固定跨文化释义。
- 色彩情绪词必须由目标受众验证，禁止把个人联想写成普遍心理效应。
- 季节、自然与材料色库应从真实观察提取，记录光照与环境，不只从色卡命名。
- 服装、妆容、空间和产品的环境色会进入整体，必须联合打样。
- 状态色不能只靠颜色传达，应同时使用文字、形状、位置或图标。
#### 6. 屏幕、印刷与实物
- 屏幕采用色光加色混合，印刷主要依油墨减色与纸张反射，不能共用同一数值预期。
- RGB数值描述设备相关信号，CMYK数值也受纸张、油墨、印刷条件影响，不是绝对颜色。
- 项目初期确定工作色彩空间、输出条件与校样流程，避免交付前临时转换。
- 高饱和屏幕色可能超出印刷色域，应先做软打样与实物校样，再决定是否调整主色。
- 印刷关注纸张白度、吸收、网点增大、叠印与总墨量；文字细线避免多色套印造成边缘风险。
- 实物颜色随光源、表面光泽和观看角度变化，应在典型光照下评估，不只看标准灯箱。
- 数字界面需测试不同亮度、夜间模式、户外反光和常见显示偏差。
- 最终交付记录色值、色彩空间、材料、光源和校样条件，保证结果可复现。
#### 7. 配色工作流
- 第一步：从内容和场景确定主情绪、识别要求与禁用语义。
- 第二步：用灰阶稿确定信息层级和明暗面积。
- 第三步：从真实素材提取主色、辅助色和点缀色，形成色样矩阵。
- 第四步：分别检验近似调和、明度对比和强调色焦点。
- 第五步：固定其他变量做前后对照，避免同时改布局造成误判。
- 第六步：完成色觉差异、低亮度和灰阶测试。
- 第七步：按屏幕、印刷或实物条件校样并归档。

### 第十二章　字体与版式：历史性格、网格、层级、留白
#### 1. 字体的历史性格
- 古典衬线字体常带书写与人文传统线索，现代衬线字体常以强烈粗细和垂直轴线形成理性感。
- 无衬线字体与工业化、公共信息和现代网格关系密切，但并不天然中性或普遍适用。
- 几何无衬线强调构造秩序，人文无衬线强调阅读与开放字形，早期工业无衬线则保留较多传统字形特征。
- 宋、楷、黑、仿宋等中文字体各有笔画、结构和历史使用背景，不以“传统／现代”二分简单归类。
- 手写与书法字体强调身体、速度和个性，正文使用须额外验证识别与疲劳。
- 字体的性格来自笔画、字腔、重心、比例、字距和媒介共同作用，不由名称决定。
#### 2. 字体选择与测试
- 先按语言覆盖、字符集、字重、数字、标点和授权筛选，再谈风格。
- 字符表用于检查单字结构，真实词组与段落用于检查字距、灰度和阅读节奏。
- 字重比较必须固定文本、字号、行距与栏宽，避免变量混杂。
- 大标题测试轮廓与负形，小字号测试识别与抗干扰，两者不能互相替代。
- 极端放大可把字腔和笔画转成抽象图形，但正文与标识仍需保留必要语义。
- 同一版面字体家族宜少，层级优先由字号、字重、间距和位置建立。
- 混排中英文时统一基线、视觉字号、标点宽度与数字风格，不机械使用相同标称字号。
#### 3. 汉字与拉丁字的造型控制
- 汉字先看中宫、重心、外轮廓、笔画穿插与字面大小，再看局部装饰。
- 拉丁字先看 x 高度、字腔、升部降部、字宽和词形，再看单字母造型。
- 笔画变形须保持结构识别，共用笔画、省略和连写不得制造误字。
- 字图结合优先让图形承担文字结构的一部分，避免把完整文字贴在无关图形上。
- 组合文字统一粗细、倾斜、字面与间距，个别特异须服务重点。
- 小尺寸下优先恢复结构、减少细节，不以等比缩小保留所有设计特征。
#### 4. 网格：把版面变成可复用关系
- 先确定版心、栏数、栏间距、基线、图注区和外边距，再放置具体内容。
- 栏宽由阅读方式与信息类型决定，长文避免过长行，高密度检索可采用分栏。
- 基线网格维持跨栏与跨页节奏，图像高度和标题间距尽量与其成倍数关系。
- 隐性网格允许有意错位，错位必须形成重音或方向，不能成为随意对齐的借口。
- 树状关系用连线，时间关系用统一时间轴，词条关系用字重和悬挂缩进，不混用结构。
- 系列页面固定标题、编号、图像和图注位置，保证跨页识别与比较。
- 网格应允许长标题、缺图、异常数据和动态内容，不只适配理想样本。
#### 5. 层级：让阅读顺序可见
- 先确定首要入口、次要解释和辅助检索，再分配字号与位置。
- 层级差必须足以被快速识别，过密的相近字号只会增加灰度噪声。
- 每个层级尽量使用少量稳定变量，避免字号、颜色、字重和样式同时变化。
- 文字块可通过栏宽、行距与边界形成稳定物体感，服务整体构图。
- 低对比标题只有在高留白和非关键阅读条件下谨慎使用，不能牺牲正文可读。
- 章节转换可用大色块、超大标题或显著留白，但一套出版物只保留一种主逻辑。
#### 6. 留白与节奏
- 外边距保护整体，段前距组织语义，图周留白保护观看，字内负形保护识别。
- 大留白可形成章节停顿与收尾，但必须与前页密度形成对照。
- 密排页面用短色条、字重和缩略图建立节点，优先于增加装饰线。
- 图版与无图页交替可调节观看节奏，强图不应连续争抢注意。
- 空白不均时先检查内容分组与对齐，不通过随意补空维持表面平衡。
- 数字界面把留白写成响应式间距规则，而非固定像素残留。
#### 7. 图像与文字的协同
- 图像承担证据、情绪或空间，文字承担命名、解释或检索，分工后再决定大小。
- 主图与局部细节配对，全景与技术图配对，避免多张图重复回答同一问题。
- 产品或主体优先时，说明文字退居稳定小区；文字优先时，图像不得切断阅读路径。
- 图像色调与字体灰度须共同评估，避免照片高对比区域吞掉文字。
- 图注统一位置、格式和精度，来源与不确定信息明确标注。
- 封面和海报集中一个视觉钩子，品牌或主题收束区保持稳定。

### 第十三章　信息图与数据美学
#### 1. 数据先于图形
- 明确问题、数据来源、统计口径、时间范围、单位和缺失处理后再选图。
- 区分原始事实、计算结果、估计与解释，视觉上不得混为同一确定层级。
- 保留数据清理和转换记录，使图中的每个结论可追溯。
- 样本不足、口径变化和异常值须明示，不用平滑、裁切或装饰掩盖。
- 图形简洁来自信息组织，不来自删除关键限制条件。
#### 2. 按任务选择结构
- 比较类别优先条形或柱形结构，并保证共同基线和一致尺度。
- 观察连续趋势优先折线结构，时间间隔须真实反映采样频率。
- 表示构成须明确整体与部分关系，类别过多时不强行使用分割圆面。
- 表示流程使用节点、方向和阶段，避免无方向的图标串联。
- 表示地理关系优先地图与节点路径，不将行政位置改成任意装饰布局。
- 表示层级使用树线、嵌套或同心结构，保持层级语义一致。
- 表示时间使用对齐年表，重要节点与背景事件分层。
#### 3. 编码与视觉诚实
- 位置与长度适合精确比较，面积、角度、颜色和体积应谨慎用于定量判断。
- 数值轴的截断、对数转换和双轴使用必须显著说明，并评估是否制造夸大。
- 图形面积须与数值采用一致的数学映射，禁止同时放大宽和高造成二次夸大。
- 同类数据共用色序与尺度，跨图比较保持单位、基线和排序逻辑。
- 颜色用于分类、顺序或发散关系时分别选合适色阶，不把装饰色板当作数据编码。
- 重要数值提供直接标签或可访问文本，不让读者只靠目测恢复信息。
#### 4. 信息层级与叙事
- 一张信息图设一个主问题，标题回答“看见什么”，副标题说明口径与范围。
- 先给结论或结构，再给证据与细节，避免平均分配视觉重量。
- 用分组、排序、对齐和空白减少搜索成本，装饰插图不得压过数据。
- 多图并列时固定阅读顺序、图例位置和比较尺度。
- 故事板按固定画格推进，最后完成结论或品牌揭示，不提前混入无关悬念。
- 面向行动的信息图明确下一步，但不通过选择性呈现诱导过度结论。
#### 5. 数据美学的验收
- 准确性：每个数字、单位、比例和来源可复核。
- 可读性：目标尺寸下文字、线宽、标记和颜色可辨。
- 可比较性：共同基线、尺度、排序和图例支持预期比较。
- 可及性：信息不只靠颜色编码，并提供文本等价物。
- 节制性：每个装饰元素不遮挡、不扭曲、不增加错误推断。
- 可追溯性：发布版本附数据日期、来源、转换说明和必要的不确定性。

## 第三篇　创作标准规范与灵感来源

### 第十四章　通用创作流程
#### 1. 立意：把愿望改成问题
- 写一句核心命题，包含对象、目标、受众、场景与期望变化。
- 区分必须解决、希望解决和明确不解决的事项。
- 指定主价值路径：理念、形式、情感、生活或制度，避免目标漂移。
- 写出伦理否决项、文化敏感项和不可妥协的安全条件。
- 交付物：一页任务书、关键术语表和验收方向。
#### 2. 调研：建立证据与语境
- 收集真实使用观察、实物或场地、历史文献、技术限制和受众语言。
- 文献与实物互证，引用回到原始来源，区分事实、推断与待核问题。
- 样本同时覆盖新手、熟手、维护者和受影响但不直接使用的人。
- 研究经典时记录形式机制及历史条件，不只保存成品图。
- 交付物：证据清单、语境图、约束表和待验证假设。
#### 3. 概念：形成可解释的核心关系
- 把调研发现压缩为一个主要矛盾和一至三个设计原则。
- 每个原则必须能转为形式、动作、空间或材料规则。
- 用发散、联想、逆向、限制、移植和组合生成差异方向。
- 概念评审先排除与题目无关的新奇，再比较机制差异。
- 交付物：概念句、原则表、方向矩阵和淘汰理由。
#### 4. 形式语言：建立可重复的系统
- 确定基础元素、核心不变量、可变项和禁止变形。
- 建立模数、网格、色板、字体、材质、动势或空间母题。
- 先制作黑白或低精度关系稿，验证主次与整体，再进入精细表现。
- 为正常、极端、缺失和错误内容制定形式规则。
- 交付物：形式语法表和关键样本，不是单张完美效果图。
#### 5. 草图与原型：让假设可测试
- 草图至少覆盖保守、折中和结构创新三类方向。
- 原型只回答当前最关键的问题，避免过早加入无关细节。
- 建筑与空间同步制作总图、平立剖、体块和行进测试。
- 平面与界面同时测试目标尺寸、极端内容和异常状态。
- 产品使用真实或等效尺度检验持握、动作、反馈和维护。
- 每轮保留版本、变量、测试记录与决策，不用覆盖文件抹掉过程。
#### 6. 评审：以证据替代偏好表决
- 评审前重读任务书，按形式、功能、语义、创新、伦理分别记录。
- 评论采用“观察—影响—建议”格式，禁止只说“不够高级”。
- 先由受众或使用者证据发言，再由专业判断解释，避免职位决定结论。
- 冲突意见写成可验证假设，安排下一轮测试而非无限讨论。
- 输出明确的通过、修改、暂缓与否决结论及责任人。
#### 7. 深化：保持系统一致并解决生产条件
- 将关键样本扩展为全场景，检查规则是否在边界情况下失效。
- 核对材料、结构、印刷、前端实现、施工或加工的真实限制。
- 控制细节收益，优先完善影响识别、使用、维护和整体关系的部分。
- 保留合理的手工与材料差异，不把所有误差都当作风格。
- 同步完成可及性、可持续性、版权与标注检查。
#### 8. 交付与复盘：让结果可实施、可追溯
- 交付源文件、规范、字体与素材授权、色彩条件、数据口径和版本说明。
- 建筑与空间交付图间共享轴线、统一图例和关键节点，数字产品交付组件状态与响应规则。
- 说明不可随意改变的核心不变量，以及允许本地调整的部分。
- 生成式工具参与时附使用范围、素材来源、人工修改与审核记录。
- 上线或建成后回访真实使用，记录形式老化、语义漂移和维护成本。
- 复盘同时保存有效规则与失效条件，纳入下一次任务书。

### 第十五章　各媒介检查清单
#### 1. 平面与视觉传达：十二条
- [ ] 五秒内有唯一清楚的首要入口，主标题与主图不互相争抢。
- [ ] 缩小到目标尺寸后，主体轮廓、核心信息和品牌仍可识别。
- [ ] 网格、边距、图注和页码跨页一致，错位具有明确目的。
- [ ] 字号、字重、颜色和位置形成稳定层级，无多余装饰性层级。
- [ ] 正文行宽、行距和对比适合连续阅读，长文不依赖高饱和底。
- [ ] 字体覆盖全部字符并完成真实词组、数字、标点与小字号测试。
- [ ] 灰阶下主次仍成立，关键信息不只靠颜色区分。
- [ ] 主色、辅助色、强调色的面积与语义一致，强调元素没有泛滥。
- [ ] 图片光源、透视、清晰度与合成边缘一致，全貌与细节分工明确。
- [ ] 标志和图形在最小尺寸下仍保留必要结构，细线无输出风险。
- [ ] 印刷或屏幕已按最终媒介校样，色彩空间和输出条件已记录。
- [ ] 素材、字体、肖像与生成式内容授权及标注完整。
#### 2. 建筑与空间：十五条
- [ ] 总平面回应地形、气候、周边尺度、既有路径和公共界面。
- [ ] 功能、流线、消防与无障碍要求相互一致，不以造型突破安全底线。
- [ ] 入口、方向、节点与出口可被首次到访者识别。
- [ ] 平面、立面、剖面共享轴线和模数，核心结构可跨图追踪。
- [ ] 大尺度空间配置连续人体参照，纪念性不依赖迷失与压迫。
- [ ] 高低、开合、疏密与行进节奏有变化，连续路径具备停顿节点。
- [ ] 日照、顶光、侧光和夜间照明在典型时段测试，暗区保留方向参照。
- [ ] 材料分缝呼应结构与模数，触感、声学、反光和维护已评估。
- [ ] 体量、退台、分带与开口形成可读层级，新旧尺度有清楚过渡。
- [ ] 实景、模型、平面和剖面构成证据链，方案比较固定视角与光照。
- [ ] 真实城市干扰、使用者与维护状态进入测试，不只审空镜效果图。
- [ ] 材料来源、耐久、能耗、可修复与拆解回收路径有记录。
- [ ] 历史、宗教与遗址语境经过核验，残损和修补不被混淆。
- [ ] 关键节点完成足尺或等效样板，施工误差有容许与修正规则。
- [ ] 交付运营维护、照明更新、材料替换和后期评估要求。
#### 3. 产品与服装：十二条
- [ ] 核心任务、使用姿态、适用人群和限制条件均已实测。
- [ ] 形态预示用途与实际操作一致，错误动作受到结构限制。
- [ ] 操作、状态、限制和反馈可见或可感，无需猜测隐藏功能。
- [ ] 重心、握持、压力点、活动量和穿脱路径符合身体尺度。
- [ ] 轮廓与关键识别特征清楚，局部装饰不妨碍结构与动作。
- [ ] 材料、触感、重量、温度和声音共同支持预期体验。
- [ ] 连接、缝制、分件与表面工艺具有生产依据，细部不只服务渲染。
- [ ] 样板与真实材料经过动作、耐久、清洁和重复使用测试。
- [ ] 尺码、调节与替代方案覆盖合理身体差异，不以单一人体作普遍标准。
- [ ] 维修、更换、回收与材料分离方式明确，装饰没有显著增加环境负担。
- [ ] 安全、警示、过敏、夹伤、绊倒等风险已按场景检查。
- [ ] 系列产品的核心不变量统一，变体不破坏识别与使用逻辑。
#### 4. 数字界面：十五条
- [ ] 每个关键场景只有一个主任务，主行动在首层可辨。
- [ ] 导航、返回、退出和当前位置始终清楚，深层内容有明确入口。
- [ ] 组件的状态、命名和交互一致，相同外观不触发不同结果。
- [ ] 文字、图标和交互控件达到项目采用的可及性对比与尺寸要求。
- [ ] 信息不只靠颜色、悬停、声音或运动传达，提供等价线索。
- [ ] 键盘、屏幕阅读、缩放、内容重排与减少动态效果路径可用。
- [ ] 触控目标与间距适合真实手持和误触场景，不只测鼠标。
- [ ] 长文、空数据、超长内容、错误、离线和加载状态均有规则。
- [ ] 响应式布局按内容优先级重组，不是简单等比缩放。
- [ ] 动效解释状态、空间或因果，持续运动可暂停且不妨碍操作。
- [ ] 表单标签、格式要求、错误原因和修正方式明确，不清空用户输入。
- [ ] 数据图表提供共同基线、单位、来源和文本等价物。
- [ ] 权限、隐私、付费、订阅和自动续费等信息诚实可见，无诱导性暗黑模式。
- [ ] 生成式内容有适用法规与平台要求的标识、审核和纠错渠道。
- [ ] 真实设备、低性能、弱网、户外反光及新手与熟手任务测试通过。

### 第十六章　评审标准与决策方法
#### 1. 形式标准
- 整体性：局部关系服务同一结构，删除任一要素会产生可说明的影响。
- 层级性：首要、次要、辅助信息在不同观看时长下均有合理顺序。
- 节奏性：重复与变化、疏密与开合、动与静形成可感知组织。
- 精确性：比例、对齐、材质、色彩和工艺在目标媒介中达到所需容差。
- 评分证据：关系图、灰阶图、足尺样本、缩样和跨页或跨场景测试。
#### 2. 功能标准
- 有效性：核心任务完成，结果达到预定指标。
- 效率性：学习、动作、时间与维护成本处于合理范围。
- 容错性：错误可预防、可发现、可恢复，关键风险有结构限制。
- 持久性：长期使用、老化、清洁、维修和替换后仍保持主要价值。
- 评分证据：任务观察、异常测试、身体测量、耐久与维护记录。
#### 3. 语义标准
- 准确性：形式指向与内容一致，不制造错误类别或用途暗示。
- 可学习性：陌生符号有稳定线索与重复机会，新手能逐步掌握。
- 语境性：颜色、图像、空间和历史符号符合使用共同体与场景。
- 开放性：允许多义时有清楚边界，歧义与误读可被控制。
- 评分证据：无说明识别测试、文化审读、延时回忆和误读记录。
#### 4. 创新标准
- 问题新：重新定义了被忽略的矛盾，而非只更换表面风格。
- 机制新：结构、材料、流程或观看关系产生新的有效连接。
- 系统新：创新能扩展到系列与边界状态，不是一次性视觉花样。
- 价值新：相较既有方案带来可测的理解、体验、资源或伦理收益。
- 评分证据：同条件对照、机制迁移记录、原型比较和长期收益评估。
#### 5. 伦理标准
- 诚实：数据、来源、合成、效果、价格与风险不作误导性呈现。
- 可及：不同能力、语言、设备和经验水平的人有合理参与路径。
- 尊重：不挪用神圣与族群符号，不猎奇呈现真实个体和创伤。
- 可持续：材料、能耗、劳动、维护和废弃成本被计入决策。
- 否决规则：违法、重大安全风险、故意欺骗和严重歧视不得以其他高分抵销。
#### 6. 评分与收敛
- 五个维度分别采用一至五级，并给每一分附证据，不用无定义总分。
- 项目开始前确定权重；安全、诚实和法定可及性作为门槛而非普通加权项。
- 评审先独立记录再集中讨论，降低权威与从众影响。
- 分差较大的维度必须回到具体观察，禁止直接取平均掩盖分歧。
- 最终选择保留“为何胜、牺牲什么、何时复审”三项说明。

### 第十七章　灵感库：从经典提取规则而非抄袭
#### 1. 灵感库的分类
- 按“问题—机制—变量—媒介—语境”建立标签，不只按风格、作者和颜色命名。
- 每条库存包含来源、授权、整体图、局部图、尺寸或观看条件、形式分析和可迁移机制。
- 将直接观察、历史材料、当代样本、失败样本和自然机制分区，避免证据层级混杂。
- 保留反例与淘汰方案，记录失效条件，防止灵感库只收藏成功表象。
- 定期合并重复条目，删除无法追溯来源或只有情绪词的收藏。
#### 2. 经典作品五步拆解
- 第一步描述可见事实：元素、尺寸关系、位置、色彩、材料、视角和层次。
- 第二步画关系图：主轴、网格、动线、图底、明暗面积、重复单元与变化点。
- 第三步还原约束：功能、技术、媒介、受众、礼仪、生产与历史制度。
- 第四步提出机制句：说明它如何用何种关系解决何种问题。
- 第五步改变题材和媒介重做，仅保留机制，并比较新方案与原作的相似风险。
#### 3. 可迁移与不可直接迁移的内容
- 可迁移：比例生成方式、层级策略、重复与变化规则、光影组织、观看顺序和证据链。
- 需重构：材料逻辑、结构方式、符号意义、身体尺度、生产工艺和交互习惯。
- 不可直接搬用：可识别轮廓、独创图形组合、完整版式、宗教仪轨符号和受保护角色形象。
- 历史残损、风化和材料锈色属于证据，不应直接变成无依据的装饰滤镜。
- 经典图录的全貌—局部、模型—平面—实景等编排方法可迁移，但内容与视觉识别须重新建立。
#### 4. 防抄袭检验
- 遮住来源后，能否用一句机制而非一个作者或风格名解释方案。
- 同时改变题材、媒介和尺度后，形式规则是否仍然有效。
- 新方案是否与来源共享可被普通观众立即识别的独创组合。
- 是否至少有两个独立来源和一项真实调研共同支撑，而非单一图像改写。
- 对高风险相似部分进行替换、重构或取得授权，并保存创作过程证据。

### 第十八章　跨文明调用的边界
#### 1. 尊重语境
- 先研究来源地区、时代、共同体、媒介、用途和禁忌，再决定是否使用。
- 区分日常装饰、身份标志、宗教仪轨、丧葬纪念和政治象征，不把它们放在同一素材层级。
- 涉及仍在生活的传统时，让相关知识持有者参与审读并说明署名、收益和撤回方式。
- 跨文明对照用于发现差异与关系，不把气韵、幽玄、崇高、味等术语互作直译。
- 以现代转译名义改变形式时，明确其为新创作，不宣称复原传统。
#### 2. 避免符号滥用
- 不以服装、肤色、文字和建筑碎片拼成刻板“民族风”。
- 不将神圣形象用于不敬场景，不将礼仪等级符号当作自由装饰。
- 不用单一朝代、地域或阶层代表整个文明，也不把跨地域交流成果归为纯一来源。
- 丝路、石窟和多元物质文化应按交流网络理解，避免“原生纯粹”的本质主义叙事。
- 当符号只提供异域情调而不改变内容、结构或体验时，优先删除。
- 无法确认身份和含义的图像只描述可见事实，不编造题材与象征。
#### 3. 合法、合宜与可持续的调用
- 合法：核实著作权、文物图像、商标、肖像、场地和数据库许可。
- 合宜：评估语境、权力关系、受众感受和现实后果，合法性不等于合宜性。
- 可追溯：保存来源、改写、参与者、许可和版本，不用“网上找到”作为来源。
- 可回馈：商业使用考虑授权费用、合作、署名和知识回馈。
- 可退出：发现误用或相关共同体提出合理异议时，预设替换与下架方案。

### 第十九章　当代补充规范
#### 1. 可持续设计
- 从全生命周期评价开采、制作、运输、使用、维护、再利用和废弃，不只统计单一材料。
- 优先减量、延长寿命、可维修、可替换和可拆解，再考虑以新材料替代。
- 避免为“自然感”增加稀缺材料、复合不可分离结构或高维护表面。
- 建筑同时评估被动式采光通风、运营能耗、热舒适和既有建筑再利用。
- 平面与包装评估数量、尺寸、油墨、复合层、运输空间和实际回收条件。
- 数字产品评估媒体体积、加载、设备负担与无效自动播放，节制也是资源策略。
- 环境收益使用可核数据与边界条件，禁止用绿色色板和模糊词汇替代证据。
#### 2. 包容性与通用设计
- 从项目开始纳入不同能力、年龄、语言、文化和设备条件，而非完成后补补丁。
- 同等使用尽量共用路径，必须分设时保证同等尊严、便利与安全。
- 提供多种感知与操作通道，使视觉、听觉、触觉和文字信息可互相补充。
- 尺寸、力度、速度和认知步骤保留合理容错，降低对精确动作和专业知识的要求。
- 让真实使用者参与原型与复核，设计者不得以模拟体验替代全部参与。
- 无障碍是持续验收项，内容更新、组件变化和环境老化后需重新测试。
#### 3. 生成式人工智能的版权、真实性与标注
- 项目开始前确认所用工具、训练与输入素材、输出范围和商业条款，不上传无权使用的保密或个人信息。
- 保存提示与参数之外的创作证据：人工选择、构图修改、局部重绘、合成、文字撰写和版本记录。
- 版权归属与保护程度依司法辖区和实际人类贡献而异，不把“机器生成”自动等同于可自由使用或可独占。
- 输出前检查与既有作品的角色、标志、构图和风格近似风险，必要时重做或取得授权。
- 不把生成图像冒称现场摄影、历史原件、数据证据或真实人物言行。
- 按所在地法规、合同和平台规则添加显式或机器可读标识，交付时保留生成记录与元数据。
- 合成内容用于新闻、文物、医疗、公共安全和科学传播时，实行更严格的人审与来源说明。
- 最终发布者承担事实、侵权、歧视、隐私和错误后果的审核责任，不以工具输出免责。

## 结尾　创作前自检30条

1. [ ] 核心命题是否同时写明对象、目标、受众、场景与期望变化？
2. [ ] 主价值路径是否明确，理念、形式、情感、生活与制度的取舍是否可解释？
3. [ ] 任务书是否列出核心限制、伦理否决项和明确不解决的事项？
4. [ ] 关键事实、来源、数据口径和不确定信息是否可追溯？
5. [ ] 是否完成真实对象、场地、材料或使用行为观察，而非只收集二手图片？
6. [ ] 目标受众中的新手、熟手、维护者和被影响者是否都被考虑？
7. [ ] 主导情绪是否唯一且可测，辅助情绪是否没有冲淡它？
8. [ ] 形式是否从内容与现实约束生成，而不是先选风格再寻找理由？
9. [ ] 创意方向是否经历足够发散，并按机制而非表面题材聚类？
10. [ ] 是否至少使用一种逆向、限制、移植或组合方法打破默认假设？
11. [ ] 保留的方案是否有清楚核心矛盾与设计原则，而非只有情绪板？
12. [ ] 是否先完成灰阶、骨架、体块或低保真原型，再进入精细表现？
13. [ ] 点、线、面、体、色、光与材质是否各自承担明确任务？
14. [ ] 网格、模数、轴线或重复单元是否稳定，破格是否具有战略目的？
15. [ ] 五秒内是否有唯一视觉入口，一分钟内是否能理解主要关系？
16. [ ] 正负形、疏密、开合、动静与留白是否共同组织观看或行进？
17. [ ] 比例是否经过真实视距、人体尺度、斜视或目标尺寸修正？
18. [ ] 色彩是否先通过灰阶层级检查，再检验色相、纯度、面积与文化语义？
19. [ ] 字体是否完成真实词组、小字号、全字符、混排与授权测试？
20. [ ] 图像、模型、平面、剖面、局部和文字是否形成互补证据链？
21. [ ] 功能预示、限制和反馈是否一致，异常、等待、错误与退出是否有设计？
22. [ ] 是否以真实尺寸、材料、光照、设备和任务完成测试？
23. [ ] 信息是否不只依赖颜色、声音、悬停或运动，并具备等价通道？
24. [ ] 是否评估长期维护、老化、清洁、维修、替换与废弃成本？
25. [ ] 历史与跨文明符号是否经过语境审读，避免神圣、族群与身份符号滥用？
26. [ ] 灵感是否被拆成形式机制并重构，而非复制可识别的独创组合？
27. [ ] 素材、字体、肖像、数据、场地和生成式工具的授权与标注是否完整？
28. [ ] 形式、功能、语义、创新、伦理五维评审是否都有证据和明确结论？
29. [ ] 交付是否包含核心不变量、可变项、边界状态、色彩条件与版本记录？
30. [ ] 是否设定发布或建成后的复审时间，用真实使用结果修正规则？
