## 02 · 东方美学规范

### 2.1 中式留白（Liu-Bai）

定义：以「无」衬「有」，用负空间建立层级与呼吸感。

量化规则（MUST）：
- 内容区留白占比 ≥ 40%（首屏 ≥ 50%）
- 主视觉周围留白 ≥ 相邻区块间距的 1.618 倍
- 禁止「填满式」布局：任何区块四周必须有不小于 `--space-4`（21px）的呼吸边距
- 留白优先于分割线：能用间距分隔的，不用边框

意境借鉴：马远《寒江独钓图》——一叶扁舟，满纸皆水。界面的「水」就是留白。

### 2.2 日式侘寂（Wabi-Sabi）

定义：不完美、不恒常、不完全之美。

应用规则（SHOULD）：
- 材质：界面背景使用极轻的纸张噪点（noise opacity 2–4%），拒绝纯 #FFFFFF
- 圆角：不做机械统一。主容器 12px、卡片 10px、输入框 8px，允许 ±2px 的自然差异
- 描边：1px 描边使用半透明墨色 `rgba(28,28,28,0.08)`，而非纯灰
- 禁止：过度抛光的高光渐变、塑料质感、绝对对称
- 色彩：主色饱和度上限 HSL S ≤ 45%，允许「旧」感——如褪色靛蓝、氧化铜绿

### 2.3 物哀（Mono no Aware）

定义：对事物无常的温柔感知。

应用规则（SHOULD）：
- 状态过渡：状态变更用 400–600ms 缓动 `cubic-bezier(0.22, 1, 0.36, 1)`，让「消逝」可被感知
- 空状态：不写「暂无数据」，写「此处尚无痕迹」，配一株极简植物线稿
- 删除/归档：保留 5 秒撤销窗口，动效为「淡出下沉」而非「瞬间消失」
- 季节感：可选主题色随季度微调（春·天水碧 / 夏·石青 / 秋·赭石 / 冬·月白）

### 2.4 幽玄（Yūgen）

定义：深奥、含蓄、不可尽言之美。

应用规则（MUST）：
- 信息渐进披露：首屏只呈现 1 个主行动（Primary CTA），次级操作收进「更多」或 hover 态
- 阴影：使用多层柔和阴影，禁止硬投影：
  ```css
  box-shadow:
    0 1px 2px rgba(28,28,28,0.04),
    0 4px 12px rgba(28,28,28,0.06),
    0 16px 40px rgba(28,28,28,0.04);
  ```
- 模糊景深：模态框背景使用 `backdrop-filter: blur(12px) saturate(0.9)`，制造「隔雾观花」
- 禁忌：把所有信息一次性摊开、高饱和撞色、闪烁提示

### 2.5 禅意（Zen）

定义：减法、专注、当下。

应用规则（MUST）：
- 单个视口内视觉焦点 ≤ 1 个（通过大小、色彩、位置三重对比建立）
- 每屏主要任务数 ≤ 3
- 动效遵循「一动作一意图」，禁止无意义的装饰动画
- 圆形/方形的「枯山水」式排布：用极简几何暗示秩序，如进度用点的疏密而非进度条

## 03 · 西方比例体系

### 3.1 黄金分割 φ = 1.618

间距模数（MUST）——斐波那契数列：

| Token | 值(px) | 用途 |
|-------|--------|------|
| --space-1 | 4 | 图标内边距 |
| --space-2 | 8 | 元素内间距 |
| --space-3 | 13 | 紧凑分组 |
| --space-4 | 21 | 段落间距 |
| --space-5 | 34 | 区块间距 |
| --space-6 | 55 | 章节间距 |
| --space-7 | 89 | 页面级留白 |

字体阶梯（MUST）——比率 1.618（展示级）/ 1.25（正文级），H2→H3 为 1.30 过渡档：

| 层级 | 字号 | 行高 | 与上一级比率 |
|------|------|------|-------------|
| Display | 68px | 1.1 | — |
| H1 | 42px | 1.2 | 1.619（展示级 φ） |
| H2 | 26px | 1.3 | 1.615（展示级 φ） |
| H3 | 20px | 1.4 | 1.30（过渡档，有意压缩层级数） |
| Body | 16px | 1.618 | 1.25（正文级） |
| Caption | 13px | 1.5 | 1.23≈1.25（正文级） |

> 口径澄清：此前「字号符合 1.618 阶梯」的笼统表述与 26→20 的 1.30 冲突。现明确为三段式——展示级 φ、H2→H3 过渡档 1.30、正文级 1.25。过渡档是为将五级内容压进有限层级的有意设计，非计算错误。正文不低于 16px，Caption 13px 仅用于非关键辅助信息。

版心分割：主内容 : 侧栏 = 61.8 : 38.2

### 3.2 黄金螺旋

焦点定位（SHOULD）：首屏主视觉（Hero 图 / 核心 CTA）落位于黄金螺旋的收束点，约为容器宽高的 (0.618, 0.382) 或镜像位。

应用场景：登录页品牌图形位置、仪表盘核心指标卡片位置、空状态插画位置、引导页视觉重心。

反例：把最重要的元素放在正中，会显得呆板；放在角落，会失去力量。

### 3.3 三分法与根号矩形

- 图片裁切遵循三分法，主体落在交叉点
- 卡片比例优先 1:1.618 或 1:√2 (1:1.414)（A4 纸比例，适合文档类内容）
- 头像/图标容器用正方形，内部图形占 61.8%

## 04 · 配色科学

### 4.1 色彩理论基础（MUST 遵守）

1. 60-30-10 法则：主色 60% / 辅色 30% / 强调色 10%
2. 明度优先：先保证明度层级清晰，再谈色相。任何两个相邻层级的明度差 ≥ 8%（L* 值）
3. 同时对比控制：高饱和色面积 ≤ 10%，避免视觉疲劳
4. 色彩和谐：主色板采用分裂互补（Split-Complementary），避免纯互补的刺眼
5. 无障碍（MUST）：正文 ≥ 4.5:1、大字（≥24px 或 ≥19px 粗体）≥ 3:1、UI 组件/图形 ≥ 3:1（WCAG 2.1 AA）。每个前景/背景组合须按 4.5 节实测表核对。
6. 冗余编码（MUST）：状态与数据系列不得仅靠颜色区分，须附加图标/文字/形状/纹理。

### 4.1.1 传统色取色参考（配色取色来源）

制定或扩展色板（见 4.2）时，从成熟的东方传统色体系中取色并借用其色名，可保证「色名—色值—意境」三者一致。以下为两类查色入口（参考网站，非运行时依赖，无需联网即可使用本 skill 既有色板）：

| 体系 | 参考入口 | 适用主题 | 用法 |
|------|---------|---------|------|
| 中国传统色 | https://zhongguose.com/ | 月白禅、千里江山、四季色 | 按色名检索（如月白、靛青、朱砂、赭石、石青、天水碧），取 HEX 与出处，作为主/辅/强调色候选及命名依据 |
| 日本传统色（和色） | https://nipponcolors.com/ | 侘寂灰、物哀、幽玄 | 按色名检索（如柿色、利休白茶、墨、蓝鼠），取 HEX 与和名，用于低饱和怀旧色与季节流转色 |

取色约束（MUST）：①取回色值须按 4.5 节实测表复核对比度，不达标则调明度/饱和度并标注「调暗/提亮」；②不得因追求古风色名牺牲无障碍；③色名须与意境一致，禁止名实不符；④仍遵守 60-30-10 与分裂互补，取色入口不改变配色法则。

- 暗色模式阴影改用边缘微光替代：`inset 0 0 0 1px rgba(255,255,255,0.06)`

## 05 · 布局与人体工学

### 5.1 栅格系统

- 12 栏栅格，间距 21px（`--space-4`），边距 34px（`--space-5`）
- 容器最大宽度：1280px（内容）/ 1440px（展示型页面）
- 断点：480 / 768 / 1024 / 1440 / 1920

### 5.2 人体工学硬指标（MUST）

| 指标 | 值 |
|------|-----|
| 正文阅读宽度 | 60–75 字符（中文 32–40 字） |
| 最小触摸目标 | 44×44px |
| 点击热区间距 | ≥ 8px |
| 行高（正文） | 1.618 |
| 段落间距 | ≥ 1.5 倍行高 |
| 首屏核心内容 | 位于折叠线以上 0–618px 区间 |
| Fitts 定律 | 高频操作靠近拇指区（移动端底部 1/3） |

### 5.3 视觉重心

- 页面重心遵循倒三角：顶部信息密度高、底部留白大，符合视线自然下沉
- 采用 F 型（内容型）或 Z 型（营销型）眼动路径设计信息序列
- 禁止：页面上半部与下半部视觉重量失衡（如顶部密集、底部死白）

### 5.4 新颖布局范式

- **「枯山水」仪表盘**：数据卡片以不规则但成组的节奏排布，组间留白由 `--space-6/7` 控制，避免均分网格的机械感
- **「卷轴」长页**：内容沿垂直方向渐次展开，每 618px 设一个「留白停顿点」，配合滚动视差，模拟手卷展开的节奏
- **「影壁」式首屏**：Hero 区用大留白 + 单一切入点（1 个 CTA），次级信息下沉一屏，呼应中式影壁「先藏后露」

## 06 · 组件与材质

| 组件 | 规范 |
|------|------|
| 按钮 | 主按钮实心，次按钮描边（1px 墨色），圆角 10px，内边距 12×21 |
| 输入框 | 底边框或无边框 + 背景色，聚焦时底部 1.5px 靛青线，禁用粗重外框 |
| 卡片 | 背景 `--color-bg-surface`，1px 半透明描边，多层柔和阴影，圆角 12px |
| 分割 | 优先用间距；必须分割时用 `rgba(28,28,28,0.08)` 1px 线，不用黑色实线 |
| 图标 | 线性 1.5px 描边，圆角端点，尺寸 16/21/34 |
| 图片 | 圆角 8px，必要处叠 2% 纸张噪点层 |

字体（MUST）：
- 字体库提供 5 个候选族：`tokens.css` 中的 zh-title / zh-body / zh-quote / en-ui / en-display。
- 中文：思源宋体（标题）/ 思源黑体（正文）/ 霞鹜文楷（引用、诗词）
- 西文：Inter（UI）/ EB Garamond（展示级）
- **使用约束**：单个视口内**最多同时使用 2 族**（典型组合：思源宋体标题 + 思源黑体正文；或 Inter UI + 思源黑体中文）。"字体库 5 族"与"同屏 ≤2 族"是两个层面——前者是可选清单，后者是同屏上限，并不矛盾（v1.1.0 口径统一）。
- 禁止：系统默认字体混排、单屏超过 2 种字体族

## 07 · 动效与时间

| 场景 | 时长 | 缓动 |
|------|------|------|
| 微交互（hover/按下） | 150ms | ease-out |
| 展开/收起 | 300ms | cubic-bezier(0.22,1,0.36,1) |
| 页面转场 | 500ms | 上述缓动 |
| 状态消逝（物哀） | 600ms | 淡出 + 位移 8px |

禅意原则：动效必须「有因」，禁止装饰性漂浮、无触发自动循环动画（loading 除外）。尊重 `prefers-reduced-motion`，降级为即时切换。

## 卷末语

好的界面像一座枯山水庭园——石材有数，砂纹有序，余者皆是留白。用户感知到的从不是像素，而是呼吸的节奏。
