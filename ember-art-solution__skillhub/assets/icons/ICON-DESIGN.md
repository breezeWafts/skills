## 一、美学立意（L0）

**一句话立意：三源归一境，虚处生万象。**

三大美学体系（东方 / 西方 / 阿拉伯-伊斯兰）不是并列陈列的符号，而是各据一方、彼此不叠压，共同**让出**中心那一片空；14 类交付物由这个「间」生长出来，因此不必逐一画出。这与总纲 `core-00` 的「底层逻辑优先于符号堆砌」同构。

| 项 | 结论 |
|---|---|
| 主范畴 | **意境**（辅「优美」）。不取崇高、悲剧、荒诞——总控是生成器而非宣泄器 |
| 美感机制 1 | **心理距离 / 虚**：主体只留弧线与极淡气韵，不做实色块，观者不迫近、不被信息推挤 |
| 美感机制 2 | **格式塔闭合律**：三段不闭合的弧让观者自行补成一个圆，「三体系汇于一境」由观者完成，而非画死 |
| 美感机制 3 | **身体内模仿 / 移情**：弧线向心收束的呼吸感，视线自然沉降到中心留白 |

**意境四步（立意—择象—布虚—留余）**

1. 立意：三源归一境。
2. 择象：三重弧（取「气韵环」虚相，不取 v1 的「三环交叠」实相）＋ 一点朱砂。
3. 布虚：中心 R<78 区域不落一笔，直径 156px（画布 30.5%）为「间」；弧段之间留 24° 气口。
4. 留余：不画任何文字行、网格、产品符号；多场景交付交给想象，是「秘」而非省略。

## 二、L1 八意识联检

| 意识 | 落地方式 | 判定 |
|---|---|---|
| 微 | 描边仅 9 / 2.4 / 1.5 三档；所有弧端点圆头；无碎装饰 | MUST ✅ |
| 并 | 单套色板（靛青＋焦墨纸纹＋唯一朱砂），单一圆角规格 104，零第二色相 | MUST ✅ |
| 气 | 三层递减气韵圆（R=168/140/196，透明度 0.075/0.05/0.032）＋ 纸纹 3%；单色图标中「≥3 层柔和」的等价转译 | SHOULD ✅ |
| 间 | 中心实留白 + 四周大留白，实测非纸色像素占比 <12%（留白 >88%，首屏级 >50%） | MUST ✅ |
| 秘 | 全图唯一焦点为朱砂一点；不解释、不罗列交付品类；信息渐进 | MUST ✅ |
| 素 | 主色靛青 HSL S≈39%（≤45%）；渐变 0；无纯白纯黑（#FAF8F3 / #1C1C1C） | MUST ✅ |
| 假 | 弧不闭合、气韵向外递减消逝；纸纹为材料痕迹；无对称强迫 | SHOULD ✅ |
| 破 | **恰好 1 处**朱砂 `--accent-ha #B03A2E`，其余元素 100% 合规；朱砂饱和度超出「素」的约束，是唯一受控破格 | MUST ✅ |

> 对 v1 的主要修正：v1 同时存在三环、三层同心圆、三行短横、朱砂点、焦墨点，形成 **2 处点状焦点 + 3 组等权重图形**，违反「单屏焦点 ≤1」「破至多 1 处」与「素」。v2 删去三行短横与焦墨点，三环改为三弧，留白从约 60% 提到 88%。

## 三、L2 秩序（黄金分割）

| 参数 | 数值 | 依据 |
|---|---|---|
| 画布 / 卡片 | 512×512 / 24–488（边长 464） | 与原四枚 skill 图标同规格，保证并排视觉一致 |
| 圆角 | 104 | 0.224 × 464，沿用家族规格 |
| 朱砂点 | **(311.15, 200.85)** | 内弧气口中心（R=78, −45°）；与卡片黄金分割交点 (24+464×0.618, 24+464×0.382) = **(310.75, 201.25)** 误差 <0.5px —— 唯一焦点即黄金螺旋收束点 |
| 弧半径 | 外 104 / 内 78 / 气韵 140·168·196 | 主半径取斐波那契模数邻值，层级比约 1.33 / 1.27，落在 1.25–1.618 阶梯区间 |
| 弧段 | 每段 96°，气口 24°，三段均布 120° | 外弧气口 −15°/105°/225°，内弧气口 −45°/75°/195°，错位 30° 形成「气」的流动 |

## 四、L3 感知 · Token 映射（零自造色值）

| 图形 | 色值 | 来源 Token |
|---|---|---|
| 卡片底 | `#FAF8F3` | `--color-bg-base` 宣纸白 |
| 三段外弧 | `#2E4A6B` @0.92 | `--color-accent` 靛青 |
| 三段内弧 | `#2E4A6B` @0.24 | 同上，透明度分层 |
| 三层气韵圆 | `#2E4A6B` @0.075 / 0.05 / 0.032 | 同上 |
| 纸纹 | `#1C1C1C` @0.030 / 0.026 / 0.028 | `--color-text-primary` 焦墨 × `--noise-opacity` 3% |
| 内缘描边 | `#2E4A6B` @0.05 | 避免「边缘硬切」 |
| 朱砂点 | `#B03A2E` | `--accent-ha` / `--color-danger`，唯一破格 |

**对比度**：靛青主弧对宣纸白约 8.9:1，朱砂点约 5.67:1（沿用规范实测值），均 ≥ 4.5:1；图形 ≥3:1 达标。图标无文字，WCAG 2.1 AA 正文条款不适用。
**无障碍**：语义不依赖单一颜色——「唯一焦点」由位置（黄金点）＋尺寸＋色相三重编码，去掉朱砂点后图形仍完整可读。无动效，`prefers-reduced-motion` 不适用。

## 五、审美自检

**审美四契机**

| 契机 | 结论 |
|---|---|
| 去目的仍成立 | 去掉「skill 标识」的功能目的，三弧留白仍是一幅自足的抽象构成 |
| 直觉可感 | 向心收束、一点破局，无需阅读说明即可感到「静」与「醒」 |
| 无目的合目的 | 弧的不闭合不为表示任何品类，却恰好显出秩序与呼吸 |
| 风格可辨 | 宣纸白 / 靛青 / 朱砂 / 圆角 / 极简几何，与原四枚 skill 图标同族 |

**审美疲劳「度」**：强调元素仅 1 处，无重复装饰、无渐变光泽、无多焦点竞争；不存在「强调泛滥」。
**三赛道复核**：功能（512/128 均可辨、透明四角可直接上传）／审美（意境成立、有论证）／价值（与「美学总控」定位同构）——三项皆通过。

**交付前确认清单**

- [x] 色值全部映射 Token，无硬编码自造色
- [x] 留白 >40%（实测 >88%）、单屏焦点 ≤1、破格恰好 1 处且其余 100% 合规
- [x] 无纯白纯黑、无渐变、主色饱和度 ≤45%
- [x] 语义不单靠颜色；对比度达标
- [x] 一句话立意 + 1 主范畴 + 3 美感机制已写出，且已转译为具体形式（三弧 / 气口 / 黄金点）
- [x] 东方主题具备「虚」的结构与留余，未贴符号
- [x] 四角透明、圆角边缘平滑、无纸纹溢出；128px 可辨识

## 六、图形语义速记

```
三段外弧      东方 / 西方 / 阿拉伯-伊斯兰三体系，各据一方、互不叠压
三段内弧      14 类交付由中心生长；与外弧错位＝气韵流动（不逐一罗列）
中心空白      「间」——万象所自生，也是总控共享的那张美学定位卡
一点朱砂      唯一焦点、唯一破格，落在黄金分割收束点
三层淡圆      「气」的场域，向外消逝＝「假」的无常
```

## 七、复现

```bash
python build/_icon_v2/gen.py         # 生成 SVG + 渲染用 HTML
python build/_icon_v2/render_pil.py  # 生成 512 PNG（4x 超采样）+ 128 预览
```

PIL 直绘而非浏览器截图：图形全由圆弧构成，超采样可精确控制圆头端点、alpha 预混与圆角遮罩，避免浏览器渲染的裁切与噪点溢出。
