# 高级审美质量门禁 · 交付前强制校验

> 主流程 **P7** 的唯一依据。**任一 MUST 项不通过，回到 P4–P6 修正后重跑，不得带病交付**。
> 三重校验：**① 领域正确性 ② 审美哲学质量 ③ 体系一致性**；另加可用性硬指标与八意识联检。

---

## 一、第一重 · 领域正确性（按产品 ID 分支）

| ID | 必过项 |
|---|---|
| A/B/C 文字 | 语法与字词句清单全过；体裁结构成立；意象有回环；术语未漏进正文；修改清单已执行 |
| D/E 影像 | 电影语言四要素（故事/角色/好奇/共鸣）齐备；z 轴前中后景 + xy 轴平衡；无同景别堆砌、无「拉抽屉」；30° 法则与银幕方向成立；转场有动机；短/长/影视节奏达标；声音轨不铺满 |
| F/G 摄影 | 摆姿/表情/构图/布光参数与情绪同向；环境可行性优先（室内窗边不套正午顶光）；自然光优先；有引导话术；拍摄参数标注〔通用参考〕并提示现场测光 |
| H/I 平面 | 3 米外主信息可读、30 cm 内有细节；信息层级唯一主信息；字体 ≤2 族；60-30-10；出血与尺寸完整；缩略图（200px）仍可识别 |
| J UI | 正文对比度 ≥4.5:1、大字 ≥3:1、UI 图形 ≥3:1；同屏字体 ≤2 族；焦点环可见；状态不只靠颜色；响应式与动效时长达标；代码引用 Token 不硬编码 |
| K/L/M 空间 | 动线有收放、不一览无余；有前中后景层次；材质与体系一致；光不均匀、以暗托明；有声景与四时；安全与尺度约束成立 |
| N 声景 | 至少 1 处刻意静默；声源有远近层次；不是全程铺满；通感映射与体系同向 |

> 领域细节清单见 `domain/*/aesthetic-checklist.md`、`aesthetics-checklist.md`、`revision-checklist.md`。

## 二、第二重 · 审美哲学质量

| # | 检查项 | 级别 | 判定 |
|---|---|---|---|
| 1 | 康德四契机：非功利 / 非概念 / 无目的合目的 / 共同感 | MUST | 四条都能在方案里找到对应 |
| 2 | 美感 ≠ 纯快感：不止于「好看 / 养眼 / 炫技 / 糖水」 | MUST | 至少达养心；意境类达养神 |
| 3 | 反套路：无网红脸 / 网红运镜 / 糖水唯美 / 炫示性消费 / 审美疲劳 | MUST | 逐项排查 |
| 4 | 审美形态定位明确，且全部参数与形态同向（`core-06` §5） | MUST | 冲突项已修正或已注明刻意反向 |
| 5 | 三层递进已写明落点，创作手法 ≥3 条且格式完整 | MUST | 层级+手法+依据+预期反应 |
| 6 | 意境类：情景交融 / 虚实相生 / 境生象外三要素齐备 | MUST（意境类） | 有「观者补足」的空处 |
| 7 | 创作深度：格式塔同构、审美距离、移情、内模仿/通感中 ≥2 项 | MUST | 各有介质转译 |
| 8 | 美感机制 ≥2 个并写入定位卡 | MUST | — |
| 9 | 象征物 ≤3 且有回环；破格 ≤1 处 | MUST | — |
| 10 | 多赛道衡量：形式自律 / 情感有效 / 文化正当 三条均有说明 | SHOULD | 未达标须在交付说明中披露 |
| 11 | 未反思「默认审美」（温柔的权力 / 炫耀性 / 文化挪用） | SHOULD | — |
| 12 | 术语是否漏进正文 / 台词 / 画面描述 | MUST（文字类） | 只允许出现在创作说明 |

**SHOULD 项**未达标可披露后交付；**MUST 项**一律回炉。

## 三、第三重 · 体系一致性（`core-00` 回归校验）

| # | 检查项 |
|---|---|
| 1 | 定位卡写明主体系 / 流派，且下沉到三级（或明确「取体系共性」＋理由） |
| 2 | **色彩观念**正确：东方=观念色 / 伊斯兰=神学编码色 / 西方=科学光学色；没有给东方主题套光学互补阴影，没有给伊斯兰主题随意改绿蓝金白的象征 |
| 3 | **光影处理**正确：东方=消解光影·意象光（或阴翳层次）；伊斯兰=切割光·琉璃反光；西方=塑造体积·明暗交界线 |
| 4 | **空间构图**正确：东方=散点游动＋留白气口；伊斯兰=无限延伸填满·无中心；西方=焦点透视/几何分割 |
| 5 | **终极目标**一致：意境 / 认主独一外化的秩序永恒 / 再现与形式；没有让东方主题追求几何完美，也没让伊斯兰主题接受残缺 |
| 6 | **风格 vs 派别**未混淆：跨时空风格调用合法；派别调用带历史语境 |
| 7 | 色值全部可溯源（色名 + HEX 或流派色表）；主色板只来自一个色库 |
| 8 | 混搭（如有）写明主次比、接缝、理由；无无主次符号拼盘 |
| 9 | 未触发三大反模式：东方主题用西方强明暗／伊斯兰主题加大留白／符号堆砌替代底层逻辑 |
| 10 | 形式六法命中 ≥3，留白体系用三法 ≥2（`core-04` §4） |

## 四、可用性硬指标（永远优先于美学表达）

1. **可读**：文字对比度达标；字号不小于场景下限；行距不宜过紧（东方体系宜更大）。
2. **可扫**：唯一主焦点；信息层级不超过 4 级；无多个同级主角。
3. **可操作 / 可通行**：UI 触摸目标与焦点环；空间动线不折返、无安全隐患；分镜可拍、无越轴。
4. **可交付**：所有数值具体（尺寸、时长、HEX、字阶、材料、参数），无「适当」「一些」「大概」占位。
5. **可复核**：〔推断〕〔补全〕〔通用参考〕三类标注齐全，用户知道哪些是假设。

> **裁决顺序**：可用性硬指标 ＞ 领域正确性 ＞ 体系一致性 ＞ 审美哲学细项 ＞ 八意识气质细项。

## 五、八意识联检

逐项过 `core-08` §4 的 8 条；冲突按「间/素/秘 ＞ 并/破 ＞ 微/气/假」裁决。
任一交付物「破」超过 1 处、或单焦点失控，直接判不通过。

## 七、一句话判据

> **把方案里所有形容词删掉，剩下的参数还能让人感到同一种美吗？**
> 能，则过关；不能，说明靠的是修辞而非美学，回 P4–P6。
