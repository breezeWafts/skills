# 拍摄知识库（工具箱）

源自飞书「摄影摄像」知识库·拍摄前期内容汇总。Step 3 按情绪查用。每项含「参数 + 情绪含义 + 使用要点」，可直接落入分镜表。

## 一、景别

| 景别 | 画面范围 | 情绪/叙事功能 |
|------|---------|--------------|
| 大远景 | 极广阔环境 | 交待环境；象征人物被困环境之中；孤独/渺小/崇高 |
| 远景 | 展现环境 | 交待故事背景 |
| 全景 | 整个人物+环境 | 人物与环境关系、画面故事感 |
| 中景 | 腰部以上 | 人物与环境互动 |
| 近景 | 胸部以上 | 表情或肢体动作、情感传递 |
| 特写 | 局部细节 | 放大细节、传达微妙情感、视觉焦点 |
| 大特写 | 眼/唇等 | 强烈情绪、心理冲击 |

**使用原则**：内容决定景别；避免同景别连续堆砌（主体相似）；避免"拉抽屉"（特写远景来回循环）；用渐松渐紧过渡；插入镜头（过渡物品特写）衔接。

## 二、机位（视角）

| 机位 | 情绪含义 |
|------|---------|
| 仰视 | 高大、强势、压迫、向往 |
| 平视·正平 | 人文纪实、平等 |
| 平视·稍高15° | 甜美、弱势 |
| 平视·稍低15° | 高大、强势 |
| 俯视 | 渺小、弱势、掌控 |
| 背面机位 | 隐匿身份、迷茫、留想象空间 |
| 第一人称（主观视线） | 代入、代入感镜头组（看的动作→看的内容→看的反应） |
| 过肩（OTS） | 对话关系、正反打 |

**视高选择**：正反打、主观视线、观众视角；注意构图、切换顺畅、节奏变化。
**画面推导机位**：平面根据图像画轴摆放机位。
**拍人**根据五官选视角，保证三庭五眼比例；**拍物**拍第三方感受（如裙摆代表风）。

## 三、运镜

| 运镜 | 操作 | 情感表达 |
|------|------|---------|
| 推 | 镜头靠近主体 | 跟随、突出主体内心、环境说明 |
| 拉 | 镜头远离主体 | 孤独感、留白、阻碍、增添元素、环境对比赋人格 |
| 摇 | 左右摇摆 | 交待对话与位置关系；低到高摇造压迫 |
| 跟 | 跟随主体 | 快速→速度感/危险靠近；缓慢→危机感/心理压力 |
| 移 | 平移跟随 | 速度感、人物引见 |
| 升降 | 上升/下降 | 上升正面表顾虑情绪波动、背面表退场 |
| 甩镜头 | 快速转动 | 画面连贯、抓表演情绪、冲击 |
| 抽帧 | 抽掉帧 | 破碎、紧张、梦幻、混乱冲击 |
| 固定延时 | 固定机位延时/加速 | 剧场感、时间流逝、等待 |

## 四、构图

| 构图法 | 要点/情绪 |
|--------|----------|
| 框架构图 | 突出主体、增加层次空间、偷窥感、困境束缚 |
| 画框嵌套 | 凸显、强调 |
| 三分法（九宫格） | 通用、主体落交叉点 |
| 对称 | 和谐、平衡、稳定；建筑/倒影/心境平和 |
| 引导线 | 道路/河流/目光引导视线汇聚焦点 |
| 前景构图 | 前景虚化、立体感、层次感 |
| 中心构图 | 主体居中、明确突出 |
| 黄金分割/螺旋 | 主体落黄金分割点/收束点 |
| 角色占空间比重 | 大→强势，小→弱势 |
| 疏密留白 | 节奏（少而美）、呼吸感 |
| 前后遮挡/虚实 | 空间层次 |

**三步构图**：①主体位置（疏密、留白）②建筑光影线条（引导线、框架线引向主体、分割画面）③空间层次（前后遮挡、虚实、明暗）。
**视觉焦点**：运动物体、眼神横线；追求顺畅/跳跃/酷炫/节奏。
**空间感**：调整机位露出更多面（广角、拉远、俯仰），增加前中后景。

## 五、光影

| 光影 | 情绪含义 |
|------|---------|
| 只有轮廓光、面部暗 | 看不见眼睛、模糊面部、隐藏内心的躯壳 |
| 阴阳脸 | 表里不一 |
| 明暗同框 | 正义邪恶对峙 |

| 边缘光/丁达尔光 | 希望、神圣、憧憬 |
| 光晕/雾气（气） | 空气感、场域、幽玄 |

## 六、色彩（含配色）

**色彩情绪**：暖色调→开心放松；冷色调→没有安全感、压抑；红色→对生活的热望/惊悚/血腥。
**风格因素**：曲线决定风格；通透靠对比度；腻靠饱和度；纹理质感靠对比度+清晰度。

**配色方案**：
- 单色：一个颜色控制饱和度和亮度变化（极简、禅意）
- 相似色：色环相邻，比例均衡（和谐、温柔）
- 互补色：色环相对，避免单调（张力）
- 补色分割：主色对面色的相邻两色
- 三等分配色：主色大 + 两副色小（主+配+点缀）
- 矩形配色：对立面相邻两边色（主+辅+强调）

**原则**：整体色相控制在 3 个左右；辅色减少比例或降低饱和度/亮度；60-30-10；高饱和面积≤10%。
**古风调色**：冷色调静谧高级，减清晰增纹理柔和唯美；曲线掐头去尾压暗提明拉开层次；色温向蓝，片紫红则色调向绿。

**传统色取色参考**（配色方案取色入口，非运行时依赖，无需联网）：

| 体系 | 参考入口 | 适用情绪 / 场景 | 用法 |
|------|---------|----------------|------|
| 中国传统色 | https://zhongguose.com/ | 古风、禅意、壮丽史诗、四季流转 | 按色名检索（如月白、靛青、朱砂、赭石、石青、天水碧），取 HEX 作为镜头主/辅/强调色候选并沿用色名 |
| 日本传统色（和色） | https://nipponcolors.com/ | 侘寂、物哀、怀旧、低饱和沉静 | 按色名检索（如柿色、利休白茶、墨、蓝鼠），取 HEX 与和名，用于低饱和场景与服装配色 |

取色约束：①色名须与镜头情绪一致，禁止名实不符；②取回色值仍须过 60-30-10 与明度优先原则；③高饱和色面积 ≤10%；④跨镜头同一情绪使用同一套色值，保证色调连贯（见 aesthetics-evan-design.md）。

## 九、配乐与转场

**配乐**：奠定风格、创造意境、强烈抒情、推动剧情。
**相似转场**：相似场景有机连接（颜色/纹理/形状/音乐），剧情流畅、节奏强、增强共鸣、降低认知负荷。
**错位蒙太奇**：不同时空切换制造错觉（恐怖悬疑）；**声音蒙太奇**：声音提前使衔接丝滑；**对比蒙太奇**：相似镜头衔接流畅。

## 十、开场方式（短视频/长视频）

1. 空镜头（环境）开场：交代环境、代入感强
2. 固定机位延时/加速：剧场感（等待主角出现）
3. 特写开场：细节动作+音效，沉浸仪式感
4. 过程开场：正在做的事切入目的
5. 结尾式开场：完成状态衔接要做的事

## 十一、必须镜头（叙事完整）

- 定场镜头：故事发生地/目的地，可空镜可有人物
- 主镜头：人物关系与相对位置
- OTS 镜头：正反打
- 视点镜头组：看的动作→看的内容→看的反应
- 切出镜头
