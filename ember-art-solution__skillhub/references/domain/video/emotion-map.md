# 情绪 → 视听语言映射表

本文件是「情绪驱动视听语言」的核心查表。Step 2 用它定位主情绪，Step 3 用它把情绪映射到全部视听参数。冲突时以本表为准。

## 一、情绪词族与主情绪词典

把内容的情绪关键词归入以下 8 大词族（括号内为近义/细分情绪）：

| 词族 | 主情绪 | 细分情绪词 |
|------|--------|-----------|
| **孤寂族** | 孤独 | 孤独、寂寥、失落、空虚、疏离、迷茫、怅惘、伤感、忧郁、落寞 |
| **温情族** | 温暖 | 温馨、幸福、眷恋、治愈、柔软、亲密、感恩、安心、怀旧 |
| **炽烈族** | 炽热 | 炽热、激情、狂喜、兴奋、愤怒、冲击力、生命力、躁动 |
| **憧憬族** | 期待 | 期待、向往、憧憬、希望、悸动、好奇、昂扬、追光 |
| **静谧族** | 平静 | 平静、释然、专注、禅意、安宁、空灵、恬淡、超脱 |
| **压抑族** | 压抑 | 压抑、恐惧、紧张、不安、绝望、危机、神秘、悬疑、束缚 |
| **怅惘族** | 怅然 | 怅然、恍惚、伤逝、物哀、无常、遗憾、惋惜、释怀前的痛 |
| **壮丽族** | 崇高 | 崇高、震撼、辽阔、敬畏、史诗、庄严、孤绝的抗争 |

**强度判定**：弱（克制、日常）/ 中（明显但不外放）/ 强（戏剧化、极致）。强度决定运镜幅度、色彩浓度、剪辑节奏。

## 二、情绪 → 视听参数映射表（核心）

### 2.1 孤独 / 怅惘 / 压抑（冷色·疏离组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 大远景、远景为主（人物渺小、被困环境）；少量特写（局部细节） |
| 机位 | 背面机位、高机位俯拍；低机位仰拍表现压迫 |
| 运镜 | 拉镜头（孤独、留白、阻碍）、缓慢跟随（危机、心理压力）；固定机位延时 |
| 构图 | 疏密留白、框架构图（困境束缚）、人物占画面比重小、前后遮挡 |
| 光影 | 只有轮廓光面部暗（隐藏内心）、阴阳脸（表里不一）、面部阴影（主动权） |
| 色彩 | 冷色调（无安全感、压抑）、低饱和、冷蓝/青灰；冷色为主，点缀极少暖色 |
| 道具/背景 | 芦苇（隔离、脆弱无常）、残阳、大海（死亡）、荒原（孤独逃避）、雨（洗白死寂）、雷电（绝望恐惧）、残垣断壁（颓唐）、铁栏杆/百叶窗/门缝（看不见的框架、隔阂）、密植荒地（重逢阻力） |
| 节奏/配乐 | 慢节奏、长镜头、留白多、低沉配乐、静默留白 |

### 2.2 温暖 / 温情 / 治愈（暖色·亲近组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 中景、近景为主（互动与表情），特写（细节与情感） |
| 机位 | 平视（正平·人文纪实）、略低机位（亲切） |
| 运镜 | 缓慢推镜（靠近、关注）、缓慢移镜（人物引见）；手持轻微呼吸感 |
| 构图 | 居中/对称（和谐稳定）、前景虚化（层次）、视觉焦点明确、暖色光斑 |
| 光影 | 柔和窗边光、暖光、明暗过渡柔和、逆光补光（反光板） |
| 色彩 | 暖色调（开心放松）、低饱和暖色、暖橙/米黄点缀 |
| 道具/背景 | 烟火气（温馨）、天空（希望）、花（柔美）、双手触碰连接（搂抱搭肩）、室内窗边、家庭场景 |
| 节奏/配乐 | 中慢节奏、温暖配乐、环境音（人声、笑声） |

### 2.3 炽烈 / 激情 / 生命力（高饱和·动感组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 近景、特写为主，快速景别切换（避免拉抽屉） |
| 机位 | 低机位仰拍（高大强势）、动势机位 |
| 运镜 | 快速推/跟/移（速度感）、甩镜头（冲击）、升降（情绪波动）、抽帧（混乱冲击） |
| 构图 | 强化动态（倾斜、断裂）、锐角线条、高饱和色块、破面破线（立体与错落） |
| 光影 | 强对比、硬光、轮廓光、高光溢出 |
| 色彩 | 红色（热望、惊悚、血腥）、高饱和、高对比；注意「破」只留 1 处点睛 |
| 道具/背景 | 烟火、动态元素、芦苇摇曳（不安）、巨物（崇高）、运动场景 |
| 节奏/配乐 | 快节奏、短镜头、强节奏配乐、音效强化 |

### 2.4 期待 / 憧憬 / 希望（向光·上升组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 远景→中景→特写递进（从环境到主体到表情） |
| 机位 | 仰拍（向往）、平视 |
| 运镜 | 推镜（接近目标）、上升升降（情绪上扬）、固定机位延时等待 |
| 构图 | 引导线（道路/河流引向远方）、黄金分割主体、留白在前方（未来感）、天空留白 |
| 光影 | 逆光、边缘光、晨光、光斑、丁达尔光 |
| 色彩 | 明亮暖色 + 天空蓝、清透、中高饱和 |
| 道具/背景 | 天空（希望）、道路、窗、光束、远景地平线 |
| 节奏/配乐 | 中速渐强、上行旋律、希望感配乐 |

### 2.5 平静 / 禅意 / 释然（留白·极简组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 大远景、空镜、固定景别 |
| 机位 | 固定机位、平视、对称 |
| 运镜 | 固定/极缓慢推拉、延时、极简；一镜一意 |
| 构图 | 大面积留白（≥50%）、三分法、极简几何、单焦点、禅意枯山水式排布 |
| 光影 | 柔和自然光、漫射、低对比、雾气 |
| 色彩 | 低饱和（≤45%）、月白/宣纸白/靛青、近乎单色 |
| 道具/背景 | 天空、水面、远山、空房间、留白墙面 |
| 节奏/配乐 | 极慢、长镜头、静默、极简配乐或环境音 |

### 2.6 压抑 / 恐惧 / 悬疑（冷暗·束缚组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 近景、特写、变形特写；大远景压迫 |
| 机位 | 低机位仰拍（压迫）、背面机位（未知）、手持晃动 |
| 运镜 | 缓慢跟随（危机）、推镜（逼近）、手持、抽帧（不安） |
| 构图 | 框架构图（束缚）、画框嵌套、遮挡、面部阴影 |
| 光影 | 阴阳脸、只留轮廓光、硬光阴影、明暗同框（正邪对峙） |
| 色彩 | 冷色低饱和、青灰/墨绿、红色点缀（血腥惊悚） |
| 道具/背景 | 铁栏杆/百叶窗/门缝（隔阂身不由己）、雨、雷电、密植荒地、芦苇（紧张未知）、残垣断壁 |
| 节奏/配乐 | 慢中带紧、静默与突发、低频音效 |

### 2.7 壮丽 / 崇高 / 史诗（辽阔·震撼组）

| 维度 | 推荐参数 |
|------|---------|
| 景别 | 大远景、全景为主 |
| 机位 | 低机位仰拍（崇高）、航拍/高机位 |
| 运镜 | 缓慢上升、大范围移动、长镜头 |
| 构图 | 辽阔留白、地平线、巨物与人对比、对称庄严 |
| 光影 | 逆光、剪影、金色时刻、强明暗 |
| 色彩 | 高对比、石青/赭石/金色、开阔色域 |
| 道具/背景 | 巨物（崇高）、大海、荒原、天空、山川、残阳 |
| 节奏/配乐 | 史诗配乐、渐强、长镜头 |

## 三、情绪→色彩基调速查

| 情绪 | 主色 | 辅色 | 点缀（≤10%） |
|------|------|------|-------------|
| 孤独/怅惘 | 冷蓝/青灰 | 月白 | 极暖一点 |
| 温暖/治愈 | 暖米黄 | 暖橙 | 苔绿 |
| 炽热/激情 | 深红 | 橙 | 朱砂（唯一破格） |
| 期待/憧憬 | 天光蓝 | 暖白 | 藤黄 |
| 平静/禅意 | 宣纸白/月白 | 靛青 | 无或极淡 |
| 压抑/悬疑 | 墨绿/青灰 | 冷灰 | 暗红 |
| 壮丽/史诗 | 石青 | 赭石 | 金 |

> 配色统一遵守 60-30-10（主:辅:强调），高饱和面积 ≤10%，情绪再强烈也只留 1 处「破」。
