# 表演指导：肢体动作 / 眼神 / 表情

用于分镜表「表演指导」列。前半部分源自拍摄知识库（约拍·摆姿、酝酿、角色动作），后半部分为影视表演专业补全（标注〔补全〕）。

## 一、体态基础（源自约拍·摆姿）

- **脊柱**：头顶上提、后颈拉伸，双肩降低后靠，深吸收腹。颈椎拉伸（头部挺直）、胸椎伸展（自信有力）、腰椎弧度（性感迷人）。
- **重心**：双脚尖不能平行；双脚交叉重心放后脚；稍息踩台阶（大腿与地面夹角>45°）。
- **关节**：手臂避免僵直，用关键线条引导视线到突出部位。直角→干练有力；锐角→抢眼冲击（时尚动感）；钝角→平静浪漫。手腕自然弧度；手臂摆成菱形避免横平分割。
- **手臂摆放**：依靠搭放 / 双手组成画框 / 拿握提（服饰道具）/ 群拍触碰连接（搂抱搭肩）。
- **三面法则（破面/破线）**：
  - 破面：y轴固定，x/z轴动（如头正体侧）→ 立体
  - 破线：y轴变化，无长直线平行线（偏头、摆胯、弯手）→ 错落
  - 破脸面：转脸/道具遮脸/光影雕刻脸；破胸面：扭胯高低肩；破腿面：踮脚交叉前后踢；破头线：倒头；破胸线：转身叉腰；破腿线：踮脚交叉。
- **支点**：有支撑点身体自然放松（自身支点如稍息，或环境支点）。
- **道具互动**：有互动、分散注意力避免紧张。

## 二、表情与情绪（源自约拍·酝酿）

**酝酿三步**：①场景第一感觉 → ②适合的故事和情绪 → ③人物配合的表情动作。

**先固定仪态，抓拍表情**：先酝酿、321 看镜头；假想场景构造表情。
**抓拍法**：暗示模特所处场景再抓拍；引导情绪（玩笑）后再抓；直接感受（听、闻、看）。

**情绪词库（19个）**：专注、向往、迷茫、憧憬、孤独、忧郁、伤感、怅惘、期待、悸动、寂寥、眷恋、释然、怅然、恍惚。

**情绪→表情/肢体映射**：

| 情绪 | 表情 | 肢体/动作 |
|------|------|----------|
| 孤独/寂寥 | 目光放空、微垂眼、无表情或淡漠 | 背影、抱臂、缩肩、独坐、缓慢动作 |
| 期待/憧憬 | 眼神发亮、微扬唇、抬头 | 身体前倾、向上伸展、望向远方 |
| 伤感/怅惘 | 垂眼、抿唇、眼神失焦 | 低头、手抚物、缓慢转身、停顿 |
| 释然 | 深呼吸、微笑、闭眼 | 舒展、张开手臂、放下动作 |
| 炽热/激情 | 睁眼、张口、强烈表情 | 快速动作、握拳、前冲、大幅度肢体 |
| 压抑/恐惧 | 紧锁眉、咬唇、瞳孔收缩 | 僵硬、后缩、护身、手部紧抓 |
| 温柔/眷恋 | 柔和眼神、浅笑 | 轻触、依靠、缓慢靠近 |
| 专注 | 凝视、眉心微收 | 身体前倾、手稳定持物 |

## 三、眼神指导

| 眼神 | 含义 |
|------|------|
| 直视镜头 | 打破第四堵墙、强烈代入、挑衅或真诚 |
| 看向画外引导线 | 引导观众视线、悬念 |
| 垂眼/失焦 | 内心戏、孤独、伤感 |
| 眼神的"看-停-转" | 看的动作→停顿→转移，制造节奏（〔补全〕） |
| 眼神光 | 逆光/窗光点亮眼神，增强生命力（〔补全〕） |

**坐标组合**（面向镜头强、远离镜头弱）：眼睛、下巴偏面向；锁骨偏远离；头部正/斜配合。

## 四、表演补全（〔补全〕）

- **微表情**：嘴角肌肉细微抽动、眼神短暂游移、呼吸节奏变化——特写中传达压抑情感的关键（〔补全〕）。
- **反应镜头**：对手戏中"听者"的反应往往比"说者"更有情绪张力，给反应留时长（〔补全〕）。
- **动作节奏**：情绪激动时动作快而碎，平静时动作慢而连续；动作的"停顿"本身是情绪（〔补全〕）。
- **手的语言**：手是最容易暴露情绪的部位——紧握（紧张）、摊开（坦诚）、抚摸（眷恋）、遮挡（羞怯/隐藏）（〔补全〕）。
- **角色动势**：吃食物→食欲表现贪婪；踉跄→迷失；回望→眷恋不舍（部分源自知识库"角色动作"）。

## 五、表演指导写法（落入分镜表）

每个含人物的镜头，表演指导列写 2–4 项，格式：
`体态/动作 + 表情 + 眼神 + 情绪依据`
例：`脊背微弓独坐→垂眼失焦→望向窗外雨（孤独·怅惘）；手轻抚杯沿停顿2秒（物哀）`
