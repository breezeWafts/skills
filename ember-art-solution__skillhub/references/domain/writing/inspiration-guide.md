# 灵感补全指南（低输入 / 情绪 / 潜意识）

用于 `SKILL.md` Step 3。**核心原则：给具体建议，不做空泛追问。** 用户说不清时，创作助手的职责是把模糊感受变成可选的方向，而不是把问题原样扔回去。

---

## 1. 信息完整度分级

| 级别 | 判定 | 动作 |
|------|------|------|
| 充足 | 体裁 + 素材 + 意图齐全 | 跳过本章，直接进 Step 4 |
| 中等 | 缺 1–2 项（如只有体裁和想法，没受众） | 只补缺项，用选项式一问，其余自行补全 |
| 稀薄 | 只有情绪词 / 一句话 / 碎片想法 / 「不知道写什么」 | 启动 2–4 节全部流程 |

「充足」的门槛很低：有体裁、有一句可写的内容，就算充足。宁可自行补全，也不要让用户填问卷。

---

## 2. 情绪坐标

从用户措辞里识别三个量：

1. **主情绪**（1 个）
2. **强度**：弱 / 中 / 强
3. **走向**：起承转合式变化 / 单一情绪贯穿 / 由低到高 / 由高到释然

### 情绪 → 写作参数映射

| 主情绪 | 意象 | 节奏与句式 | 视角 | 结尾方式 |
|--------|------|-----------|------|---------|
| 失落 / 怅惘 / 怀念 / 遗憾 | 旧物、黄昏、空房间、雨、旧照片 | 慢；长句为主 | 自我观察 | 留白、开放式 |
| 期待 / 雀跃 / 希望 | 光、清晨、路、门、启程 | 中快；短句为主 | 自我观察 | 行动指向 |
| 愤怒 / 不甘 / 委屈 / 压抑 | 火、裂缝、对峙、噪音 | 快；短句 + 断裂 | 上帝视角或强主观 | 反讽、爆发 |
| 平静 / 安宁 / 释然 / 松弛 | 水、窗、日常物件、风 | 慢；均衡句 | 上帝视角 / 自我观察 | 回扣式 |
| 焦虑 / 迷茫 / 倦怠 | 迷宫、未读消息、赶路、雾 | 快；碎片化短句 | 自我观察 | 悬置、不闭环 |
| 感动 / 温暖 / 感激 | 手、背影、饭菜、灯 | 中速；长短交替 | 自我观察 | 升华、呼应 |

映射是起点不是枷锁：用户给出明确偏好时以用户为准；情绪混合时取主导者，其余作为副色。

---

## 3. 潜意识线索提取

从用户输入里找五类线索，每一类都可成为创作燃料：

| 线索 | 识别信号 | 转化方式 |
|------|---------|---------|
| 重复词 | 同一个词/意象出现两次以上 | 直接作为全文核心意象 |
| 主动展开的细节 | 用户就某一点多说了几句 | 作为动情点的落点 |
| 比喻与类比 | 「像……」「感觉像是……」 | 变成标题或开篇画面 |
| 矛盾与自我修正 | 「也不是……其实……」「但好像又……」 | 成为「转」的冲突内核 |
| 强烈否定 | 「最讨厌……」「再也受不了……」 | 反推出人物真正珍视的东西 |

### 引导问题（最多问 2 个，必须选项式）

按缺失信息从下列清单取用，禁止一次抛出 3 个以上问题：

1. 这个感觉最接近哪个画面？（给 3 个具体画面选项）
2. 如果把它交给一个人，会是谁？（给 3 类人物选项）
3. 你最想让别人读完说哪句话？（给 3 句备选）
4. 这件事里最不肯放下的细节是什么？（给 3 个方向提示）
5. 想写得克制一点，还是痛快一点？（二选一）

用户回答后，把选项语言直接用于正文，不另造抽象词。

---

## 4. 方向建议生成

稀薄输入下，输出 3 个具体方向，每个包含四要素：

```
方向 A｜<灵魂点类型>：<具体的点>
- 一句话梗概：谁 / 在什么处境 / 发生了什么反常的事 / 结果如何
- 标题：按体裁标题公式给出可用标题
- 推荐体裁：小说 / 广告文案 / 散文 / 演讲稿……
- 情绪落点：读完想让人产生什么感受
```

灵魂点类型裁决规则：

- 情绪强度「强」且外放 → 优先 **爆点**（耸人听闻、反常规）
- 情绪强度「强」但内敛 → 优先 **动情点**（感动人的）
- 情绪偏弱、用户带着明确问题 → 优先 **卖点**（能解决什么）
- 三者都沾 → 选最贴近用户原话的那个

**用户说「你定 / 按你的来」**：立即选最贴合情绪坐标的一个方向，说明一句「为什么选它」，然后直接进 Step 4 生成全文，不再追问。

---

## 5. 禁止事项

- 禁止空泛追问：「你想写什么」「主题是什么」「能再多说点吗」——这类问题把劳动推回给用户。
- 禁止连续多轮追问：一轮最多 2 个选项式问题；用户不答即自行补全。
- 禁止把情绪诊断当创作结论：情绪词只用于映射参数，不给用户贴心理标签。
- 禁止编造事实：用户素材里的真实细节不足时，用「待补」占位，不虚构人名、数据、经历。
- 禁止在 coach 模式直接倒出全文：必须先给方向，等用户确认。

---

## 6. 示例

**用户输入**：「最近总是想起我妈做的饭，说不上为什么，就是有点闷。」

- 完整度：稀薄（有情绪，无体裁无素材）
- 情绪坐标：主情绪=怀念/怅惘；强度=中；走向=由低到释然
- 潜意识线索：重复意象「饭」；自述「说不上为什么」= 未展开枝节
- 映射：旧物/饭菜/灯；慢速长短交替；自我观察；呼应式结尾
- 方向建议：
  - A｜动情点：「一碗没吃完的饭」——一个人加班到深夜，发现冰箱里留着一份饭，没留纸条。标题《冰箱里那碗饭》。体裁：微小说。情绪落点：被惦记的酸与暖。
  - B｜卖点：「味觉记忆比照片更久」——从一道家常菜讲记忆的存储方式。标题《为什么我们记得的不是生日，是那顿饭》。体裁：新媒体文章。
  - C｜爆点：「我妈从没说过爱我，但她每天多做一个人的饭」——反常规切入亲情表达。标题《不说爱的那代人》。体裁：演讲稿。

用户选 A 或说「你定」，即按 A 进入构思与生成。
