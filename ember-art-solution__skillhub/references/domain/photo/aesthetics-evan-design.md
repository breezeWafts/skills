# evan-design 东方美学 · 影像化转译

源自 evan-design 设计 skill，把界面美学规范转译为镜头语言，供 Step 5 审美校验。核心信条：**留白是呼吸、比例是节奏、色彩是语义**。设计分歧时以 L1 意境层为准。

## 一、三层哲学 → 影像三层

| 层级 | 界面原义 | 影像转译 |
|------|---------|---------|
| L1 意境层 | 东方美学（留白/侘寂/物哀/幽玄/禅） | 画面的气质与情绪：空镜、含蓄、无常、克制 |
| L2 秩序层 | 黄金分割/螺旋/模数 | 构图比例：三分法、黄金分割、主体位置 |
| L3 感知层 | 配色科学、人体工学、材质动效 | 色彩基调、光影质感、运动节奏 |

**统一性原则（MUST）**：全片只允许一套主色板、一套构图节奏、一套运动风格。跨镜头"风格漂移"视为缺陷。

## 二、L1 东方美学的影像化

| 美学 | 内核 | 影像落地 |
|------|------|---------|
| **留白（刘白）** | 以无衬有 | 主体周围留白≥40%（禅意镜≥50%）；留白优先于遮挡；空镜承接情绪 |
| **侘寂（Wabi-Sabi）** | 不完美、不恒常 | 旧感材质、斑驳墙面、不完美构图、自然光；拒绝对称抛光 |
| **物哀（Mono no Aware）** | 对无常的温柔感知 | 消逝感（落叶、残阳、雨停）、季节感、慢动作告别、淡出转场 |
| **幽玄（Yūgen）** | 深奥含蓄不可尽言 | 单焦点、渐进披露、隔雾观花（雾/纱/景深遮挡）、不完整构图 |
| **禅（Zen）** | 减法专注当下 | 一镜一意、单视觉焦点、极简、长镜头、静默 |

## 三、八大审美意识（微/并/气/间/秘/素/假/破）影像校验

| 意识 | 内核 | 影像校验项 | 等级 |
|------|------|-----------|------|
| **微** | 细节蕴含整体 | 至少1个关键特写（眼神/手/物）承载情绪；细节自洽 | SHOULD |
| **并** | 独立而统一 | 全片色调、运动风格统一；无风格漂移 | MUST |
| **气** | 无形场域 | 空气感：雾、光晕、景深、呼吸感；主体与背景有"气" | SHOULD |
| **间** | 流动空间 | 留白与景深营造呼吸；主体周围留白≥相邻元素1.618倍 | MUST |
| **秘** | 秘而不宣 | 单镜头焦点≤1；不完整构图/遮挡驱动想象；信息渐进 | MUST |
| **素** | 返璞归真 | 主色饱和度≤45%（除非炽烈/破格）；高饱和面积≤10% | MUST |
| **假** | 顺应自然 | 季节感、痕迹感、自然光；保留不完美痕迹 | SHOULD |
| **破** | 秩序中的偶然 | 全片至多1处破格（唯一高饱和/超规镜头），标注 `ha`；其余全守序 | MUST |

**裁决优先级**：间/素/秘（气质）＞并/破（秩序）＞微/气/假（感知）。
**破的硬约束**：先守后破、破而不滥——全片其余镜头完全合规、且仅1处显式标注时才成立。多则为噪音。

## 四、L2 比例秩序（影像化）

- **黄金分割 φ=1.618**：主体落画面 (0.618, 0.382) 或镜像位；避免正中呆板或角落失力。
- **三分法**：主体落九宫格交叉点（源自知识库 Vlog 构图）。
- **黄金螺旋**：主视觉/情绪高潮镜头落收束点。
- **斐波那契节奏**：镜头时长可按 1/2/3/5/8 秒的节奏组接，形成呼吸韵律。

## 五、L3 配色与场域（影像化）

**60-30-10**：主色60% / 辅色30% / 强调色10%。
**明度优先**：先保证画面明度层次（暗部/中间调/亮部）清晰再谈色相。

**主题色板（影像化）**：

| 主题 | 底色 | 强调色 | 适配情绪 |
|------|------|--------|---------|
| 月白禅（默认） | 宣纸白 #FAF8F3 | 靛青 #2E4A6B | 平静、禅意、孤独 |
| 侘寂灰 | 古纸 #E8E0D0 | 柿色 #C77B45 | 怀旧、怅惘、物哀 |
| 千里江山 | 绢白 #EDE6D6 | 石青 #2E5A88 / 赭石 #A0522D | 壮丽、史诗 |

**暗调**（压抑/悬疑）：背景墨夜 #16181A，非纯黑；强调色明度提升10-15%、饱和度降低5%；用边缘微光替代硬阴影。
**季节色**（假）：春天水碧 / 夏石青 / 秋赭石 / 冬月白——用于情绪随季节流转的长视频。

## 六、反模式（禁止，源自设计 skill 反模式转译）

- 高饱和撞色（红绿/紫黄）大面积使用
- 纯白纯黑的极端画面（用宣纸白/墨夜）
- 机械均分的"信息墙"式构图
- 无意义的装饰性运动/转场
- 主体与背景贴死、无留白无呼吸
- 一屏/一镜多个同等权重焦点
- 硬切边无柔化（失去「秘」的想象空间）
- 情绪未铺垫就"破"：满屏多处高饱和/超规镜头

## 七、审美校验清单（Step 5 交付前逐条确认）

- [ ] 全片色调统一，无风格漂移（并）
- [ ] 关键镜头主体周围留白≥40%，禅意镜≥50%（间）
- [ ] 单镜头焦点≤1，有渐进披露/不完整构图（秘）
- [ ] 主色饱和度≤45%，高饱和≤10%（素）
- [ ] 至少1处关键特写承载情绪（微）
- [ ] 雾/光晕/景深营造空气感（气）
- [ ] 季节感/痕迹感/自然光（假）
- [ ] 全片至多1处破格并标注 `ha`，其余全守序（破）
- [ ] 主体落三分法/黄金分割点（L2）
- [ ] 60-30-10 配色，明度层次清晰（L3）
