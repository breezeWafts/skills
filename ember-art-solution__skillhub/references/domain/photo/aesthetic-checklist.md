# 审美质量校验清单（Aesthetic QA）

v1.2.0 新增。用于 Step 6 交付前的「审美能力」把关，确保方案不仅技术上正确、更在审美上成立且有专业纵深。理论源自《美学原理 30 讲》康德美学与审美意识形态批判、《美的历程》审美疲劳与意境论。与 `aesthetics-evan-design.md`（东方八意识校验）叠加使用，本文件偏「审美哲学质量」，后者偏「东方形式气质」。

## 一、康德审美四契机校验（摄影版）

| 契机 | 原义 | 摄影校验问题 |
|------|------|------------|
| **非功利而有愉悦** | 审美不涉及利害，却是愉快的 | 方案的愉悦是否纯粹来自形式与情感，而非炫耀财富/身份/颜值？（避免"炫富式""网红式"讨好） |
| **非概念而普遍** | 无概念却要求普遍赞同 | 情绪是否清晰可感，让不同观者都能领会，而非只有创作者自懂？ |
| **无目的而合目的** | 无明确目的却合乎目的 | 画面是否"不为说明什么"却恰好表达了情绪？（避免说明文式的直白摆拍） |
| **无概念而必然（共同感）** | 诉诸人心可普遍传达的共同感 | 情感是否真诚可传达，而非孤芳自赏或刻意煽情？ |

## 二、美感 vs 快感（避免沦为纯感官讨好）

- **美感**（审美快感）：无利害、独立自足、形式引起诸认识能力和谐。
- **快感**（要区分）：
  - 生理快感——单纯好看、养眼刺激（依赖刺激物，被对象征服）
  - 道德快感——勉强的愉快，受制于道德标准
- **校验**：方案若只停在"好看"（糖水片、网红脸、无脑美颜式唯美），未进入"养心/养神"，判定为"仅养眼"，需按 aesthetic-creative 的三层递进法深化。

## 三、反套路与主体性校验（审美意识形态批判）

源自伊格尔顿「温柔的权力」、布尔迪厄趣味区隔、拉康镜像阶段。目的是让方案有独立审美，避免同质化。

| 反模式 | 表现 | 破解 |
|--------|------|------|
| **网红脸/网红构图** | 千篇一律的姿势、滤镜、打卡角度 | 回到情绪本身重新设计姿态；用象征手法制造独特意象 |
| **糖水片** | 只有形式甜美，无情感内核 | 注入故事情境与内心戏（养心层）；加入虚实与余味（养神层） |
| **炫示性消费** | 用名牌/豪车/场景堆砌身份 | 检验非功利契机——情绪是否独立于物质符号 |
| **镜像误认** | 追求"理想我"的完美幻象 | 允许不完美、侘寂、真实痕迹（呼应 evan-design「假」「侘寂」） |
| **审美疲劳** | 元素堆砌、过犹不及、重复套路 | 克制——留白、减法、单焦点；"度"的把握 |

## 四、意境校验（意境类方案必查）

- [ ] **情景交融**：情与景互相渗透，无"有景无情"或"有情无景"
- [ ] **虚实相生**：实写与留白/虚景比例得当（约 40:60 至 60:40）
- [ ] **境生象外**：画面之外有余味，观者可"想"到画外之意
- [ ] **顿悟性**：不是慢慢累积的感动，而是瞬间的点睛（一个特写、一束光、一个停顿）

## 五、审美形态一致性校验

- [ ] 方案的主审美形态（优美/崇高/悲剧/喜剧/荒诞/意境）已明确写出
- [ ] 全部视觉参数（构图/光/色/姿态）与审美形态同向，无调性冲突
- [ ] 套图各张围绕同一主形态，辅助形态主次分明
- [ ] 崇高/悲剧类：有"张力与尊严"，而非单纯场面大/单纯凄惨

## 六、创作深度校验

- [ ] 达到至少「养眼 + 养心」两层；意境/禅意主题达到「养神」
- [ ] 若用象征/隐喻，象征含义明确且服务情绪（非为象征而象征）
- [ ] 力的结构（线条/方向/张力）与情绪同构（格式塔）
- [ ] 有恰当的审美距离：不刻意煽情，也不冷漠炫技
- [ ] 调动了至少一种通感（触觉/听觉/动觉等）

## 七、交付前总校验表（Step 6 逐条确认）

```
审美哲学质量：
[ ] 康德四契机通过（非功利/非概念/无目的合目的/共同感）
[ ] 未沦为纯"养眼"（有养心或养神纵深）
[ ] 无网红脸/糖水片/炫示性消费等套路
[ ] 审美形态定位明确且参数同向
[ ] 意境类：情景交融+虚实相生+境生象外
[ ] 创作深度：三层递进达标、同构成立、审美距离恰当、有通感

东方气质（见 aesthetics-evan-design.md）：
[ ] 并：整组色调/光向统一
[ ] 间：留白≥40%，禅意≥50%
[ ] 秘：单张焦点≤1
[ ] 素：饱和≤45%，高饱和≤10%
[ ] 微/气/假/破：细节、空气感、自然、破格守序

输出完整性：
[ ] 视觉方案表含「审美形态定位」「创作手法」项
[ ] 〔补全〕项清单完整
```

## 八、校验不通过的处理

1. 定位问题属于哪一层（审美哲学 / 东方气质 / 输出完整性）。
2. 回到对应步骤修正：
   - 审美形态问题 → Step 2 重新定位，Step 3 重新映射
   - 创作深度不足 → Step 4 调用 aesthetic-creative 深化
   - 东方气质问题 → 按 aesthetics-evan-design 清单修正
3. 修正后重新走 Step 6 校验，直至全部通过。
