# 人像构图知识库（画幅 / 景别 / 机位 / 构图法）

源自飞书摄影知识库·Vlog 构图与机位，转译为人像静态摄影，部分按专业惯例补全（标注〔补全〕）。Step 3 按情绪查用，Step 4 落地构图设计。

## 一、画幅（Aspect Ratio）

| 画幅 | 特点 | 适配 |
|------|------|------|
| 3:4 | 经典人像竖幅，体态自然 | 半身、全身人像、写真 |
| 4:5 | 小红书/社交媒体竖幅，视觉饱满 | 半身特写、时尚人像 |
| 9:16 | 手机全屏竖幅，冲击力强 | 短视频封面、竖屏大片 |
| 1:1 | 方图聚焦、稳定、复古 | 特写、情绪人像、胶片感 |
| 3:2 / 16:9 | 横幅，展示环境与天空 | 环境人像、大远景、孤独/崇高 |

**选择原则**：情绪向内（孤独、禅意、炽热）多用横幅或方图突出留白/张力；情绪向外（亲切、日常）多用竖幅。用途为社媒优先 4:5 / 9:16。

## 二、景别

| 景别 | 画面范围 | 情绪/叙事功能 |
|------|---------|--------------|
| 大远景 | 极广阔环境，人物极小 | 交待环境；人物渺小/被困；孤独、崇高 |
| 远景 | 展现环境，人物较小 | 交待故事背景、环境氛围 |
| 全景 | 整个人物 + 环境 | 人物与环境关系、画面故事感、展示全身姿态 |
| 中景 | 腰部以上 | 人物与环境互动、摆姿展示 |
| 近景 | 胸部以上 | 表情与情绪传递、人像主力景别 |
| 特写 | 面部/局部细节 | 放大眼神、微表情、视觉焦点 |
| 大特写 | 眼/唇等极局部 | 强烈情绪、心理冲击、"微"细节 |

**套图景别节奏**：远→全→中→近→特递进，避免同景别连续堆砌；用"插入镜头"（道具/手/光影特写）衔接。

## 三、机位（视角）

| 机位 | 情绪含义 |
|------|---------|
| 仰视 | 高大、强势、压迫、向往 |
| 平视·正平 | 人文纪实、平等、亲切 |
| 平视·稍高15° | 甜美、弱势、显脸小 |
| 平视·稍低15° | 高大、强势、气场 |
| 俯视 | 渺小、弱势、掌控；拍躺姿/地面构图 |
| 背面机位 | 隐匿身份、迷茫、留想象空间 |
| 第一人称/主观 | 代入、沉浸 |
| 过肩（OTS） | 关系、互动（多人场景） |

**视高选择原则**：拍人根据五官选视角，保证三庭五眼比例；拍物拍第三方感受（如裙摆代表风）。人像常用略高机位显脸小、低机位拉长腿部线条。

## 四、构图法

| 构图法 | 要点 / 情绪 |
|--------|------------|
| 框架构图 | 突出主体、增加层次、偷窥感、困境束缚 |
| 画框嵌套 | 凸显、强调 |
| 三分法（九宫格） | 通用，主体/眼睛落交叉点 |
| 对称 | 和谐、平衡、稳定；建筑/倒影/心境平和 |
| 引导线 | 道路/河流/目光引导视线汇聚焦点 |
| 前景构图 | 前景虚化、立体感、层次感 |
| 中心构图 | 主体居中、明确突出 |
| 黄金分割/螺旋 | 主体落黄金分割点/收束点 |
| 角色占空间比重 | 大→强势，小→弱势 |
| 疏密留白 | 节奏（少而美）、呼吸感 |
| 前后遮挡/虚实 | 空间层次 |
| 背影构图 | 留想象空间、孤独、故事感 |

**三步构图法**：①主体位置（疏密、留白）→ ②建筑光影线条（引导线、框架线引向主体、分割画面）→ ③空间层次（前后遮挡、虚实、明暗）。

## 五、人像构图专项〔补全〕

- **视线留白**：人物视线方向留更多空间，忌眼神顶边。
- **头部空间**：头顶留适当呼吸空间，忌顶天或过度留白。
- **眼睛落点**：眼睛落上三分线（约画面上方 1/3）最自然。
- **单人位置**：居中（明确）或三分点（呼吸/故事）；环境人像人物偏一侧，留白在视线方向。
- **多人构图**：建立主次焦点（1 个主视觉），用前后错落与身体朝向建立关系线。
- **前景虚化**：用枝叶/窗框/纱作前景，制造"气"与偷窥感。

## 六、空间层次与视觉焦点

- **空间感**：调整机位露出更多面（广角、拉远、俯仰），增加前中后景。
- **视觉焦点**：运动物体、眼神横线；追求顺畅/跳跃/酷炫/节奏。人像确保**单一焦点**（通常眼睛）。
- **纵深**：前景（虚化）+ 中景（主体）+ 背景（环境/光影），营造「间」与「气」。

## 七、构图避坑

- 主体与背景贴死、无留白无呼吸。
- 一图多个同等权重焦点（违反「秘」）。
- 水平线倾斜（除非刻意动感）、切关节（肘/膝处裁切）。
- 机械居中的"证件照式"呆板构图。
- 前景遮挡主体面部或视觉焦点。
