## 双重审美校验清单（Step 6 交付前逐条确认）

### A. 审美哲学质量（aesthetic-checklist.md）
- [ ] 康德四契机：非功利/非概念/无目的合目的/共同感
- [ ] 美感非纯快感：不止于"养眼/糖水片"，有养心或养神纵深
- [ ] 反套路：无网红脸/炫示性消费/审美疲劳
- [ ] 审美形态定位明确，全部参数与之同向
- [ ] 意境类：情景交融 + 虚实相生 + 境生象外
- [ ] 创作深度：三层递进达标、格式塔同构、审美距离恰当、有通感

### B. 东方形式气质（aesthetics-evan-design.md）
- [ ] 并：整组色调/光向统一，无风格漂移
- [ ] 间：主体留白≥40%，禅意镜≥50%
- [ ] 秘：单张焦点≤1，渐进披露/不完整构图
- [ ] 素：主色饱和≤45%，高饱和≤10%
- [ ] 微：至少1处关键特写承载情绪
- [ ] 气：雾/光晕/景深营造空气感
- [ ] 假：自然光/季节痕迹/自然质感
- [ ] 破：至多1处破格并标注 `ha`，其余守序
- [ ] L2：主体落三分法/黄金分割
- [ ] L3：60-30-10 配色，明度层次清晰
- [ ] 布光：光向统一、光比服务情绪、逆光补面
