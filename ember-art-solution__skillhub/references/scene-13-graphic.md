# 平面美学 · 海报 / 封面 / 版式（H · I）

> 服务 `core-02` 的 H（海报）与 I（封面装帧），并为 J 的首屏、M 的展陈导视提供版式依据。
> 前置：`core-02` §4 平面通用子流程；本文件是它的展开与细化。
> 依据：`core-00` 三大体系的构图与空间逻辑、`core-03` 取色、`core-04` 六法与留白三法、`core-08` 八意识。

---

## 一、版式的三种体系原型（先选原型，再排元素）

| 原型 | 结构 | 留白 | 信息层级 | 适配流派 |
|---|---|---|---|---|
| **偏置气口型**（东方） | 主体偏于一角或一侧，视线沿虚实游走；散点、非对称 | 大留白，计白当黑，留白承担呼吸 | 主信息唯一，其余退到虚处；层级靠位置与疏密而非字号悬殊 | 宋代美学、侘寂、水墨 |
| **饱满边框型**（东方明清 / 伊斯兰） | 中心辐射或多视角满构图；图案「图必有意」；密纹无中心无限延伸 | 极少留白，呼吸在结构层级间 | 层级由边框、纹样密度与对称秩序建立 | 明清、阿拔斯、波斯、摩尔 |
| **网格焦点型**（西方） | 黄金分割 / 斐波那契模数 / 严格网格；焦点透视式的单一视觉中心 | 负空间服务比例与焦点，不是气韵 | 层级按 1 : 0.618 : 0.382 字阶递减，强对比 | 哥特、印象派、构成主义、冷抽象、包豪斯 |

**禁止**：在同一版面里同时用「偏置气口」与「严格对称满构图」而无过渡说明——那是 `core-00` 底层逻辑冲突。

---

## 二、信息层级

```
主信息（唯一主角） → 次信息（0.618） → 辅助信息（0.382） → 落款/技术信息（最小）
```

- **唯一主角**：一张海报只有一个第一眼被读到的东西。多个同级主角是最高频的失败原因。
- 层级不超过 4 级；同级元素字阶、字重、色值完全一致（八意识之「并」）。
- 东方体系可让层级差**更小**（靠位置与留白区分），西方体系层级差**更大**（靠字号与对比）。
- 主文案的字数上限：海报 ≤12 字，封面书名 ≤8 字为佳；长标题必须分行并给出断行依据。

## 三、字体规范

| 项 | 规则 |
|---|---|
| 族数 | 同版面 ≤2 族（衬线＋无衬线，或 中文＋西文） |
| 字阶 | 展示级按 φ=1.618；H2→H3 过渡档 1.30；正文级 1.25；东方体系可加大阶梯间隔以显疏朗 |
| 行距 | ≥ 字高 1.5 倍；**东方留白体系宜 ≥1.8 倍** |
| 字距 | 展示级可收紧，正文保持默认；中文标题可用字距制造「间」 |
| 书法 / 手写体 | 只在东方体系且内容确需人文气时使用；不得与几何无衬线混排作同级 |
| 西文 | 哥特用黑体/衬线，构成主义/包豪斯用无衬线，印象派用手写感但不逾 2 族 |

**字体气质须与体系一致**：宋式的疏朗 ≠ 构成主义的紧凑；明清的富丽 ≠ 侘寂的素。

## 四、栅格与版心

| 体系 | 栅格 |
|---|---|
| 东方 | 偏置版心，可用「一角落款 + 大面积素底」；分割优先于线条（不用可见框线切分） |
| 西方 | 黄金分割版心（主:侧 ≈ 61.8:38.2）、斐波那契间距模数、主视觉落黄金螺旋收束点 |
| 伊斯兰 | 中心辐射或无限网格；图案无起点终点，边框承担叙事 |

**安全与出血**：印刷稿留 3 mm 出血；重要信息距裁切边 ≥ 8 mm；屏幕稿按平台画幅（9:16 / 1:1 / 4:5 / 16:9）分别出规格。

## 五、视觉动线（对应 `core-04` §1.6）

```
主体确定 → 具象引导（路、河、枝、目光、手势） / 抽象引导（色块、光影、透视、线条）
         → 串联次要重点 → 收于落款或留白
```

- 主视觉的「势」应指向主信息，而非把视线导出画面。
- 东方体系允许动线回环（游观），西方体系动线应闭合于唯一焦点。
- 检查法：把图缩到 200px，第一眼落点是否仍是主信息？

## 六、色与质感

- 取色按 `core-03`：60-30-10，高饱和 ≤10%，点睛色 ≤1 处（八意识之「破」）。
- **色彩留白**：减色相、降饱和、素色托主体；**光影留白**：光不平均、以暗托明、以雾遮形。
- 质感每案 ≤2 类，按体系选：
  - 东方：宣纸／绢／粗陶／粉墙／木纹／水墨晕染
  - 西方：铜版／金属／玻璃／网点印刷／高光相纸
  - 伊斯兰：琉璃砖／Zellige 马赛克／石膏雕花／金箔／书法墨
- 印刷工艺建议必须写清：烫印、压凹、专色、裸脊、模切、UV、过油；**工艺要为体系服务**（侘寂宜压凹与素纸，明清/波斯宜烫金与专色）。

## 七、封面 / 装帧专项（I 类）

| 部位 | 要点 |
|---|---|
| 封面 | 书名、作者、副题、主视觉；缩略图可识别；留白或满地纹按体系二选一 |
| 书脊 | 书架上连续可辨；系列书脊拼合后可组成完整纹样（伊斯兰无限纹样 / 明清吉祥纹尤其适合） |
| 封底 | 文案、条码、定价；信息层级最弱，不抢封面 |
| 勒口 | 作者简介与推荐语；可放一处「秘」（渐进披露的小细节） |
| 开本与版心 | 开本比例与版心留白联动；东方体系版心可偏上或偏侧，留「地脚」气口 |
| 环衬 / 内文 | 环衬纸色与封面素底同源；内文字阶、行距、页眉页脚延续同一套秩序 |
| 系列延展 | 共享栅格、字阶、色板、书脊规则；每册只换主视觉与一处点睛色 |

**缩略图测试**：电商 200px 宽度下，书名与主视觉仍须可读可辨；否则减元素，不靠加字号硬救。

## 八、海报专项（H 类）

| 类型 | 规格要点 |
|---|---|
| 商业 / 活动海报 | 主信息 3 米可读；时间地点层级明确；二维码/落款置于动线终点 |
| 电影 / 展览海报 | 主视觉取自分镜的「决定性一帧」；色调与全片/全展同源；可留一处「秘」不作解释 |
| 公益 / 文化海报 | 立意优先，避免炫示；用一个象征物贯穿，禁堆符号 |
| 系列海报 | 「并」：各张独立成立，共享栅格与字阶；整套只允许 1 处「破」 |

## 九、执行清单（P6 → P7）

1. 选版式原型并说明理由（与 `core-00` 体系一致）。
2. 信息层级 ≤4 级、唯一主角、字阶按体系定。
3. 字体 ≤2 族，行距达标，族气质与体系一致。
4. 栅格/版心与体系一致，出血与安全边距写清。
5. 视觉动线串联次要重点，200px 缩略图测试通过。
6. 色板 60-30-10，色名 + HEX + 色库来源，高饱和 ≤10%。
7. 留白三法 ≥2（若体系适用）；破格 ≤1 处且目的明确。
8. 质感 ≤2 类，工艺建议具体。
9. 3 米可读 / 30 cm 有细节 / 200px 可识别，三档全过。
10. 对比度达标（正文 ≥4.5:1，大字 ≥3:1），状态不只靠颜色。
11. `core-04` 六法命中 ≥3；八意识联检通过。
12. `core-10` 三重校验通过。

## 十、反模式

1. **留白当万能高级公式**：给明清、波斯、摩尔主题套大留白，违反底层逻辑。
2. **多主角**：主标题、副标题、主视觉、LOGO 四者争第一眼。
3. **字体超市**：三族以上、字重混乱、书法体与几何无衬线同级混排。
4. **符号拼盘**：青花 + 枯山水 + 彩窗 + 蒙德里安网格，无主次与接缝。
5. **点睛色泛滥**：朱砂、烫金、高饱和到处点，破格失控。
6. **忽略缩略图与印刷**：屏幕好看、印出来偏色，电商小图完全糊掉。
