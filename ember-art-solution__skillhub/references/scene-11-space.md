# 空间美学 · 室内 / 园林 / 造景（K · L · M）

> 服务 `core-02` 的 K（室内）、L（园林庭院）、M（造景陈设展陈）三类交付。
> 知识来源：`core-00` 东方/伊斯兰空间逻辑、《知中 1·山水》《知日 42·枯山水》《禅与极简生活艺术》《设计与死》（`core-05`）、《其他参考.md》留白要义，以及**联网补全**的《园冶》造景八法与中式五感营造资料。
> **核心命题**：空间美学不是摆放物件，而是**经营视线、时间与呼吸**。实体谦逊后退，把主场交还给空、光、风与观者的想象。

---

## 一、总纲：空间的四条底层原则

1. **先定空间逻辑，再定形制**：东方＝散点游动、移步换景、留白气口；伊斯兰＝内向庭院、无限几何、格栅切光；西方＝轴线、焦点透视、比例模数。**不要先挑家具/材料**。
2. **实体退让**：「美不在繁复，而在留白；不在奢华，而在意境；不在占有，而在欣赏」。大面积虚白不是贫乏，是容纳万象的容器。
3. **时间是材料**：日影游移、四时流转、材质老化（包浆、青苔、褪色）都是设计内容，不是损耗。
4. **五感协同**：视觉／触觉／听觉／嗅觉／空间节奏共同构成体验；只做视觉的空间没有「气」。

## 二、造景八法（L · M 核心工具箱）

来源：《园冶》「园林巧于因借」及联网补全的古典园林构景手段。**一个方案至少用到 3 法，其中必含 1 个「藏/漏/障」类含蓄手法**。

| 法 | 定义 | 操作要点 | 现代转译 |
|---|---|---|---|
| **借景** | 「夫借景，林园之最要者也」，收无限于有限 | 远借山塔、邻借花木、仰借流云飞鸟、俯借池中倒影、应时而借春花秋月朝暮霞光 | 梳理场地外部视线，借用原有大树、远山、城市天际线，不额外堆造 |
| **框景** | 「嘉则收之」，以门洞、窗框、廊柱、枝干为画框 | 框住的应是四季可变之景；脚步移动时画中景物随之变化 | 景墙镂空、入口门洞、乔木围合的天然框，在转折处制造惊喜 |
| **漏景** | 由框景发展，若隐若现、半藏半露 | 漏窗、漏墙、疏林枝桠、山石间隙；兼顾静态定点与移动视点 | 半透格栅、穿孔板、疏植，制造含蓄与好奇 |
| **夹景** | 两侧屏障夹出狭长视觉通道 | 屏蔽杂乱次要景物，把视线定向引向远端主景 | 林荫步道、高绿篱夹道；狭长地块强化纵深 |
| **对景** | 甲乙两处互为观赏对象，双向对话 | 讲究视线对位、高低呼应；与框景的「单向一幅画」不同 | 湖面两端构筑物、步道尽头置石与对面廊架 |
| **障景 / 抑景** | 「先挡后放」，欲扬先抑 | 入园先以假山、密林、景墙挡视线，绕过之后豁然开朗；一收一放拉满层次 | 入口玄关、植物组团、景墙，避免一览无余 |
| **添景** | 远景单薄时补近中景过渡 | 乔木、置石、建筑小品；形成前中后景三层 | 前景树、置石、低位照明 |
| **藏景** | 园中园，藏在僻静处 | 含蓄，目的是为了更好地显露 | 隐藏的茶室、下沉庭院、转角小景 |

**配套**：
- **叠山理水**：太湖石品评「瘦、皱、漏、透」；山水相依、刚柔并济；「虽由人作，宛自天开」。
- **曲径通幽 / 移步换景**：以廊、墙、门窗分割串联空间，让人在行进中不断发现新景致。
- **小中见大**：借景 + 障景 + 层次是三大杠杆，与面积无关。

> **体系分派**：中式明清园林 → 八法全用、饱满繁复、移步换景；日式枯山水 → 借景/框景 + 极简非对称 + 大面积砂纹留白；伊斯兰庭院（Riad）→ 内向封闭 + 水景 + 格栅切光 + 密纹铺装（**不用中式留白**）。

## 三、空间序列：起承转合与收放节奏

```
抑（狭窄/幽闭/遮挡） → 转（廊、折、漏） → 扬（豁然开朗/主景） → 留（可停留的空处） → 余（回望/余韵）
```

- **收如敛气凝神，放似云开见月**；轴线隐而不发，气息流动不止。
- 每个停留点应有：一个可看的景、一个可听的声、一个可触的材质、一个可坐/可倚的尺度。
- 东方空间不追求严苛对称，讲体块之间的「揖让与顾盼」。
- 动线不折返、不一览无余；出口不必早早暴露（秘）。

## 四、光：空间里最谦逊的设计师

| 原则 | 操作 |
|---|---|
| **惜光如金** | 拒绝满室无差别通明；明度整体压低，让影子有领域去生长 |
| **光不均匀** | 以暗托明、以雾遮形；让日影从格栅与窗洞筛落，随时间游移 |
| **时间性** | 清晨层层晕染、正午斑驳、黄昏斜照、夜间 2700K 温润；四季角度不同 |
| **媒介** | 木格栅、竹帘、半透宣纸、青砖、智能调光玻璃（通电通透、断电朦胧，合「虚实相生」） |
| **体系差异** | 东方＝意象光/阴翳层次；伊斯兰＝格栅（Mashrabiya）切割光线造「神圣之光」与幽玄；西方＝塑造体积与明暗交界 |

> 光痕是片刻即逝的，比恒定的造型更触动人——它教人欣赏无常。

## 五、材质与触觉（素 / 假 / 微）

| 要领 | 说明 |
|---|---|
| 保住「会呼吸的毛孔」 | 原木不覆厚漆、保留结疤；手工纸透纤维；石头带未经驯化的棱角 |
| 温、润、韧、朴 | 榫卯凹凸的微起伏、老木包浆的柔润微凉、夯土粗粝、麻绳纤维张力、青砖微涩 |
| 拒绝过度抛光 | 封闭涂层会杀死材质的本真与时间性 |
| 允许变旧 | 青苔缓慢侵占、包浆累积，是「假」（对自然的绝对信赖） |
| 动线节点配置 | 玄关台面、扶手末端、坐具边缘是触觉交互关键位 |
| 体系选材 | 东方：竹木石麻纸陶／伊斯兰：琉璃砖、Zellige 马赛克、石膏雕花、金属／西方：石材、玻璃、钢、抛光面 |

**材质数量**：同一空间主材质 ≤3 类，避免「符号超市」。

## 六、声景与嗅觉（K · L · M 的「气」）

| 层 | 内容 |
|---|---|
| 收纳自然声 | 雨打檐下石缸、风拂竹帘、炉火烹茶如松涛、水滴落砚池、檐角铜铃 |
| 以稀声反衬寂静 | 声音不具侵略性，反而为寂静划出更分明的轮廓与深度；**每案至少 1 处静默段** |
| 声源分层 | 近处细响 / 中景水声 / 远处风或钟，形成远近层次 |
| 气味走廊 | 檀香、沉香挥发曲线缓慢，随通风在廊道、庭院、厅堂间形成可感知的路径 |
| 共振 | 香气渐浓时一声铜铃轻响，如古琴泛音，激活听觉记忆 |
| 四季 | 春日泥香、夏夜凉风、秋月清辉、冬雪折竹声，都是可感的「饰面」 |

> 真正的静谧绝非死寂，而是足以容纳所有细微声响的广阔背景。

## 八、三类交付的规格与执行顺序

### K · 室内设计

```
1 一句话立意（境界目标） → 2 体系与空间逻辑 → 3 平面动线与收放序列
→ 4 分区与停留点 → 5 材质表（≤3 类） → 6 光方案（自然光时变 + 人工光层次）
→ 7 声景与气味 → 8 陈设清单（每件说得出「为什么在这」） → 9 四时变化 → 10 落地约束
```
**验收**：动线有抑扬；实体退让给「空」；光不均匀；有声景与静默；材质本真；人体工学尺度达标。

### L · 园林 / 庭院

```
1 立意与场地外部视线梳理 → 2 游观动线（起承转合） → 3 选 ≥3 个造景法并标位置
→ 4 叠山理水 → 5 植物与四时 → 6 铺装与纹样 → 7 亭榭点位 → 8 视线经营图 → 9 夜景光
```
**验收**：不一览无余；有「小中见大」；借景有明确对象；四时皆有可看之处；体系逻辑一致（枯山水 vs 明清 vs Riad 不混）。

### M · 造景 / 陈设 / 展陈 / 装置

```
1 主题与叙事线 → 2 主视点/次视点/拍点位 → 3 前中后景层次（core-04 §1.5）
→ 4 材料与质感 → 5 光影与时间 → 6 视线引导（core-04 §1.6） → 7 可拍性与出片位
→ 8 安全与动线
```
**验收**：至少一处框景/借景；有唯一单焦点；留白处可容纳人；不堆砌符号；`core-04` 六法命中 ≥3。

## 九、反模式

1. **符号堆砌**：雕花窗棂 + 红木 + 水墨挂画 = 「中式」，却仍用均质照明、对称满摆、无气口。
2. **把留白当空房**：只搬空家具，没给光、声、想象留位置。
3. **时间被抹掉**：全部做新、全部恒定照度、禁止老化。
4. **声景 = 循环 BGM**：全程铺满，寂静被消灭。
5. **体系混搭无接缝**：枯山水 + 彩窗 + 月亮门同院，且无主次说明。
6. **只考虑镜头不考虑身体**：出片好看但尺度不适、动线折返、无处可停留。
